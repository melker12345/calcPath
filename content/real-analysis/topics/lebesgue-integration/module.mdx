# Lebesgue Integration

Measure-theoretic integration, convergence theorems, and the dominated convergence theorem.

The Lebesgue integral is a generalization of the Riemann integral that integrates over a much larger class of functions (including all Riemann integrable functions) and has far superior convergence properties (monotone convergence, dominated convergence, Fatou's lemma).

It is the integral used in modern analysis, probability theory (expectation), and functional analysis (L^p spaces).

## Measure and Measurable Functions (Brief)

<!-- section: measure-measurable -->

Lebesgue measure on ℝ^n assigns to intervals their usual volume and extends by countable additivity to a large class of sets (measurable sets). A set has measure zero if it can be covered by intervals of arbitrarily small total volume (e.g. countable sets, the Cantor set, rationals).

A function f is measurable if the sets {x | f(x) > a} are measurable for all a (or equivalent conditions). The intuition: Lebesgue integration works by slicing the *range* into horizontal bands and asking "how big is the set of inputs landing above height a?" — so a function is admissible precisely when every such "above height a" set has a well-defined size. All continuous functions, all monotone functions, and (crucially) pointwise limits of measurable functions are measurable; this closure under limits is what makes the convergence theorems possible.

**ELI5**

- Lebesgue measure is "length/area/volume" made rigorous so that it works for very wild sets (as long as they are not too pathological).
- Measurable functions are those for which we can sensibly talk about "the set where the function is above a certain height" having a well-defined size.

**Worked Example:**

Show the Dirichlet function $D(x) = 1$ for $x \in \mathbb{Q}$, $D(x) = 0$ otherwise, is measurable on $\mathbb{R}$.

- Step 1: To check measurability we test the super-level sets $\{x \mid D(x) > a\}$ for every real $a$.
- Step 2: If $a \geq 1$, then $D(x) > a$ is impossible, so the set is $\emptyset$, which is measurable.
- Step 3: If $0 \leq a < 1$, then $D(x) > a$ exactly where $D(x) = 1$, i.e. the set is $\mathbb{Q}$, which is measurable (it is countable, hence a countable union of the measurable singletons $\{q\}$).
- Step 4: If $a < 0$, then $D(x) > a$ everywhere, so the set is $\mathbb{R}$, which is measurable.
- Step 5: Every super-level set is measurable, so $D$ is measurable.
- Sanity check: $\mathbb{Q}$ is countable, so $m(\mathbb{Q}) = 0$; thus $D = 0$ except on a null set. It is *not* Riemann integrable, because it is discontinuous at every point, so its discontinuity set has measure $1 > 0$ on $[0,1]$, violating Lebesgue's criterion. Measurability is a much weaker demand than Riemann integrability.

## Simple Functions and the Integral Definition

<!-- section: simple-functions-definition -->

A simple function is a finite linear combination of characteristic functions of measurable sets: $\varphi = \sum c_k \chi_{E_k}$.

For nonnegative simple $\varphi$ the integral is defined as $\sum c_k\, m(E_k)$ ($m$ = Lebesgue measure), with the convention $0 \cdot \infty = 0$.

For a general nonnegative measurable f the integral is the sup of integrals of simple functions 0 ≤ φ ≤ f.

For signed f one splits into positive and negative parts (provided at least one has finite integral).

**ELI5**

- First integrate the simplest possible functions: constants on measurable "bricks". The integral is height times measure of the brick.
- For a general nonnegative function, approximate it from below by simple functions (like a histogram that gets finer); the integral is the least upper bound of the areas of those approximations.

**Worked Example (simple function on disjoint bricks):**

Integrate the simple function $\varphi = 2\,\chi_{[0,1)} + 5\,\chi_{[1,3)} + 0 \cdot \chi_{[3,\infty)}$ over $\mathbb{R}$.

- Step 1: Read off the constant heights and their level sets: $c_1 = 2$ on $E_1 = [0,1)$, $c_2 = 5$ on $E_2 = [1,3)$, $c_3 = 0$ elsewhere.
- Step 2: Measure each brick: $m(E_1) = 1 - 0 = 1$, $m(E_2) = 3 - 1 = 2$.
- Step 3: Apply $\int \varphi = \sum_k c_k\, m(E_k) = 2 \cdot 1 + 5 \cdot 2 + 0 = 2 + 10 = 12$.
- Sanity check: $\varphi$ is an ordinary step function here, so its Riemann integral is the sum of rectangle areas $2\cdot 1 + 5 \cdot 2 = 12$ — the two integrals agree, as they must for a step function.

**Worked Example (a genuinely non-Riemann case):**

The characteristic function of the rationals in $[0,1]$ is simple: $1 \cdot \chi_{\mathbb{Q} \cap [0,1]} + 0 \cdot \chi_{\text{irrationals} \cap [0,1]}$. Its integral is $1 \cdot m(\mathbb{Q} \cap [0,1]) + 0 = 0$, because $\mathbb{Q}\cap[0,1]$ is countable, hence $m(\mathbb{Q} \cap [0,1]) = 0$. Here the convention $0 \cdot \infty = 0$ is not even needed; the point is that Lebesgue's "height times measure" recipe handles a set with no length at all.

## Comparison with Riemann Integral; When They Agree

<!-- section: comparison-riemann-agree -->

If f is Riemann integrable on [a,b] then it is Lebesgue integrable and the two integrals coincide.

The converse is false: the Dirichlet function is Lebesgue integrable (integral 0) but not Riemann integrable.

A bounded function on [a,b] is Riemann integrable if and only if its set of discontinuities has Lebesgue measure zero (Lebesgue's criterion).

**ELI5**

- Every "nice" function you integrated with Riemann sums in calculus is also Lebesgue integrable and gives the same number.
- Lebesgue can handle functions that jump on dense sets (as long as the jumps are on a set of measure zero) because it doesn't care about values on measure-zero sets.

**Worked Example (the two functions side by side):**

Compare Thomae's function and the Dirichlet function on $[0,1]$; both equal $0$ almost everywhere, but only one is Riemann integrable.

- Step 1: Thomae's function is $T(x) = 1/q$ if $x = p/q$ in lowest terms with $q > 0$, and $T(x) = 0$ if $x$ is irrational. It is continuous at every irrational and discontinuous at every rational.
- Step 2: The discontinuity set of $T$ is $\mathbb{Q} \cap [0,1]$, which is countable and therefore has measure zero. By Lebesgue's criterion (bounded $+$ discontinuities of measure zero), $T$ is Riemann integrable.
- Step 3: Its Riemann integral is $0$: for any $\varepsilon > 0$ only finitely many points have $T(x) \geq \varepsilon$, so the upper sums can be made arbitrarily small while the lower sums are $0$. Hence the Lebesgue integral also equals $0$.
- Step 4: The Dirichlet function $D$ is discontinuous *everywhere*, so its discontinuity set is all of $[0,1]$, of measure $1$. Lebesgue's criterion fails, so $D$ is not Riemann integrable.
- Step 5: But $D = 0$ almost everywhere, so its Lebesgue integral is $0$.
- Sanity check: both functions equal $0$ a.e. and have Lebesgue integral $0$; the discriminator is the *size of the discontinuity set* ($0$ for $T$, $1$ for $D$), which is exactly what Riemann integrability sees and the Lebesgue integral ignores.

## Convergence Theorems (Monotone, Dominated, Fatou)

<!-- section: convergence-theorems -->

- Monotone convergence: if $0 \leq f_n \uparrow f$ pointwise (measurable), then $\int f_n \uparrow \int f$ (possibly $\infty$).
- Fatou's lemma: $\int \liminf f_n \leq \liminf \int f_n$ (for nonnegative measurable).
- Dominated convergence: if $f_n \to f$ pointwise and $|f_n| \leq g$ integrable, then $\int f_n \to \int f$ and $f$ integrable.

These are the reasons Lebesgue theory is vastly superior for passing limits inside integrals.

**ELI5**

- Monotone: if you increase the function pointwise the areas can only increase, and in the limit you get the area of the limit function (no "mass escapes to infinity").
- Fatou: think of it as an "anti-cheating" rule — you can lose area in the limit (mass can leak away), but you can never *gain* area out of nowhere. So the area of the limit is at most the smallest area the sequence settles toward: $\int \liminf f_n \leq \liminf \int f_n$.
- Dominated: if everything is squeezed under an integrable "umbrella" g, then you can pass the limit inside; the domination prevents the areas from oscillating or escaping.

**Worked Example (DCT succeeds):**

Compute $\lim_{n \to \infty} \int_0^\infty \dfrac{e^{-x}}{1 + n\,x^2}\,dx$.

- Step 1: Identify the pointwise limit. For each fixed $x > 0$, $\dfrac{e^{-x}}{1 + n x^2} \to 0$ as $n \to \infty$ (the denominator blows up); at $x = 0$ the value is $e^{0} = 1$ for every $n$, but $\{0\}$ has measure zero, so the pointwise limit a.e. is $f(x) = 0$.
- Step 2: Find a dominator independent of $n$. Since $1 + n x^2 \geq 1$, we have $\dfrac{e^{-x}}{1 + n x^2} \leq e^{-x} =: g(x)$ for all $n \geq 1$ and all $x \geq 0$.
- Step 3: Check $g$ is integrable: $\int_0^\infty e^{-x}\,dx = [-e^{-x}]_0^\infty = 0 - (-1) = 1 < \infty$. Good.
- Step 4: DCT applies, so $\lim_n \int_0^\infty \dfrac{e^{-x}}{1 + n x^2}\,dx = \int_0^\infty 0\,dx = 0$.
- Sanity check: each integrand is squeezed between $0$ and the fixed integrable umbrella $e^{-x}$, and it collapses to $0$ pointwise, so the areas must collapse to $0$ too. The answer is $0$.

**Worked Example (limit and integral do NOT commute):**

Consider $f_n = \chi_{[n,\,n+1]}$ on $\mathbb{R}$ with Lebesgue measure.

- Step 1: Pointwise limit. Fix $x$; for all $n > x$ we have $x \notin [n, n+1]$, so $f_n(x) = 0$ eventually. Hence $f_n \to 0$ pointwise everywhere.
- Step 2: Integrals. $\int f_n = m([n,n+1]) = 1$ for every $n$, so $\lim_n \int f_n = 1$.
- Step 3: Compare with the integral of the limit: $\int \lim_n f_n = \int 0 = 0 \neq 1$.
- Step 4: Why DCT does not save us: any $g$ with $g \geq f_n$ for all $n$ must satisfy $g \geq 1$ on each of the disjoint unit intervals $[n, n+1]$, so $\int g \geq \sum_{n} 1 = \infty$. No integrable dominator exists — the "mass" of size $1$ marches off to $+\infty$.

## Common Mistakes

- **Thinking Lebesgue integral is always 'harder' to compute**: For most explicit functions the value is the same as Riemann; the advantage is theoretical (theorems) and for wilder functions.
- **Forgetting that the domination or monotonicity hypotheses are necessary**: Without them limits and integrals may not commute (escaping mass, oscillation).
- **Confusing 'almost everywhere' with 'everywhere'**: Functions are identified if they differ on a set of measure zero; derivatives and integrals recover the function only a.e.
- **Believing every derivative is Lebesgue integrable**: There exist functions differentiable everywhere with non-Lebesgue-integrable derivative on [a,b]; the FTC holds in a more subtle way.
- **Mixing Lebesgue measure zero with 'empty' or 'finite'**: The Cantor set has measure zero but is uncountable and perfect; the rationals are countable hence measure zero.

The dominated convergence theorem (DCT) is one of the most powerful and frequently invoked results in Lebesgue integration theory. It justifies passing limits inside integrals under a domination hypothesis that is often easy to check in practice.

It is the reason we can differentiate under the integral sign, interchange limits and expectations in probability, and prove many approximation and convergence results in analysis.

## Statement of the Theorem

<!-- section: statement-dct -->

Let $(X, \mu)$ be a measure space (e.g. $\mathbb{R}$ with Lebesgue measure). Let $f_n$ be a sequence of measurable functions such that $f_n(x) \to f(x)$ for almost every $x$, and suppose there exists an integrable function $g$ ($\int |g|\,d\mu < \infty$) such that $|f_n(x)| \leq g(x)$ for almost every $x$ and all $n$.

Then $f$ is integrable and $\int f_n\,d\mu \to \int f\,d\mu$.

Moreover, $\int |f_n - f|\,d\mu \to 0$ (convergence in $L^1$).

**ELI5**

- If the functions are all dominated in absolute value by a single integrable "umbrella" g, and they converge pointwise a.e., then their integrals converge to the integral of the limit, and the areas of the differences go to zero.
- The domination prevents the "mass" from escaping to infinity or oscillating too wildly.

**Worked Example (hypotheses must be checked — a "tall spike"):**

On $\mathbb{R}$ with Lebesgue measure, let $f_n(x) = n\,\chi_{(0,\,1/n)}(x)$ (height $n$ on the shrinking interval $(0, 1/n)$, zero elsewhere).

- Step 1: Pointwise limit. Fix $x$. If $x \leq 0$, then $f_n(x) = 0$ for all $n$. If $x > 0$, then once $n > 1/x$ we have $x \geq 1/n$, so $x \notin (0, 1/n)$ and $f_n(x) = 0$. Thus $f_n \to 0$ pointwise everywhere (no exceptional point at all here).
- Step 2: Integrals. $\int f_n = n \cdot m\big((0, 1/n)\big) = n \cdot \tfrac{1}{n} = 1$ for every $n$, so $\lim_n \int f_n = 1$.
- Step 3: Integral of the limit: $\int \lim_n f_n = \int 0 = 0 \neq 1$.
- Step 4: Locate the missing hypothesis. The candidate envelope $\sup_n f_n$ satisfies $\sup_n f_n(x) = \lfloor 1/x \rfloor$-order growth near $0$; concretely any dominating $g$ must obey $g(x) \geq f_n(x) = n$ on $(0, 1/n)$, forcing $g(x) \geq 1/x$ for small $x > 0$. But $\int_0^1 \tfrac{1}{x}\,dx = \infty$, so no *integrable* dominator $g$ exists. DCT simply does not apply — its conclusion genuinely fails.
- Sanity check: the "mass" here is $1$ for every $n$ but is concentrated on an ever-thinner spike, so it never disperses to the limit function $0$. This is the escaping-mass phenomenon in vertical form, complementing the $\chi_{[n,n+1]}$ horizontal version.

## Proof Sketch (Using Fatou and Monotone Convergence)

<!-- section: proof-sketch-fatou-monotone -->

Apply Fatou's lemma to the nonnegative functions $g + f_n$ and $g - f_n$ (or $|g| + f_n$ etc.).

Since $|f_n| \leq g$ a.e., we have $g \pm f_n \geq g - |f_n| \geq 0$ a.e. for *every* $n$, so both sequences $(g + f_n)$ and $(g - f_n)$ are nonnegative and measurable — exactly the setting Fatou's lemma requires. (Here $g$ must be integrable and $f$ is integrable too, since $|f| \leq g$ a.e. by taking the limit of $|f_n| \leq g$.)

Fatou gives $\int (g + f) \leq \liminf \int (g + f_n) = \int g + \liminf \int f_n$, which rearranges to $\int f \leq \liminf \int f_n$.

Applying the same to $g - f_n$ yields the reverse inequality $\limsup \int f_n \leq \int f$.

Hence the limit exists and equals $\int f$.

For $L^1$ convergence one applies the same argument to $|f_n - f|$ (dominated by $2g$).

**ELI5**

- By adding and subtracting the dominator $g$ you turn the signed $f_n$ into nonnegative sequences to which Fatou applies.
- The resulting inequalities squeeze liminf and limsup of the integrals to be equal to the integral of the limit.

**Worked Example (running the squeeze on a concrete integral):**

Show $\displaystyle \lim_{n \to \infty} \int_0^\infty \frac{e^{-x} \sin(n x)}{n}\,dx = 0$ by imitating the DCT proof machinery.

- Step 1: Set $f_n(x) = \dfrac{e^{-x}\sin(n x)}{n}$ and $g(x) = e^{-x}$. Since $|\sin(n x)| \leq 1$ and $n \geq 1$, we get $|f_n(x)| = \dfrac{e^{-x}\,|\sin(nx)|}{n} \leq e^{-x} = g(x)$ for all $x \geq 0$.
- Step 2: $g$ is integrable: $\int_0^\infty e^{-x}\,dx = 1 < \infty$.
- Step 3: Pointwise, $|f_n(x)| \leq e^{-x}/n \to 0$, so $f_n \to 0$ a.e. (in fact everywhere).
- Step 4: Now the Fatou argument at the heart of DCT: $g + f_n \geq 0$ and $g - f_n \geq 0$ because $|f_n| \leq g$. Fatou on $g + f_n$ gives $\int g + \int 0 \leq \liminf \int (g + f_n) = \int g + \liminf \int f_n$, so $0 \leq \liminf \int f_n$. Fatou on $g - f_n$ gives, after the same rearrangement, $\limsup \int f_n \leq 0$.
- Step 5: Combining, $0 \leq \liminf \int f_n \leq \limsup \int f_n \leq 0$, so $\lim_n \int f_n = 0$.
- Sanity check: the amplitude of the oscillating integrand is $e^{-x}/n$, which is uniformly killed by the $1/n$ factor under the fixed umbrella $e^{-x}$; the areas are forced to $0$. Answer: $0$.

## Differentiation under the Integral Sign (Parametrized Integrals)

<!-- section: differentiation-under-integral -->

A typical application: consider $I(\alpha) = \int_a^b f(x,\alpha)\,dx$. Under suitable domination on the partial derivative $\partial f/\partial \alpha$ one may differentiate under the integral: $I'(\alpha) = \int \frac{\partial f}{\partial \alpha}(x,\alpha)\,dx$.

The domination hypothesis of DCT (applied to difference quotients) justifies the passage to the limit that defines the derivative.

**ELI5**

- If you have a family of functions parametrized by α, and the rate of change with respect to α is controlled by an integrable function independent of α (in a neighborhood), then you can compute the derivative of the total integral by integrating the partial derivative.
- This is the rigorous justification for many calculations in physics and probability (e.g. differentiating moment generating functions).

**Worked Example (differentiate under the sign and verify both ways):**

Let $\displaystyle I(\alpha) = \int_0^1 e^{\alpha x}\,dx$ and compute $I'(\alpha)$ at a fixed $\alpha_0$.

- Step 1: Justify the interchange. The integrand is $f(x, \alpha) = e^{\alpha x}$, with $\dfrac{\partial f}{\partial \alpha} = x\, e^{\alpha x}$. Restrict $\alpha$ to a bounded neighborhood $|\alpha| \leq M$. Then for $x \in [0,1]$ we have $\big|x\, e^{\alpha x}\big| \leq 1 \cdot e^{M} = e^{M} =: g(x)$, and $g$ is integrable on $[0,1]$ since $\int_0^1 e^{M}\,dx = e^{M} < \infty$. The dominator is independent of $\alpha$, so DCT applied to the difference quotients licenses differentiating under the integral.
- Step 2: Differentiate under the sign: $I'(\alpha) = \displaystyle\int_0^1 \frac{\partial}{\partial \alpha} e^{\alpha x}\,dx = \int_0^1 x\, e^{\alpha x}\,dx$.
- Step 3: Evaluate that integral by parts with $u = x$, $dv = e^{\alpha x}\,dx$ (assume $\alpha \neq 0$): $\int_0^1 x\, e^{\alpha x}\,dx = \Big[\tfrac{x}{\alpha}e^{\alpha x}\Big]_0^1 - \int_0^1 \tfrac{1}{\alpha}e^{\alpha x}\,dx = \tfrac{e^{\alpha}}{\alpha} - \tfrac{1}{\alpha}\cdot\tfrac{e^{\alpha}-1}{\alpha} = \tfrac{e^{\alpha}}{\alpha} - \tfrac{e^{\alpha}-1}{\alpha^2}$.
- Step 4: Cross-check against the closed form. For $\alpha \neq 0$, $I(\alpha) = \dfrac{e^{\alpha}-1}{\alpha}$. By the quotient rule, $I'(\alpha) = \dfrac{\alpha\, e^{\alpha} - (e^{\alpha}-1)}{\alpha^2} = \dfrac{e^{\alpha}}{\alpha} - \dfrac{e^{\alpha}-1}{\alpha^2}$.
- Sanity check: the two expressions in Steps 3 and 4 are identical, confirming the interchange was valid. (At $\alpha = 0$ both approaches give $I'(0) = \int_0^1 x\,dx = \tfrac12$, consistent with the limit of the closed form.)

## Relation to Other Convergence Theorems; When DCT Is Not Needed

<!-- section: relation-other-theorems -->

- Monotone convergence requires only monotonicity and nonnegativity; no domination needed (but the limit integral may be infinite).
- Fatou's lemma is a one-sided inequality that often serves as a stepping stone to DCT.
- Bounded convergence theorem is the special case of DCT on a finite-measure space with $|f_n| \leq M$ (constant, which is integrable when measure finite).

When the measure space is finite (e.g. probability space) and the $f_n$ are uniformly bounded, DCT reduces to bounded convergence and is very easy to apply.

**ELI5**

- On a probability space, if your random variables are bounded by a fixed constant (or by an integrable random variable), you can pass limits inside expectations freely.
- Monotone convergence is the tool for increasing sequences without needing an a-priori bound.

**Worked Example (bounded convergence on a finite-measure space):**

On $[0,1]$ with Lebesgue measure, let $f_n(x) = x^n$. Show $\int_0^1 f_n\,dx \to 0$ via bounded convergence, then confirm directly.

- Step 1: Pointwise limit. For $0 \leq x < 1$, $x^n \to 0$; at $x = 1$, $x^n = 1$ for all $n$. So $f_n \to f$ where $f(x) = 0$ on $[0,1)$ and $f(1) = 1$. Since $\{1\}$ has measure zero, $f_n \to 0$ almost everywhere.
- Step 2: Uniform bound. $|f_n(x)| = x^n \leq 1$ for all $x \in [0,1]$ and all $n$, so the constant $M = 1$ dominates. On the finite-measure space $[0,1]$ the constant $1$ is integrable ($\int_0^1 1\,dx = 1 < \infty$), so the bounded convergence theorem applies — no cleverness needed to find $g$.
- Step 3: Conclude $\int_0^1 x^n\,dx \to \int_0^1 0\,dx = 0$.
- Sanity check (direct computation): $\int_0^1 x^n\,dx = \dfrac{1}{n+1} \to 0$ as $n \to \infty$. This matches the bounded-convergence conclusion, confirming the interchange. Note that on the infinite line a constant bound would *not* be integrable, which is exactly why the finite-measure hypothesis matters here.

## Common Mistakes

- **Forgetting to verify the domination hypothesis**: Pointwise convergence alone is not enough (escaping mass counter-examples).
- **Using a dominator that depends on n**: The g must work for all n simultaneously.
- **Applying DCT on an infinite-measure space with a constant bound**: A constant is not integrable over $\mathbb{R}$; one needs decay (e.g. $g(x) = e^{-|x|}$, which has $\int_{\mathbb{R}} e^{-|x|}\,dx = 2$).
- **Confusing almost-everywhere convergence with everywhere**: The theorem only requires a.e. convergence and a.e. domination; values on a null set can be redefined arbitrarily.
- **Thinking DCT implies $L^1$ convergence of $f_n$ to $f$**: It does, under the stated hypotheses ($\int |f_n - f| \to 0$). This is sometimes called "dominated convergence in $L^1$".
