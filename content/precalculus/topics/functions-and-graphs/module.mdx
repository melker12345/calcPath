# Functions & Graphs

Function notation, domain and range, symmetry, inverses, composition, transformations, and piecewise definitions.

## Function (mathematics)

<!-- section: what-is-a-function -->

A function is a fundamental mathematical object that assigns to each input in its domain exactly one output. This precise relationship underpins almost all of precalculus, calculus, and higher mathematics.

### What Is a Function

:::definition[Function]{#function-definition}
A **function** $f$ from a set $A$ (the domain) to a set $B$ (the codomain) is a rule that assigns to every element $x \in A$ exactly one element $f(x) \in B$. We write this as

$$f: A \to B.$$

The "exactly one" condition is essential: no input may produce two different outputs.
:::

Functions can be presented in many forms: an algebraic formula such as $f(x) = 2x + 1$, a table of input-output pairs, a graph in the coordinate plane, or even a verbal description. Only the last two hide the rule; the definition is the same in every case.

:::proposition[Vertical line test]
A curve in the coordinate plane is the graph of a function of $x$ precisely when no vertical line intersects it more than once.
:::

The test is the definition drawn: a vertical line collects all the outputs assigned to one input, so two intersections are two outputs for the same $x$.

:::definition[Equality of functions]
Two functions are equal if they have the same domain and produce the same output for every input in that domain.
:::

:::intuition
Think of a vending machine or a soda fountain button: press "A1" and you always get the same drink. If pressing A1 sometimes gave cola and sometimes orange, it would violate the function rule.

In programming, a pure function is deterministic: same inputs always yield the same output, making it reliable and testable.
:::

:::example[Determining whether a relation is a function from a set of points]
Given the set of ordered pairs: $\{(1,4), (2,4), (3,5), (1,6)\}$.
:::

:::solution
Group by input (first coordinate): input $1$ appears in both $(1,4)$ and $(1,6)$, so it is paired with outputs $4$ and $6$.
Because input $1$ maps to two different outputs, this relation fails the "exactly one output" rule, so it is **not** a function.
If we remove the pair $(1,6)$, the remaining set $\{(1,4), (2,4), (3,5)\}$ is a function: each input ($1, 2, 3$) now appears exactly once.
Sanity check the "shared output" case: inputs $1$ and $2$ both map to $4$. This is fine — a function may send different inputs to the same output; only one input to two outputs is forbidden.
:::

### Common Mistakes

- **Vertical line test misapplied on non-graphs**: The test only applies to graphs in the Cartesian plane; equations or sets of points require checking the definition directly.
- **Forgetting that different inputs may share outputs**: A function can send 1 and 2 both to 5; only the reverse (one input to two outputs) is forbidden.
- **Confusing a function with being one-to-one (injective)**: Not every function is invertible; $f(x)=x^2$ is a function but not one-to-one over all reals.
- **Ignoring the domain when claiming two formulas define the same function**: $f(x)=x/x$ and $g(x)=1$ agree where defined but have different domains.
- **Assuming every relation or equation defines y as a function of x**: Circles, vertical lines, and $x=y^2$ are classic counterexamples.
- **Forgetting that the codomain is part of the definition**: Two functions with same rule but declared different codomains are technically different (though range is what matters for outputs produced).

## Domain of a function

<!-- section: domain -->

The domain tells us exactly where a function is allowed to receive inputs. It is the first thing to determine when analyzing or graphing any function given by a formula.

### Domain of a Function

:::definition[Domain]{#domain-definition}
The **domain** of a function is the complete set of input values for which the function produces a defined output.
:::

When a function is given by a formula, the domain is not announced: it is whatever survives after we exclude the values that cause division by zero, negative numbers under even roots, or other undefined operations.

:::recipe[Reading the domain off a formula]
Start from all real numbers and delete the inputs that break an operation.

1. Denominators cannot be zero: for $f(x) = 1/(x-2)$ the domain is all reals except $x=2$.
2. Even roots require nonnegative radicands: $\sqrt{x+3}$ requires $x \ge -3$.
3. Logarithms require positive arguments: $\log(x)$ requires $x > 0$.

Intersect the surviving conditions, then write the answer in interval notation or set-builder notation.
:::

:::intuition
The domain is the "approved ingredients list" for the function recipe. You cannot feed the function something off the list or the calculation breaks (division by zero, square root of negative, etc.).
:::

:::example[Finding the domain of $f(x) = \\frac{\\sqrt{9 - x^2}}{x - 1}$]
Square root requires the inside $\ge 0$: $9 - x^2 \ge 0 \implies x^2 \le 9 \implies -3 \le x \le 3$.
:::

:::solution
1. Denominator cannot be zero: $x \ne 1$.
2. $x=1$ is already inside the interval from step 1, so we must exclude it explicitly.
3. Combine both requirements: keep $-3 \le x \le 3$ but remove $x=1$. The domain is therefore $[-3, 1) \cup (1, 3]$ (all $x$ with $-3 \le x \le 3$, $x \ne 1$).
4. Sanity check: test $x=1$ (excluded — denominator is $0$) and $x=0$ (included — gives $\frac{\sqrt{9}}{-1} = -3$, defined) ✓.
:::

### Common Mistakes

- **Forgetting to exclude points that make radicands negative or logs undefined**: Always check even roots and logs first.
- **Stating the domain without considering simplification**: A factor that cancels may turn an asymptote into a hole; simplify before deciding exclusions.
- **Using incorrect interval notation**: Remember to use parentheses for strict inequalities and brackets for inclusive; unions ∪ for disjoint pieces.
- **Assuming all real numbers is always the answer**: Most interesting functions have restrictions; defaulting to ℝ without checking is a common error.
- **Confusing domain with range**: Domain concerns inputs (x-values); range is outputs (y-values).
- **Over-restricting for odd roots or polynomials**: Cube roots and polynomials are defined for all reals; only even roots and certain denominators/logarithms restrict.

## Range (mathematics)

<!-- section: range -->

The range describes every value the function can actually output. Determining the range often requires more work than the domain: completing the square, analyzing extrema, or using the graph.

### Range of a Function

:::definition[Range]{#range-definition}
The **range** (or image) of a function is the set of all possible output values $y = f(x)$ as $x$ runs through the entire domain.
:::

While the domain is often easy to read from the formula, the range may require analyzing the minimum/maximum values, solving for $x$ in terms of $y$, or inspecting the graph. For example, $f(x) = x^2$ (domain all reals) has range $[0, \infty)$ because squares are never negative and can be arbitrarily large.

:::intuition
If domain is "what you can put in", range is "what you can possibly get out". A function that squares its input can never spit out a negative number no matter what you feed it.
:::

:::example[Determining the range of $f(x) = x^2 - 4x + 7$]
Find every value this quadratic can output.
:::

:::solution
Complete the square: $x^2 - 4x + 7 = (x-2)^2 - 4 + 7 = (x-2)^2 + 3$.
$(x-2)^2 \ge 0$ for all real $x$, with equality at $x=2$.
Therefore the smallest value of $f$ is $3$ (attained at $x=2$), and since $(x-2)^2$ grows without bound, $f$ can be arbitrarily large.
Range is $[3, \infty)$.
Sanity check: $f(2) = 4 - 8 + 7 = 3$ ✓, matching the minimum we found.
:::

:::recipe[Finding a range by solving for the input]
When there is no obvious minimum to complete-square, the general technique is to **solve for $x$ in terms of $y$** and ask which $y$ produce a real, in-domain $x$. The values of $y$ that fail are exactly the ones missing from the range.
:::

:::example[Determining the range of $f(x) = \\dfrac{x}{x+1}$ (domain $x \ne -1$) by solving for $x$]
Set $y = \dfrac{x}{x+1}$ and solve for $x$: multiply out to get $y(x+1) = x$, i.e. $yx + y = x$.
:::

:::solution
1. Gather $x$-terms: $yx - x = -y \implies x(y - 1) = -y$.
2. Solve: $x = \dfrac{-y}{y-1} = \dfrac{y}{1-y}$.
3. This gives a valid $x$ for every $y$ except $y = 1$, where the denominator $y-1$ is zero (no $x$ maps to $1$).
4. Range is all reals except $1$: $(-\infty, 1) \cup (1, \infty)$.
5. Sanity check: $y=1$ would require $x = x+1$, i.e. $0 = 1$, which is impossible — confirming $1$ is never an output.
:::

### Common Mistakes

- **Assuming range is always all reals when domain is**: Even with full domain, $x^2$ never produces negatives.
- **Confusing range with codomain**: The codomain is what we say the function maps into; the range is the actual image of the domain under f.
- **Forgetting to use completing the square or calculus for quadratics**: Vertex form immediately reveals min/max for parabolas.
- **Thinking range of 1/x is all nonzero**: Actually yes it is, but students sometimes claim positive only.
- **Ignoring holes or asymptotes when reading range from graph**: A function may approach but never reach a horizontal asymptote, excluding that value from range.
- **For exponential or log**: exp range (0,∞), log domain (0,∞) but range all reals; mix them up.

## Even and odd functions

<!-- section: even-odd -->

Symmetry in functions is a powerful shortcut. Even functions mirror across the y-axis; odd functions rotate 180° around the origin. Recognizing them saves work in graphing, integration, and series.

### Even and Odd Functions

:::definition[Even and odd functions]{#even-odd-definition}
A function is **even** if

$$f(-x) = f(x) \quad \text{for all } x \text{ in the domain,}$$

and **odd** if

$$f(-x) = -f(x) \quad \text{for all } x \text{ in the domain.}$$
:::

The graph of an even function is symmetric with respect to the y-axis; examples are $f(x) = x^2$, $f(x) = |x|$ and $f(x) = \cos x$. The graph of an odd function is symmetric with respect to the origin; examples are $f(x) = x^3$ and $f(x) = \sin x$.

Most functions are neither. Knowing symmetry can simplify integrals, graphing, and Fourier analysis later.

:::intuition
Even is like a mirror down the y-axis: the left side of the graph is the mirror image of the right side.

Odd is point symmetry through the origin: if you rotate the graph 180 degrees around (0,0) it looks the same.
:::

:::example[Classifying $f(x) = x^4 - 3x^2$ and proving the property]
The test is always the same: compute $f(-x)$, then compare it to both $f(x)$ (even?) and $-f(x)$ (odd?).
:::

:::solution
Compute $f(-x) = (-x)^4 - 3(-x)^2 = x^4 - 3x^2 = f(x)$. (Recall $(-x)^n = x^n$ for even $n$.)
Since $f(-x) = f(x)$ for every real $x$, the function is even.
Graphically this means the graph is symmetric left-right about the y-axis.

Contrast with a function that is **neither**. Take $h(x) = x^2 + x$.

Compute $h(-x) = (-x)^2 + (-x) = x^2 - x$.
Is it even? $x^2 - x \ne x^2 + x$ (they differ unless $x=0$), so not even.
Is it odd? $-h(x) = -(x^2 + x) = -x^2 - x$, and $x^2 - x \ne -x^2 - x$, so not odd.
Since $h(-x)$ matches neither $h(x)$ nor $-h(x)$, $h$ is neither even nor odd. This is the typical outcome when a formula mixes even powers (like $x^2$) with odd powers (like $x$).
:::

### Common Mistakes

- **Forgetting to check the entire domain**: Symmetry must hold for every x in the domain, not just some points or positive x.
- **Misclassifying polynomials by degree only**: Even degree can be odd if only odd powers (e.g. x^3 + x is odd); check the powers present.
- **Confusing even/odd with increasing/decreasing**: Monotonicity is different from y-axis or origin symmetry.
- **Thinking constant functions are odd**: Constants (nonzero) are even; only the zero function is both.
- **Sign errors when testing odd**: f(-x) must equal exactly the negative, including all terms.
- **Assuming trig functions: sin is odd, cos even, tan odd**: Always verify with the definitions rather than memorizing only.

## Inverse function

<!-- section: inverses -->

Inverses let us reverse processes. Not every function has one; it must be one-to-one. The inverse swaps domain and range.

### Inverse Functions

:::definition[Inverse function]{#inverse-definition}
If a function $f$ is one-to-one (injective), its **inverse function** $f^{-1}$ is the function satisfying

$$f(f^{-1}(y)) = y \qquad \text{and} \qquad f^{-1}(f(x)) = x.$$

The inverse "undoes" the original function.
:::

:::proposition[Horizontal line test]
A function has an inverse if and only if it is one-to-one; on its graph this is the horizontal line test — no horizontal line may meet the graph more than once.
:::

The domain of $f^{-1}$ is the range of $f$, and vice versa: reversing the arrows swaps the two sets.

:::recipe[Finding a formula for an inverse]
1. Write $y = f(x)$.
2. Swap $x$ and $y$.
3. Solve the new equation for $y$; that expression is $f^{-1}(x)$.
4. Check both compositions return the input, and record the swapped domain and range.
:::

:::intuition
An inverse is like an undo button. If $f$ turns 3 into 7, the inverse turns 7 back into 3. Only functions that never repeat an output value have a true undo button.
:::

:::example[Finding the inverse of $f(x) = 2x + 5$]
Set $y = 2x + 5$.
:::

:::solution
1. Swap: $x = 2y + 5$.
2. Solve: $x - 5 = 2y \implies y = \frac{x-5}{2}$.
3. Therefore $f^{-1}(x) = \frac{x-5}{2}$.
4. Verify both directions: $f(f^{-1}(x)) = 2\left(\frac{x-5}{2}\right) + 5 = (x - 5) + 5 = x$ ✓, and $f^{-1}(f(x)) = \frac{(2x+5)-5}{2} = \frac{2x}{2} = x$ ✓.
:::

:::example[Inverting a non-injective function by restricting the domain]
$f(x) = x^2$ on all reals has no inverse, because $f(2) = f(-2) = 4$: the output $4$ has two preimages, so there is no unique way to "undo" it (it fails the horizontal line test).
:::

:::solution
Restrict the domain to make $f$ one-to-one. Choose $x \ge 0$; now each nonnegative output comes from exactly one input.
Set $y = x^2$ with $x \ge 0$ and solve: $x = \sqrt{y}$ (we take the **positive** root because the restricted domain is $x \ge 0$).
Swapping names, $f^{-1}(x) = \sqrt{x}$.
Track domains and ranges: the restricted $f$ has domain $[0,\infty)$ and range $[0,\infty)$, so $f^{-1}$ has domain $[0,\infty)$ and range $[0,\infty)$ — the swap of the original.
Verify: for $x \ge 0$, $f^{-1}(f(x)) = \sqrt{x^2} = |x| = x$ ✓ (the last equality holds precisely because $x \ge 0$; this is exactly why the domain restriction matters).
:::

### Common Mistakes

- **Trying to invert non-injective functions without restricting domain**: x² has no inverse over reals; restrict to [0,∞) first.
- **Forgetting to swap x and y then solve**: The swap step is essential; simply negating or other shortcuts fail.
- **Ignoring domain/range swap**: The inverse's domain is the original range; formulas may need adjustment for the new domain.
- **Not verifying the composition is identity**: Always check f(f^{-1}(x))=x and f^{-1}(f(x))=x on the proper domains.
- **Assuming all functions have inverses**: Linear, exp, log do (with care); quadratics, trig over full periods do not.
- **Sign or algebra errors when solving for inverse**: Isolate carefully after the swap; common in linear and rational cases.

## Composition of functions

<!-- section: composition -->

Composition chains functions: the output of one becomes input to the next. It is the mathematical version of "do this, then that."

### Composition of Functions

:::definition[Composition of functions]{#composition-definition}
The **composition** of $f$ and $g$ is the function

$$(f \circ g)(x) = f(g(x)).$$

We apply $g$ first, then feed the result into $f$.
:::

:::proposition[Order matters, grouping does not]
Composition is associative,

$$(f \circ g) \circ h = f \circ (g \circ h),$$

but it is not commutative: in general $f \circ g \ne g \circ f$.
:::

This operation lets us build complicated functions by chaining simpler ones, exactly as we do when describing multi-step processes.

:::intuition
Composition is "function of a function": first do one transformation, then do another to the result. Like "take the temperature in Celsius, convert to Fahrenheit, then tell me if it is above freezing."
:::

:::example[Computing and simplifying a composition]
Let $f(x) = x^2 + 1$ and $g(x) = 3x - 1$.
:::

:::solution
Compute $(f \circ g)(x) = f(g(x)) = f(3x-1) = (3x-1)^2 + 1 = 9x^2 - 6x + 1 + 1 = 9x^2 - 6x + 2$. (Here we substituted the whole expression $3x-1$ into $f$ wherever an $x$ appeared.)
Compute $(g \circ f)(x) = g(f(x)) = g(x^2 + 1) = 3(x^2 + 1) - 1 = 3x^2 + 3 - 1 = 3x^2 + 2$.
They are different ($9x^2 - 6x + 2 \ne 3x^2 + 2$), showing order matters.
Sanity check at $x=1$: $(f\circ g)(1) = f(g(1)) = f(2) = 2^2 + 1 = 5$, and the formula gives $9 - 6 + 2 = 5$ ✓. Meanwhile $(g\circ f)(1) = g(f(1)) = g(2) = 5$, and its formula gives $3 + 2 = 5$; they coincide at this one point but not in general.

A note on domain (rigor): for $(f \circ g)(x)$ to be defined, $x$ must be in the domain of $g$ **and** $g(x)$ must be in the domain of $f$. Here both $f$ and $g$ are defined on all reals, so the composition is too; but with roots or denominators inside, always intersect these two conditions. For instance, $(f \circ g)(x) = f(\sqrt{x})$ inherits the restriction $x \ge 0$ from the inner $\sqrt{x}$.
:::

### Common Mistakes

- **Reversing the order of composition**: f∘g means g inside; students often compute the outer function first.
- **Forgetting that composition is not commutative**: f(g(x)) ≠ g(f(x)) in general (e.g. sin(x^2) vs (sin x)^2).
- **Not checking domains for the inner function**: g(x) must be in domain of f; the overall domain is restricted to where g(x) is valid for f.
- **Algebra errors when simplifying (f∘g)**: Expand carefully; (3x-1)^2 +1 is not the same as applying in wrong order.
- **Assuming (f∘g)^{-1} = f^{-1} ∘ g^{-1}**: Actually (f∘g)^{-1} = g^{-1} ∘ f^{-1} (reverse order).
- **Confusing composition with multiplication or addition of functions**: (f+g)(x)=f(x)+g(x) is pointwise, not chained.

## Transformation of functions

<!-- section: transformations -->

Transformations let us take a basic parent function and quickly obtain families of related graphs without starting from scratch each time.

### Transformations of Functions

We can obtain new functions from old by shifting, stretching, reflecting, or flipping.

:::proposition[The basic transformations]
Let $f$ be a function, and let $h$, $k$ and $c$ be constants.

- Horizontal shift: $f(x - h)$ shifts the graph right by $h$ (left if $h$ negative).
- Vertical shift: $f(x) + k$ shifts up by $k$.
- Horizontal stretch/compress: $f(cx)$ ( |c|>1 compresses toward y-axis).
- Vertical stretch: $c f(x)$.
- Reflection: $-f(x)$ over x-axis; $f(-x)$ over y-axis.
:::

These transformations preserve many important properties while allowing us to move graphs to convenient locations.

A useful mental split: everything **inside** $f(\cdot)$ acts on the input (horizontal, and behaves "backwards" — you solve for what the argument must be), while everything **outside** acts on the output (vertical, and behaves the way you'd expect). When several transformations combine, apply horizontal operations to the $x$-coordinate and vertical operations to the $y$-coordinate of each point, respecting how they are nested.

:::intuition
Transformations are like giving the whole graph a "move and resize" command without changing its basic shape. Right/left for inside the function, up/down for outside.
:::

:::example[Applying successive transformations to $f(x) = \\sqrt{x}$]
Start with parent $y = \sqrt{x}$ (domain $[0,\infty)$, range $[0,\infty)$).
:::

:::solution
To get $g(x) = 2\sqrt{x-3} - 4$, read the transformations off the formula:
Inside $(x-3)$: horizontal shift right 3 units.
Multiply the root by 2: vertical stretch by factor 2.
Subtract 4: vertical shift down 4 units.
New domain: the inside must stay nonnegative, $x-3 \ge 0 \implies x \ge 3$, i.e. domain $[3, \infty)$.
New range: $\sqrt{x-3} \ge 0$, so $2\sqrt{x-3} \ge 0$, so $2\sqrt{x-3} - 4 \ge -4$; range is $[-4, \infty)$.
The corner point (originally $(0,0)$) moves to $(3, -4)$: the input $x=3$ makes the root $0$, and then $g(3) = 2\cdot 0 - 4 = -4$.
Sanity check with a second point: on the parent, $(1,1)$ satisfies $\sqrt{1}=1$. Its image should be $x: 1 \to 1+3 = 4$, $y: 1 \to 2\cdot 1 - 4 = -2$, i.e. $(4, -2)$. Verify directly: $g(4) = 2\sqrt{4-3} - 4 = 2\cdot 1 - 4 = -2$ ✓.
:::

:::example[A transformation with a reflection: locating the image of the corner point]
Transform the parent $f(x) = \sqrt{x}$ into $g(x) = -2\sqrt{x-1} + 3$ and find the image of the corner $(0,0)$.
:::

:::solution
Horizontal: inside $(x-1)$ shifts right 1, so the $x$-coordinate $0 \to 1$.
Vertical, applied in order to the output: the root value at the corner is $0$; multiply by $-2$ (reflect over the x-axis and stretch by 2) gives $-2\cdot 0 = 0$; then $+3$ gives $0 + 3 = 3$. So the $y$-coordinate $0 \to 3$.
The corner lands at $(1, 3)$.
Sanity check: $g(1) = -2\sqrt{1-1} + 3 = -2\cdot 0 + 3 = 3$ ✓. (Note the reflection did not move the corner's height here only because the root is $0$ there; away from the corner, $-2$ flips points below the shifted axis.)
:::

### Common Mistakes

- **Reversing horizontal shift direction**: f(x-h) shifts right (h positive inside moves graph right); intuition often gets the sign backwards.
- **Mixing inside vs outside multipliers**: c f(x) is vertical stretch by |c|; f(c x) is horizontal.
- **Forgetting reflections flip the whole graph including shifts already applied**: Order of operations in successive transforms matters.
- **Domain/range adjustments after shifts/stretches**: Inside horizontal changes domain; vertical changes range. Always update both.
- **Thinking -f(x) reflects over y-axis**: -f(x) is over x-axis; f(-x) is over y-axis.
- **Assuming stretches always expand**: |c|<1 actually compresses (shrinks).

## Piecewise function

<!-- section: piecewise -->

Piecewise functions use different rules in different intervals. They model real-world situations with thresholds (tax brackets, speed limits, absolute value).

### Piecewise Functions

:::definition[Piecewise function]{#piecewise-definition}
A **piecewise function** is defined by different formulas on different parts of its domain. We use a brace notation:

$$f(x) = \begin{cases} x+1 & \text{if } x < 0 \\ 2x & \text{if } x \ge 0 \end{cases}$$
:::

To evaluate, choose the piece that contains the input. To graph, draw each piece only on its interval and be careful at the "seams" (check continuity or jumps).

Piecewise definitions appear naturally when modeling real situations that change rules at thresholds (tax brackets, absolute value, etc.).

:::intuition
A piecewise function is like having two (or more) different recipes and a rule that says "use recipe A on weekdays before noon, recipe B otherwise." The overall machine is still one function.
:::

:::example[Evaluating and graphing a piecewise function]
Let $f(x) = \begin{cases} -x & x < 1 \\ x^2 & x \ge 1 \end{cases}$
:::

:::solution
Evaluate $f(-2)$: since $-2 < 1$, use the first piece: $f(-2) = -(-2) = 2$.
Evaluate $f(1)$: since $1 \ge 1$, use the second piece: $f(1) = 1^2 = 1$.
Evaluate $f(3)$: since $3 \ge 1$, use the second piece: $f(3) = 3^2 = 9$.
Check the seam at $x = 1$. Approaching from the left we follow the first piece: as $x \to 1^-$, $f(x) = -x \to -1$. Approaching from the right (and at $x=1$ itself) we follow the second piece: $f(x) = x^2 \to 1$. The left limit ($-1$) and the right value ($1$) disagree, so the graph has a **jump discontinuity** at $x = 1$: plot an open circle at $(1, -1)$ on the line and a closed circle at $(1, 1)$ on the parabola.
Sanity check: each input satisfies exactly one condition (the conditions $x<1$ and $x\ge 1$ partition the reals with no gap or overlap), so every evaluation used a single, unambiguous piece.
:::

### Common Mistakes

- **Evaluating at the boundary with the wrong piece**: The definition specifies ≤ or < ; always check the exact condition at the point.
- **Forgetting to graph only on the piece's interval**: Do not extend a piece beyond its if-condition.
- **Missing jump discontinuities**: At boundaries, left and right limits may differ; plot open/closed circles correctly.
- **Assuming the function must be continuous**: Piecewise functions are often discontinuous by design (step functions, absolute value at 0 is continuous but many are not).
- **Algebra mistakes when finding where pieces meet**: Solve the boundary equations carefully when finding intercepts or intersections.
- **Not stating the full domain when describing the function**: The pieces together must cover the intended domain without gaps or overlaps in conditions.
