# Analytic Trigonometry

Angle formulas, laws of sines and cosines, inverse trig, equations, and substitution preview.

## Double-angle formula

<!-- section: double-angle -->

Double angle lets you express trig of twice the angle using only the original angle. Extremely useful for integration and solving equations.

### Double-Angle Formulas

$\sin 2\theta = 2 \sin \theta \cos \theta$

$\cos 2\theta = \cos^2 \theta - \sin^2 \theta = 2\cos^2 \theta - 1 = 1 - 2\sin^2 \theta$

$\tan 2\theta = \frac{2 \tan \theta}{1 - \tan^2 \theta}$

These come from the angle addition formulas with $\alpha = \beta = \theta$: for instance $\sin(\theta + \theta) = \sin\theta\cos\theta + \cos\theta\sin\theta = 2\sin\theta\cos\theta$. They are identities, so they hold for every $\theta$ (and for $\tan 2\theta$, wherever $\tan\theta$ and $\tan 2\theta$ are defined). Extremely useful for integration and solving trig equations. The three forms of $\cos 2\theta$ are all equal — pick whichever leaves you with only the quantity you already know: use $2\cos^2\theta - 1$ if you know $\cos\theta$, and $1 - 2\sin^2\theta$ if you know $\sin\theta$.

**ELI5**

- Double-angle is a "zoom" button: you know the trig of one angle and want the trig of the angle twice as wide. Instead of measuring the wide angle from scratch, the formula rebuilds it from the pieces of the small one — like predicting how far a door swings open at $2\times$ the push from how far it swings at $1\times$.

**Worked Example (know cosine, quadrant II):**

**Find $\sin 2\theta$ given $\cos\theta = -\tfrac{3}{5}$, with $\theta$ in quadrant II.**

1. We need $\sin\theta$. From the Pythagorean identity $\sin^2\theta = 1 - \cos^2\theta = 1 - \tfrac{9}{25} = \tfrac{16}{25}$, so $\sin\theta = \pm\tfrac{4}{5}$.
2. In quadrant II sine is positive, so $\sin\theta = +\tfrac{4}{5}$.
3. Apply the formula: $\sin 2\theta = 2\sin\theta\cos\theta = 2\cdot\tfrac{4}{5}\cdot\left(-\tfrac{3}{5}\right) = -\tfrac{24}{25}$.
4. Sanity check: $\theta$ in QII means $\theta \in (90^\circ, 180^\circ)$, so $2\theta \in (180^\circ, 360^\circ)$ — the lower half of the circle, where sine is negative. Our answer $-\tfrac{24}{25}$ is negative. ✓

**Worked Example (using $\cos 2\theta$):**

**Given $\sin\theta = \tfrac{4}{5}$ with $\theta$ in quadrant II, find $\cos 2\theta$.**

1. Because we know $\sin\theta$ directly, pick the form $\cos 2\theta = 1 - 2\sin^2\theta$ so no extra work is needed.
2. $\cos 2\theta = 1 - 2\left(\tfrac{4}{5}\right)^2 = 1 - 2\cdot\tfrac{16}{25} = 1 - \tfrac{32}{25} = -\tfrac{7}{25}$.
3. Sanity check via a different form: $\cos\theta = -\tfrac{3}{5}$ (QII), so $\cos^2\theta - \sin^2\theta = \tfrac{9}{25} - \tfrac{16}{25} = -\tfrac{7}{25}$. Same answer. ✓

### Common Mistakes

- **Double-angle misapplication**: Using sin(2θ)=2sinθ instead of 2sin cos; or confusing which double-angle form of cos 2θ to pick for simplification.
- **Sign when using 1-2sin²**: Choose the form that matches known value and quadrant.
- **For tan 2θ denominator 1-tan²**: Zero when tan θ = ±1, corresponding to 2θ = π/2 +kπ where tan undefined.
- **Forgetting these are identities not equations**: True for all θ (where defined).
- **Using for half angle backwards**: Half angle solves for half from double; different.
- **Calculator in degree when using π**: Formulas assume radian or consistent, but identities hold either.

## Half-angle formula

<!-- section: half-angle -->

Half-angle formulas let you "split" an angle and compute exact trig values when you know the full angle (useful for 15°, 22.5° etc).

### Half-Angle Formulas

$\sin(\theta/2) = \pm \sqrt{\frac{1 - \cos \theta}{2}}$

$\cos(\theta/2) = \pm \sqrt{\frac{1 + \cos \theta}{2}}$

$\tan(\theta/2) = \frac{\sin \theta}{1 + \cos \theta} = \frac{1 - \cos \theta}{\sin \theta}$

The $\pm$ sign is not free: it is fixed by the quadrant of $\theta/2$ (not of $\theta$). The square root itself always returns a nonnegative number, so you attach the sign that sine or cosine actually has in the quadrant where $\theta/2$ lands. The two $\tan(\theta/2)$ formulas need $\theta$ to avoid the points where their denominators vanish ($1 + \cos\theta \ne 0$, i.e. $\theta \ne \pi + 2k\pi$, for the first; $\sin\theta \ne 0$ for the second), but at least one of the two always works.

These are derived from the $\cos 2\alpha$ double-angle forms by setting $\alpha = \theta/2$ and solving. For example, from $\cos\theta = 1 - 2\sin^2(\theta/2)$ we get $2\sin^2(\theta/2) = 1 - \cos\theta$, hence $\sin(\theta/2) = \pm\sqrt{\tfrac{1-\cos\theta}{2}}$.

**ELI5**

- If double-angle is the "zoom in" button, half-angle is "zoom out": you know a full angle and want the trig of the angle half as wide. That is how you get exact values for oddball angles like $15^\circ$ or $22.5^\circ$ — you halve a friendly angle you already know ($30^\circ$, $45^\circ$) instead of memorizing a new one.

**Worked Example:**

**Find the exact value of $\sin 22.5^\circ$.**

1. Notice $22.5^\circ = \tfrac{45^\circ}{2}$, so take $\theta = 45^\circ$, where $\cos 45^\circ = \tfrac{\sqrt2}{2}$.
2. Choose the sign: $22.5^\circ$ is in quadrant I, where sine is positive, so use $+$.
3. Substitute: $\sin 22.5^\circ = \sqrt{\dfrac{1 - \tfrac{\sqrt2}{2}}{2}}$.
4. Clear the inner fraction by writing $1 = \tfrac{2}{2}$: the numerator is $\tfrac{2-\sqrt2}{2}$, so the expression is $\sqrt{\dfrac{2-\sqrt2}{4}} = \dfrac{\sqrt{2-\sqrt2}}{2}$.
5. Sanity check: numerically $\sqrt{2-\sqrt2} \approx \sqrt{0.586} \approx 0.765$, so the result is $\approx 0.383$. A calculator gives $\sin 22.5^\circ \approx 0.383$. ✓

### Common Mistakes

- **Half-angle sign choice**: Always determine the quadrant of the half-angle before picking + or - in front of the square root.
- **Forgetting the 2 in denominator**: (1 - cos)/2 inside the sqrt, not (1-cos)/sqrt2.
- **Using for double instead**: These solve for half; double angle goes the other way.
- **tan half two forms**: Both equal; choose the one avoiding division by small number.
- **Domain**: θ/2 must be in domain where original defined, and sqrt arg ≥0 which it is by identities.
- **Calculator for 22.5 without exact**: Loses the nice radical form.

## Sum-to-product identity

<!-- section: sum-to-product -->

These identities collapse sums of sines or cosines into products. Magic for solving equations and simplifying waves (beats).

### Sum-to-Product and Product-to-Sum Identities

Sum-to-product:

$\sin A + \sin B = 2 \sin(\frac{A+B}{2}) \cos(\frac{A-B}{2})$

$\sin A - \sin B = 2 \cos(\frac{A+B}{2}) \sin(\frac{A-B}{2})$

$\cos A + \cos B = 2 \cos(\frac{A+B}{2}) \cos(\frac{A-B}{2})$

$\cos A - \cos B = -2 \sin(\frac{A+B}{2}) \sin(\frac{A-B}{2})$

These turn sums into products, which matters because a product equals zero exactly when one of its factors is zero — so an equation like $\sin A + \sin B = 0$ becomes two easy equations. They hold for all $A$ and $B$. (Setting $A = B$ recovers the double-angle formula, a useful consistency check: $\sin A + \sin A = 2\sin A$, and the identity gives $2\sin A\cos 0 = 2\sin A$. ✓)

**ELI5**

- Adding two sine waves of nearly equal frequency is like two singers holding almost the same note: instead of hearing two tones you hear one tone that slowly swells and fades. The identity is the math of that swelling — it rewrites the sum as one wave (the average frequency) times a slow envelope (the half-difference frequency). That throb is what musicians call "beats."

**Worked Example:**

**Evaluate $\sin 75^\circ + \sin 15^\circ$ exactly.**

1. Use $\sin A + \sin B = 2\sin\!\left(\tfrac{A+B}{2}\right)\cos\!\left(\tfrac{A-B}{2}\right)$ with $A = 75^\circ$, $B = 15^\circ$.
2. Compute the half-sum and half-difference: $\tfrac{A+B}{2} = \tfrac{90^\circ}{2} = 45^\circ$ and $\tfrac{A-B}{2} = \tfrac{60^\circ}{2} = 30^\circ$.
3. Substitute the known values: $2\sin 45^\circ\cos 30^\circ = 2\cdot\tfrac{\sqrt2}{2}\cdot\tfrac{\sqrt3}{2} = \tfrac{\sqrt2\cdot\sqrt3}{2} = \tfrac{\sqrt6}{2}$.
4. Sanity check: $\tfrac{\sqrt6}{2} \approx \tfrac{2.449}{2} \approx 1.225$, while directly $\sin 75^\circ + \sin 15^\circ \approx 0.966 + 0.259 = 1.225$. ✓

### Common Mistakes

- **Sum-to-product arithmetic**: (A+B)/2 and (A-B)/2 must be computed carefully; mixing up which is which ruins the identity application.
- **Sign in cos A - cos B**: Has the minus in front of the sin sin term.
- **Forgetting product-to-sum the other way**: Sometimes needed too.
- **Using when A or B make arg undefined**: Check domains.
- **Calculator for exact**: Loses the simplified radical.
- **Confusing with double angle**: Similar looking but different (A=B case recovers double).

## Sum and difference formula

<!-- section: sum-difference -->

The addition formulas let us compute trig for sums and differences of known angles, giving exact values for 15°, 75°, etc., and are the basis for many identities.

### Sum and Difference Formulas

Addition formulas:

$\sin(A \pm B) = \sin A \cos B \pm \cos A \sin B$

$\cos(A \pm B) = \cos A \cos B \mp \sin A \sin B$

$\tan(A \pm B) = \frac{\tan A \pm \tan B}{1 \mp \tan A \tan B}$

These are proved using the distance formula on unit-circle points or using Euler's formula with complex exponentials. Read the "top/bottom" signs carefully: in $\cos(A \pm B)$ the sign in front of the $\sin A\sin B$ term is *opposite* to the sign in the argument (that is what $\mp$ means), so $\cos(A - B) = \cos A\cos B + \sin A\sin B$. In the $\tan$ formula the denominator can vanish — that happens precisely when $A \pm B = \tfrac{\pi}{2} + k\pi$, exactly where $\tan(A\pm B)$ is undefined, so the formula is faithful to the function.

They let us find exact values for angles like $15^\circ = 45^\circ - 30^\circ$ and expand expressions.

**ELI5**

- Think of angles as amounts of turning. If you know exactly how "sideways" and "up" a $45^\circ$ turn leaves you and the same for a $30^\circ$ turn, these formulas tell you where a $45^\circ - 30^\circ = 15^\circ$ turn leaves you — no new measurement needed. Master three friendly angles ($30^\circ, 45^\circ, 60^\circ$) and you can build many others for free.

**Worked Example:**

**Find the exact value of $\sin 15^\circ$.**

1. Write $15^\circ$ as a difference of known angles: $15^\circ = 45^\circ - 30^\circ$.
2. Apply $\sin(A - B) = \sin A\cos B - \cos A\sin B$ with $A = 45^\circ$, $B = 30^\circ$: $\sin 15^\circ = \sin 45^\circ\cos 30^\circ - \cos 45^\circ\sin 30^\circ$.
3. Substitute known values: $\left(\tfrac{\sqrt2}{2}\right)\!\left(\tfrac{\sqrt3}{2}\right) - \left(\tfrac{\sqrt2}{2}\right)\!\left(\tfrac{1}{2}\right) = \tfrac{\sqrt6}{4} - \tfrac{\sqrt2}{4} = \tfrac{\sqrt6 - \sqrt2}{4}$.
4. Sanity check: $\tfrac{\sqrt6 - \sqrt2}{4} \approx \tfrac{2.449 - 1.414}{4} \approx \tfrac{1.035}{4} \approx 0.259$, and $\sin 15^\circ \approx 0.259$. ✓

### Common Mistakes

- **Sum/difference sign errors**: The minus in cos(A-B) = cosA cosB + sinA sinB is frequently flipped.
- **For tan(A+B) the denominator sign**: 1 - tanA tanB for + ; 1 + for - .
- **Forgetting mp signs**: In cos(A±B) the sin term flips sign with the ± .
- **Using for half/double instead**: These are for arbitrary A B; double is special case.
- **Domain where tan defined in tan formula**: If 1 - tanA tanB =0 the sum hits asymptote.
- **Calculator in wrong mode for exact problems**: Use exact values of 30 45 60, not decimal approx.

## Law of sines

<!-- section: law-of-sines -->

The law of sines generalizes the right-triangle ratios to any triangle, allowing us to solve for missing sides or angles when we have AAS, ASA or the tricky SSA.

### Law of Sines

In any triangle ABC with sides a,b,c opposite angles A,B,C respectively:

$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$

where R is the circumradius.

This is derived by dropping an altitude and using area formulas or by using the extended unit-circle definition. The law applies to *any* triangle (not just right triangles), and the shared ratio equals $2R$, the diameter of the triangle's circumscribed circle.

The law is the right tool exactly when a known side is *paired* with its opposite angle: this happens in AAS, ASA (find the third angle first, then you have a side–angle pair), and SSA. SAS and SSS give you no such pair, so those need the Law of Cosines instead.

**ELI5**

- The Law of Sines says a triangle's sides and their opposite angles rise and fall together: the biggest side faces the biggest angle, and the ratio of each side to the sine of its facing angle is the same throughout the triangle. Know one matched side–angle pair and it acts as a conversion rate for finding any other side or angle.

**Worked Example:**

**Solve the triangle with $A = 40^\circ$, $a = 8$, $B = 60^\circ$: find side $b$ and angle $C$.**

1. This is AAS. Find the third angle first: $C = 180^\circ - 40^\circ - 60^\circ = 80^\circ$.
2. Use the matched pair $\tfrac{a}{\sin A}$ as the conversion rate: $\tfrac{a}{\sin A} = \tfrac{b}{\sin B}$, i.e. $\tfrac{8}{\sin 40^\circ} = \tfrac{b}{\sin 60^\circ}$.
3. Solve for $b$: $b = \tfrac{8\sin 60^\circ}{\sin 40^\circ} \approx \tfrac{8\cdot 0.8660}{0.6428} \approx \tfrac{6.928}{0.6428} \approx 10.8$. (Keep full precision until the end; round once.)
4. Sanity check: the angles from smallest to largest are $A = 40^\circ < B = 60^\circ < C = 80^\circ$, so the sides should order the same way: $a = 8 < b \approx 10.8 < c$. Since $b > a$ matches $B > A$, the result is consistent. ✓

### Common Mistakes

- **Ambiguous case (SSA)**: When using Law of Sines with two sides and angle opposite one of them, there may be zero, one, or two possible triangles. Always check the height h = b sin A against the given side.
- **Calculator mode**: Degrees or radians must match the problem (usually degrees in triangle problems).
- **Assuming unique triangle**: SSA can be ambiguous; draw the picture.
- **Forgetting to find the third angle first**: In AAS/ASA you get third angle from 180 sum before applying law.
- **Rounding too early**: Keep precision until final answer.
- **Using law of sines for SAS or SSS**: Those are for law of cosines.

## Law of cosines

<!-- section: law-of-cosines -->

The law of cosines is Pythagoras with a correction term for the included angle. It lets us solve SAS and SSS triangles.

### Law of Cosines

For any triangle:

$c^2 = a^2 + b^2 - 2ab \cos C$

(and cyclic permutations).

When $C = 90^\circ$, $\cos C = 0$ and the correction term vanishes, recovering Pythagoras $c^2 = a^2 + b^2$. Note that $C$ must be the angle *opposite* side $c$ — equivalently, the angle *included* between sides $a$ and $b$.

Useful for SAS (two sides + included angle) to find the third side, or SSS to find an angle via the rearranged form $\cos C = \tfrac{a^2 + b^2 - c^2}{2ab}$. This SSS form is unambiguous: $\arccos$ returns a single angle in $[0^\circ, 180^\circ]$, and a negative right-hand side correctly yields an obtuse angle — so the Law of Cosines never has the ambiguity that plagues SSA.

**ELI5**

- The Law of Cosines is Pythagoras wearing a correction collar. The term $-2ab\cos C$ measures how far the corner angle strays from a right angle. If $C$ is acute, $\cos C > 0$, the correction is subtracted, and the opposite side $c$ comes out shorter than Pythagoras would predict; if $C$ is obtuse, $\cos C < 0$, the correction *adds* length and $c$ comes out longer.

**Worked Example (SAS — find a side):**

**Two sides measure $a = 5$ and $b = 7$ with included angle $C = 60^\circ$. Find side $c$.**

1. Apply the law with $C$ between $a$ and $b$: $c^2 = a^2 + b^2 - 2ab\cos C = 5^2 + 7^2 - 2\cdot 5\cdot 7\cos 60^\circ$.
2. Since $\cos 60^\circ = \tfrac12$: $c^2 = 25 + 49 - 70\cdot\tfrac12 = 74 - 35 = 39$, so $c = \sqrt{39} \approx 6.24$.
3. Sanity check: $c$ should sit between $|b - a| = 2$ and $b + a = 12$ (triangle inequality), and it does. ✓

**Worked Example (SSS — find an angle):**

**Find angle $C$ given sides $a = 3$, $b = 4$, $c = 6$.**

1. Rearrange for the cosine of the angle opposite $c$: $\cos C = \tfrac{a^2 + b^2 - c^2}{2ab} = \tfrac{9 + 16 - 36}{2\cdot 3\cdot 4} = \tfrac{-11}{24} \approx -0.4583$.
2. Take the inverse cosine: $C = \arccos(-0.4583) \approx 117.3^\circ$.
3. Sanity check: the cosine came out negative, so $C$ is obtuse — and indeed $c^2 = 36 > a^2 + b^2 = 25$, which is exactly the condition for the angle opposite $c$ to exceed $90^\circ$. ✓

### Common Mistakes

- **Law of Cosines for angle**: When solving for angle, the numerator a²+b²-c² can be negative (obtuse); arccos handles it correctly if you keep the sign.
- **Using wrong angle**: The cos C is for the angle opposite side c (included between a and b).
- **Forgetting the 2ab**: The formula has the 2.
- **Mixing with law of sines**: Use cos for SAS/SSS, sines for AAS/ASA/SSA.
- **Calculator in rad vs deg for arccos**: arccos returns radians or degrees per mode; convert if needed for answer.
- **Rounding intermediate**: Keep exact or high precision for arccos input.

## Inverse trigonometric functions

<!-- section: inverse-trig -->

Inverse trig recover the angle from a known sine, cosine or tangent value. Their ranges are restricted to make them functions (one-to-one).

### Inverse Trigonometric Functions

The inverse trig functions recover an angle from a known trig value within a restricted principal range where the function is one-to-one.

- $\arcsin x$ : domain [-1,1], range [-π/2, π/2]
- $\arccos x$ : domain [-1,1], range [0, π]
- $\arctan x$ : domain all reals, range (-π/2, π/2)
- $\text{arccsc}, \text{arcsec}, \text{arccot}$ defined similarly with their own conventions.

The range restriction is the whole point. Sine (say) is not one-to-one on all of $\mathbb{R}$ — infinitely many angles share the value $\tfrac12$ — so "the angle whose sine is $x$" has no single answer until we pin it to one slice. We choose the slice where the function is one-to-one and still hits every output value: $[-\tfrac{\pi}{2}, \tfrac{\pi}{2}]$ for $\arcsin$, $[0, \pi]$ for $\arccos$, $(-\tfrac{\pi}{2}, \tfrac{\pi}{2})$ for $\arctan$. These are essential for solving trig equations ("what angle has this sine?") and in calculus for integrals and derivatives.

**ELI5**

- Sine is like a revolving door: many different pushes (angles) land you at the same spot. $\arcsin$ has to undo that, but "which push?" is ambiguous — so it always reports the answer from one agreed-upon quarter-turn of the door. That is the "principal value": one consistent representative, not the only true angle.

**Worked Example (evaluating a sum):**

**Compute $\arctan 1 + \arcsin 0.5$.**

1. $\arctan 1 = \tfrac{\pi}{4}$ because $\tan\tfrac{\pi}{4} = 1$ and $\tfrac{\pi}{4} \in (-\tfrac{\pi}{2}, \tfrac{\pi}{2})$.
2. $\arcsin 0.5 = \tfrac{\pi}{6}$ because $\sin\tfrac{\pi}{6} = \tfrac12$ and $\tfrac{\pi}{6} \in [-\tfrac{\pi}{2}, \tfrac{\pi}{2}]$.
3. Add over a common denominator: $\tfrac{\pi}{4} + \tfrac{\pi}{6} = \tfrac{3\pi}{12} + \tfrac{2\pi}{12} = \tfrac{5\pi}{12}$.
4. Sanity check: $\tfrac{5\pi}{12} = 75^\circ$, which is $45^\circ + 30^\circ$ — exactly the two angles we found. ✓

**Worked Example (the composition trap):**

**Evaluate $\arcsin\!\left(\sin\tfrac{5\pi}{6}\right)$.**

1. It is tempting to answer $\tfrac{5\pi}{6}$, but $\tfrac{5\pi}{6}$ is *not* in $\arcsin$'s range $[-\tfrac{\pi}{2}, \tfrac{\pi}{2}]$, so that cannot be the output.
2. First evaluate the inside: $\sin\tfrac{5\pi}{6} = \tfrac12$.
3. Now $\arcsin\tfrac12 = \tfrac{\pi}{6}$, the angle in range with that sine.
4. So $\arcsin\!\left(\sin\tfrac{5\pi}{6}\right) = \tfrac{\pi}{6} \ne \tfrac{5\pi}{6}$. The identity $\arcsin(\sin x) = x$ holds only when $x$ already lies in the principal range. ✓

### Common Mistakes

- **Range of inverse functions**: arcsin range is [-π/2,π/2]; arccos [0,π]. Using the wrong branch or forgetting the range produces answers outside the principal value.
- **Calculator mode**: arccos etc return in current angle mode; check.
- **arcsin(sin x) ≠ x for all x**: Only true inside the principal range; outside it gives the co-terminal in range.
- **Domain restrictions**: arcsin and arccos only defined for [-1,1]; arctan all reals.
- **Confusing arctan with 1/tan**: arctan is inverse function, not reciprocal (which is cot).
- **Quadrant when solving**: After arcsin you may need to add π - result for other quadrant solutions in equations.

## Trigonometric equation

<!-- section: trig-equations -->

Solving trig equations requires identities to reduce to basic forms, then inverse trig plus the periodic general solution, followed by checking for extraneous roots.

### Trigonometric Equations

To solve trig equations:

1. Use identities to rewrite in terms of a single function.
2. Solve the basic equation sin x = k or similar (use inverse + general solution).
3. Find all solutions in the desired interval by adding the period(s).
4. Check for extraneous solutions introduced by squaring or other operations.

General solutions (for integer $m$, with $|k| \le 1$ required for sine and cosine):
- $\sin x = k$ : two families, $x = \arcsin k + 2m\pi$ and $x = \pi - \arcsin k + 2m\pi$ (the QI/QII pair with the same sine).
- $\cos x = k$ : $x = \pm\arccos k + 2m\pi$ (cosine is even, so a value and its negative share the cosine).
- $\tan x = k$ : $x = \arctan k + m\pi$ (period $\pi$, so one family suffices).

**ELI5**

- Solving a trig equation is like asking "at what times does the Ferris wheel put me exactly 3 meters up?" Because the wheel keeps turning, there is not one answer but a repeating schedule. So you find the answers in one full turn, then tack on "$+$ every period" to capture all the rest.

**Worked Example:**

**Solve $2\sin^2 x - \sin x - 1 = 0$ for $x \in [0, 2\pi)$.**

1. The equation is quadratic in $\sin x$. Substitute $u = \sin x$: $2u^2 - u - 1 = 0$.
2. Factor: $(2u + 1)(u - 1) = 0$, so $u = 1$ or $u = -\tfrac12$.
3. Back-substitute the first root: $\sin x = 1 \Rightarrow x = \tfrac{\pi}{2}$ (the only solution in $[0, 2\pi)$).
4. Back-substitute the second: $\sin x = -\tfrac12$. Sine is negative in QIII and QIV; the reference angle is $\tfrac{\pi}{6}$, giving $x = \pi + \tfrac{\pi}{6} = \tfrac{7\pi}{6}$ and $x = 2\pi - \tfrac{\pi}{6} = \tfrac{11\pi}{6}$.
5. Collect: $x = \tfrac{\pi}{2},\ \tfrac{7\pi}{6},\ \tfrac{11\pi}{6}$ — three solutions.
6. Sanity check: substitute $x = \tfrac{7\pi}{6}$: $\sin = -\tfrac12$, so $2\cdot\tfrac14 - (-\tfrac12) - 1 = \tfrac12 + \tfrac12 - 1 = 0$. ✓ (No squaring was used here, so no extraneous roots can appear; when you do square, always verify each candidate this way.)

### Common Mistakes

- **General solution omissions**: Forgetting the ± or the period when writing the general solution from inverse trig leads to missing families of solutions.
- **Quadrant when solving equations**: After taking arcsin or arccos you must add the other angle in the correct quadrant where the function has the same value.
- **Calculator mode**: Solving trig equations numerically without ensuring degree/radian mode matches the problem statement.
- **Extraneous solutions**: Squaring both sides of a trig equation (to get sin² or similar) can introduce solutions that do not satisfy the original.
- **Not using identities first**: Trying to solve without reducing to single function leads to harder equations.
- **Forgetting to check solutions in original**: Especially after squaring or multiplying by expressions that could be zero.

## Trigonometric substitution

<!-- section: trig-sub -->

Trig substitution is a change of variable that turns an awkward square root of a quadratic into a clean trig function, using the Pythagorean identities. It is the payoff of everything above: inverse trig, identities, and reference triangles all combine here. This is a preview of a technique developed fully in integral calculus.

### Trigonometric Substitution (Preview)

Although more fully developed in calculus, trig substitution is the technique of writing x = a tan θ, x = a sin θ, or x = a sec θ to simplify expressions involving √(a² - x²), √(x² + a²), or √(x² - a²).

Each substitution matches one Pythagorean identity so the radical collapses to a single trig function: $\sqrt{a^2 - x^2}$ with $x = a\sin\theta$ uses $1 - \sin^2\theta = \cos^2\theta$; $\sqrt{x^2 + a^2}$ with $x = a\tan\theta$ uses $1 + \tan^2\theta = \sec^2\theta$; $\sqrt{x^2 - a^2}$ with $x = a\sec\theta$ uses $\sec^2\theta - 1 = \tan^2\theta$. After substitution the integral becomes easier, and back-substitution using inverse trig or a reference triangle recovers the answer in $x$. Choose $\theta$ in the standard range for the corresponding inverse function so the new trig factor is nonnegative and the square root simplifies without an absolute value; e.g. for the sine substitution take $\theta \in [-\tfrac{\pi}{2}, \tfrac{\pi}{2}]$, where $\cos\theta \ge 0$.

**ELI5**

- When something under a square root looks like a Pythagorean triple missing one leg, invent an angle whose trig ratios "name" the sides of that right triangle. The radical is just one side of the triangle in disguise, so replacing $x$ with a trig expression makes it collapse to a clean single function — and now you are integrating an ordinary sine or cosine instead of a stubborn root.

**Worked Example:**

**Evaluate $\displaystyle\int \frac{dx}{\sqrt{9 - x^2}}$.**

1. The form $\sqrt{a^2 - x^2}$ with $a = 3$ calls for $x = 3\sin\theta$, with $\theta \in [-\tfrac{\pi}{2}, \tfrac{\pi}{2}]$. Then $dx = 3\cos\theta\,d\theta$.
2. Simplify the radical: $\sqrt{9 - 9\sin^2\theta} = \sqrt{9\cos^2\theta} = 3\cos\theta$ (nonnegative because $\cos\theta \ge 0$ on the chosen range, so no absolute value is needed).
3. Substitute everything: $\displaystyle\int \frac{3\cos\theta\,d\theta}{3\cos\theta} = \int d\theta = \theta + C$.
4. Back-substitute: from $x = 3\sin\theta$ we get $\sin\theta = \tfrac{x}{3}$, so $\theta = \arcsin\tfrac{x}{3}$. Thus the integral is $\arcsin\tfrac{x}{3} + C$.
5. Sanity check by differentiating: $\tfrac{d}{dx}\arcsin\tfrac{x}{3} = \tfrac{1}{\sqrt{1 - (x/3)^2}}\cdot\tfrac13 = \tfrac{1}{3\sqrt{1 - x^2/9}} = \tfrac{1}{\sqrt{9 - x^2}}$, the original integrand. ✓

### Common Mistakes

- **Choosing the wrong sub for the radical form**: a²-x² -> sin; x²+a² -> tan; x²-a² -> sec.
- **Forgetting the dx in terms of dθ**: dx = a sec² dθ for tan sub etc; must substitute it too.
- **Not drawing the reference triangle for back-sub**: The triangle with opp=x, hyp=3 etc lets you express sinθ = x/3 etc without memorizing.
- **Assuming cos or tan always positive**: Choose the range of θ so the sub functions are positive in the interval, or use abs.
- **Leaving answer in θ**: Must back-sub to x (or arcsin(arctan etc)).
- **Forgetting +C in indefinite integral**: Always.
