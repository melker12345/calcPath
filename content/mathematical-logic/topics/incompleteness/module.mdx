# Incompleteness and Independence

Gödel's incompleteness theorems (1931) are among the most profound results in the foundations of mathematics. They show that any sufficiently strong consistent formal system for arithmetic is necessarily incomplete: there are true statements about the natural numbers that the system can never prove.

Later work (Cohen's forcing, 1963) showed that many important questions in set theory (most famously the Continuum Hypothesis) are independent of ZFC — neither provable nor refutable from the standard axioms.

## Gödel's First Incompleteness Theorem

<!-- section: godel1 -->

Gödel's first incompleteness theorem is one of the deepest results in the foundations of mathematics: it shows that no sufficiently powerful consistent formal system for arithmetic can be complete. There will always be true arithmetic statements that the system can neither prove nor disprove.

The hypotheses are crucial: the system must be consistent (otherwise it proves everything), it must be recursively axiomatizable (its axioms must be effectively listable), and it must be strong enough to express basic arithmetic (able to represent the recursive functions or at least Robinson arithmetic Q). Under those conditions one can construct, inside the system itself, a sentence that says "I am not provable in this system."

In this section you will learn the precise statement, the role of the diagonal lemma that produces self-referential sentences, why the Gödel sentence is true but unprovable, and how the second incompleteness theorem and forcing extend the story to consistency and independence.

**First Incompleteness Theorem**: Let $T$ be a consistent, recursively axiomatizable formal system that is strong enough to represent basic arithmetic (e.g., can interpret Robinson arithmetic Q or Peano arithmetic). Then there exists a sentence $\phi$ (the "Gödel sentence") such that:

- $T \nvdash \phi$
- $T \nvdash \neg\phi$

Moreover, if $T$ is sound (proves only true sentences), then $\phi$ is actually true (in the standard model $\mathbb{N}$).

The proof uses the **diagonal lemma** (fixed-point theorem): for any formula $\psi(x)$ there is a sentence $\phi$ such that $T \vdash \phi \leftrightarrow \psi(\ulcorner\phi\urcorner)$, where $\ulcorner\phi\urcorner$ is the Gödel number (code) of $\phi$.

:::intuition
Imagine a powerful but consistent book of rules for proving facts about numbers. Gödel shows you can construct a sentence that asserts its own unprovability within the system.

If the book could prove it, it would be proving something false (that it is provable when it isn't). If it could prove the negation, it would be inconsistent. Hence the sentence is true but unprovable inside the system.
:::

**Worked Example:** constructing and analyzing the Gödel sentence for PA.

We build the Gödel sentence step by step and then verify it is true-but-unprovable.

- **Step 1 — a provability predicate.** Assign to each formula and each finite sequence of formulas a numerical code (a "Gödel number"), so that syntax becomes arithmetic. Define $\text{Prov}_{PA}(y)$ to abbreviate the arithmetic formula "there exists a number $x$ such that $x$ codes a valid PA-proof whose last line has code $y$." Checking "$x$ codes a proof of $y$" is a bounded, purely syntactic check (each line is an axiom or follows from earlier lines by a rule), so the relation is primitive recursive and PA can represent it.

- **Step 2 — diagonalize.** Apply the diagonal lemma to the formula $\psi(y) \equiv \neg\,\text{Prov}_{PA}(y)$. The lemma hands us a sentence $\phi$ with
$$PA \vdash \phi \leftrightarrow \neg\,\text{Prov}_{PA}(\ulcorner\phi\urcorner).$$
Read aloud: $\phi$ says "there is no number coding a PA-proof of *me*."

- **Step 3 — $\phi$ is unprovable (needs only consistency).** Suppose $PA \vdash \phi$. Then some concrete number $n$ codes that proof, so $PA \vdash \text{Prov}_{PA}(\ulcorner\phi\urcorner)$ (the derivability condition D1). But the fixed point gives $PA \vdash \neg\,\text{Prov}_{PA}(\ulcorner\phi\urcorner)$, so $PA$ proves both a statement and its negation — $PA$ is inconsistent. Contrapositive: if $PA$ is consistent, $PA \nvdash \phi$.

- **Step 4 — $\neg\phi$ is unprovable (needs slightly more, e.g. soundness or $\omega$-consistency).** If $PA \vdash \neg\phi$, then by the fixed point $PA \vdash \text{Prov}_{PA}(\ulcorner\phi\urcorner)$, i.e. $PA$ claims a proof of $\phi$ exists. But by Step 3 no such proof exists, so $PA$ would be proving a false $\Sigma_1$ statement — impossible if $PA$ is sound (or, more weakly, $\omega$-consistent). Hence $PA \nvdash \neg\phi$.

- **Sanity check — is $\phi$ true?** By Step 3, $\phi$ genuinely has no PA-proof; therefore what $\phi$ *asserts* ("I have no PA-proof") is factually correct in the standard model $\mathbb{N}$. So $\phi$ is a true sentence that PA can neither prove nor refute. $\checkmark$

Note the asymmetry: unprovability of $\phi$ needs only consistency, while unprovability of $\neg\phi$ needs a soundness-type assumption. Rosser's trick modifies $\phi$ so that plain consistency suffices for both directions.

## Gödel's Second Incompleteness Theorem

<!-- section: godel2 -->

Intuitively, the second theorem is what you get by *formalizing the first theorem inside the system itself*. The first theorem's argument "if $T$ is consistent then $\phi$ is unprovable" is elementary enough that $T$ can carry it out; so $T$ proves "$\text{Con}(T) \to \neg\text{Prov}_T(\ulcorner\phi\urcorner)$", i.e. $T \vdash \text{Con}(T) \to \phi$. If $T$ could also prove $\text{Con}(T)$, it would then prove $\phi$ — contradicting the first theorem. So it cannot.

**Second Incompleteness Theorem**: Under the same assumptions on $T$ (consistent, recursively axiomatizable, strong enough to satisfy the Hilbert–Bernays–Löb derivability conditions), if $T$ is consistent then $T$ does not prove $\text{Con}(T)$ (its own consistency statement).

Here $\text{Con}(T)$ is the arithmetic sentence asserting that there is no number coding a proof of $0=1$ from the axioms of $T$.

The **Hilbert–Bernays–Löb derivability conditions** on the provability predicate $\text{Prov}_T$ are what make the formalization go through: (D1) if $T\vdash A$ then $T\vdash\text{Prov}_T(\ulcorner A\urcorner)$; (D2) $T\vdash \text{Prov}_T(\ulcorner A\to B\urcorner) \to (\text{Prov}_T(\ulcorner A\urcorner)\to\text{Prov}_T(\ulcorner B\urcorner))$; (D3) $T\vdash \text{Prov}_T(\ulcorner A\urcorner)\to\text{Prov}_T(\ulcorner\text{Prov}_T(\ulcorner A\urcorner)\urcorner)$.

:::intuition
Not only are there true-but-unprovable sentences; even the statement "this system will never prove something contradictory" cannot be proved inside the system itself (assuming it is consistent).

This dooms Hilbert's program of finding a finitary consistency proof for all of mathematics inside a weak system.
:::

**Worked Example:** deriving Gödel II from Gödel I.

Take $T = PA$ and let $\phi$ be the Gödel sentence from the previous section, satisfying $PA \vdash \phi \leftrightarrow \neg\,\text{Prov}_{PA}(\ulcorner\phi\urcorner)$.

- **Step 1 — formalize "$\phi$ is unprovable."** The first theorem's proof (Step 3 above) shows: consistency of $PA$ implies $\phi$ is unprovable. This argument is itself finitary, so PA can prove the formalized version
$$PA \vdash \text{Con}(PA) \to \neg\,\text{Prov}_{PA}(\ulcorner\phi\urcorner).$$

- **Step 2 — use the fixed point.** Since $PA \vdash \neg\,\text{Prov}_{PA}(\ulcorner\phi\urcorner) \leftrightarrow \phi$, substitute to get $PA \vdash \text{Con}(PA) \to \phi$.

- **Step 3 — suppose PA proved its own consistency.** If $PA \vdash \text{Con}(PA)$, then by Step 2 and modus ponens $PA \vdash \phi$.

- **Step 4 — contradiction.** But the first theorem says $PA \nvdash \phi$ (assuming $PA$ consistent). So the assumption in Step 3 is impossible: a consistent $PA$ does **not** prove $\text{Con}(PA)$.

- **Sanity check.** $\text{Con}(PA)$ is *true* in the standard model (PA really is consistent), yet unprovable in PA — so it is another concrete true-but-unprovable arithmetic sentence, exactly as the first theorem predicts. $\checkmark$

This does not mean PA's consistency is unknowable: Gentzen gave a genuine consistency proof for PA, but it uses transfinite induction up to the ordinal $\varepsilon_0$, a principle stronger than anything PA can carry out internally — consistent with Gödel II rather than contradicting it.

## Proof Theory and Ordinal Analysis

<!-- section: proof-theory -->

Before the definitions, the guiding idea: Gödel II says a theory cannot prove its own consistency, but a *stronger* principle can. Proof theory pins down exactly *how much* extra strength is needed, and packages that answer as a single ordinal. Two theories can then be compared even when neither can interpret the other.

**Proof theory** studies the strength of formal systems by measuring the "proof-theoretic ordinals" needed to prove their consistency.

- Gentzen: $\text{Con}(\text{PA})$ is equivalent (over a weak base theory such as primitive recursive arithmetic) to the well-foundedness of the ordinal notation for $\varepsilon_0$, i.e. transfinite induction up to $\varepsilon_0$.
- Stronger systems (second-order arithmetic, set theory) have larger proof-theoretic ordinals.
- **Ordinal analysis** assigns to each theory the *smallest recursive ordinal* $\alpha$ such that transfinite induction up to $\alpha$, formalized over a weak base, proves the theory's consistency. (Recursive = the ordinal has a computable notation system; this is what lets a finitary base theory even talk about it.)

A key engine behind these results is **cut elimination** (Gentzen's *Hauptsatz*): in the sequent calculus, every proof can be transformed into a *cut-free* proof — one that uses no lemmas, only building up the final statement from its subformulas. Cut-free proofs have the **subformula property**: every formula appearing in the proof is a subformula of the end-sequent. A proof of the empty sequent (a contradiction) could therefore only arise from a contradictory axiom. Bounding the ordinal "height" of cut-elimination for a theory is what yields its consistency proof and its proof-theoretic ordinal.

:::intuition
Think of each theory as a tower, and its proof-theoretic ordinal as the tower's *height*. You cannot certify a tower is sound while standing on it — you need a taller ladder. The ordinal tells you the exact length of ladder required: PA needs a ladder of length $\varepsilon_0$, and no shorter one will reach.

Because every theory gets tagged with a height, you can rank theories on one shared yardstick even when neither can "see inside" the other.
:::

**Worked Example:** what $\varepsilon_0$ is, and how Gentzen uses it.

- **Step 1 — build the ordinal.** Start from $\omega$ (the first infinite ordinal) and repeatedly exponentiate base $\omega$:
$$\omega,\quad \omega^{\omega},\quad \omega^{\omega^{\omega}},\quad \omega^{\omega^{\omega^{\omega}}},\ \dots$$
Each term is vastly larger than the previous, yet each is still a countable ordinal. The limit (supremum) of this sequence is $\varepsilon_0$.

- **Step 2 — the fixed-point description.** $\varepsilon_0$ is the *smallest* ordinal $\alpha$ with $\omega^{\alpha} = \alpha$ — the first fixed point of the map $\alpha \mapsto \omega^{\alpha}$. (Check: each finite tower is strictly below its own $\omega$-exponential, so the fixed point can only be reached in the limit — exactly at $\varepsilon_0$.) It is countable and recursive: there is a computable way to write down and compare ordinal notations below it.

- **Step 3 — Gentzen's assignment.** Gentzen attaches to every PA-proof an ordinal $< \varepsilon_0$, and gives a reduction procedure (eliminating cuts) that, applied to a purported PA-proof of $0=1$, produces another such proof with a *strictly smaller* ordinal.

- **Step 4 — the contradiction.** If a PA-proof of $0=1$ existed, iterating Step 3 would generate an infinite strictly-decreasing sequence of ordinals below $\varepsilon_0$. But transfinite induction up to $\varepsilon_0$ says no such infinite descending sequence exists (well-foundedness). Contradiction, so no PA-proof of $0=1$ exists — that is, $\text{Con}(PA)$.

- **Sanity check — consistent with Gödel II.** The proof needs induction up to $\varepsilon_0$, which PA cannot prove for its *own* ordinal notation. So PA does not thereby prove its own consistency; the extra strength lives precisely in that one transfinite-induction principle. And $\varepsilon_0$ is the *least* ordinal that works, which is exactly why it is called the proof-theoretic ordinal of PA. $\checkmark$

## Forcing and Independence Results

<!-- section: forcing -->

To show a statement $S$ is **independent** of ZFC — neither provable nor refutable — you exhibit two models of ZFC: one satisfying $S$, one satisfying $\neg S$. (Recall the **Continuum Hypothesis** CH: $2^{\aleph_0} = \aleph_1$, i.e. there is no set whose size is strictly between the naturals and the reals.) One direction is often handled by an inner model, the other by forcing.

**Forcing** (Cohen 1963) is a technique for building new models of set theory from old ones by "adding generic sets" while preserving the truth of the axioms of ZFC. Starting from a model $M$ (the *ground model*), one chooses a partial order $\mathbb{P}$ of "forcing conditions" (finite approximations to the object being added) and a *generic filter* $G$ meeting every dense set of $M$; the extension $M[G]$ is the smallest model of ZFC containing $M$ and $G$.

Using forcing one can prove the independence of CH: there exist models of ZFC where CH holds and models where it does not.

Many other statements are independent: the Axiom of Choice (relative to ZF), existence of measurable cardinals, etc.

**Inner models** are transitive sub-universes containing all the ordinals and definable inside the ambient model. Gödel's constructible universe $L$ — the sets you get by iterating *definable* power sets along the ordinals — is the canonical example; $L$ satisfies AC and even GCH, so it witnesses that CH is *consistent* with ZFC.

:::intuition
Forcing is like carefully "adding new real numbers" (or other sets) to a model of set theory in a controlled way that doesn't break the ZFC axioms. Different choices of what you add can make the continuum large or small.

It shows that ZFC by itself does not decide many natural questions about sets; you need additional axioms (large cardinals, determinacy, forcing axioms, etc.) to settle them.
:::

**Worked Example:** forcing $\neg$CH, both directions of independence.

Goal: show CH is independent of ZFC. We assume $\text{Con}(ZFC)$, so a (countable, transitive) model $M \models ZFC$ exists; arrange $M \models GCH$.

- **Step 1 — the two-part strategy.** We need a model where CH holds and one where it fails. The first is free: $L$ (or our GCH ground model $M$) already satisfies CH. So all the work is in producing a model of $\neg$CH.

- **Step 2 — choose the forcing.** Let $\kappa = (\aleph_2)^M$. Take $\mathbb{P}$ = finite partial functions from $\kappa \times \omega$ to $\{0,1\}$, ordered by reverse inclusion. Each generic $G$ assembles, for every $\alpha < \kappa$, a distinct new function $\omega \to \{0,1\}$ — a new *Cohen real*. So $M[G]$ gains $\kappa$ many new reals.

- **Step 3 — count the continuum.** These $\kappa$ reals are distinct, so in $M[G]$ we have $2^{\aleph_0} \ge \kappa = \aleph_2^M$.

- **Step 4 — preserve cardinals.** $\mathbb{P}$ has the countable chain condition (any antichain is countable, because conditions are finite). The ccc guarantees forcing collapses no cardinals and adds no new cofinalities, so $\aleph_1^M$ and $\aleph_2^M$ are still $\aleph_1$ and $\aleph_2$ in $M[G]$. This is the crucial step: without cardinal preservation, "adding $\aleph_2$ reals" would be meaningless if $\aleph_2$ itself changed.

- **Step 5 — conclude $\neg$CH.** In $M[G]$: $2^{\aleph_0} \ge \aleph_2 > \aleph_1$, so CH fails. (A counting of nice names shows $2^{\aleph_0} = \aleph_2$ exactly, but $\ge \aleph_2$ already refutes CH.)

- **Sanity check.** We now have $M \models ZFC + CH$ and $M[G] \models ZFC + \neg CH$, both from the same assumption $\text{Con}(ZFC)$. Neither $CH$ nor $\neg CH$ can be a theorem of ZFC (a theorem holds in *every* model), so CH is independent. $\checkmark$

## Common Mistakes

- **Crucial hypotheses for incompleteness:** Misstating the first incompleteness theorem as "there are true statements that cannot be proved" omits the requirements. The system must be consistent, recursively axiomatizable, and able to express enough arithmetic.

- **Self-reference is not essential:** Thinking incompleteness applies only to "weird" self-referential sentences is mistaken. While the Gödel sentence is self-referential, incompleteness propagates to many "ordinary" mathematical statements via interpretability (e.g., consistency statements, combinatorial principles).

- **Knowing consistency is still possible:** Believing that the second incompleteness theorem says "we can never know if mathematics is consistent" is wrong. We have good evidence (from stronger theories or from believing in the standard model) even if the weak theory cannot prove its own consistency.

- **Independence is not absolute:** Confusing "independent of ZFC" with "undecidable in principle" or "meaningless" is an error. Many independent statements become decided once we adopt additional natural axioms.

- **Research on CH continues:** Assuming that because CH is independent, set theorists have "given up" on the continuum problem is incorrect. Active research continues on which additional axioms best capture "the true" universe of sets (large cardinals, forcing axioms, etc.).

- **Many unprovable truths exist:** Thinking Gödel sentences are the only unprovable truths is false. There are infinitely many, and the set of theorems is a proper subset of the truths in the standard model.
