# Propositional Logic

Propositional logic (also called sentential logic or propositional calculus) is the simplest layer of formal logic. It studies how we combine whole statements ("propositions") using connectives such as "and", "or", "not", "implies", and "if and only if". Unlike predicate logic, it does not look inside the statements at objects or quantifiers; a proposition is treated as an indivisible atom that is either true or false.

This system gives us precise tools to analyze arguments, build truth tables, detect tautologies, and decide satisfiability. Every proof in mathematics ultimately rests on valid propositional reasoning, and computer science uses it for circuit design, automated reasoning, and SAT solvers.

## Propositions and Connectives

<!-- section: connectives -->

A **proposition** is a declarative sentence that is either true or false, but not both. Examples: "2 + 2 = 4", "It is raining", "Every even integer greater than 2 is the sum of two primes". We denote atomic propositions by lowercase letters: $p$, $q$, $r$, ...

The five standard connectives are:

- Negation: $\neg p$ ("not p") — true when $p$ is false.
- Conjunction: $p \land q$ ("p and q") — holds only when both are true.
- Disjunction: $p \lor q$ ("p or q", inclusive) — true when at least one true.
- Implication: $p \to q$ ("if p then q") — false only when $p$ true and $q$ false.
- Biconditional: $p \leftrightarrow q$ ("p if and only if q") — true when both same truth value.

Each has a precise truth table. The implication $p \to q$ is material implication; it does not require causation in natural language.

A connective is called **binary** if it takes two inputs (like $\land$, $\lor$, $\to$, $\leftrightarrow$) and **unary** if it takes one (like $\neg$). Since two atoms have $2^2 = 4$ input rows and each row can independently map to T or F, there are exactly $2^4 = 16$ possible binary connectives; only a handful have standard names. A set of connectives is **functionally complete** if every one of those truth functions can be expressed using only that set. For example $\{\neg, \land\}$ is functionally complete (we recover $\lor$ from De Morgan and $\to$ from $\neg p \lor q$), whereas $\{\land, \lor\}$ is not, because with no negation you can never turn an all-true row false.

:::intuition
Think of propositions as light switches: on (true) or off (false). Connectives are wiring diagrams: AND requires both switches on, OR needs at least one, NOT flips the switch, IMPLIES is a one-way safety: if the first is on, the second must be too (otherwise the circuit "fails").

Everyday: "If it rains, the ground is wet" is an implication. It is false only on the day it rains but the ground stays dry.
:::

:::example
Build the truth table for $p \to q$ (implication).
:::

:::solution
Columns for each subexpression, rows for all combinations:

| $p$ | $q$ | $p \to q$ |
|-----|-----|-----------|
| T   | T   | T         |
| T   | F   | F         |
| F   | T   | T         |
| F   | F   | T         |

Only one falsifying case (where the implication is false): when the antecedent $p$ is true but the consequent $q$ is false. All other rows are true. This shows why "false implies anything" is vacuously true.
:::

:::example
Show that $\{\neg, \land\}$ can express disjunction $p \lor q$.
:::

:::solution
We want a formula using only $\neg$ and $\land$ whose truth table matches $p \lor q$ (true unless both are false). Step 2: By De Morgan, $\neg(\neg p \land \neg q) \equiv p \lor q$. Step 3: Verify by table — the only row where $p \lor q$ is false is $p = q = \text{F}$:

| $p$ | $q$ | $\neg p \land \neg q$ | $\neg(\neg p \land \neg q)$ | $p \lor q$ |
|-----|-----|-----------------------|------------------------------|------------|
| T   | T   | F                     | T                            | T          |
| T   | F   | F                     | T                            | T          |
| F   | T   | F                     | T                            | T          |
| F   | F   | T                     | F                            | F          |

The last two columns agree in every row, so the construction is correct. Since $\lor$ (and, similarly, $\to$ and $\leftrightarrow$) can be rebuilt this way, $\{\neg, \land\}$ is functionally complete.
:::

## Truth Tables and Tautologies

<!-- section: tautologies -->

A **truth table** enumerates all $2^n$ possible assignments of truth values to $n$ atomic propositions and computes the value of the compound formula under each.

A formula is a **tautology** (or logically valid) if it evaluates to true no matter the assignment of truth values. A **contradiction** is false under every assignment. A **contingent** formula is true under some and false under others. These three categories are exhaustive and mutually exclusive: every formula is exactly one of them.

To check whether a formula is a tautology you can build the full table, or use the faster **falsification shortcut**: *assume* the formula is false and try to solve for a consistent truth assignment. If that attempt forces a contradiction (some atom would have to be both true and false), no falsifying assignment exists, so the formula is a tautology. If instead you find a consistent assignment, that assignment is an explicit counterexample proving it is *not* a tautology.

:::intuition
A tautology is a statement that is "always safe", no matter what the facts are. "It is raining or it is not raining" is true even if you have no weather report. Tautologies are the logical skeleton that every correct argument must preserve.

Building a truth table is like testing every possible combination of light-switch positions to see if the final bulb always lights.
:::

:::example
Prove that $p \lor \neg p$ is a tautology (law of excluded middle).
:::

:::solution
Build the table for the two possible assignments:

| $p$ | $\neg p$ | $p \lor \neg p$ |
|-----|----------|-----------------|
| T   | F        | T               |
| F   | T        | T               |

The formula evaluates to T in both rows, hence it is a tautology (always true, no matter the truth value of p). This is a foundational law in classical logic.
:::

:::example
Show that hypothetical syllogism $(p \to q) \land (q \to r) \to (p \to r)$ is a tautology, using the falsification shortcut instead of writing all $2^3 = 8$ rows.
:::

:::solution
1. Assume the whole implication is false. An implication is false only when its antecedent is true and its consequent is false, so we need $(p \to q) \land (q \to r)$ true and $(p \to r)$ false. Step 2: For $(p \to r)$ to be false we need $p = \text{T}$ and $r = \text{F}$. Step 3: The antecedent being true means both $p \to q$ and $q \to r$ are true. Since $p = \text{T}$, $p \to q$ true forces $q = \text{T}$. Step 4: But then $q \to r$ is $\text{T} \to \text{F} = \text{F}$, contradicting that $q \to r$ is true. Step 5: The assumption "the formula is false" leads to a contradiction, so no falsifying assignment exists. Hence the formula is a tautology. Sanity check: this is exactly transitivity of implication — "if $p$ forces $q$ and $q$ forces $r$, then $p$ forces $r$" — which is what we expect to hold.
:::

## Satisfiability and Validity

<!-- section: satisfiability -->

A formula (or set of formulas) is **satisfiable** if there is some truth assignment making the whole thing true. It is **valid** (a tautology) if it comes out true for every possible assignment. Unsatisfiable formulas are contradictions.

The **satisfiability problem** (SAT) asks whether a given formula in conjunctive normal form is satisfiable. It is NP-complete, yet central to verification, AI planning, and hardware design.

Two formulas are **logically equivalent** if they have identical truth tables (same value under every assignment). We write $p \equiv q$. A useful bridge between these ideas: a formula is a tautology exactly when its negation is unsatisfiable, and it is satisfiable exactly when its negation is not a tautology. This duality is why SAT solvers can also answer validity questions — to test whether $\varphi$ is valid, ask whether $\neg\varphi$ is satisfiable and expect the answer "no".

:::intuition
Satisfiable = there is some way the world could be that makes your claim true. "It is Tuesday and raining" is satisfiable (just wait for a rainy Tuesday).

Valid = true no matter how the world is. "It is Tuesday or it is not Tuesday" cannot be false.

A detective's hypothesis is satisfiable if consistent with evidence; a valid deduction is forced by the evidence alone.
:::

:::example
Is $(p \to q) \land (q \to r) \land p \land \neg r$ satisfiable?
:::

:::solution
1. A conjunction is true only if every conjunct is true, so assume all four hold and try to build a consistent assignment. Step 2: The last two conjuncts, $p$ and $\neg r$, force $p = \text{T}$ and $r = \text{F}$. Step 3: With $p = \text{T}$, the conjunct $p \to q$ (which must be true) forces $q = \text{T}$, since $\text{T} \to \text{F}$ would be false. Step 4: With $q = \text{T}$, the conjunct $q \to r$ must be true, but $q \to r = \text{T} \to \text{F} = \text{F}$. Step 5: Contradiction — we needed $q \to r$ true but it came out false. No assignment satisfies all conjuncts, so the formula is **unsatisfiable**. Sanity check: the four conjuncts say "$p$ leads to $q$, $q$ leads to $r$, $p$ holds, but $r$ does not" — chaining the first three forces $r$, clashing with the fourth, exactly as the algebra found.
:::

:::example
Is the clause set $\{p \lor q,\; \neg p \lor r,\; \neg q \lor \neg r\}$ satisfiable?
:::

:::solution
1. Rather than assume unsatisfiability, we hunt for one model by case analysis. Try $p = \text{T}$. Step 2: The second clause $\neg p \lor r$ becomes $\text{F} \lor r$, so it needs $r = \text{T}$. Step 3: The third clause $\neg q \lor \neg r$ becomes $\neg q \lor \text{F}$, so it needs $\neg q = \text{T}$, i.e. $q = \text{F}$. Step 4: Check the first clause $p \lor q = \text{T} \lor \text{F} = \text{T}$ — satisfied. Step 5: The assignment $p = \text{T},\, q = \text{F},\, r = \text{T}$ makes all three clauses true, so the set is **satisfiable**. Finding a single satisfying assignment (a "witness") is enough; we do not need to inspect the other rows.
:::

## Logical Equivalence and Normal Forms

<!-- section: normal-forms -->

A **literal** is an atom or its negation ($p$ or $\neg p$). A **clause** is a disjunction of literals, e.g. $\neg p \lor q \lor r$. Every propositional formula is logically equivalent to one in **disjunctive normal form** (DNF: an OR of ANDs of literals) and one in **conjunctive normal form** (CNF: an AND of ORs of literals — that is, an AND of clauses). Existence is guaranteed: from a truth table you can read off a DNF (one AND-term per true row) or a CNF (one clause per false row), so no formula is ever "unconvertible". The forms are not unique, though — many equivalent CNFs exist for the same formula.

Useful equivalences (replace subformulas):

- Double negation: $\neg\neg p \equiv p$
- De Morgan: $\neg(p \land q) \equiv \neg p \lor \neg q$; $\neg(p \lor q) \equiv \neg p \land \neg q$
- Implication elimination: $p \to q \equiv \neg p \lor q$
- Distribution, commutativity, associativity, idempotence, etc.

:::intuition
Normal forms are "standardized recipes". CNF is like a checklist of requirements that must all hold ("AND of rules"); each rule is an "OR of allowed options". SAT solvers love CNF because it is easy to plug in values and see if any clause goes false.

Converting is like algebraic simplification but for logic: you expand and cancel until only the two allowed connectives remain in the right pattern.
:::

:::example
Convert $p \to (q \land r)$ to CNF.
:::

:::solution
1. Eliminate the implication using $p \to q \equiv \neg p \lor q$: this gives $\neg p \lor (q \land r)$. Step 2: Push the disjunction inside the conjunction with the distributive law $a \lor (b \land c) \equiv (a \lor b) \land (a \lor c)$, taking $a = \neg p$, $b = q$, $c = r$: this yields $(\neg p \lor q) \land (\neg p \lor r)$. Step 3: Both parts are clauses (disjunctions of literals) joined by AND, so this is CNF with two clauses. Sanity check: the original is false only when $p = \text{T}$ and $q \land r = \text{F}$; the CNF is false exactly when $\neg p \lor q$ or $\neg p \lor r$ is false, i.e. when $p = \text{T}$ and $q = \text{F}$, or $p = \text{T}$ and $r = \text{F}$ — the same set of falsifying rows.
:::

:::example
Convert $\neg(p \leftrightarrow q)$ to CNF.
:::

:::solution
1. Expand the biconditional. $p \leftrightarrow q$ is true when $p$ and $q$ share a truth value, so $p \leftrightarrow q \equiv (p \land q) \lor (\neg p \land \neg q)$. Step 2: Negate both sides and apply De Morgan to the outer OR: $\neg\big((p \land q) \lor (\neg p \land \neg q)\big) \equiv \neg(p \land q) \land \neg(\neg p \land \neg q)$. Step 3: Apply De Morgan inside each factor: $\neg(p \land q) \equiv \neg p \lor \neg q$, and $\neg(\neg p \land \neg q) \equiv p \lor q$ (using double negation). Step 4: Combine: $\neg(p \leftrightarrow q) \equiv (\neg p \lor \neg q) \land (p \lor q)$, a CNF of two clauses. Sanity check: $\neg(p \leftrightarrow q)$ is exclusive-or, true exactly when $p$ and $q$ differ; the clause $p \lor q$ rules out both-false and $\neg p \lor \neg q$ rules out both-true, leaving precisely the two "differ" rows.
:::

## Common Mistakes

- **Misreading implication:** The formula $p \to q$ is true whenever $p$ is false, regardless of $q$. This is the source of many vacuous-truth confusions; it does not mean "causes" or English "only if".

- **Affirming the consequent:** From $p \to q$ and $q$, one cannot conclude the antecedent. This inference is invalid (see truth table: when the antecedent is false and consequent true, the implication holds).

- **Denying the antecedent:** From $p \to q$ and $\neg p$, one cannot conclude $\neg q$. This inference is also invalid.

- **Confusing conjunction and disjunction:** "and/or" ambiguity in English often leads to mistakes when confusing $\land$ with $\lor$.

- **Exclusive versus inclusive or:** Most math uses inclusive $\lor$ (true if at least one is true).

- **Partial checks for tautologies:** You must check all $2^n$ rows; partial checks are insufficient.

- **Not provable versus false:** In pure propositional logic (no extra axioms), many contingent statements are neither provable nor disprovable.
