# Set Theory as a First-Order Theory

Every other chapter of this subject studies a logical apparatus — connectives, quantifiers, deduction, structures, computation — and tests it on small examples. This chapter turns that apparatus on the largest object it has: the axiom system that the rest of mathematics is written in.

The move is easy to describe and hard to absorb. ZFC is a list of *sentences* in a first-order language with one binary relation symbol, $\in$. That is all it is. It is not a description of a universe of sets, any more than the group axioms are a description of a particular group; it is a constraint, and the things satisfying the constraint are its models. Once that reading is taken seriously, the questions of this chapter become ordinary model theory: which sentences follow from the list, what the models look like, when two models agree about a formula, and what a theory of this strength can prove about theories of this strength.

The payoff is that several facts that look mystical from inside mathematics become routine. A countable model of set theory contains a set it believes is uncountable, and no contradiction follows. The continuum hypothesis has no truth value determined by ZFC, for the same reason commutativity has none determined by the group axioms. ZFC needs infinitely many axioms and cannot be trimmed to finitely many. Each of these is a statement about a theory and its models, provable with the tools of the chapters *Model Theory*, *Formal Systems* and *Incompleteness*.

:::note[Scope, and where the set theory itself lives]
The mathematics *of* sets — the axioms one at a time and what each builds, ordinal and cardinal arithmetic, the alephs, Zorn's lemma and the other equivalents of choice, the construction of $L$, forcing posets and generic filters — is the subject **Set Theory**, whose chapters *Naive Set Theory*, *ZFC Axioms*, *Ordinals & Cardinals*, *The Axiom of Choice*, *Independence & Forcing* and *Advanced Set Theory* treat it at length. This chapter assumes those results and studies ZFC *as a theory*: schemas, relativisation, absoluteness, reflection, models, and independence as a model-theoretic phenomenon. Where a set-theoretic fact is needed it is stated and attributed, not re-derived.
:::

Throughout, $\mathcal{L}_\in$ is the language of set theory, $V$ denotes the universe of all sets, $\mathrm{Ord}$ the class of ordinals, $V_\alpha$ the levels of the cumulative hierarchy, and $\operatorname{Con}(T)$ the arithmetical sentence asserting that the theory $T$ proves no contradiction. Lower-case Greek $\varphi, \psi, \chi$ always denote formulas; upper-case $M, N$ denote models or classes.

## ZFC as a List of Sentences

<!-- section: zfc -->

A first-order theory is a set of sentences in a fixed language, and everything a logician asks about ZFC is asked about that set of sentences. So the first job is to see the axioms written as formulas rather than described in English — because two of them are not formulas at all.

:::definition[The theory ZFC]{#zfc-theory}
$\mathcal{L}_\in$ is the first-order language whose only non-logical symbol is the binary relation symbol $\in$; its atomic formulas are $x \in y$ and $x = y$. **ZFC** is the $\mathcal{L}_\in$-theory consisting of the sentences

$$\text{Extensionality},\ \text{Pairing},\ \text{Union},\ \text{Power Set},\ \text{Infinity},\ \text{Foundation},\ \text{Choice},$$

together with every instance of the **Separation** and **Replacement** schemas. **ZF** is ZFC without Choice, and $\mathrm{ZFC}^-$ is ZFC without Power Set.
:::

Written out, Extensionality and Foundation are single sentences of a few symbols each:

$$\forall x\, \forall y\, \bigl(\forall z\,(z \in x \leftrightarrow z \in y) \to x = y\bigr),$$

$$\forall x\, \bigl(\exists y\,(y \in x) \to \exists y\,(y \in x \wedge \neg\exists z\,(z \in y \wedge z \in x))\bigr).$$

There is no symbol for $\emptyset$, $\cup$, $\mathcal{P}$ or $\omega$ anywhere in the language. Each of those is an abbreviation licensed by an existence axiom together with a uniqueness theorem proved from Extensionality, exactly as the chapter *ZFC Axioms* sets out. For a logician the point of the austerity is that the syntax stays finite and checkable: one can ask whether a string is a formula, whether a finite list of formulas is a proof, and — crucially for Gödel's theorems — whether a string is an axiom.

:::definition[Axiom schema]{#schema}
An **axiom schema** is a template containing a syntactic parameter, together with the rule that every result of substituting an $\mathcal{L}_\in$-formula for that parameter is an axiom. **Separation** is the schema whose instance for a formula $\varphi(x, \bar{p})$, in which $y$ is not free, is

$$\forall \bar{p}\, \forall a\, \exists y\, \forall x\,\bigl(x \in y \leftrightarrow (x \in a \wedge \varphi(x,\bar{p}))\bigr),$$

and **Replacement** is the schema whose instance for $\varphi(x,y,\bar{p})$ is

$$\forall \bar{p}\, \forall a\,\Bigl(\forall x \in a\, \exists! y\, \varphi(x,y,\bar{p}) \to \exists b\, \forall x \in a\, \exists y \in b\; \varphi(x,y,\bar{p})\Bigr).$$
:::

The parameters $\bar{p}$ are not decoration. Without them one could not separate $\{x \in a : x \in p\}$ for an arbitrary set $p$, and the resulting theory would be far weaker than intended.

:::intuition
A schema is a machine that emits axioms, not an axiom. The English sentence "for every property, the sub-collection of $a$ with that property is a set" quantifies over properties, and first-order logic has no variables ranging over formulas — its quantifiers range over the objects of the structure, which here are sets. So the quantification is pushed out of the object language into the metalanguage: instead of one sentence about all formulas, we take infinitely many sentences, one per formula, and the infinitude is managed by a rule anyone can check mechanically.
:::

:::pitfall
"Infinitely many axioms" does not mean "not a legitimate theory". What Gödel's theorems and every proof-theoretic argument require is that the axiom set be **effectively axiomatised** — that some algorithm decides whether a given sentence is an axiom. Separation and Replacement pass that test, since recognising an instance is a parsing problem. A theory axiomatised by *all true arithmetic sentences* is the kind that fails it.
:::

Because the two schemas overlap, the list above is redundant, and seeing exactly how is a useful exercise in reading an instance.

:::theorem[Separation is derivable from Replacement]{#separation-from-replacement}
Over the remaining axioms of ZF, every instance of Separation follows from an instance of Replacement.
:::

:::proof
Fix $\varphi(x,\bar{p})$ and a set $a$, and let

$$\psi(x,y,\bar p) \ \equiv\ \bigl(\varphi(x,\bar p) \wedge y = \{x\}\bigr) \vee \bigl(\neg\varphi(x,\bar p) \wedge y = \emptyset\bigr),$$

where $y = \{x\}$ and $y = \emptyset$ abbreviate their $\Delta_0$ definitions, so that $\psi$ is a genuine $\mathcal{L}_\in$-formula. It is functional on $a$: for each $x \in a$ exactly one $y$ answers to it, namely the singleton $\{x\}$ when $\varphi(x,\bar p)$ holds and $\emptyset$ when it fails, and Pairing guarantees the singleton exists. The instance of Replacement for $\psi$ therefore yields a set

$$b = \bigl\{\,\{x\} : x \in a,\ \varphi(x,\bar p)\,\bigr\} \cup \{\emptyset\}$$

— the second term present only if some $x \in a$ fails $\varphi$. Applying Union to $b$ gives

$$\bigcup b = \{x \in a : \varphi(x,\bar p)\},$$

since each singleton contributes its one element and $\emptyset$ contributes nothing. That is the conclusion of the Separation instance for $\varphi$, and the argument used only Pairing, Union and one instance of Replacement.
:::

Separation is nevertheless listed, for two reasons a logician cares about. First, the subtheory of ZF with Replacement deleted and Separation retained — **Zermelo set theory**, written Z — is a genuinely different and strictly weaker theory, and one wants a name for it; the last section of this chapter exhibits a model of it. Second, keeping Separation separate lets one calibrate which instances an argument actually needs, which is what makes fine-grained results such as "this theorem uses only $\Delta_0$-Separation" statable.

:::example[Reading a single instance]
Write the instance of Replacement that proves $\{ \mathcal{P}(x) : x \in a \}$ is a set, and say which instance of Separation the same formula gives.
:::

:::solution
1. Let $\varphi(x,y)$ be $\forall z\,(z \in y \leftrightarrow \forall w\,(w \in z \to w \in x))$, which says "$y$ is the set of all subsets of $x$".
2. Power Set gives existence of such a $y$ for each $x$, and Extensionality gives uniqueness, so $\forall x \in a\,\exists! y\,\varphi(x,y)$. That is the hypothesis of the Replacement instance for this $\varphi$, and its conclusion hands us the set $\{\mathcal{P}(x) : x \in a\}$.
3. The Separation instance for the formula $\exists u \in a\,\varphi(u,x)$ carves the same collection out of any set already known to contain it.
4. A different $\varphi$ gives a *different axiom*. There is no single sentence of $\mathcal{L}_\in$ from which both instances follow uniformly; the uniformity lives only in the template.
:::

The schemas are not a presentational convenience that a cleverer axiomatisation could remove. That is a theorem, and one of the cleanest illustrations in mathematics of the second incompleteness theorem doing real work.

:::theorem[ZFC is not finitely axiomatisable]{#not-finitely-axiomatisable}
If ZFC is consistent, then there is no finite set $T$ of $\mathcal{L}_\in$-sentences with exactly the same consequences as ZFC.
:::

:::proof[Sketch]
Suppose $T$ were such a finite set, and let $\tau$ be the conjunction of its members, so that ZFC $\vdash \tau$ and $\tau \vdash \sigma$ for every axiom $\sigma$ of ZFC. The Reflection Principle, proved in the section *Reflecting the Universe in a Set*, says that for each finite list of formulas ZFC proves some level $V_\alpha$ agrees with $V$ about all of them; applied to the conjuncts of $\tau$ it yields ZFC $\vdash \exists\alpha\,(V_\alpha \models \tau)$. But $V_\alpha$ is a *set*, so this says ZFC proves that $\tau$ has a model, and the soundness theorem — formalisable in ZFC for set-sized structures — gives ZFC $\vdash \operatorname{Con}(\tau)$. Since $\tau$ axiomatises ZFC, ZFC proves $\operatorname{Con}(\tau) \to \operatorname{Con}(\mathrm{ZFC})$, so ZFC $\vdash \operatorname{Con}(\mathrm{ZFC})$, contradicting Gödel's second incompleteness theorem from the chapter *Incompleteness*. The argument rests on two imported results: reflection, proved below, and Gödel's second theorem, whose proof is not reproduced here.
:::

:::remark[NBG, and what is really going on]
Von Neumann–Bernays–Gödel class theory **is** finitely axiomatisable, and it proves exactly the same $\mathcal{L}_\in$-sentences as ZFC — it is a conservative extension. There is no paradox: NBG has variables for classes, so the single sentence "for every class $F$ that is a function and every set $a$, the image $F[a]$ is a set" does the work of the whole Replacement schema. The reflection argument fails for NBG because the reflecting object would have to satisfy the class quantifiers too. The lesson is that finite axiomatisability is a property of a *presentation in a language*, not of a body of mathematics.
:::

:::summary
ZFC is an effectively axiomatised, infinite set of $\mathcal{L}_\in$-sentences. Separation and Replacement are schemas because first-order quantifiers range over sets and not over formulas; Replacement subsumes Separation instance by instance; and the infinitude is unavoidable, since a finite axiomatisation would let ZFC prove its own consistency.
:::

## Models of ZFC and the Skolem Paradox

<!-- section: models-of-zfc -->

A model of ZFC is nothing more exotic than a structure for a language with one binary relation, in the sense of the chapter *Model Theory*: a non-empty domain $M$ together with a binary relation $E \subseteq M \times M$ interpreting $\in$, such that every axiom comes out true under the usual satisfaction clauses. The elements of $M$ need not be sets in any prior sense, and $E$ need not be real membership.

:::definition[Model, standard model, transitive model]{#model-defs}
An $\mathcal{L}_\in$-structure is a pair $(M, E)$ with $E$ a binary relation on the non-empty set $M$. It is **standard** (or **well-founded**) if $E$ is genuine membership restricted to $M$ and is well-founded, and **transitive** if in addition $M$ is a transitive set: $x \in y \in M$ implies $x \in M$. For transitive $M$ we write $M \models \varphi$ with $E = {\in}$ understood.
:::

Transitivity is the condition that makes a model *honest about its elements*: what $M$ believes are the members of one of its sets really are its members, all of them. Nearly every theorem in the rest of this chapter has "transitive" in its hypothesis for that reason, and the section *Relativisation and Absoluteness* says exactly which beliefs it protects.

The first thing to settle is whether there are any models at all, and here the metatheory is delicate.

:::theorem[ZFC cannot produce a model of itself]{#no-provable-model}
If ZFC is consistent, then ZFC does not prove the sentence "there exist a set $M$ and a relation $E$ on $M$ with $(M,E) \models \mathrm{ZFC}$".
:::

:::proof
Working in ZFC, satisfaction for a *set*-sized structure is definable: there is an $\mathcal{L}_\in$-formula $\mathrm{Sat}(M,E,\ulcorner\varphi\urcorner)$ expressing the Tarski clauses by recursion on the coded formula, and ZFC proves the soundness theorem for it. So if ZFC proved that some $(M,E)$ satisfies every ZFC axiom, ZFC would prove that no contradiction is derivable from those axioms — that is, ZFC $\vdash \operatorname{Con}(\mathrm{ZFC})$. Gödel's second incompleteness theorem says a consistent, effectively axiomatised theory interpreting arithmetic does not prove its own consistency, and ZFC interprets arithmetic via the von Neumann naturals. Hence no such proof exists.
:::

:::pitfall
This is *not* the claim that ZFC has no models. If ZFC is consistent then by the completeness theorem it has one; what the theorem says is that the existence of one cannot be established inside ZFC. Every result below of the form "if there is a transitive model of ZFC then …" carries that hypothesis explicitly, and it is a genuine extra assumption — strictly stronger than $\operatorname{Con}(\mathrm{ZFC})$, since a transitive model would make $\operatorname{Con}(\mathrm{ZFC})$ true rather than merely consistent.
:::

Granting a model, model theory immediately produces a small one, and the result is the single most disorienting fact in the subject.

:::theorem[Downward Löwenheim–Skolem for ZFC]{#ls-for-zfc}
If ZFC has a model, it has a countable model. If ZFC has a transitive model, it has a countable transitive model.
:::

:::proof
$\mathcal{L}_\in$ is countable, so the downward Löwenheim–Skolem theorem of the chapter *Model Theory* produces a countable elementary substructure $(N, E) \preceq (M, \in)$ of any given model $M$. For the second claim, take $M$ transitive and $N \preceq M$ countable. Since $N$ is an elementary substructure of a structure whose relation is genuine membership, $E$ is membership restricted to $N$ and is therefore well-founded, and $N$ satisfies Extensionality because $M$ does and Extensionality is a sentence. The Mostowski collapse below replaces $(N,\in)$ by an isomorphic transitive set, which is countable because the collapse is a bijection, and which satisfies ZFC because it is isomorphic to a model of ZFC.
:::

:::theorem[Mostowski collapse]{#mostowski}
Let $(N,E)$ be a well-founded structure satisfying Extensionality, with $E$ set-like. Then there are a unique transitive set $\bar{N}$ and a unique isomorphism $\pi : (N,E) \to (\bar{N},\in)$, given by the recursion

$$\pi(x) = \{\,\pi(y) : y \mathbin{E} x\,\}.$$
:::

:::proof[Sketch]
Well-foundedness makes the displayed recursion legitimate, by the transfinite recursion theorem of the final section applied to the well-founded relation $E$. Put $\bar{N} = \pi[N]$. It is transitive, because every member of $\pi(x)$ is some $\pi(y)$ and hence lies in the range. Surjectivity is immediate. Injectivity follows from Extensionality in $N$ by $E$-induction: if $\pi(x) = \pi(x')$ then $x$ and $x'$ have the same $E$-members by the induction hypothesis, so $x = x'$. That $\pi$ is a homomorphism both ways is read off the recursion. Uniqueness follows because any two such isomorphisms agree by induction on $E$. The routine part is the verification of the recursion's hypotheses; the substantive ones are exactly well-foundedness and extensionality, and the theorem fails without either.
:::

:::example[Skolem's paradox]
Let $M$ be a countable transitive model of ZFC. Inside $M$, Cantor's theorem holds, so $M \models$ "$\mathcal{P}(\omega)$ is uncountable". Yet $M$ is countable, so the set $(\mathcal{P}(\omega))^M$ is countable in $V$. Resolve the apparent contradiction.
:::

:::solution
1. Unwind what "uncountable" abbreviates. The sentence $M$ satisfies is: *there is no function $f$ with domain $\omega$ whose range is all of $\mathcal{P}(\omega)$* — and the quantifier "there is no function" ranges over $M$ only.
2. In $V$ such a function does exist, because $(\mathcal{P}(\omega))^M \subseteq M$ is a countable set. But that function is not an element of $M$.
3. So $M$ is right about every set it can see and wrong about nothing: "$M \models$ $(\mathcal{P}(\omega))^M$ is uncountable" and "$(\mathcal{P}(\omega))^M$ is countable" are claims about *different quantifier ranges*, and they are jointly consistent.
4. The moral is that "uncountable" is not absolute between transitive models: a model can lack the very bijection that would reveal a set's true size. The section *Relativisation and Absoluteness* turns this observation into a syntactic criterion, and the section on cardinals shows it is exactly the mechanism by which forcing changes cardinalities.
:::

:::intuition
A model of set theory is like a library that believes it holds every book. It is right that no catalogue *on its own shelves* lists its holdings in a single countable sequence — and it cannot see the catalogue in the city library across the street, which does exactly that. Nothing inside is false; the library simply has no access to the external enumeration.
:::

:::summary
Models of ZFC are structures for a one-relation language; transitive ones are those that do not misreport membership. ZFC cannot prove it has a model, but if it has one it has a countable transitive one, and such a model necessarily misjudges cardinality from the outside — the Skolem paradox, which is a failure of absoluteness and not a contradiction.
:::

## Relativisation and Absoluteness

<!-- section: absoluteness -->

Skolem's paradox showed that a model's verdict on a formula can differ from the truth in $V$. Absoluteness theory is the syntax that predicts when this can happen. The device is relativisation: restricting every quantifier of a formula to a class.

:::definition[Relativisation]{#relativisation}
Let $M$ be a class or set. The **relativisation** $\varphi^M$ of an $\mathcal{L}_\in$-formula $\varphi$ is defined by recursion:

$$(x \in y)^M \equiv x \in y, \qquad (x = y)^M \equiv x = y,$$

$$(\neg\psi)^M \equiv \neg(\psi^M), \qquad (\psi \wedge \chi)^M \equiv \psi^M \wedge \chi^M,$$

$$(\exists x\,\psi)^M \equiv \exists x\,(x \in M \wedge \psi^M), \qquad (\forall x\,\psi)^M \equiv \forall x\,(x \in M \to \psi^M).$$

For a set $M$ and parameters in $M$, $\varphi^M$ holds if and only if $M \models \varphi$.
:::

Relativisation is what lets a theory talk about a model of itself without a satisfaction predicate. For a *proper class* $M$ there is no set-sized structure to apply Tarski's definition to, and indeed "$M \models \mathrm{ZFC}$" is not a single sentence; but $\varphi^M$ is a perfectly good formula for each fixed $\varphi$, so the assertion that $M$ satisfies ZFC becomes a schema of statements, one per axiom. That distinction is the whole reason the section on choice can speak of the inner model $L$ without contradicting the theorem *ZFC cannot produce a model of itself*.

:::definition[Absoluteness]{#absoluteness-def}
Let $M \subseteq N$ be classes and $\varphi(\bar{x})$ a formula. Then $\varphi$ is **upward absolute** if $\varphi^M(\bar{a}) \to \varphi^N(\bar{a})$ for all $\bar{a} \in M$, **downward absolute** if the converse implication holds, and **absolute between $M$ and $N$** if both do. "Absolute for $M$" with no second class named means absolute between $M$ and $V$.
:::

The syntactic criterion turns on how the quantifiers are bounded.

:::definition[Bounded quantifiers and the class $\Delta_0$]{#delta-zero}
$\exists x \in y\,\psi$ abbreviates $\exists x\,(x \in y \wedge \psi)$ and $\forall x \in y\,\psi$ abbreviates $\forall x\,(x \in y \to \psi)$; these are **bounded** quantifiers. A formula is **$\Delta_0$** if it is built from atomic formulas using connectives and bounded quantifiers only. A formula is $\Sigma_1$ if it has the form $\exists y\,\psi$ with $\psi \in \Delta_0$, and $\Pi_1$ if it has the form $\forall y\,\psi$ with $\psi \in \Delta_0$.
:::

:::theorem[$\Delta_0$ formulas are absolute for transitive classes]{#delta-zero-absolute}
Let $M$ be a transitive class and $\varphi(\bar{x})$ a $\Delta_0$ formula. Then for all $\bar{a} \in M$,

$$\varphi^M(\bar{a}) \leftrightarrow \varphi(\bar{a}).$$
:::

:::proof
Induction on the structure of $\varphi$. Atomic formulas are unchanged by relativisation, so the base case is immediate, and the connective cases follow at once from the induction hypothesis, since relativisation commutes with $\neg$ and $\wedge$. The only case with content is the bounded quantifier. Suppose $\varphi$ is $\exists x \in a\,\psi$ with $\psi$ a $\Delta_0$ formula and $a \in M$ among the parameters. Then

$$\varphi^M \equiv \exists x\,(x \in M \wedge x \in a \wedge \psi^M).$$

If $\varphi^M$ holds, a witness $x$ satisfies $x \in a$ and, by the induction hypothesis, $\psi(x)$; so $\varphi$ holds. Conversely if $\varphi$ holds, take a witness $x \in a$. Transitivity of $M$ together with $a \in M$ gives $x \in M$, and the induction hypothesis gives $\psi^M(x)$; so $\varphi^M$ holds. The bounded universal quantifier is the dual argument. Transitivity was used exactly once, and it is indispensable: it is what guarantees that the external witness is also available internally.
:::

:::corollary[One unbounded quantifier: up and down]{#sigma-pi-absolute}
Let $M \subseteq N$ be transitive classes. Every $\Sigma_1$ formula is upward absolute from $M$ to $N$, and every $\Pi_1$ formula is downward absolute from $N$ to $M$.
:::

:::proof
Let $\varphi \equiv \exists y\,\psi$ with $\psi$ a $\Delta_0$ formula, and suppose $\varphi^M(\bar a)$ holds. Then some $y \in M \subseteq N$ has $\psi^M(y,\bar a)$, hence $\psi(y,\bar a)$ by the theorem *$\Delta_0$ formulas are absolute for transitive classes* applied to $M$, hence $\psi^N(y,\bar a)$ by the same theorem applied to $N$. So $\varphi^N(\bar a)$. The $\Pi_1$ statement is this applied to the negation: $\neg\varphi$ is (equivalent to) $\Sigma_1$, and contraposing upward absoluteness for it gives downward absoluteness for $\varphi$.
:::

:::intuition
A bounded quantifier searches inside a set the model already possesses, and a transitive model possesses all of that set's members — so the search inside and the search outside comb through exactly the same objects. An unbounded quantifier searches the whole universe, where the model's shelves may be missing something. Hence the asymmetry: existential claims survive going up (a witness you have, a bigger world also has), and universal claims survive coming down (if nothing anywhere is a counterexample, nothing here is).
:::

:::example[A stock of absolute notions]
Show that "$x$ is empty", "$x \subseteq y$", "$x$ is transitive" and "$z = x \cup y$" are $\Delta_0$, hence absolute for transitive classes.
:::

:::solution
1. "$x$ is empty" is $\forall w \in x\,(w \neq w)$ — bounded.
2. "$x \subseteq y$" is $\forall w \in x\,(w \in y)$ — bounded.
3. "$x$ is transitive" is $\forall w \in x\,\forall u \in w\,(u \in x)$ — bounded.
4. "$z = x \cup y$" is $\forall w \in z\,(w \in x \vee w \in y) \wedge \forall w \in x\,(w \in z) \wedge \forall w \in y\,(w \in z)$ — bounded.
5. Each is therefore absolute for every transitive class, with no hypothesis on which axioms the class satisfies. The same argument covers "$x$ is an ordered pair", "$r$ is a relation", "$f$ is a function", "$f$ is injective", "$z = x \cap y$" and "$z = \bigcup x$", which is why elementary set-theoretic bookkeeping never causes trouble between models.
:::

:::example[Power set is not absolute]
Show that "$z = \mathcal{P}(x)$" is $\Pi_1$ but not absolute, and exhibit a transitive model that gets it wrong.
:::

:::solution
1. The formula is $\forall w\,(w \in z \leftrightarrow w \subseteq x)$. The inner "$w \subseteq x$" is $\Delta_0$; the outer $\forall w$ is unbounded, so the formula is $\Pi_1$ and by the corollary *One unbounded quantifier: up and down* it is downward absolute.
2. It is not upward absolute, and so not absolute. Let $M$ be a countable transitive model of ZFC and put $z = (\mathcal{P}(\omega))^M$. Then $M \models$ "$z = \mathcal{P}(\omega)$", because $M$ contains every subset of $\omega$ that it can see.
3. In $V$, however, $z$ is a countable set while $\mathcal{P}(\omega)$ is uncountable, so $z \neq \mathcal{P}(\omega)$ holds in $V$.
4. The missing objects are precisely the subsets of $\omega$ lying outside $M$. This is Skolem's paradox again, now diagnosed by counting unbounded quantifiers rather than by inspecting the model.
:::

:::pitfall
Absoluteness always carries two hypotheses that are easy to drop: the classes must be **transitive**, and the smaller one must contain the parameters. For non-transitive models even $\Delta_0$ formulas fail — take $M = \{\{0\}\}$, in which the element $\{0\}$ satisfies "$x$ is empty", because $M$ contains no member of $\{0\}$ to witness otherwise.
:::

:::remark[The Lévy hierarchy]
Continuing past $\Sigma_1$ and $\Pi_1$ by counting alternations of unbounded quantifiers gives the **Lévy hierarchy** $\Sigma_n, \Pi_n, \Delta_n$, the set-theoretic analogue of the arithmetical hierarchy from the chapter *Computability*. A formula provably equivalent to both a $\Sigma_1$ and a $\Pi_1$ formula is called $\Delta_1$ and is absolute for transitive models of a modest fragment of ZF. Most of the notions used in ordinary mathematics turn out to be $\Delta_1$; the exceptions — power set, cardinality, "constructible", "measurable" — are exactly the ones independence proofs manipulate.
:::

:::summary
Relativisation $\varphi^M$ restricts quantifiers to $M$; for a set $M$ it agrees with $M \models \varphi$, and for proper classes it is the only available formulation, one sentence at a time. $\Delta_0$ formulas are absolute for transitive classes, $\Sigma_1$ formulas go up, $\Pi_1$ formulas come down. Notions defined by unbounded quantification over subsets are the ones models disagree about.
:::

## Reflecting the Universe in a Set

<!-- section: reflection -->

The universe $V$ is not a set, so the sentence "$V \models \varphi$" cannot even be formed. What can be formed, for each fixed $\varphi$, is $\varphi^V$, which is just $\varphi$ itself; one may then ask whether some *set* agrees with $V$ about $\varphi$. The Reflection Principle answers yes, for any finite list of formulas at once, and it is a theorem schema of ZF.

:::definition[Reflection for a list of formulas]{#reflects}
Let $\varphi_1,\dots,\varphi_n$ be formulas and $M$ a set. Say $M$ **reflects** $\varphi_1,\dots,\varphi_n$ if for each $i$ and all parameters $\bar{a} \in M$,

$$\varphi_i^M(\bar{a}) \leftrightarrow \varphi_i(\bar{a}).$$
:::

:::theorem[Lévy–Montague Reflection Principle]{#reflection}
For each finite list $\varphi_1,\dots,\varphi_n$ of $\mathcal{L}_\in$-formulas, ZF proves: for every ordinal $\beta$ there is a limit ordinal $\alpha > \beta$ such that $V_\alpha$ reflects $\varphi_1,\dots,\varphi_n$.
:::

:::proof
Close the list under subformulas, so we may assume every subformula of each $\varphi_i$ is on the list, and rewrite $\forall$ as $\neg\exists\neg$ so that $\exists$ is the only quantifier. For each $\varphi_i$ of the form $\exists y\,\psi(y,\bar{x})$ define

$$F_i(\bar{a}) = \text{the least } \gamma \text{ with } \exists y \in V_\gamma\,\psi(y,\bar{a}), \text{ and } F_i(\bar a) = 0 \text{ if no such } y \text{ exists}.$$

This is a legitimate class function, because every set has a rank and the ordinals are well-ordered. Now set

$$G(\xi) = \sup\{\,F_i(\bar{a}) : i \le n,\ \bar{a} \in V_\xi\,\} + 1.$$

The collection being supped is the image of the set $V_\xi^{\,<\omega}$ under finitely many definable functions, so Replacement makes it a set of ordinals and the supremum exists. Starting from $\alpha_0 = \beta + 1$, put $\alpha_{k+1} = \max(G(\alpha_k), \alpha_k + 1)$ and $\alpha = \sup_k \alpha_k$, a limit ordinal greater than $\beta$.

We show $V_\alpha$ reflects the list, by induction on the structure of the formulas. Atomic formulas and connectives are immediate. Let $\varphi_i \equiv \exists y\,\psi$ and $\bar{a} \in V_\alpha$. If $\varphi_i^{V_\alpha}(\bar a)$ holds, a witness in $V_\alpha$ satisfies $\psi^{V_\alpha}$, hence $\psi$ by the induction hypothesis, so $\varphi_i(\bar a)$. Conversely suppose $\varphi_i(\bar a)$. Since $\alpha$ is a limit and $V_\alpha = \bigcup_k V_{\alpha_k}$, we have $\bar{a} \in V_{\alpha_k}$ for some $k$; by construction $F_i(\bar a) < G(\alpha_k) \le \alpha_{k+1} \le \alpha$, so a witness $y$ lies in $V_\alpha$. The induction hypothesis converts $\psi(y,\bar a)$ into $\psi^{V_\alpha}(y,\bar a)$, giving $\varphi_i^{V_\alpha}(\bar a)$.
:::

The construction repays a second look, because the pattern recurs throughout set theory. Each $F_i$ is a **Skolem function** in disguise: it records how far up the hierarchy one must climb to find a witness. Closing an ordinal under finitely many such functions and iterating $\omega$ times produces a **closure point**, and the closure points form a closed unbounded class. Reflection is the statement that closure points reflect — which is also why the $\alpha$ produced is a limit, and why the theorem gives *arbitrarily large* such $\alpha$ rather than one.

:::pitfall
Reflection is a *schema*: one theorem per finite list. It does **not** say that some $V_\alpha$ reflects all of ZFC — that would assert the existence of a set model of ZFC, contradicting the theorem *ZFC cannot produce a model of itself*. The quantifier "for each finite list" lives in the metatheory, outside the object language, and moving it inside is the commonest error in this area.
:::

:::corollary[Every finite fragment has a transitive set model]{#finite-fragment-model}
For each finite $T \subseteq \mathrm{ZFC}$, ZFC proves that there are arbitrarily large $\alpha$ with $V_\alpha \models T$.
:::

:::proof
Apply the Reflection Principle to the sentences of $T$ together with all their subformulas, obtaining arbitrarily large limit $\alpha$ with $V_\alpha$ reflecting them. Each $\tau \in T$ is an axiom of ZFC, hence true in $V$, hence — being reflected — true in $V_\alpha$. Transitivity of $V_\alpha$ is automatic, and $V_\alpha$ is a set, so $(V_\alpha,\in)$ is a transitive set model of $T$.
:::

This corollary is the workhorse of independence proofs. A forcing argument needs a ground model that is a set, so that one can form its extension; producing an outright model of ZFC is impossible, but every actual argument uses only finitely many axioms, and for those the corollary supplies a model. Combined with the theorem *Downward Löwenheim–Skolem for ZFC* and the Mostowski collapse, one obtains *countable transitive* models of any finite fragment — the standing hypothesis of the chapter *Independence & Forcing*.

:::example[Reflecting a single formula]
Let $\varphi$ be $\forall x\,\exists y\,(x \in y)$, which holds in $V$. Trace the $\alpha$ the proof of reflection produces from $\beta = 0$, and check the reflection directly.
:::

:::solution
1. The only unbounded existential is $\exists y\,(x \in y)$, so there is one Skolem function: $F(a)$ is the least $\gamma$ with some $y \in V_\gamma$ containing $a$. Taking $y = \{a\}$, whose rank is $\operatorname{rank}(a)+1$, gives $F(a) = \operatorname{rank}(a) + 2$.
2. Hence $G(\xi) = \sup\{\operatorname{rank}(a)+2 : a \in V_\xi\} + 1 = \xi + 2$ for $\xi > 0$, and iterating from $\alpha_0 = 1$ gives $\alpha_k = 2k+1$, so $\alpha = \sup_k \alpha_k = \omega$.
3. Check directly: for $x \in V_\omega$ we have $\{x\} \in V_\omega$, since $V_\omega$ is closed under pairing. So $\varphi^{V_\omega}$ holds, matching $\varphi$.
4. Note the failure at a successor stage: $V_5$ does not reflect $\varphi$, because $x = V_4 \in V_5$ has no $y \in V_5$ containing it. The limit condition in the theorem is doing real work.
:::

:::example[Reflection does not transfer to a single sentence]
A student writes: "By reflection, ZFC proves $\exists \alpha\,(V_\alpha \models \mathrm{ZFC})$, so ZFC proves its own consistency." Diagnose precisely where this breaks, and say what ZFC *does* prove.
:::

:::solution
1. The sentence $V_\alpha \models \mathrm{ZFC}$ is expressible in ZFC, since satisfaction for set-sized structures is definable and ZFC is a definable set of codes. So the claimed conclusion is at least meaningful — the failure is not one of syntax.
2. But reflection never proves it. For each finite list, ZFC proves the corresponding instance; there is no instance whose list is all of ZFC, because the lists are finite.
3. What ZFC does prove, for each finite $T \subseteq \mathrm{ZFC}$, is $\exists\alpha\,(V_\alpha \models T)$, hence $\operatorname{Con}(T)$. So ZFC proves the consistency of each of its finite fragments — infinitely many theorems, one per fragment.
4. Gödel's second theorem is therefore not contradicted, and in fact this is a proof that ZFC is not finitely axiomatisable: a finite axiomatisation would let step 3 be applied to the whole theory at once.
:::

:::remark[Reflection as an axiom, and its strengthenings]
Some presentations take reflection as a primitive schema and derive Infinity and Replacement from it over the remaining axioms — the Lévy reflection schema. Strengthening it by demanding that the reflecting $V_\alpha$ be elementary in $V$ for *all* formulas at once is inconsistent, by the pitfall above; demanding second-order reflection instead yields large-cardinal axioms, which the chapter *Advanced Set Theory* treats.
:::

:::summary
For every finite list of formulas, ZF proves some level $V_\alpha$ agrees with $V$ about all of them. This yields transitive set models of every finite fragment of ZFC, underwrites the non-finite-axiomatisability theorem, and must always be read as a schema — never as a single statement quantifying over all formulas.
:::

## Choice as a Sentence, and Relative Consistency

<!-- section: choice -->

For a logician the Axiom of Choice is interesting not for what it builds but for its *status*: a sentence that can be added to ZF, whose negation can equally be added, and neither of which ZF refutes. The equivalents — Zorn's lemma, the well-ordering theorem, every vector space has a basis, Tychonoff's theorem — are the business of the chapter *The Axiom of Choice* in the subject Set Theory. Here AC is an object of metamathematics.

:::definition[AC as an $\mathcal{L}_\in$-sentence]{#ac-sentence}
The Axiom of Choice is the sentence

$$\forall a\,\Bigl(\forall x \in a\,\exists u\,(u \in x) \to \exists f\,\bigl(\operatorname{Fn}(f) \wedge \operatorname{dom}(f) = a \wedge \forall x \in a\,(f(x) \in x)\bigr)\Bigr),$$

where $\operatorname{Fn}(f)$, $\operatorname{dom}(f) = a$ and $f(x) \in x$ abbreviate their $\Delta_0$ definitions in terms of Kuratowski pairs. The quantifier $\exists f$ is unbounded, so AC as written is $\Pi_2$ in the Lévy hierarchy, and there is no reason to expect it to be absolute.
:::

:::proposition[Finite choice is a schema of theorems of ZF]{#finite-choice}
For each numeral $n$, ZF proves: every family of exactly $n$ non-empty sets has a choice function.
:::

:::proof
Induct in the metatheory on $n$. For $n = 0$ the empty function works. Suppose the claim proved for $n$ and let $a = \{x_1,\dots,x_{n+1}\}$ have non-empty members. The hypothesis $\exists u\,(u \in x_{n+1})$ is a single existential statement of the theory, so a proof may introduce a witness $u$ by existential instantiation — one witness, mentioned once, with no choice principle involved. The induction hypothesis gives a choice function $f$ for $\{x_1,\dots,x_n\}$, and $f \cup \{(x_{n+1},u)\}$ is a set by Pairing and Union and is a choice function for $a$.
:::

:::pitfall
That proposition is infinitely many theorems, one per numeral, proved by an induction in the *metatheory*. It is not the same statement as the single sentence "every finite family of non-empty sets has a choice function" — though that sentence is also a theorem of ZF, proved by induction *inside* the theory on the cardinality of the family. The distinction between a schema established in the metatheory and one sentence established internally runs through this whole chapter, and in the theorem *ZFC is not finitely axiomatisable* it is precisely what separates a theorem from a contradiction.
:::

Everything provable about AC's status is *relative*. No argument establishes that ZFC is consistent, since that would entail $\operatorname{Con}(\mathrm{ZF})$, which is unprovable in ZF.

:::definition[Inner model]{#inner-model}
An **inner model** of ZF is a transitive class $M$ containing every ordinal such that $\varphi^M$ holds for every axiom $\varphi$ of ZF. As with relativisation generally, "$M$ is an inner model of ZF" abbreviates a schema of statements, one per axiom, and not a single sentence.
:::

:::theorem[The inner-model method]{#inner-model-method}
Let $S$ and $T$ be theories in the same language and suppose there is a formula defining a class $M$ such that $S$ proves $M$ is non-empty and, for each axiom $\tau$ of $T$, $S \vdash \tau^M$. Then $\operatorname{Con}(S) \to \operatorname{Con}(T)$, and this implication is provable in a weak arithmetic.
:::

:::proof
Suppose $T$ were inconsistent, so there is a derivation of a contradiction from finitely many axioms $\tau_1,\dots,\tau_k$ of $T$. Relativisation commutes with the rules of a first-order proof system: if $\sigma$ follows from $\sigma_1,\dots,\sigma_m$ by a rule, then $\sigma^M$ follows from $\sigma_1^M,\dots,\sigma_m^M$ — for the quantifier rules this uses that $M$ is non-empty, and for the propositional rules it is immediate, since relativisation commutes with the connectives. Relativising the derivation step by step therefore converts it into a derivation of a contradiction from $\tau_1^M,\dots,\tau_k^M$, each of which $S$ proves. So $S$ is inconsistent. The whole transformation is a primitive recursive operation on proof codes, which is why the implication holds provably in arithmetic and not merely in the metatheory.
:::

:::theorem[Gödel 1938, Cohen 1963]{#ac-independence}
If ZF is consistent, then so are $\mathrm{ZF} + \mathrm{AC}$ and $\mathrm{ZF} + \neg\mathrm{AC}$; hence AC is independent of ZF. If ZFC is consistent, then so are $\mathrm{ZFC} + \mathrm{CH}$ and $\mathrm{ZFC} + \neg\mathrm{CH}$; hence CH is independent of ZFC.
:::

:::proof[Sketch]
For the consistency of AC, Gödel defines the constructible hierarchy $L = \bigcup_{\alpha} L_\alpha$, where $L_{\alpha+1}$ is the set of subsets of $L_\alpha$ definable over the structure $(L_\alpha,\in)$ with parameters. One verifies that $L$ is an inner model of ZF and that ZF proves $\mathrm{AC}^L$ — the well-ordering comes from the definability hierarchy itself, which orders each level canonically by the formulas and parameters defining its members. The inner-model method then yields $\operatorname{Con}(\mathrm{ZF}) \to \operatorname{Con}(\mathrm{ZFC})$; the same model gives $\operatorname{Con}(\mathrm{ZFC}+\mathrm{CH})$, since CH holds in $L$. For the negations, Cohen's forcing starts from a countable transitive model of a sufficient finite fragment — supplied by the corollary *Every finite fragment has a transitive set model* — and adjoins generic sets, taking a symmetric submodel in the case of $\neg\mathrm{AC}$. Both constructions are carried out in the chapter *Independence & Forcing*; what is imported here is their shape, and the inner-model method above is the piece that converts a construction into a consistency statement.
:::

:::intuition
Consistency proofs of this kind never certify a theory. They trade: they show that if the trusted theory is safe, so is the doubted one. An inner model is a way of reinterpreting the doubted theory's vocabulary inside the trusted one, so that any proof of a contradiction would translate back into a contradiction we had already agreed was impossible.
:::

:::example[Why "AC is independent" is not "AC is false"]
A student argues: "Cohen produced a model of ZF in which choice fails, so choice is false." Locate the error.
:::

:::solution
1. Independence is a property of a pair — a theory and a sentence — not of a sentence alone. AC is independent of ZF in exactly the sense that commutativity is independent of the group axioms.
2. A model of $\mathrm{ZF} + \neg\mathrm{AC}$ shows only that the axioms of ZF do not *force* AC. A model of $\mathrm{ZF} + \mathrm{AC}$, namely $L$, exists equally, and the two are on a level.
3. Whether AC is "true" is then a question about which structure, if any, mathematical practice intends — a question outside the theory. Mathematicians adopt AC because its consequences are indispensable and, given $\operatorname{Con}(\mathrm{ZF})$, no contradiction can arise from doing so.
4. Symmetrically, "ZFC $\nvdash$ CH" does not license asserting $\neg\mathrm{CH}$.
:::

:::example[What a relative consistency statement costs]
Explain why $\operatorname{Con}(\mathrm{ZF}) \to \operatorname{Con}(\mathrm{ZFC})$ is provable but $\operatorname{Con}(\mathrm{ZFC})$ is not, and why a transitive model of ZFC is a stronger assumption than $\operatorname{Con}(\mathrm{ZFC})$.
:::

:::solution
1. The implication is proved by a syntactic transformation of proofs, as in the theorem *The inner-model method*; it never asserts that any proof-free situation obtains, so Gödel's second theorem does not apply to it.
2. $\operatorname{Con}(\mathrm{ZFC})$ itself is an arithmetical sentence which, by Gödel's second theorem, ZFC does not prove if it is consistent.
3. A transitive model of ZFC is stronger still. If one exists, then ZFC is not merely consistent: its arithmetical consequences are *true*, since a transitive model computes $\omega$ and the arithmetic on it correctly, by absoluteness of $\Delta_0$ notions. So "there is a transitive model" implies $\operatorname{Con}(\mathrm{ZFC})$, implies $\operatorname{Con}(\mathrm{ZFC} + \operatorname{Con}(\mathrm{ZFC}))$, and so on up.
4. This is why careful statements say "assume there is a countable transitive model of a sufficiently large finite fragment of ZFC" — by the corollary *Every finite fragment has a transitive set model*, that assumption costs nothing.
:::

:::summary
AC is a single $\Pi_2$ sentence of $\mathcal{L}_\in$, and ZF and ZFC are different theories. Relative consistency is established by the inner-model method, which relativises a hypothetical contradiction back into the base theory; $L$ gives $\operatorname{Con}(\mathrm{ZF}) \to \operatorname{Con}(\mathrm{ZFC})$ and forcing gives the other direction. Independence is a statement about provability, never a truth value.
:::

## Ordinals Are Absolute, Cardinals Are Not

<!-- section: ordinals-cardinals -->

Ordinals and cardinals are developed in the chapter *Ordinals & Cardinals* of the subject Set Theory: an ordinal is a transitive set well-ordered by $\in$, a cardinal is an ordinal not in bijection with any smaller ordinal, and the alephs enumerate the infinite cardinals. What concerns us here is a single contrast with far-reaching consequences — the notion of ordinal is absolute for transitive models, and the notion of cardinal is not.

:::theorem[Being an ordinal is absolute]{#ordinal-absolute}
Over ZF, the formula "$x$ is an ordinal" is equivalent to a $\Delta_0$ formula, hence is absolute for transitive classes. Consequently, for a transitive class $M$ one has $\mathrm{Ord}^M = \mathrm{Ord} \cap M$, and this is either an ordinal or the whole class $\mathrm{Ord}$.
:::

:::proof
With Foundation available, every set is well-founded, so "$\in$ well-orders $x$" reduces to "$\in$ linearly orders $x$". Hence "$x$ is an ordinal" is equivalent to

$$\forall u \in x\,\forall v \in u\,(v \in x) \ \wedge\ \forall u \in x\,\forall v \in x\,(u \in v \vee u = v \vee v \in u),$$

whose quantifiers are all bounded. By the theorem *$\Delta_0$ formulas are absolute for transitive classes*, $M$ and $V$ agree about it for every $x \in M$, which is the first claim. For the second: $\mathrm{Ord} \cap M$ is transitive, since the members of an ordinal are ordinals and $M$ is transitive, and it is linearly ordered by $\in$; a transitive set of ordinals is an ordinal, and a transitive proper class of ordinals is $\mathrm{Ord}$.
:::

:::definition[The height of a model]{#height}
For a transitive set model $M$, the ordinal $\mathrm{Ord} \cap M$ is the **height** of $M$. An inner model is exactly a transitive class model of height $\mathrm{Ord}$.
:::

A countable transitive model therefore has countable height, and yet it satisfies "there are uncountably many ordinals". The mechanism is the failure of absoluteness one level up.

:::theorem[Cardinality is downward absolute only]{#cardinal-downward}
Let $M$ be a transitive class. Then:

1. "$f$ is a bijection from $x$ onto $y$" is $\Delta_0$, hence absolute.
2. "$\kappa$ is a cardinal" is $\Pi_1$, hence downward absolute: if $\kappa \in M$ is a cardinal in $V$, then $M \models$ "$\kappa$ is a cardinal".
3. The converse fails: there are a transitive $M$ and a $\kappa \in M$ with $M \models$ "$\kappa$ is a cardinal" while $\kappa$ is countable in $V$.
:::

:::proof
(1) Being a set of ordered pairs, being single-valued, having domain $x$ and range $y$, and injectivity are all expressible with quantifiers bounded by $f$, $x$ and $y$, using the $\Delta_0$ definition of the Kuratowski pair.

(2) "$\kappa$ is a cardinal" says $\kappa$ is an ordinal and there is no pair $(\beta,f)$ with $\beta \in \kappa$ and $f$ a bijection from $\beta$ onto $\kappa$. Pushing the negation inward puts it in the form $\forall w\,\psi$ with $\psi$ a $\Delta_0$ formula, using part (1) and the absoluteness of "is an ordinal"; so it is $\Pi_1$, and the corollary *One unbounded quantifier: up and down* makes it downward absolute. Concretely: a bijection witnessing failure inside $M$ is a genuine bijection in $V$ by part (1), so if $V$ has no such bijection, neither does $M$.

(3) Let $M$ be a countable transitive model of ZFC and let $\kappa = (\omega_1)^M$, the least ordinal $M$ believes is uncountable. By the theorem *Being an ordinal is absolute*, $\kappa$ is a genuine ordinal, and $\kappa \subseteq M$ by transitivity, so $\kappa$ is countable in $V$ and is not a cardinal there. Inside $M$, no bijection from a smaller ordinal onto $\kappa$ exists, so $M \models$ "$\kappa$ is a cardinal".
:::

:::intuition
Cardinality asks for the *non-existence* of a bijection, and non-existence claims are exactly what a model can get wrong by being too small. Adding sets to a model can only destroy cardinals, never create them: a new bijection can collapse two cardinals into one, but no newly added set can un-do a bijection that was already present.
:::

:::corollary[Inner models preserve cardinals downward]{#inner-model-cardinals}
If $M$ is an inner model of ZF and $\kappa$ is a cardinal in $V$, then $\kappa$ is a cardinal in $M$. Hence $(\omega_1)^M \le \omega_1$ for every inner model $M$. The converse fails in general.
:::

:::proof
The first claim is part (2) of the theorem *Cardinality is downward absolute only*, since an inner model is in particular a transitive class. For the second, $(\omega_1)^M$ is the least ordinal $M$ regards as uncountable; $\omega_1$ is uncountable in $V$, hence uncountable in $M$ by the first claim, hence at least the least such ordinal of $M$. The converse fails because $M$ may simply lack a bijection that $V$ has: an ordinal $M$ believes to be a cardinal need not be one in $V$, exactly as in part (3) above.
:::

:::example[Counting inside and outside a countable model]
Let $M$ be a countable transitive model of ZFC and $\kappa = (\omega_1)^M$. Compute the cardinality of $\kappa$ as evaluated in $V$, and decide whether $M \models$ "$\kappa$ is countable".
:::

:::solution
1. $\kappa$ is an ordinal of $M$ and $M$ is transitive, so every element of $\kappa$ lies in $M$; since $M$ is countable, $\kappa$ is a countable set. It is infinite, since $\omega \in \kappa$. Hence $|\kappa| = \aleph_0$ as computed in $V$.
2. $M \models$ "$\kappa$ is uncountable", because $\kappa$ was chosen as the least ordinal of $M$ admitting no bijection with $\omega$ *inside $M$*. So the answer to the second question is no.
3. The two are compatible: the bijection $\omega \to \kappa$ exists in $V$ but not in $M$. The sentence "$\kappa$ is countable" is $\Sigma_1$, hence upward absolute — true in $V$, and there is no reason for it to be true in the smaller $M$.
:::

:::remark[Cardinal collapse and preservation]
This is exactly the phenomenon forcing exploits. A forcing extension $M[G]$ may contain a surjection $\omega \to (\omega_1)^M$, in which case $(\omega_1)^M$ is no longer a cardinal in $M[G]$ — the cardinal has been *collapsed*. Showing that a given forcing does not collapse cardinals is a standard proof obligation, usually discharged by the countable chain condition; the chapter *Independence & Forcing* gives the argument. Cohen's model for $\neg\mathrm{CH}$ is designed so that the cardinals of $M$ survive while the continuum is pushed above $\aleph_1$.
:::

:::pitfall
"$\kappa$ is a cardinal" and "$\kappa = \aleph_1$" behave differently. The first is downward absolute; the second is absolute in neither direction, because $\aleph_1$ is defined as the *least* uncountable cardinal, and a model missing bijections will name the wrong ordinal. Always relativise the notation — write $(\omega_1)^M$, never a bare $\omega_1$, when working inside a model.
:::

:::summary
Being an ordinal is $\Delta_0$ and therefore absolute, so all transitive models agree about ordinals and each has a height. Being a cardinal is $\Pi_1$ and only downward absolute, so models overestimate cardinality; the gap between $(\omega_1)^M$ and $\omega_1$ is the engine of the Skolem paradox, of $L$'s slimness, and of cardinal collapse in forcing.
:::

## Induction and Recursion as Theorem Schemas

<!-- section: transfinite -->

Transfinite induction and transfinite recursion are usually presented as tools for building objects. Seen from logic they are results about the theory: the first is a theorem schema derived from Foundation, and the second is a theorem schema whose proof is the principal consumer of Replacement. Both are schemas for the same reason Separation is — they quantify over formulas.

:::theorem[$\in$-induction schema]{#in-induction}
For each formula $\varphi(x,\bar p)$, ZF proves

$$\forall x\,\bigl(\forall y \in x\,\varphi(y,\bar p) \to \varphi(x,\bar p)\bigr) \ \to\ \forall x\,\varphi(x,\bar p).$$
:::

:::proof
Assume the hypothesis and suppose some $a$ has $\neg\varphi(a,\bar p)$. Let $t$ be the transitive closure of $\{a\}$, which exists by Replacement, Union and Infinity, and put $S = \{x \in t : \neg\varphi(x,\bar p)\}$, a set by Separation, with $a \in S$ so $S \neq \emptyset$. By Foundation there is an $\in$-minimal $x \in S$, that is, one with $x \cap S = \emptyset$. Every $y \in x$ lies in $t$, because $t$ is transitive and $x \in t$, and $y \notin S$ by minimality; so $\varphi(y,\bar p)$ holds for every $y \in x$. The hypothesis then gives $\varphi(x,\bar p)$, contradicting $x \in S$.
:::

:::corollary[Transfinite induction on ordinals]{#transfinite-induction}
For each formula $\varphi$, ZF proves: if $\varphi(0)$ holds, and $\varphi(\beta) \to \varphi(\beta+1)$ for every ordinal $\beta$, and $\varphi(\lambda)$ holds whenever $\lambda$ is a limit ordinal with $\varphi(\beta)$ for all $\beta < \lambda$, then $\varphi(\alpha)$ holds for every ordinal $\alpha$.
:::

:::proof
Apply the $\in$-induction schema to the formula "$x$ is an ordinal $\to \varphi(x)$". For an ordinal $\alpha$, the hypothesis $\forall y \in \alpha\,\varphi(y)$ says exactly that $\varphi(\beta)$ holds for all $\beta < \alpha$, since the members of $\alpha$ are precisely the ordinals below it. The three clauses then cover the trichotomy "$\alpha = 0$, $\alpha$ a successor, $\alpha$ a limit", which is itself a theorem of ZF.
:::

:::pitfall
The three-clause form is a convenience, not the content. What the $\in$-induction schema gives is the single clause "if $\varphi$ holds below $x$ then $\varphi$ holds at $x$"; the limit case is not an extra burden imposed by infinity but simply the case where "below" has no largest element. An argument that verifies a successor step and stops is not an incomplete induction — it is not an induction at all.
:::

:::theorem[Transfinite recursion schema]{#transfinite-recursion}
Let $\gamma(x,y)$ be a formula with $\forall x\,\exists! y\,\gamma(x,y)$, defining a class function $G$. Then ZF proves there is a class function $F$ on $\mathrm{Ord}$, definable from $\gamma$, with

$$F(\alpha) = G\bigl(F \restriction \alpha\bigr) \quad\text{for every ordinal } \alpha,$$

and $F$ is unique with this property. Here "$F$ is a class function" again abbreviates a formula, so the theorem is one statement per $\gamma$.
:::

:::proof[Sketch]
Call a set $h$ an **$\alpha$-approximation** if $h$ is a function with domain $\alpha$ and $h(\xi) = G(h \restriction \xi)$ for every $\xi < \alpha$. Any two approximations agree on the intersection of their domains, by the corollary *Transfinite induction on ordinals* applied to "$h(\xi) = h'(\xi)$", so an $\alpha$-approximation is unique if it exists. Existence for every $\alpha$ is proved by transfinite induction: at $0$ take the empty function; at a successor $\alpha+1$ extend the $\alpha$-approximation by the single value $G(h)$; at a limit $\lambda$ take the union of the approximations below $\lambda$, which is a function because they cohere. The essential step is that this union is a *set*: the assignment $\xi \mapsto$ (the unique $\xi$-approximation) is a definable functional relation on the set $\lambda$, so Replacement collects the approximations into a set and Union merges them. Finally define $F(\alpha)$ to be $h(\alpha)$ for any $(\alpha+1)$-approximation $h$; coherence makes this well defined, and uniqueness of $F$ is another transfinite induction. The part not written out is the routine verification that the extended function at a successor is again an approximation.
:::

:::intuition
Replacement is what converts "for each $\xi$ there is a stage" into "the stages form a set". Without it one can still speak of each approximation individually, but never gather them, and a recursion that cannot gather its own history stalls at the first limit ordinal. That is the precise sense in which Replacement is the axiom of *length*: Power Set makes the universe wide, Replacement makes it tall.
:::

:::example[Zermelo set theory cannot reach $V_{\omega+\omega}$]
Zermelo set theory Z is ZFC with Replacement deleted and Separation retained. Show that $V_{\omega+\omega}$ is a model of Z, and deduce that Z does not prove the range of the recursion $F(0) = \omega$, $F(n+1) = \mathcal{P}(F(n))$ is a set.
:::

:::solution
1. $V_{\omega+\omega}$ is transitive, and it satisfies Extensionality and Foundation because those are $\Delta_0$-style conditions inherited by transitive sets, and Separation because a subset of an element of $V_{\omega+\omega}$ has no greater rank.
2. It satisfies Pairing, Union and Power Set because $\operatorname{rank}(\{a,b\})$, $\operatorname{rank}(\bigcup a)$ and $\operatorname{rank}(\mathcal{P}(a))$ each exceed $\max(\operatorname{rank}(a),\operatorname{rank}(b))$ by at most $2$, and $\omega+\omega$ is a limit ordinal, so the results stay below it. Infinity holds since $\omega \in V_{\omega+1}$, and Choice holds relativised if it holds in $V$.
3. Each $F(n)$ has rank $\omega + n$ and so lies in $V_{\omega+\omega}$. But $\{F(n) : n \in \omega\}$ has rank $\omega+\omega$ and is therefore *not* an element of $V_{\omega+\omega}$.
4. So $V_{\omega+\omega} \models \mathrm{Z}$ while refuting that instance of Replacement. By soundness, Z does not prove the range of this recursion is a set — the theorem *Transfinite recursion schema* genuinely needs Replacement, and Z is strictly weaker than ZF.
:::

:::example[Why the recursion theorem must be a schema]
Explain why transfinite recursion cannot be stated as a single sentence of $\mathcal{L}_\in$ covering all class functions $G$, and why the analogous statement for *set* functions is a single theorem.
:::

:::solution
1. A class function $G$ is presented by a formula $\gamma$, and no set-sized object in $V$ codes "all definable class functions"; by Tarski's undefinability theorem there is not even a definable truth predicate for $\mathcal{L}_\in$ from which one could build such a coding.
2. So "for every class function $G$ there is $F$ with $F(\alpha) = G(F \restriction \alpha)$" quantifies over formulas, which first-order syntax forbids — exactly the situation of Separation and Replacement.
3. The remedy is the same: one theorem per $\gamma$, generated by a template that can be checked mechanically in the metatheory.
4. For a *set* function $g$ the obstacle vanishes, because $g$ is an object a first-order quantifier can range over. "For every set $A$, every $a \in A$ and every $g : A^{<\omega} \to A$ there is a unique $f : \omega \to A$ with $f(0) = a$ and $f(n+1) = g(f \restriction (n+1))$" is a single theorem of ZF. This is why ordinary recursion on $\mathbb{N}$ raises none of these issues.
:::

:::remark[Where the ordinal arithmetic lives]
The uses of these schemas — ordinal addition, multiplication and exponentiation, Cantor normal form, the hierarchies $V_\alpha$ and $L_\alpha$, the rank function — are developed in the chapters *Ordinals & Cardinals* and *ZFC Axioms* of the subject Set Theory. The logical content isolated here is that every one of them is a definition by a schema instance, and that each needs Replacement precisely at its limit stages.
:::

:::summary
$\in$-induction follows from Foundation by way of the transitive closure, and transfinite induction on ordinals is its restriction to $\mathrm{Ord}$. Transfinite recursion is a theorem schema, one instance per defining formula, whose proof uses Replacement to gather the approximations at limit stages — a use that $V_{\omega+\omega} \models \mathrm{Z}$ shows to be unavoidable.
:::

## Common Mistakes

- **Treating a schema as a sentence.** "Separation says that for every property…" is metatheory. Inside $\mathcal{L}_\in$ there is one axiom per formula, and no sentence quantifying over formulas exists. The same error turns the Reflection Principle into a claim that some $V_\alpha$ models all of ZFC, which is false.

- **Thinking ZFC proves it has a model.** If ZFC is consistent it has a model, by the completeness theorem applied in the metatheory — but ZFC cannot prove this, since it would then prove $\operatorname{Con}(\mathrm{ZFC})$. Every theorem about transitive models carries "if such a model exists" as a hypothesis.

- **Reading the Skolem paradox as a contradiction.** A countable model satisfying "$\mathcal{P}(\omega)$ is uncountable" is consistent, because the bijection that would refute the model's belief lies outside it. Uncountability is not absolute.

- **Forgetting transitivity in an absoluteness argument.** $\Delta_0$ absoluteness fails badly for non-transitive models; the proof uses transitivity exactly to import an external witness of a bounded quantifier.

- **Blaming Foundation for Russell's paradox.** It is Separation, replacing unrestricted comprehension, that blocks the paradoxical collection — Foundation rules out $x \in x$ and membership cycles, which is a different job, and ZF without Foundation is still free of Russell's contradiction.

- **Confusing independence with falsity.** "ZF $\nvdash$ AC" and "ZFC $\nvdash$ CH" are statements about provability. Neither licenses asserting the negation, any more than the existence of a non-abelian group refutes commutativity for all groups.

- **Asserting absolute consistency.** Gödel's construction of $L$ and Cohen's forcing both prove *relative* consistency: $\operatorname{Con}(\mathrm{ZF}) \to \operatorname{Con}(\mathrm{ZFC})$ and so on. Dropping the hypothesis produces a claim that is provably unprovable.

- **Using $\omega_1$ unrelativised inside a model.** Write $(\omega_1)^M$. Cardinality is only downward absolute, so a model's $\aleph_1$ is generally a countable ordinal when viewed from outside.

- **Stopping an induction at the successor step.** In the $\in$-induction schema there is only one step, "everything below implies here"; a limit ordinal is the case where "below" has no largest element, not an optional extra.
