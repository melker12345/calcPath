# Set Theory

Set theory is the foundation on which almost all of modern mathematics is built. Every mathematical object — numbers, functions, spaces, groups — can be encoded as a set. Zermelo-Fraenkel set theory with the Axiom of Choice (ZFC) is the standard axiomatic system.

The axioms carefully restrict how sets may be formed so that paradoxes (Russell's paradox) are avoided while still allowing all the constructions mathematicians need.

## The Zermelo-Fraenkel Axioms (ZFC)

<!-- section: zfc -->

Zermelo-Fraenkel set theory with the Axiom of Choice (ZFC) provides the standard foundation for virtually all of mathematics. The axioms were designed to permit every construction working mathematicians actually need—while blocking the paradoxes (such as Russell's "set of all sets that do not contain themselves") that destroyed naive set theory at the beginning of the twentieth century.

The core philosophy is conservative construction: sets are completely determined by their elements, and the only legitimate ways to build new sets from old ones are explicitly listed operations that stay "local" and avoid self-reference. Infinity is postulated so that the natural numbers exist inside the universe. The Axiom of Choice, listed apart because it is independent of the remaining axioms, asserts that arbitrary collections of nonempty sets admit choice functions; its consequences range from "every vector space has a basis" to the well-ordering theorem.

In this section you will learn each axiom, the motivation behind it, why the Axiom of Choice is special, and how the whole system enables the transfinite and cardinal arithmetic that appear later.

:::definition[The axioms of ZFC]{#zfc-axioms}
In most versions the axioms are:

- Extensionality: sets with the same elements are equal.
- Empty Set: there is a set with no elements.
- Pairing, Union, Power Set: basic ways to build new sets from old.
- Infinity: there is an infinite set (containing the empty set and closed under successor).
- Separation (Aussonderung): from any set you may form the subset of elements satisfying a property (avoids Russell).
- Replacement: the image of a set under a definable function is a set.
- Foundation (Regularity): every non-empty set has an $\in$-minimal element (no infinite descending membership chains).
:::

:::intuition
Extensionality says a set is completely determined by its members — a set is just a "bag of stuff", nothing more.

Separation is the "safe subset" rule: you can carve out the red marbles from a bag, but you cannot form "the set of all sets that do not contain themselves".

Foundation prevents weird loops like a set containing itself.
:::

:::example[Separation blocks Russell's paradox.]
Naive set theory allowed *unrestricted comprehension*: for any property $\phi$, the collection $\{x \mid \phi(x)\}$ is a set. Separation weakens this to *restricted* comprehension — you may only carve a subset **out of a set you already have**: $\{x \in A \mid \phi(x)\}$.
:::

:::solution
Take the property $\phi(x) : x \notin x$ and suppose, for contradiction, that a *universal* set $V$ (a set of all sets) exists. Separation then hands us
$$R = \{ x \in V \mid x \notin x \}.$$
Since $R$ is itself a set and $R \in V$, we may ask whether $R \in R$.

Test both cases.
If $R \in R$, then $R$ satisfies the defining property, so $R \notin R$.
If $R \notin R$, then $R$ satisfies the defining property, so $R \in R$.

Either way we get $R \in R \iff R \notin R$, a contradiction.

Separation itself is never at fault — it only produces a subset of a *given* set. The single false assumption was that a universal set $V$ exists. So the real conclusion is: **there is no set of all sets.** (Equivalently, $\{x \mid x \notin x\}$ is a proper class, not a set.)

Sanity check: with no universal $V$ to separate from, the paradoxical $R$ can never be formed, which is exactly why ZFC is consistent where naive comprehension was not.
:::

:::example[which axiom builds $\mathcal{P}(\mathbb{N})$?]
Suppose we already have $\omega = \{0,1,2,\dots\}$ (from the Axiom of Infinity). We want to justify that $\mathcal{P}(\omega)$ — the set of *all* subsets of $\omega$, i.e. the reals in disguise — is legitimately a set.
:::

:::solution
1. Extensionality, Pairing, and Union only build sets whose members are already visible; none of them can gather *every* subset at once. Replacement produces the image of a set under a definable function, but there is no single function whose image is "all subsets."
2. The **Power Set** axiom is precisely the tool: it asserts that for any set $A$ there is a set $\mathcal{P}(A)$ whose members are exactly the subsets of $A$. Applying it to $A = \omega$ gives $\mathcal{P}(\omega)$ directly.
3. Sanity check: this matches question `set-zfc-3` — Power Set (not Infinity or Replacement) is what makes the power set of $\mathbb{N}$ exist.
:::

## Axiom of Choice and Its Equivalents

<!-- section: choice -->

:::definition[Axiom of Choice]{#axiom-of-choice}
For any collection $\{A_i\}_{i \in I}$ of non-empty sets, there is a *choice function* $f$ with domain $I$ such that

$$f(i) \in A_i \quad \text{for every } i \in I.$$
:::

In words: you can simultaneously pick one element out of each set, even when the collection is infinite and no explicit rule tells you which element to take.

The subtlety is entirely about the *simultaneous, uniform* selection over an infinite index set. If $I$ is finite, or if each $A_i$ comes with a built-in way to point at a distinguished element (e.g. each $A_i \subseteq \mathbb{N}$, so "take the least element" works), then no axiom is needed. AC is exactly the extra strength required when the sets are arbitrary and infinitely many.

:::theorem[Equivalents of the Axiom of Choice]
Over ZF, each of the following is equivalent to AC:

- Every vector space admits some basis.
- Zorn's lemma (for partial orders).
- The well-ordering theorem.
- Tychonoff's theorem for product topologies.
- Certain statements about the reals, etc.
:::

:::theorem[Independence of AC]
AC is independent of the other ZF axioms (Gödel 1938 consistency, Cohen 1963 independence).
:::

:::intuition
Imagine infinitely many pairs of shoes. AC lets you pick the left shoe from each pair simultaneously, even though there is no "rule" that works for all pairs at once without a global well-ordering.

For finite collections you don't need AC; the trouble starts with infinitely many arbitrary sets.
:::

:::example[every vector space has a basis (via Zorn's lemma).]
Recall Zorn's lemma: if every *chain* (totally ordered subset) in a non-empty partially ordered set $P$ has an upper bound in $P$, then $P$ has a maximal element. Fix a vector space $V$ over a field $\mathbb{F}$.
:::

:::solution
1. Step 1 (set up the poset). Let $P$ be the collection of all *linearly independent* subsets of $V$, ordered by inclusion $\subseteq$. It is non-empty because $\emptyset \in P$ (the empty set is vacuously independent).
2. Step 2 (verify the chain condition). Let $\mathcal{C}$ be a chain in $P$ and put $U = \bigcup_{S \in \mathcal{C}} S$. Claim: $U$ is linearly independent, so $U \in P$ and is an upper bound for $\mathcal{C}$. Indeed, any linear dependence uses only *finitely many* vectors $v_1,\dots,v_n \in U$. Each $v_k$ lies in some $S_k \in \mathcal{C}$; since $\mathcal{C}$ is totally ordered, one of these $S_k$ contains all the others, hence contains $v_1,\dots,v_n$. But that $S_k$ is independent, so the only dependence is trivial. Thus $U$ is independent.
3. Step 3 (apply Zorn). Every chain has an upper bound, so Zorn's lemma yields a maximal linearly independent set $B$.
4. Step 4 (maximal independent $\Rightarrow$ spanning). Suppose $B$ did *not* span $V$; pick $w \in V \setminus \operatorname{span}(B)$. Then $B \cup \{w\}$ is still independent (any dependence involving $w$ would express $w$ in terms of $B$, contradicting $w \notin \operatorname{span}(B)$). This strictly enlarges $B$, contradicting maximality. Hence $B$ spans $V$.
5. Conclusion: $B$ is linearly independent and spanning, i.e. a basis. Sanity check: the only place AC/Zorn entered was Step 3 — for a *finite-dimensional* space you can build a basis by hand without it, which is why the difficulty is genuinely about infinite dimension.
:::

## Ordinals, Cardinals, and Well-Ordering

<!-- section: ordinals-cardinals -->

:::definition[Ordinal]{#ordinal-definition}
An **ordinal** is a transitive set well-ordered by $\in$.
:::

Ordinals represent order types of well-ordered sets. $0 = \emptyset$, $1 = \{0\}$, $2 = \{0,1\}$, $\omega$ (the first infinite one) = {0,1,2,...}, and so on.

:::theorem[Order type of a well-ordering]
Every well-ordered set is order-isomorphic to a unique ordinal.
:::

:::definition[Cardinal]{#cardinal-definition}
A **cardinal** is an ordinal not bijective with any smaller ordinal.
:::

Finite cardinals = finite ordinals. Infinite: $\aleph_0 = |\mathbb{N}|$, $\aleph_1$, $2^{\aleph_0} = \mathfrak{c}$, etc.

:::theorem[Cantor's theorem]{#cantor-theorem}
For any set $X$, the cardinality of its power set is strictly larger:

$$|X| < |\mathcal{P}(X)|.$$
:::

Hence there is no largest cardinal.

:::intuition
Ordinals are "counting numbers" that also encode order: $\omega$ is the order type of the naturals; after all of them comes $\omega+1$.

Cardinals answer "how many?" ignoring order. Two sets have same cardinal if there is a bijection between them.

$\aleph_0$ is the smallest infinity; the continuum may or may not be $\aleph_1$ (continuum hypothesis).
:::

:::example[order type depends on the ordering, cardinal does not.]
Step 1. The naturals $0 < 1 < 2 < \cdots$ in their usual order form a well-ordered set (every non-empty subset has a least element), and its order type is the ordinal $\omega$.
:::

:::solution
The integers $\dots < -2 < -1 < 0 < 1 < 2 < \dots$ in their usual order are **not** well-ordered: the subset $\{\dots,-2,-1\}$ has no least element. So this ordering has *no* order type as an ordinal at all.

Well-ordering is a property of the *ordering*, not of the underlying set. Re-list the same integers as
$$0,\; -1,\; 1,\; -2,\; 2,\; -3,\; 3,\; \dots$$
This new order *is* a well-order (it is a copy of $0,1,2,3,\dots$), so now $\mathbb{Z}$ has order type $\omega$.

Sanity check on cardinality: none of this changed how *many* integers there are. The zig-zag list is itself a bijection $\omega \to \mathbb{Z}$, so $|\mathbb{Z}| = |\omega| = \aleph_0$. Order type changed from "undefined" to $\omega$; the cardinal stayed $\aleph_0$ throughout — exactly the ordinality-vs-cardinality distinction.
:::

:::example[Cantor's theorem via diagonalization.]
We prove $|X| < |\mathcal{P}(X)|$ for *every* set $X$ (finite or infinite).
:::

:::solution
Step 1 ($\le$, an injection exists). The map $x \mapsto \{x\}$ sends $X$ injectively into $\mathcal{P}(X)$, so $|X| \le |\mathcal{P}(X)|$.

Step 2 (no surjection exists). Suppose toward contradiction that $f : X \to \mathcal{P}(X)$ is *onto*. Define the "diagonal" set
$$D = \{\, x \in X \mid x \notin f(x) \,\} \in \mathcal{P}(X).$$
Since $f$ is onto, $D = f(y)$ for some $y \in X$. Now ask whether $y \in D$:
$$y \in D \iff y \notin f(y) \iff y \notin D,$$
using the definition of $D$ and then $f(y) = D$. That is a contradiction, so no surjection $X \to \mathcal{P}(X)$ can exist.

Combining: there is an injection but no surjection, so the inequality is strict, $|X| < |\mathcal{P}(X)|$.

Sanity check: for $X = \{a,b\}$ we get $|X| = 2$ and $|\mathcal{P}(X)| = 4$ ($\emptyset,\{a\},\{b\},\{a,b\}$), and indeed $2 < 4$. Applying the theorem repeatedly ($X, \mathcal{P}(X), \mathcal{P}(\mathcal{P}(X)),\dots$) produces ever-larger cardinals, so **there is no largest cardinal**. This matches questions `set-ordinals-cardinals-2` and `-4`.
:::

## Transfinite Induction and Recursion

<!-- section: transfinite -->

:::theorem[Transfinite induction]{#transfinite-induction}
To prove $\forall \alpha \, \phi(\alpha)$ for ordinals, it is enough to prove:

1. $\phi(0)$
2. If $\phi(\beta)$ then $\phi(\beta+1)$
3. If $\lambda$ limit and $\phi(\beta)$ for all $\beta < \lambda$, then $\phi(\lambda)$.
:::

This generalizes ordinary induction.

:::definition[Transfinite recursion]{#transfinite-recursion}
**Transfinite recursion** defines functions on ordinals by recursion along the well-ordering.
:::

Just as ordinary recursion defines $F(n+1)$ from $F(n)$, transfinite recursion has three matching clauses — a base value $F(0)$, a successor rule $F(\beta+1)$ from $F(\beta)$, and a **limit rule** that assembles $F(\lambda)$ from the whole "history" $\{F(\beta) : \beta < \lambda\}$ (typically as a union or supremum). The limit clause is what ordinary recursion never needs, because $\mathbb{N}$ has no limit stages.

:::theorem[Well-ordering theorem]{#well-ordering}
Assuming AC, every set admits a well-ordering, hence can be put in bijection with an ordinal (its cardinal).
:::

:::intuition
Ordinary induction stops at finite numbers. Transfinite induction lets you "keep going past infinity": after proving it for all finite stages, you still have to check the limit stage $\omega$ (and higher limits).

It is the only way to prove statements about all ordinals or define functions that go on "forever".
:::

:::example[defining ordinal addition by transfinite recursion.]
We define $\alpha + \gamma$ by recursion on the *second* argument $\gamma$, using all three clauses.
:::

:::solution
Step 1 (base). $\alpha + 0 = \alpha$.

Step 2 (successor). $\alpha + (\beta + 1) = (\alpha + \beta) + 1$ — take the successor of the previously defined value.

Step 3 (limit). For a limit ordinal $\lambda$, $\alpha + \lambda = \sup\{\, \alpha + \beta \mid \beta < \lambda \,\}$ — glue together everything defined below $\lambda$.

Now compute $1 + \omega$ and $\omega + 1$ to see that ordinal addition is **not commutative**.
$1 + \omega$: since $\omega$ is a limit, use Step 3: $1 + \omega = \sup\{1 + n \mid n < \omega\} = \sup\{1,2,3,\dots\} = \omega$.
$\omega + 1$: since $1 = 0 + 1$ is a successor, use Step 2: $\omega + 1 = (\omega + 0) + 1 = \omega + 1$, the successor of $\omega$, which is strictly greater than $\omega$.

Conclusion: $1 + \omega = \omega \neq \omega + 1$. Sanity check: intuitively, prepending one item to an $\omega$-list ($\ast,0,1,2,\dots$) just relabels an $\omega$-list, while appending one item after all of $\omega$ ($0,1,2,\dots,\ast$) creates a brand-new last element — so the results genuinely differ.
:::

:::example[transfinite induction — every ordinal is $0$, a successor, or a limit.]
We prove $\phi(\alpha)$: "$\alpha = 0$, or $\alpha = \beta + 1$ for some $\beta$, or $\alpha$ is a limit ordinal (nonzero with no immediate predecessor)." We run through the three induction clauses.
:::

:::solution
1. Step 1 (base). $\phi(0)$ holds: $\alpha = 0$ satisfies the first disjunct outright.
2. Step 2 (successor). Assume $\phi(\beta)$; consider $\alpha = \beta + 1$. Then $\alpha$ is by construction a successor, so its second disjunct holds. (Note $\phi(\beta)$ was not even needed here — successors classify themselves.)
3. Step 3 (limit). Let $\lambda$ be a limit-candidate: $\lambda \neq 0$ and, by the induction hypothesis, every $\beta < \lambda$ falls into one of the three types. If $\lambda$ had an immediate predecessor $\mu$ (so $\lambda = \mu + 1$) it would be a successor; since we are in the remaining case where no such $\mu$ exists, $\lambda$ is nonzero with no immediate predecessor — which is exactly the definition of a limit ordinal, so the third disjunct holds.
4. The three cases are exhaustive, so $\phi(\alpha)$ holds for every ordinal $\alpha$. Sanity check: $\omega$ has predecessors $0,1,2,\dots$ but none of them is *immediate* (there is no largest natural number below $\omega$), so $\omega$ is correctly classified as a limit — and this is precisely the case that forgetting Step 3 would miss.
:::

## Common Mistakes

- **No universal set:** Believing that "the set of all sets" exists is wrong — it leads directly to Russell's paradox and is forbidden by the axioms.

- **Choice is independent:** Assuming the Axiom of Choice is "obviously true" or "obviously false" is mistaken. It is independent; both ZF+AC and ZF+¬AC are consistent (relative to ZF).

- **Cardinality versus ordinality:** Confusing cardinality with ordinality for infinite sets leads to errors. $|\mathbb{N}| = |\mathbb{Z}| = \aleph_0$ even though as ordered sets they look different.

- **Many different infinities:** Thinking every infinite set has the same size is incorrect. Cantor's theorem and the diagonal argument show uncountably many different infinities.

- **Transfinite induction includes limits:** Applying "induction" only to the successor step and forgetting the limit-ordinal case is a mistake in transfinite settings (e.g., proving something for all ordinals < $\omega_1$).

- **CH requires extra axioms:** Claiming CH is "true" or "false" in ordinary mathematics without specifying extra axioms is wrong; it is independent of ZFC.
