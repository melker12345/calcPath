# Modular Arithmetic

Congruences, the Chinese remainder theorem, and quadratic residues with Jacobi and Legendre symbols.

Modular arithmetic is arithmetic on the "clock": after reaching the modulus you wrap around. Formally, we work in the ring of residue classes $\mathbb{Z}/n\mathbb{Z}$. It lets us ignore multiples of the modulus and focus only on remainders, which simplifies calculations involving divisibility, cyclic patterns, and large exponents.

This is the language of modern cryptography (Diffie-Hellman, RSA, elliptic curves), checksums, hashing, and computer science (hash tables, cyclic buffers). Many Diophantine problems and congruences become tractable only after translating them into modular equations.

Key concepts: congruence relation, arithmetic operations that are well-defined on classes, inverses when they exist, and the Chinese Remainder Theorem for combining information from several moduli.

## Congruences and Residue Classes

<!-- section: congruences-residues -->

:::definition[Congruence modulo $m$]{#congruence}
For a positive integer $m$, we say $a \equiv b \pmod{m}$ ($a$ is congruent to $b$ modulo $m$) if and only if $m$ divides $(a-b)$, that is,

$$a - b = m k \quad \text{for some integer } k.$$
:::

This is an equivalence relation on $\mathbb{Z}$: reflexive, symmetric, transitive.

:::definition[Residue classes]
The equivalence classes are the residue classes $[0], [1], \dots, [m-1]$. We usually represent each class by its least nonnegative residue $r$ with $0 \leq r < m$.
:::

:::proposition[Arithmetic is well-defined on classes]{#congruence-arithmetic}
Addition, subtraction, and multiplication are well-defined on classes: if $a\equiv a' \pmod m$ and $b\equiv b' \pmod m$ then $a+b \equiv a'+b'$, $a-b \equiv a'-b'$, and $a b \equiv a' b' \pmod m$.
:::

:::intuition
On a 12-hour clock, 10 o'clock + 5 hours is 3 o'clock, not 15. 15 ≡ 3 mod 12 because they differ by a multiple of 12 (the full cycles).

All numbers that leave the same remainder when divided by m are "the same" for purposes of mod-m arithmetic.
:::

:::example[Compute $17 + 25 \pmod{12}$]
The point is that we may replace each number by its residue *before* adding, because addition is well-defined on classes.
:::

:::solution
Reduce the first term: $17 = 12 + 5$, so $17 \equiv 5 \pmod{12}$.
Reduce the second term: $25 = 24 + 1 = 2\cdot 12 + 1$, so $25 \equiv 1 \pmod{12}$.
Add the residues: $5 + 1 = 6$, so $17 + 25 \equiv 6 \pmod{12}$.

Sanity check by adding first, then reducing: $17 + 25 = 42$, and $42 = 3\cdot 12 + 6$, so $42 \equiv 6 \pmod{12}$. Both routes agree, which is exactly what "well-defined on classes" guarantees.
:::

## Modular Inverses and Linear Congruences

<!-- section: inverses-congruences -->

:::definition[Multiplicative inverse]{#modular-inverse}
An integer $a$ has a **multiplicative inverse** modulo $m$ (written $a^{-1} \bmod m$) if there exists $x$ with

$$a x \equiv 1 \pmod m.$$
:::

:::theorem[When an inverse exists]
The inverse $a^{-1} \bmod m$ exists if and only if $\gcd(a,m) = 1$, that is, $a$ and $m$ are coprime.
:::

:::recipe[Solving a linear congruence $ax \equiv b \pmod m$]
- Compute d = gcd(a,m).
- Solutions exist iff d divides b.
- If so, there are exactly d distinct solutions modulo m.
- First find one particular solution using extended gcd (scale), then add multiples of m/d.
:::

:::intuition
The inverse is the "undo" multiplier: multiply by it and you get back to 1 (mod m). Only possible when a and m share no common factors other than 1.

Solving ax ≡ b mod m is like "divide both sides by a" but you must check the gcd condition and accept multiple answers when d>1.
:::

:::example[Solve $5x \equiv 3 \pmod 7$]
Check solvability: $d = \gcd(5,7) = 1$, and $1 \mid 3$, so a solution exists. Because $d = 1$ there is exactly one solution modulo $7$.
Find the inverse of $5$ via the extended Euclidean algorithm: we want integers with $5s + 7t = 1$. Here $5\cdot 3 + 7\cdot(-2) = 15 - 14 = 1$, so $5\cdot 3 \equiv 1 \pmod 7$ and $5^{-1} \equiv 3 \pmod 7$.
Multiply both sides of the congruence by $3$: $x \equiv 3\cdot 3 \equiv 9 \equiv 2 \pmod 7$.
:::

:::solution
1. Sanity check: $5\cdot 2 = 10 \equiv 3 \pmod 7$ (since $10 - 7 = 3$). Correct, and it is the unique solution modulo $7$.
:::

:::example[(many solutions):]
**Solve $6x \equiv 8 \pmod{10}$**
:::

:::solution
$d = \gcd(6,10) = 2$, and $2 \mid 8$, so solutions exist; there will be exactly $d = 2$ of them modulo $10$.
Divide the whole congruence (both sides *and* the modulus) by $d = 2$: $3x \equiv 4 \pmod 5$.
Now $\gcd(3,5) = 1$; the inverse of $3$ mod $5$ is $2$ (since $3\cdot 2 = 6 \equiv 1$). So $x \equiv 2\cdot 4 = 8 \equiv 3 \pmod 5$.
Lift back to modulus $10$ by adding multiples of $m/d = 5$: $x \equiv 3$ and $x \equiv 8 \pmod{10}$.

Sanity check: $6\cdot 3 = 18 \equiv 8 \pmod{10}$ and $6\cdot 8 = 48 \equiv 8 \pmod{10}$. Two solutions, as predicted.
:::

## Powers and Euler/Fermat (preview)

<!-- section: modular-powers -->

A number like $3^{100}$ has $48$ digits, yet $3^{100} \bmod 7$ is a single digit. The trick is never to build the giant number: because multiplication is well-defined on residue classes, we may reduce modulo $m$ after every multiplication (or, faster, use repeated squaring), keeping every intermediate value below $m^2$.

Even the exponent can shrink.

:::theorem[Fermat's little theorem]{#fermat-little}
If $p$ is prime and $\gcd(a,p) = 1$, then

$$a^{p-1} \equiv 1 \pmod p.$$
:::

So the powers of $a$ cycle with period dividing $p-1$; hence $a^{k} \bmod p$ depends only on $k \bmod (p-1)$.

:::theorem[Euler's theorem]{#euler-theorem}
If $\gcd(a,m) = 1$, then

$$a^{\varphi(m)} \equiv 1 \pmod m,$$

where $\varphi$ is Euler's totient.
:::

The exponent can therefore be reduced modulo $\varphi(m)$. Fermat is the special case $m = p$ prime, where $\varphi(p) = p-1$.

:::intuition
Exponents wrap around in the exponent "clock" whose size is related to how many invertible residues there are.

You can reduce the exponent first using the theorem, making huge exponents trivial.
:::

:::example[Compute $3^{100} \bmod 7$ using Fermat (preview)]
Hypotheses: $7$ is prime and $\gcd(3,7) = 1$, so Fermat's Little Theorem applies: $3^{6} \equiv 1 \pmod 7$.
Reduce the exponent modulo $p - 1 = 6$: $100 = 16\cdot 6 + 4$, so the exponent is congruent to $4$.
Therefore $3^{100} = (3^{6})^{16}\cdot 3^{4} \equiv 1^{16}\cdot 3^{4} \equiv 3^{4} \pmod 7$.
Evaluate the small leftover: $3^{4} = 81$, and $81 = 11\cdot 7 + 4$, so $3^{4} \equiv 4 \pmod 7$.
:::

:::solution
1. So $3^{100} \equiv 4 \pmod 7$.
2. Sanity check by squaring: $3^{2} = 9 \equiv 2$, so $3^{4} \equiv 2^{2} = 4 \pmod 7$, matching the answer.
3. Note the subtlety that keeps this rigorous: you reduce the *exponent* modulo $p-1$, but the *base* modulo $p$. Reducing the exponent modulo $p$ would be wrong.
:::

## The Ring Z/nZ

<!-- section: ring-structure -->

:::definition[The ring $\mathbb{Z}/n\mathbb{Z}$]{#z-mod-n}
The set of residue classes modulo $n$, with the induced $+$ and $\cdot$, forms a ring $\mathbb{Z}/n\mathbb{Z}$.
:::

:::theorem[$\mathbb{Z}/n\mathbb{Z}$ is a field exactly for prime $n$]
$\mathbb{Z}/n\mathbb{Z}$ is a field precisely when $n$ is prime, i.e. every nonzero element has an inverse.
:::

When n composite the ring has zero-divisors: e.g. mod 6, 2*3≡0 but neither is 0 mod6.

This algebraic structure explains why some equations have more or fewer solutions mod n than over the reals.

:::intuition
Modulo a prime everything (nonzero) has an inverse, like the usual numbers. Modulo composite some numbers "eat" others to give zero, which has no inverse.

The ring view lets us import all the usual algebra rules (distributivity etc.) while remembering the wrap-around.
:::

:::example[Zero divisors mod 6]
Take the classes $[2]$ and $[3]$ in $\mathbb{Z}/6\mathbb{Z}$. Neither is the zero class: $2 \not\equiv 0$ and $3 \not\equiv 0 \pmod 6$.
Multiply: $2\cdot 3 = 6 \equiv 0 \pmod 6$. So two nonzero elements multiply to zero. These are **zero divisors**, and $6$ is composite ($6 = 2\cdot 3$), which is exactly why they exist.
Consequence: $2$ cannot have an inverse mod $6$. If it did, multiplying $2\cdot 3 \equiv 0$ by $2^{-1}$ would give $3 \equiv 0 \pmod 6$, which is false. (Indeed $\gcd(2,6) = 2 \neq 1$.)
:::

:::solution
1. Contrast with a prime modulus: mod $5$ there are no zero divisors, since $5$ prime means $5 \mid ab$ forces $5 \mid a$ or $5 \mid b$. That absence of zero divisors is what makes $\mathbb{Z}/5\mathbb{Z}$ a field.
:::

## Common Mistakes

- **Reducing inconsistently**: You may reduce each term before combining *or* combine first and reduce at the end, but do it consistently. For example $5 + 7 = 12 \equiv 0 \pmod 6$, and reducing first gives $5 + 7 \equiv (-1) + 1 = 0 \pmod 6$ — same answer. The error is stopping halfway (e.g. reducing one term and forgetting to finish reducing the sum).
- **Inverses exist for all a**: Only when coprime to m. 2 has no inverse mod 4 (2x even, never 1 mod4).
- **Number of solutions to ax≡b mod m**: Exactly d=gcd(a,m) solutions when d|b, not always 1 or always 0.
- **Negative remainders**: We conventionally use 0 ≤ r < m. -1 ≡ m-1 mod m is the standard positive representative.
- **Confusing ≡ with =**: a ≡ b mod m does not mean a=b; it means they differ by multiple of m. Never drop the "mod m" when it matters.

The Chinese Remainder Theorem (CRT) tells us when and how we can combine several modular conditions into a single congruence modulo the product of the moduli. It is named after ancient Chinese mathematicians who used it to solve calendar and astronomical problems.

In modern terms, if the moduli m1, m2, ..., mk are pairwise coprime, then the system
$x \equiv a_i \pmod{m_i}$ (for $i=1$ to $k$)
has a unique solution modulo M = m1 m2 ... mk.

CRT is indispensable in cryptography (RSA, secret sharing), computing with large numbers (break into small-modulus pieces), and in the structure theory of rings (Z/MZ ≅ product of Z/miZ when coprime).

The constructive proof gives an explicit formula for the solution using the inverses of the partial products.

## Statement and Pairwise Coprime Condition

<!-- section: crt-statement -->

:::theorem[Chinese Remainder Theorem]{#crt}
Let $m_1, \dots, m_k$ be positive integers that are **pairwise coprime** ($\gcd(m_i, m_j) = 1$ for $i \neq j$). Let $a_1, \dots, a_k$ be any integers. Then the system of congruences

$$
x \equiv a_i \pmod{m_i} \quad (i=1,\dots,k)
$$

has a solution, and the solution is unique modulo $M = m_1 m_2 \cdots m_k$.
:::

:::proof
Coprimeness gives *exactly one* class: the product $M = m_1 m_2 \cdots m_k$ has one residue class for each combination of remainders $(a_1, \dots, a_k)$. There are $m_1 m_2 \cdots m_k = M$ possible combinations and $M$ residue classes mod $M$, and coprimeness makes the correspondence a bijection — so every combination is hit exactly once.
:::

If the mi are not pairwise coprime, solutions may still exist but are not guaranteed for arbitrary ai, and when they exist the modulus is the lcm of the mi rather than the product.

:::intuition
Imagine several clocks of different sizes (the mi) that are "coprime in size". There is exactly one time that satisfies all the hand positions ai simultaneously, and it repeats every full product of the clock sizes.

Pairwise coprime means no two clocks share a common "tick factor", so their cycles combine fully without overlap or gaps in the combined period.
:::

:::example[Solve the classic system by search (to see uniqueness concretely)]
$$
x \equiv 2 \pmod 3, \qquad x \equiv 3 \pmod 5, \qquad x \equiv 2 \pmod 7.
$$
:::

:::solution
Here $m = 3, 5, 7$ are pairwise coprime, so $M = 3\cdot 5\cdot 7 = 105$ and CRT promises exactly one solution modulo $105$. We can find it by successive sieving:

Start from the last condition: $x \equiv 2 \pmod 7$ gives candidates $2, 9, 16, 23, 30, \dots$
Keep those with $x \equiv 3 \pmod 5$: of the list, $23$ works ($23 = 4\cdot 5 + 3$). So now $x \equiv 23 \pmod{35}$.
Finally impose $x \equiv 2 \pmod 3$: $23 = 7\cdot 3 + 2$, so $23 \equiv 2 \pmod 3$ already holds.

So $x \equiv 23 \pmod{105}$.

Sanity check: $23 \bmod 3 = 2$, $23 \bmod 5 = 3$, $23 \bmod 7 = 2$ — all three conditions hold, and by CRT no other class mod $105$ does. The next section derives the same answer with the explicit formula.
:::

## Constructive Proof and Explicit Solution

<!-- section: constructive-crt -->

Write $M_i = M / m_i$ for the product of all moduli except $m_i$. Since $\gcd(M_i, m_i) = 1$ (by pairwise coprimeness), $M_i$ has an inverse $y_i \bmod m_i$, that is $M_i y_i \equiv 1 \pmod{m_i}$.

:::theorem[Explicit CRT solution]{#crt-formula}
With $M_i$ and $y_i$ as above, the solution of the system is

$$
x = \sum_{i=1}^k a_i M_i y_i \pmod{M}.
$$
:::

:::proof
Each term $a_i M_i y_i \equiv a_i \cdot 1 \equiv a_i \pmod{m_i}$, and $\equiv 0$ mod the other $m_j$ (because $M_i$ is divisible by $m_j$). Summing gives the correct $a_i$ mod each $m_i$, and uniqueness follows from the ring isomorphism, or by noting the difference of two solutions is $0$ mod each $m_i$ and hence mod $M$.
:::

:::intuition
For each condition, build a number that is 0 mod every other modulus but "1" mod its own (using the inverse). Scale it by the desired ai and add them all up. The total satisfies all conditions at once.

The big modulus M is the "least common multiple period" guaranteed by coprimeness.
:::

:::example[Solve $x\equiv 2 \pmod 3,\ x\equiv 3 \pmod 5,\ x\equiv 2 \pmod 7$ with the explicit formula]
Set $M = 3\cdot 5\cdot 7 = 105$. For each modulus compute $M_i = M/m_i$ and then the inverse $y_i \equiv M_i^{-1} \pmod{m_i}$.
:::

:::solution
$i=1$ ($m_1 = 3$): $M_1 = 105/3 = 35$, and $35 \equiv 2 \equiv -1 \pmod 3$. We need $y_1$ with $(-1)\,y_1 \equiv 1$, so $y_1 \equiv -1 \equiv 2 \pmod 3$.
$i=2$ ($m_2 = 5$): $M_2 = 105/5 = 21$, and $21 \equiv 1 \pmod 5$. So $y_2 \equiv 1 \pmod 5$.
$i=3$ ($m_3 = 7$): $M_3 = 105/7 = 15$, and $15 \equiv 1 \pmod 7$. So $y_3 \equiv 1 \pmod 7$.

Assemble the solution $x = \sum_i a_i M_i y_i$:
$$
x = 2\cdot 35\cdot 2 \;+\; 3\cdot 21\cdot 1 \;+\; 2\cdot 15\cdot 1 = 140 + 63 + 30 = 233.
$$
Reduce mod $105$: $233 = 2\cdot 105 + 23$, so $x \equiv 23 \pmod{105}$.

Sanity check: $23 \bmod 3 = 2$, $23 \bmod 5 = 3$, $23 \bmod 7 = 2$. All three hold, and this matches the answer found by sieving in the previous section.
:::

## When Moduli Are Not Coprime

<!-- section: non-coprime-case -->

:::theorem[CRT with general moduli]
If $\gcd(m_i, m_j) > 1$ for some pair, a solution exists if and only if for every such pair

$$a_i \equiv a_j \pmod{\gcd(m_i, m_j)}.$$

When solutions exist, they are unique modulo $\operatorname{lcm}(m_1, \dots, m_k)$, which is smaller than the product.
:::

The general case can be handled by iteratively solving two at a time, or using the explicit formula with care on the lcm.

:::intuition
If two conditions conflict on the overlapping part (the gcd), no solution. E.g. x≡1 mod 4 and x≡2 mod 6: gcd=2, but 1≢2 mod2, impossible.

If consistent on overlaps, the combined period is the lcm, not the full product.
:::

:::example[Consistent non-coprime system]
$$
x \equiv 3 \pmod 4, \qquad x \equiv 7 \pmod 6.
$$
:::

:::solution
Check the compatibility condition first. Here $\gcd(4,6) = 2$, so we need $3 \equiv 7 \pmod 2$. Both $3$ and $7$ are odd, i.e. $3 \equiv 7 \equiv 1 \pmod 2$, so the system is consistent and a solution exists.
Substitute the first congruence: write $x = 4k + 3$ and plug into the second: $4k + 3 \equiv 7 \pmod 6$, i.e. $4k \equiv 4 \pmod 6$.
Divide through by $\gcd(4,6) = 2$, remembering the modulus also divides by $2$: $2k \equiv 2 \pmod 3$. Since $\gcd(2,3) = 1$, cancel the $2$: $k \equiv 1 \pmod 3$.
Back-substitute $k = 3m + 1$: $x = 4(3m + 1) + 3 = 12m + 7$.

So $x \equiv 7 \pmod{12}$, and note $\mathrm{lcm}(4,6) = 12$ — the period is the lcm, not the product $24$.

Sanity check: $7 \bmod 4 = 3$ (target $3$, good) and $7 \bmod 6 = 1$. The second target was written as $7 \pmod 6$, and $7 \equiv 1 \pmod 6$, so both conditions hold.
:::

## Applications

<!-- section: crt-applications -->

- RSA decryption: compute mod p and mod q separately then combine via CRT (much faster for large exponents).
- Secret sharing and threshold schemes.
- Fast multiplication of huge integers by splitting via CRT into smaller pieces.
- Solving systems of linear Diophantine equations.
- In computing, representing numbers in mixed-radix systems.

:::theorem[Ring form of the CRT]
When the $m_i$ are pairwise coprime and $M = m_1 \cdots m_k$, there is a ring isomorphism

$$\mathbb{Z}/M\mathbb{Z} \cong \prod_i \mathbb{Z}/m_i \mathbb{Z},$$

and this is the algebraic heart of the CRT.
:::

:::intuition
Big hard problems mod a composite can be broken into easy problems mod the prime power factors, solved independently, then glued back together uniquely.

This "divide and conquer" via coprime pieces is why RSA can use huge moduli safely yet compute efficiently.
:::

:::example[RSA-style small CRT]
Suppose we work modulo $M = pq$ with $p = 5$, $q = 13$, so $M = 65$. A CRT-based RSA decryption computes the message separately mod each prime and then glues the pieces. Say the two partial results are
$$
m \equiv 3 \pmod 5, \qquad m \equiv 6 \pmod{13},
$$
and we want $m \bmod 65$. Apply the explicit formula with $M_1 = 65/5 = 13$ and $M_2 = 65/13 = 5$:
:::

:::solution
$y_1 \equiv M_1^{-1} \pmod 5$: $13 \equiv 3 \pmod 5$, and $3\cdot 2 = 6 \equiv 1$, so $y_1 = 2$.
$y_2 \equiv M_2^{-1} \pmod{13}$: $5 \cdot 8 = 40 \equiv 1 \pmod{13}$, so $y_2 = 8$.

Then
$$
m = 3\cdot 13\cdot 2 + 6\cdot 5\cdot 8 = 78 + 240 = 318, \qquad 318 = 4\cdot 65 + 58,
$$
so $m \equiv 58 \pmod{65}$.

Sanity check: $58 \bmod 5 = 3$ and $58 \bmod 13 = 58 - 4\cdot 13 = 6$. Both partial results are recovered — this "gluing" is exactly what makes CRT-RSA faster than working mod $pq$ directly, since the per-prime exponentiations are on smaller numbers.
:::

## Common Mistakes

- **Forgetting the pairwise coprime hypothesis**: The simple product modulus and guaranteed unique solution require gcd(mi,mj)=1 for all pairs. Counterexamples exist otherwise.
- **Using the formula without inverses existing**: If not coprime, $M_i$ may not be invertible $\bmod m_i$; the construction fails.
- **Claiming no solution when consistent on gcds**: Even if not pairwise coprime, check the compatibility a_i ≡ a_j mod gcd(mi,mj) before declaring impossibility.
- **Solution unique mod product always**: When not coprime the period is lcm ≤ product; multiple solutions mod product may exist or none.
- **Sign errors in explicit formula**: The $y_i$ are inverses of $M_i \bmod m_i$; easy to pick the wrong sign or representative when computing by hand.

The congruence relation a ≡ b mod m is the central equivalence relation of number theory. It turns the integers into a ring of residue classes and allows us to do arithmetic while "ignoring" multiples of m. Understanding its algebraic properties (it is a congruence in the algebraic sense: compatible with + and *) is what makes modular arithmetic powerful.

This topic formalizes what we used intuitively in the previous modular arithmetic topic: the quotient ring construction, the ideal (m), and how congruences interact with divisibility and gcd.

It sets the stage for rings Z/nZ, Euler's theorem generalizations, and the isomorphism theorems via CRT.

## Definition and Equivalence Relation Properties

<!-- section: definition-equivalence -->

The relation $a \equiv b \pmod m$ means $m \mid (a-b)$.

:::proposition[Congruence is an equivalence relation]
For a fixed modulus $m$, congruence mod $m$ is reflexive, symmetric and transitive.
:::

:::proof
- Reflexive: a ≡ a mod m (m divides 0).
- Symmetric: if a≡b then b≡a ( - (a-b) ).
- Transitive: if a≡b and b≡c then a-c = (a-b)+(b-c) divisible by m.
:::

:::definition[Residue class]
The equivalence classes are $[r] = \{ \dots, r-2m, r-m, r, r+m, r+2m, \dots \}$ for $r = 0, 1, \dots, m-1$, the standard representatives.
:::

:::intuition
"Same mod m" means they are identical after you throw away complete cycles of m. Like two times on different days that show the same clock position.

The three properties (reflexive/symmetric/transitive) are exactly what is needed for "being the same" to be consistent and partition the integers into clean buckets.
:::

:::example[The four classes mod 4]
Modulo $4$ there are exactly $4$ residue classes, each an arithmetic progression with common difference $4$:
:::

:::solution
$[0] = \{\dots, -8, -4, 0, 4, 8, \dots\}$ (the multiples of $4$).
$[1] = 1 + 4\mathbb{Z} = \{\dots, -7, -3, 1, 5, 9, \dots\}$.
$[2] = 2 + 4\mathbb{Z} = \{\dots, -6, -2, 2, 6, 10, \dots\}$.
$[3] = 3 + 4\mathbb{Z} = \{\dots, -5, -1, 3, 7, 11, \dots\}$.

Verify these really partition $\mathbb{Z}$: every integer lands in exactly one class (its remainder on division by $4$), and no integer is in two. For instance $-1 \equiv 3 \pmod 4$ because $-1 - 3 = -4$ is a multiple of $4$; this is why $-1$ is a handy stand-in for the "top" class $m-1$ when handling signs.
:::

## Congruence is a Ring Congruence

<!-- section: ring-congruence -->

:::proposition[Congruence is compatible with $+$ and $\times$]
If $a_1 \equiv b_1 \pmod m$ and $a_2 \equiv b_2 \pmod m$, then

$$a_1 + a_2 \equiv b_1 + b_2, \qquad a_1 - a_2 \equiv b_1 - b_2, \qquad a_1 a_2 \equiv b_1 b_2 \pmod m.$$
:::

:::proof
This follows immediately from the definition: the differences are multiples of $m$, and $(a_1-b_1) + (a_2-b_2)$ is again a multiple of $m$ for the sum, with the cross term handling multiplication.
:::

Consequently the set of classes with induced + and * forms the quotient ring Z/mZ (also written Z_m).

:::intuition
You can add or multiply two "clock readings" and the result doesn't depend on which representative you chose for each. The arithmetic is well-defined on the classes themselves.

This is why  (10 mod12) + (5 mod12) = 3 mod12 no matter if you think of 10 as 22 or -2.
:::

:::example[Well-defined multiplication mod 5]
The claim is that the product of two classes does not depend on which representatives you pick. Test it with $[7]\cdot[8]$ mod $5$, where $7 \equiv 2$ and $8 \equiv 3 \pmod 5$.
:::

:::solution
Using the original representatives: $7\cdot 8 = 56 = 11\cdot 5 + 1$, so $56 \equiv 1 \pmod 5$.
Using the reduced representatives: $2\cdot 3 = 6 \equiv 1 \pmod 5$.

Same class, as promised. To see *why* the choice is irrelevant, replace $7$ by another representative, say $7 = 2 + 5$: $(2 + 5)\cdot 3 = 6 + 15$, and $15 \equiv 0 \pmod 5$, so the extra $15$ contributes nothing and we again get $\equiv 1$. The general reason is the identity $(a + km)(c) = ac + m(kc)$: shifting a representative by a multiple of $m$ only adds a multiple of $m$ to the product.
:::

## Connection to Ideals and Divisibility

<!-- section: ideals-divisibility -->

:::definition[The ideal $m\mathbb{Z}$]
The set $m\mathbb{Z} = \{\text{multiples of } m\}$ is the principal ideal generated by $m$, and congruence $a \equiv b \pmod m$ means

$$a - b \in m\mathbb{Z}.$$
:::

The gcd appears naturally: the common solutions to x≡a mod m, x≡b mod n etc.

:::proposition[Solvability of $kx \equiv c \pmod m$]
If $d = \gcd(k,m)$ then the congruence $k x \equiv c \pmod m$ has solutions if and only if $d \mid c$, and then exactly $d$ solutions modulo $m$, as seen earlier.
:::

Z/mZ is a field iff m prime (i.e. the ideal (m) is maximal).

:::intuition
The "ignore multiples of m" bucket is literally the ideal mZ, the multiples.

Divisibility questions translate into membership in ideals or kernels of maps.
:::

:::example[Solve 6x ≡ 9 mod 15]
d=gcd(6,15)=3, 3 divides 9, ok.
:::

:::solution
1. Divide eq by 3: 2x ≡3 mod5.
2. Inverse of 2 mod5 is 3 (2*3=6≡1).
3. x≡9≡4 mod5.
4. Solutions mod15: x=5k +4 for k=0,1,2 (the d=3 lifts).
5. Check: x=4: 6*4=24≡9 mod15? 24-15=9 yes.
6. x=9: 6*9=54, 54/15=3.6, 15*3=45,54-45=9 yes.
7. x=14: 6*14=84, 15*5=75,84-75=9 yes.
:::

## Induced Maps and Homomorphisms

<!-- section: homomorphisms -->

:::proposition[The reduction map is a homomorphism]
The natural projection $\pi\colon \mathbb{Z} \to \mathbb{Z}/m\mathbb{Z}$, $a \mapsto [a]$, is a ring homomorphism with kernel $m\mathbb{Z}$.
:::

By the first isomorphism theorem Z / mZ ≅ image.

More generally, congruences let us define maps on residue classes consistently.

This is the beginning of quotient constructions used throughout algebra.

:::intuition
The map that sends every integer to its "remainder bucket" respects addition and multiplication. It "forgets" the exact value but keeps the modular information.

Kernels capture exactly what is being set to zero (the multiples of m).
:::

:::example[The projection mod 3]
Let $\pi\colon \mathbb{Z} \to \mathbb{Z}/3\mathbb{Z}$ send each integer to its class. Check that it respects addition:
:::

:::solution
$\pi(5) = [2]$ (since $5 \equiv 2$) and $\pi(7) = [1]$ (since $7 \equiv 1$).
Add the inputs first: $\pi(5 + 7) = \pi(12) = [0]$ (since $12 \equiv 0 \pmod 3$).
Add the outputs: $[2] + [1] = [3] = [0]$.

The two agree, so $\pi(5+7) = \pi(5) + \pi(7)$, confirming $\pi$ is a homomorphism on this example. Its kernel is $\pi^{-1}([0]) = \{a : a \equiv 0 \pmod 3\} = 3\mathbb{Z}$, the multiples of $3$ — exactly the elements "forgotten" (sent to zero) by the map.
:::

## Common Mistakes

- **Thinking congruence only for positive remainders**: Classes include negatives; -1 is always a valid representative equivalent to m-1.
- **Dropping the modulus when manipulating**: a≡b mod m and c≡d mod m does NOT imply a/c ≡ b/d unless inverses exist.
- **Confusing the ideal (m) with the number m**: The congruence is membership of difference in the ideal mZ.
- **Assuming all rings Z/nZ behave like fields**: Only when n prime; otherwise zero divisors exist and not every equation has unique solution.
- **Forgetting that transitivity requires the same m**: a≡b mod m, b≡c mod n with m≠n does not imply a≡c mod anything in particular without lcm.

The Jacobi symbol (a/n) generalizes the Legendre symbol to odd composite n: if n= product p_i^{e_i} odd, (a/n) = product (a/p_i)^{e_i} (Legendre).

It is completely multiplicative in a, and (a/n)=0 if gcd(a,n)>1.

Unlike Legendre, (a/n)=1 does not imply a is quadratic residue mod n (it can be 1 even if non-residue mod some p| n, as long as the product of signs is +1).

It is still useful because it can be computed using a reciprocity law similar to Legendre, in time comparable to gcd, without factoring n.

Used in the Solovay-Strassen primality test (a probabilistic test using the Jacobi symbol).

## Definition

<!-- section: jacobi-def -->

:::definition[Jacobi symbol]{#jacobi-symbol}
For an odd positive integer $n > 1$ and an integer $a$, the **Jacobi symbol** is defined by factoring $n$ into odd primes (with multiplicity) and multiplying the Legendre symbols: if $n = \prod_i p_i^{e_i}$, then

$$\left(\frac{a}{n}\right) = \prod_i \left(\frac{a}{p_i}\right)^{e_i},$$

where the factors on the right are Legendre symbols. If $\gcd(a,n) > 1$ then $\left(\frac{a}{n}\right) = 0$, and for $n = 1$ we set $\left(\frac{a}{1}\right) = 1$ by convention.
:::

:::intuition
It is the "product of the yes/no answers" for the prime power factors of n.

It can say +1 even when there is no square root mod n, because the "no" from one prime can be canceled by "yes" from another.
:::

:::example[Compute the Jacobi symbol $\left(\tfrac{2}{15}\right)$]
Factor the (odd) modulus: $15 = 3\cdot 5$, so by definition $\left(\tfrac{2}{15}\right) = \left(\tfrac{2}{3}\right)\left(\tfrac{2}{5}\right)$, a product of Legendre symbols.
:::

:::solution
Use the rule $\left(\tfrac{2}{p}\right) = 1$ if $p \equiv 1$ or $7 \pmod 8$, and $-1$ if $p \equiv 3$ or $5 \pmod 8$:

$3 \equiv 3 \pmod 8$, so $\left(\tfrac{2}{3}\right) = -1$.
$5 \equiv 5 \pmod 8$, so $\left(\tfrac{2}{5}\right) = -1$.

Hence $\left(\tfrac{2}{15}\right) = (-1)(-1) = 1$.

Sanity check that this does **not** mean $2$ is a square mod $15$: a solution to $x^2 \equiv 2 \pmod{15}$ would require $x^2 \equiv 2 \pmod 3$. But mod $3$ the only squares are $0$ and $1$, never $2$, so there is no solution mod $3$ and therefore none mod $15$. This is the classic warning: for composite $n$, $\left(\tfrac{a}{n}\right) = 1$ can arise because the two $-1$ factors cancel, even though $a$ is a non-residue.
:::

## Properties and Reciprocity

<!-- section: jacobi-properties -->

:::proposition[Properties of the Jacobi symbol]
The Jacobi symbol satisfies:

- $\left(\frac{a}{n}\right) = \left(\frac{b}{n}\right)$ if $a \equiv b \pmod n$, so $\left(\frac{a}{n}\right) = \left(\frac{a \bmod n}{n}\right)$.
- It is completely multiplicative in the top: $\left(\frac{ab}{n}\right) = \left(\frac{a}{n}\right)\left(\frac{b}{n}\right)$.
- The supplementary rules $\left(\frac{-1}{n}\right) = (-1)^{(n-1)/2}$ and $\left(\frac{2}{n}\right) = (-1)^{(n^2-1)/8}$.
:::

:::theorem[Reciprocity for the Jacobi symbol]
If $m, n$ are odd, positive and coprime, then

$$\left(\frac{m}{n}\right)\left(\frac{n}{m}\right) = (-1)^{\frac{m-1}{2}\cdot\frac{n-1}{2}},$$

the same law as for primes.
:::

These allow computing (a/n) by a Euclidean-like algorithm (repeatedly flip using reciprocity, reduce mod, factor out 2 and -1 using the rules), without ever factoring n.

The running time is O(log^2 n) like gcd.

:::intuition
The reciprocity law works for the composite Jacobi just as for Legendre, letting you swap the arguments with a sign.

Combined with the special rules for 2 and -1, you can reduce the size like Euclid algorithm for gcd, computing the symbol fast.
:::

:::example[Compute the Jacobi symbol $\left(\tfrac{5}{21}\right)$ using reciprocity]
Here $m = 5$ and $n = 21$ are odd, positive, and coprime, so Jacobi reciprocity applies. The whole point of the reciprocity route is that it works *without factoring* $21$.
:::

:::solution
Apply the law: $\left(\tfrac{5}{21}\right)\left(\tfrac{21}{5}\right) = (-1)^{\frac{5-1}{2}\cdot\frac{21-1}{2}} = (-1)^{2\cdot 10} = 1$. Since the sign is $+1$, $\left(\tfrac{5}{21}\right) = \left(\tfrac{21}{5}\right)$.
Reduce the top mod the bottom: $21 \equiv 1 \pmod 5$, so $\left(\tfrac{21}{5}\right) = \left(\tfrac{1}{5}\right) = 1$.

Hence $\left(\tfrac{5}{21}\right) = 1$.

Cross-check via the definition (which *does* factor $21 = 3\cdot 7$): $\left(\tfrac{5}{21}\right) = \left(\tfrac{5}{3}\right)\left(\tfrac{5}{7}\right)$.

$\left(\tfrac{5}{3}\right) = \left(\tfrac{2}{3}\right) = -1$ (since $5 \equiv 2 \pmod 3$ and $3 \equiv 3 \pmod 8$).
$\left(\tfrac{5}{7}\right)$: both $5 \equiv 1$ and — no, use reciprocity directly. The exponent is $\frac{5-1}{2}\cdot\frac{7-1}{2} = 2\cdot 3 = 6$ (even), so $\left(\tfrac{5}{7}\right) = \left(\tfrac{7}{5}\right) = \left(\tfrac{2}{5}\right)$, and $5 \equiv 5 \pmod 8$ gives $\left(\tfrac{2}{5}\right) = -1$. So $\left(\tfrac{5}{7}\right) = -1$.

Product: $(-1)(-1) = 1$, matching the reciprocity computation.
:::

## Use in Primality Tests

<!-- section: jacobi-primality -->

:::recipe[Solovay-Strassen test]
For random $a$, compute the Jacobi symbol $\left(\frac{a}{n}\right)$ and the power $a^{(n-1)/2} \bmod n$. If $n$ is prime they are equal by Euler's criterion (the power equals Legendre = Jacobi).

- If for some $a$ they differ, $n$ is composite.
- If they agree for many $a$, declare $n$ a probable prime.
:::

It detects Carmichael numbers (for which the power is 1, but Jacobi may differ for some a).

:::intuition
For prime, the power must equal the Jacobi symbol.

If for a witness a the power mod n does not equal the easily computed Jacobi, then n cannot be prime.
:::

:::example[Solovay-Strassen on a small composite]
Take $n = 9$ (obviously composite, but small enough to compute by hand) and witness $a = 2$. The test compares $a^{(n-1)/2} \bmod n$ against the Jacobi symbol $\left(\tfrac{a}{n}\right)$.
:::

:::solution
Compute the power: $(n-1)/2 = 4$, and $2^{4} = 16 \equiv 7 \pmod 9$.
Compute the Jacobi symbol: $\left(\tfrac{2}{9}\right)$. Since $9 = 3^2$, $\left(\tfrac{2}{9}\right) = \left(\tfrac{2}{3}\right)^2 = (-1)^2 = 1$.
Compare: $7 \not\equiv 1 \pmod 9$. The two disagree, so $a = 2$ is a **witness** proving $9$ is composite.

Why it works: for a genuine prime $p$, Euler's criterion forces $a^{(p-1)/2} \equiv \left(\tfrac{a}{p}\right) \pmod p$ for every $a$ coprime to $p$. Any single $a$ that violates this equality certifies compositeness. For a Carmichael number such as $561$ the Fermat test can be fooled ($a^{560} \equiv 1 \pmod{561}$ for all coprime $a$), yet the stronger Solovay-Strassen equality still fails for many $a$, which is why this test catches Carmichael numbers that the plain Fermat test misses.
:::

## Common Mistakes

- **(a/n)=1 implies quadratic residue mod n**: False for composite n; it is necessary but not sufficient.
- **Jacobi requires factoring n**: No, the reciprocity algorithm computes it without factoring n (that's its point).
- **Jacobi defined for even n**: No, n must be odd positive.
- **Confusing with Legendre**: Legendre is the special case when n prime; Jacobi can be 1 for non-residues.

The Legendre symbol (a/p) is a compact notation that is 1 if a is quadratic residue mod p (p odd prime not dividing a), -1 if non-residue, and 0 if p divides a.

It is a character mod p, completely multiplicative in a, and satisfies the law of quadratic reciprocity that allows computing it in logarithmic time without finding square roots (like a Jacobi symbol but for prime).

It is the main tool for deciding quadratic residuosity and appears in many formulas (class numbers, L-functions, etc).

## Definition

<!-- section: legendre-def -->

:::definition[Legendre symbol]{#legendre-symbol}
For an odd prime $p$ and an integer $a$, the **Legendre symbol** $\left(\frac{a}{p}\right)$ is

- 0 if p | a

- 1 if p ∤ a and a is quadratic residue mod p

- -1 if p ∤ a and a is quadratic non-residue mod p.
:::

It can be computed via Euler's criterion,

$$\left(\frac{a}{p}\right) \equiv a^{(p-1)/2} \pmod p,$$

taking the representative $-1$ or $1$.

:::intuition
A compact +1 / -1 / 0 "yes/no/ divisible" answer to "is a a square mod p?"

Like a "sign" that tells the residuosity.
:::

:::example[Compute the Legendre symbol $\left(\tfrac{3}{7}\right)$]
Here $p = 7$ is an odd prime and $7 \nmid 3$, so the symbol is $\pm 1$. Use Euler's criterion, $\left(\tfrac{a}{p}\right) \equiv a^{(p-1)/2} \pmod p$:
:::

:::solution
$(p-1)/2 = 3$, so compute $3^{3} = 27$.
Reduce: $27 = 3\cdot 7 + 6$, so $27 \equiv 6 \equiv -1 \pmod 7$.

Since the result is $-1$, $\left(\tfrac{3}{7}\right) = -1$: $3$ is a quadratic non-residue mod $7$.

Sanity check against the squares mod $7$, which are $\{1, 2, 4\}$: indeed $3$ is not among them.
:::

## Properties

<!-- section: legendre-properties -->

:::proposition[Properties of the Legendre symbol]
For an odd prime $p$:

- $\left(\frac{a}{p}\right) = \left(\frac{b}{p}\right)$ if $a \equiv b \pmod p$; equivalently $\left(\frac{a}{p}\right) = \left(\frac{a \bmod p}{p}\right)$, and the symbol is $0$ when $p \mid a$.
- Completely multiplicative in the top: $\left(\frac{ab}{p}\right) = \left(\frac{a}{p}\right)\left(\frac{b}{p}\right)$.
- $\left(\frac{-1}{p}\right) = (-1)^{(p-1)/2}$, which is $1$ iff $p \equiv 1 \pmod 4$.
- $\left(\frac{2}{p}\right) = (-1)^{(p^2-1)/8}$, which is $1$ iff $p \equiv 1$ or $7 \pmod 8$.
:::

:::intuition
It only depends on a mod p.

Multiplicativity lets you factor the top argument into primes and compute for each.
:::

:::example[Compute $\left(\tfrac{6}{7}\right)$ via multiplicativity]
Factor the top: $6 = 2\cdot 3$, so $\left(\tfrac{6}{7}\right) = \left(\tfrac{2}{7}\right)\left(\tfrac{3}{7}\right)$.
:::

:::solution
$\left(\tfrac{2}{7}\right)$: the rule is $\left(\tfrac{2}{p}\right) = 1$ when $p \equiv \pm 1 \pmod 8$ and $-1$ when $p \equiv \pm 3 \pmod 8$. Since $7 \equiv 7 \equiv -1 \pmod 8$, we get $\left(\tfrac{2}{7}\right) = 1$.
$\left(\tfrac{3}{7}\right) = -1$ from the previous example.

So $\left(\tfrac{6}{7}\right) = 1\cdot(-1) = -1$: $6$ is a non-residue mod $7$.

Sanity check: the squares mod $7$ are $\{1, 2, 4\}$, and $6$ is not among them. (Watch the $\left(\tfrac{2}{p}\right)$ rule carefully here: $7 \equiv 7 \pmod 8$ falls in the $\pm 1$ case, giving $+1$, not $-1$.)
:::

## Quadratic Reciprocity Preview

<!-- section: legendre-reciprocity-preview -->

:::theorem[Law of quadratic reciprocity]{#quadratic-reciprocity}
For distinct odd primes $p, q$,

$$\left(\frac{p}{q}\right)\left(\frac{q}{p}\right) = (-1)^{\frac{p-1}{2}\cdot\frac{q-1}{2}}.$$
:::

This lets you flip the symbol and reduce the size, like Euclid algorithm for computing the symbol in log time.

:::intuition
The symbols (p/q) and (q/p) are almost the same, except a sign flip when both p and q are 3 mod4.

This reciprocity is what makes the symbol computable efficiently.
:::

:::example[Compute $\left(\tfrac{5}{13}\right)$ by repeated reduction]
Both $5$ and $13$ are odd primes, so reciprocity applies at each flip. The strategy mirrors the Euclidean algorithm: flip, then reduce the top mod the bottom.
:::

:::solution
Flip $\left(\tfrac{5}{13}\right)$: the exponent is $\frac{5-1}{2}\cdot\frac{13-1}{2} = 2\cdot 6 = 12$ (even), so the sign is $+1$ and $\left(\tfrac{5}{13}\right) = \left(\tfrac{13}{5}\right)$. (Both $5 \equiv 1$ and $13 \equiv 1 \pmod 4$, and the sign is $-1$ only when *both* are $\equiv 3 \pmod 4$.)
Reduce: $13 \equiv 3 \pmod 5$, so $\left(\tfrac{13}{5}\right) = \left(\tfrac{3}{5}\right)$.
Flip $\left(\tfrac{3}{5}\right)$: the exponent is $\frac{3-1}{2}\cdot\frac{5-1}{2} = 1\cdot 2 = 2$ (even), so again $+1$ and $\left(\tfrac{3}{5}\right) = \left(\tfrac{5}{3}\right)$.
Reduce: $5 \equiv 2 \pmod 3$, so $\left(\tfrac{5}{3}\right) = \left(\tfrac{2}{3}\right)$.
Evaluate $\left(\tfrac{2}{3}\right)$: since $3 \equiv 3 \pmod 8$, $\left(\tfrac{2}{3}\right) = -1$.

Chaining the equalities, $\left(\tfrac{5}{13}\right) = -1$, so $5$ is a non-residue mod $13$.

Sanity check by listing the squares mod $13$ (it suffices to square $1$ through $6$, since $x$ and $-x$ give the same square):
$$
1^2 = 1,\quad 2^2 = 4,\quad 3^2 = 9,\quad 4^2 \equiv 3,\quad 5^2 \equiv 12,\quad 6^2 \equiv 10.
$$
The residues are $\{1, 3, 4, 9, 10, 12\}$, and $5$ is not among them — confirming $\left(\tfrac{5}{13}\right) = -1$. The recurring lesson: track the reciprocity sign carefully, since a single mis-parity flips the whole answer.
:::

## Common Mistakes

- **(a/p) defined only for p odd prime**: For p=2 use other (Kronecker or direct).
- **Forgetting 0 case**: (0/p)=0.
- **Thinking the symbol gives the square root**: It only decides existence, not computes the root (which is harder, Tonelli-Shanks).
- **Sign errors in reciprocity**: The exponent (p-1)/2 *(q-1)/2 is the number of 3 mod4 primes in the pair; flip sign only if both 3 mod4.

A number a is a quadratic residue modulo m if there exists x such that x^2 ≡ a mod m (and usually gcd(a,m)=1 for the nonzero case).

The theory of quadratic residues is central to number theory, with applications to cryptography (quadratic residuosity assumption in some protocols), primality tests, and the law of quadratic reciprocity which gives an efficient way to decide residuosity without finding the square root.

This topic introduces the basic definitions, Euler's criterion, and the Legendre symbol (next topic).

## Definition and Examples

<!-- section: quadratic-residue-def -->

:::definition[Quadratic residue]{#quadratic-residue}
Let $m > 1$ and let $a$ be an integer with $\gcd(a,m) = 1$. Then $a$ is a **quadratic residue** mod $m$ if the congruence

$$x^2 \equiv a \pmod m$$

has a solution $x$. Otherwise $a$ is a quadratic non-residue mod $m$.
:::

We usually consider a mod m in 1 to m-1 coprime.

:::proposition[Exactly half the classes are residues]
For $m = p$ an odd prime, there are exactly $(p-1)/2$ nonzero quadratic residues and the same number of non-residues.
:::

:::proof
The squaring map $x \mapsto x^2$ on the $p-1$ nonzero classes is two-to-one, since $x$ and $-x$ have the same square and are distinct for $p > 2$. So its image — the set of nonzero residues — has size $(p-1)/2$.
:::

:::intuition
Is there an integer x whose square "lands on" a when you look only at remainders mod m?

Half the possible nonzero remainders are "perfect squares" mod p, the other half are not.
:::

:::example[Quadratic residues mod 7]
Square every nonzero residue and reduce mod $7$:
$$
1^2 = 1,\quad 2^2 = 4,\quad 3^2 = 9 \equiv 2,\quad 4^2 = 16 \equiv 2,\quad 5^2 = 25 \equiv 4,\quad 6^2 = 36 \equiv 1.
$$
The distinct values are $\{1, 2, 4\}$, so those three are the quadratic residues and $\{3, 5, 6\}$ are the non-residues.
:::

:::solution
1. Note the symmetry that halves the work: $x$ and $-x = 7 - x$ produce the same square, so the six nonzero elements pair up as $(1,6), (2,5), (3,4)$, giving only $(p-1)/2 = 3$ distinct squares. This is why exactly half of the nonzero residues mod an odd prime are quadratic residues.
:::

## Euler's Criterion

<!-- section: euler-criterion -->

:::theorem[Euler's criterion]{#euler-criterion}
For an odd prime $p$ not dividing $a$, the integer $a$ is a quadratic residue mod $p$ if and only if

$$a^{(p-1)/2} \equiv 1 \pmod p,$$

and $a^{(p-1)/2} \equiv -1 \pmod p$ when $a$ is a non-residue.
:::

:::proof
By Fermat, $a^{p-1} \equiv 1 \pmod p$, so $\big(a^{(p-1)/2} - 1\big)\big(a^{(p-1)/2} + 1\big) \equiv 0 \pmod p$. Since $\mathbb{Z}/p\mathbb{Z}$ is a field (no zero divisors), $a^{(p-1)/2}$ must be $\equiv +1$ or $\equiv -1$ — never anything else. To see which sign corresponds to residues, use that the group $(\mathbb{Z}/p\mathbb{Z})^\times$ is cyclic with a generator $g$: write $a = g^{k}$, so $a$ is a square exactly when $k$ is even. Then $a^{(p-1)/2} = g^{k(p-1)/2} = \big(g^{(p-1)/2}\big)^{k} = (-1)^{k}$, because $g^{(p-1)/2} \equiv -1$ ($g$ has order $p-1$). So the power is $+1$ for even $k$ (residues) and $-1$ for odd $k$ (non-residues).
:::

:::intuition
Raise a to the "half" power (p-1)/2 mod p; if you get 1 it is a square, if -1 it is not. This is a quick test without searching for x.

It works because in the cyclic group the squares are exactly the even powers, and raising to (p-1)/2 sends even to 1 and odd to -1.
:::

:::example[Is $3$ a quadratic residue mod $7$?]
Apply Euler's criterion with $p = 7$ (odd prime, $7 \nmid 3$): compute $3^{(p-1)/2} = 3^{3} \pmod 7$.
:::

:::solution
$3^{3} = 27 = 3\cdot 7 + 6$, so $3^{3} \equiv 6 \equiv -1 \pmod 7$.
The result is $-1$, so by Euler's criterion $3$ is a **non-residue** mod $7$.

Sanity check: the residues mod $7$ are $\{1, 2, 4\}$ (from the earlier example), and $3$ is not among them. Contrast $2^{3} = 8 \equiv 1 \pmod 7$, which correctly flags $2$ as a residue.
:::

## Number of Solutions and -1 as Residue

<!-- section: number-solutions-minus-one -->

:::proposition[Counting square roots]
For $p$ an odd prime, the equation $x^2 \equiv a \pmod p$ has

$$1 + \left(\frac{a}{p}\right) \text{ solutions},$$

where $\left(\frac{a}{p}\right)$ is the Legendre symbol ($1$ if $a$ is a residue, $-1$ if not, $0$ if $p \mid a$).
:::

:::corollary[When $-1$ is a square]
$-1$ is a quadratic residue mod $p$ if and only if $p \equiv 1 \pmod 4$, since $(-1)^{(p-1)/2} = 1$ exactly when $(p-1)/2$ is even.
:::

:::intuition
A nonzero square root comes in a $\pm$ pair: if $x$ works, so does $-x$, and for $p > 2$ these are distinct. So a nonzero residue has exactly $2$ roots and a non-residue has $0$ — never exactly one. (The lone exception is $a \equiv 0$, whose only root is $x = 0$.)

Whether $-1$ itself is a square depends only on $p \bmod 4$: yes when $p \equiv 1 \pmod 4$ (e.g. mod $5$, since $2^2 = 4 \equiv -1$), no when $p \equiv 3 \pmod 4$.
:::

:::example[Is $-1$ a quadratic residue mod $5$ and mod $7$?]
The test is $p \equiv 1 \pmod 4 \iff -1$ is a residue.
:::

:::solution
Mod $5$: $5 \equiv 1 \pmod 4$, so $-1$ should be a residue. Confirm directly: $-1 \equiv 4 \pmod 5$, and $2^2 = 4$, so $x = 2$ (and $x = 3$) solve $x^2 \equiv -1 \pmod 5$. The count is $1 + \left(\tfrac{-1}{5}\right) = 1 + 1 = 2$ solutions, as expected.
Mod $7$: $7 \equiv 3 \pmod 4$, so $-1$ should be a non-residue. Confirm: $-1 \equiv 6 \pmod 7$, and the squares mod $7$ are $\{1, 2, 4\}$, which excludes $6$. The count is $1 + \left(\tfrac{-1}{7}\right) = 1 + (-1) = 0$ solutions.

Both match the $p \bmod 4$ rule and the "$1 + \left(\tfrac{a}{p}\right)$" solution-count formula.
:::

## Common Mistakes

- **Including a divisible by p as residue**: Usually we say nonzero quadratic residue, excluding 0 which trivially is 0^2.
- **For composite moduli the count is more complicated**: Not necessarily half; use Jacobi or CRT to combine.
- **Euler criterion requires p odd prime not dividing a**: For p=2 separate case; for a multiple of p, 0.
- **Confusing residue with the square root existing in integers**: Residue is existence mod m, not that a is a perfect square in Z.
