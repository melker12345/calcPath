# Diophantine Equations

Linear and classical Diophantine equations: Pythagorean triples, Pell's equation, Hasse principle, Thue's theorem, and Fermat's Last Theorem.

A Diophantine equation is a polynomial equation with integer coefficients for which one seeks integer solutions (or rational, or in other rings).

The theory studies existence, finiteness, parametrization, or effective bounds for solutions in various cases.

Linear: solved by extended Euclid.

Quadratic: Hasse principle, Pell, etc.

Higher degree: Fermat, Thue, Mordell, elliptic curves (finitely many integral points by Siegel), and in general undecidable by Matiyasevich (Hilbert 10th negative).

This topic introduces the general notion and basic examples before the specialized chapters.

## General Notions

<!-- section: diophantine-general -->

:::definition[Diophantine equation]{#diophantine-equation}
A Diophantine equation is

$$f(x_1,\dots,x_k) = 0,$$

where $f$ is a polynomial with integer coefficients, and we look for solutions $(x_1,\dots,x_k) \in \mathbb{Z}^k$. The inhomogeneous form $f(x_1,\dots,x_k) = h$ (with $h$ a fixed integer) is the same thing after moving $h$ to the left.
:::

Sometimes we instead ask for rational solutions in $\mathbb{Q}^k$. These two questions are closely linked: any rational solution can be scaled by a common denominator into an integer solution of a related *homogeneous* equation, so rational and integer questions often translate into each other.

The main tools of the subject are: **congruence obstructions** (checking solvability mod $m$), **local–global principles** (checking over $\mathbb{R}$ and the $p$-adics), **descent** (turning a solution into a strictly smaller one), and **heights** (measuring the arithmetic size of solutions to prove finiteness).

:::intuition
Polynomial eq with integer coeff, want integer (or rational) answers for the variables.

Some have none, some infinitely many (parametrized), some finite but hard to find all.
:::

:::proposition[Congruence obstruction]
If an equation has an integer solution, it must also be solvable modulo every integer $m$. So finding one $m$ where it fails proves there are no integer solutions.
:::

:::example
Show $x^2 + y^2 = 3$ has no integer solutions.
:::

:::solution
1. Work modulo $4$. Every square is $\equiv 0$ or $1 \pmod 4$: if $x$ is even then $x^2 \equiv 0$, and if $x$ is odd then $x = 2k+1$ so $x^2 = 4k^2 + 4k + 1 \equiv 1 \pmod 4$.
2. So the sum $x^2 + y^2$ can only be $0+0=0$, $0+1=1$, or $1+1=2 \pmod 4$. It can never be $3 \pmod 4$.
3. But $3 \equiv 3 \pmod 4$, which is not in the reachable set $\{0,1,2\}$.
4. Step 4 (conclusion). No integer $x,y$ can satisfy the equation. Sanity check: the smallest candidates $0^2+1^2=1$, $1^2+1^2=2$, $0^2+2^2=4$ indeed skip over $3$. $\checkmark$
5. (Note this is a *sufficient* test, not a necessary one: passing every congruence check does not guarantee an integer solution exists — that is exactly the subtlety the Hasse principle addresses later in this topic.)
:::

## Hilbert Tenth Problem

<!-- section: diophantine-hilbert10 -->

Hilbert's 10th problem (1900): is there an algorithm that, given a Diophantine eq, decides if it has integer solutions?

:::theorem[Matiyasevich: Hilbert's tenth problem is unsolvable]
Answered negatively by Matiyasevich (1970, building on Davis-Putnam-Robinson): the recursively enumerable sets are exactly the Diophantine sets. Since the halting problem is undecidable, there is no algorithm deciding solvability of Diophantine equations.
:::

:::intuition
There is no general computer program that can look at any polynomial eq with integer coeffs and always correctly say "yes there are integer solutions" or "no".

Some families are decidable (linear, quadratic in some cases, elliptic curves under conjectures), but not uniformly for all.
:::

:::example
How the negative answer is proved (the idea, made concrete).
:::

:::solution
1. Step 1 (what "Diophantine set" means). A set $S \subseteq \mathbb{Z}$ is *Diophantine* if there is a polynomial $P$ with integer coefficients such that $n \in S$ exactly when $P(n, x_1, \dots, x_k) = 0$ has a solution in nonnegative integers $x_1,\dots,x_k$. For example, the composite numbers form a Diophantine set: $n$ is composite iff $n = (x_1 + 2)(x_2 + 2)$ has a solution, i.e. iff $n - (x_1+2)(x_2+2) = 0$ is solvable.
2. Step 2 (the DPRM theorem). Davis, Putnam, Robinson, and Matiyasevich proved that the Diophantine sets are *exactly* the recursively enumerable (computably listable) sets. The hardest ingredient was showing the exponential relation $y = 2^x$ is Diophantine, done using solutions of a Pell-type equation whose growth mimics exponentials (this is where continued-fraction / Fibonacci-like recurrences enter).
3. Step 3 (the reduction). The halting problem "does Turing machine $M$ halt on input $w$?" defines a recursively enumerable set that is known to be undecidable. By Step 2 we can build a specific polynomial $P_{M,w}$ so that $P_{M,w}(x_1,\dots,x_k) = 0$ has a solution *iff* $M$ halts on $w$.
4. Step 4 (conclusion). If some algorithm could decide solvability of every Diophantine equation, feeding it $P_{M,w}$ would decide the halting problem — impossible. Hence no such algorithm exists.
:::

## Finiteness Results

<!-- section: diophantine-finiteness -->

:::definition[Genus of a curve]
The **genus** of a curve is a measure of its geometric complexity: lines and conics have genus $0$, smooth cubics (elliptic curves) have genus $1$, and higher-degree curves generally have genus $\ge 2$.
:::

The genus controls how many rational or integer points the curve can have.

:::theorem[Faltings' theorem, the Mordell conjecture]
A smooth projective curve of genus $\ge 2$ defined over $\mathbb{Q}$ has only *finitely many* rational points. (Proved 1983.)
:::

:::theorem[Siegel's theorem]
An affine curve of genus $\ge 1$ (for instance an elliptic curve $y^2 = x^3 + ax + b$) has only finitely many *integer* points, even though it may have infinitely many *rational* points. (1929.)
:::

Specialized finiteness results — Thue (fixed-value binary forms of degree $\ge 3$), Mordell, and others — are special cases or precursors of these theorems.

A key caveat: Faltings' and Siegel's proofs are **ineffective** — they guarantee finiteness but do not, by themselves, bound the size of the solutions, so they don't tell you when to stop searching. Baker's method (linear forms in logarithms) gives *effective* but astronomically large bounds in many cases, which combined with computation can list all solutions.

:::intuition
High genus curves (complicated shapes) can't have too many rational points; only finite.

This solves many Dioph eq by viewing as points on curves.
:::

:::example
Finiteness of integer points on a Mordell curve $y^2 = x^3 + k$.
:::

:::solution
1. Take $k = 1$, so $y^2 = x^3 + 1$. Siegel's theorem guarantees finitely many integer points; let us actually pin them down.
2. Rewrite as $y^2 - 1 = x^3$, i.e. $(y-1)(y+1) = x^3$.
3. Try small values. For $x = -1$: $y^2 = 0$, so $y = 0$, giving $(-1, 0)$. For $x = 0$: $y^2 = 1$, so $y = \pm 1$, giving $(0, 1)$ and $(0, -1)$. For $x = 2$: $y^2 = 9$, so $y = \pm 3$, giving $(2, 3)$ and $(2, -3)$.
4. For $x = 1$: $y^2 = 2$, not a square. For $x = 3$: $y^2 = 28$, not a square. For $x = 4$: $y^2 = 65$, not a square. As $x$ grows, $x^3 + 1$ falls strictly between the consecutive squares near it and rarely lands on one.
5. Step 4 (conclusion). It is a classical fact (provable by factoring in $\mathbb{Z}[\sqrt{-1}]$-style descent, or read off tables) that the *only* integer points are $(-1,0)$, $(0,\pm 1)$, $(2,\pm 3)$ — a finite list, as Siegel promised. Sanity check on $(2,3)$: $3^2 = 9$ and $2^3 + 1 = 9$. $\checkmark$
:::

## Common Mistakes

- **All Dioph eq are decidable**: No, Hilbert 10 negative.
- **Rational solutions always exist if real do**: No, Hasse fails for higher deg.
- **Finiteness means we can find them all**: Finiteness yes, but finding may be hard without effective proofs.
- **Linear always solvable if gcd divides**: Yes for two vars; for more vars similar but with more params.

A linear Diophantine equation is $ax + by = c$ with $a,b,c$ integers, and we seek integer solutions $x,y$.

It has solutions if and only if $\gcd(a,b)$ divides $c$.

The general solution is found from one particular solution using the extended Euclidean algorithm, then adding the homogeneous solutions (integer multiples of $(b/d, -a/d)$, where $d = \gcd(a,b)$).

This is the most basic Diophantine equation and the starting point for the theory of linear equations in more variables and for the geometry of numbers.

## Solvability Condition

<!-- section: linear-dioph-solvability -->

:::theorem[Solvability of a linear Diophantine equation]{#linear-solvability}
The equation

$$ax + by = c$$

has integer solutions $x,y$ if and only if $d = \gcd(a,b)$ divides $c$.
:::

:::proof
"Only if": if $(x,y)$ is a solution, then $d \mid a$ and $d \mid b$, so $d$ divides $ax + by = c$.

"If": if $d \mid c$, use the extended Euclidean algorithm to find $x_0, y_0$ with $a x_0 + b y_0 = d$ (this is always possible — Bézout's identity). Multiplying through by $c/d$ (an integer, since $d \mid c$) gives $a\left(x_0 \tfrac{c}{d}\right) + b\left(y_0 \tfrac{c}{d}\right) = c$, an explicit solution.
:::

:::intuition
The left side a x + b y is always a multiple of the greatest common "step" d=gcd(a,b). So c must be reachable, i.e. multiple of d.

If yes, then you can reach it.
:::

:::example
Solve $6x + 9y = 3$ completely.
:::

:::solution
Step 1 (solvability check). $d = \gcd(6,9) = 3$, and $3 \mid 3$, so solutions exist.

Step 2 (find a Bézout combination for $d$). We want $6u + 9v = 3$. By inspection $6(-1) + 9(1) = -6 + 9 = 3$, so $u = -1, v = 1$.

Step 3 (scale to $c$). Here $c/d = 3/3 = 1$, so the particular solution is already $x_0 = -1$, $y_0 = 1$.

Step 4 (add the homogeneous solutions). The homogeneous steps are $b/d = 9/3 = 3$ and $a/d = 6/3 = 2$, so the general solution is
$$x = -1 + 3t, \qquad y = 1 - 2t, \qquad t \in \mathbb{Z}.$$

Step 5 (sanity check). $6(-1 + 3t) + 9(1 - 2t) = -6 + 18t + 9 - 18t = 3$ for every $t$. $\checkmark$ For $t = 1$ this gives $(2, -1)$, and $6(2) + 9(-1) = 12 - 9 = 3$. $\checkmark$
:::

## Finding All Solutions

<!-- section: linear-dioph-general -->

:::theorem[General solution of $ax + by = c$]{#linear-general-solution}
Once you have one particular solution $(x_0, y_0)$ to $ax + by = c$, every solution is given by

$$x = x_0 + \frac{b}{d}\,t, \qquad y = y_0 - \frac{a}{d}\,t, \qquad t \in \mathbb{Z},$$

where $d = \gcd(a,b)$.
:::

:::proof
The difference of any two solutions satisfies the homogeneous equation $a x + b y = 0$, i.e. it lies in the kernel of the map $(x,y) \mapsto ax + by$. That kernel is generated by $(b/d, -a/d)$: it clearly satisfies $a(b/d) + b(-a/d) = 0$, and dividing by $d$ makes it the *smallest* integer step (using coprimeness of $a/d$ and $b/d$), so no solutions are skipped.
:::

:::intuition
From one solution, you can add "full cycles" of the smaller coefficient and subtract from the other to stay at the same total c.

The step size is b/d and a/d because dividing by d gives the primitive equation.
:::

:::example
List several solutions of $6x + 9y = 3$ from the particular solution $(-1, 1)$.
:::

:::solution
The general solution is $x = -1 + 3t$, $y = 1 - 2t$ (from the previous section).

Enumerate a few values of $t$:

$t = -1$: $(x,y) = (-4, 3)$, and $6(-4) + 9(3) = -24 + 27 = 3$. $\checkmark$
$t = 0$: $(x,y) = (-1, 1)$, and $6(-1) + 9(1) = -6 + 9 = 3$. $\checkmark$
$t = 1$: $(x,y) = (2, -1)$, and $6(2) + 9(-1) = 12 - 9 = 3$. $\checkmark$
$t = 2$: $(x,y) = (5, -3)$, and $6(5) + 9(-3) = 30 - 27 = 3$. $\checkmark$

Step 3 (observation). Consecutive $x$-values differ by $3 = b/d$ and consecutive $y$-values differ by $-2 = -a/d$, exactly the homogeneous step. Every integer solution appears for exactly one $t$.
:::

## Applications to Frobenius and Chicken Nugget

<!-- section: linear-dioph-applications -->

:::theorem[Frobenius number for two coins]{#frobenius-number}
For two *coprime* positive integers $a, b$, the largest integer **not** representable as a nonnegative combination $ax + by$ (with $x, y \ge 0$) is the **Frobenius number**

$$g(a,b) = ab - a - b.$$
:::

Coprimality is essential: if $\gcd(a,b) = e > 1$, then only multiples of $e$ are ever representable, so there is no largest non-representable number and the formula does not apply.

For three or more coin denominations there is no simple closed formula, and computing the Frobenius number is NP-hard in general.

In programming and contest math, the linear Diophantine equation is used to solve "make exactly amount $c$ using packs of size $a$ and $b$".

:::intuition
With coins of value $a$ and $b$ (coprime), the amounts you cannot make are finite; the biggest is $ab - a - b$.

Once you can make $a$ consecutive amounts in a row, you can make every larger amount too: just keep adding one more coin of value $a$ to whichever of those you already have.
:::

:::example
Frobenius number for $a = 4$, $b = 7$.
:::

:::solution
Step 1 (formula). $\gcd(4,7) = 1$, so $g(4,7) = 4\cdot 7 - 4 - 7 = 28 - 11 = 17$.

Step 2 (verify $17$ is not representable). We need $4x + 7y = 17$ with $x,y \ge 0$. Try each $y$: $y=0 \Rightarrow 4x = 17$ (no); $y = 1 \Rightarrow 4x = 10$ (no); $y = 2 \Rightarrow 4x = 3$ (no); $y \ge 3 \Rightarrow 7y \ge 21 > 17$. So $17$ is impossible. $\checkmark$

Step 3 (verify everything above $17$ works). It suffices to hit $4$ consecutive values, then add $4$'s:
$$18 = 4(1) + 7(2), \quad 19 = 4(3) + 7(1), \quad 20 = 4(5) + 7(0), \quad 21 = 4(0) + 7(3).$$
From these four consecutive amounts $18,19,20,21$, adding copies of $4$ reaches $22, 23, 24, 25, \dots$ and hence every integer $\ge 18$.

Step 4 (conclusion). $17$ is the largest non-representable amount, matching the formula. $\checkmark$
:::

## Common Mistakes

- **Forgetting the d | c check**: Many solutions claimed when impossible.
- **Negative solutions allowed**: Diophantine usually allows negative x,y unless specified nonnegative (Frobenius is nonnegative).
- **Unique solution**: There are infinitely many if any, parametrized by t.
- **d= gcd(a,b) in the steps**: Always divide the coefficients by d when writing the general solution.

A Pythagorean triple is a triple of positive integers $a,b,c$ with $a^2 + b^2 = c^2$ (the side lengths of a right triangle with integer sides).

Primitive triples (those with $\gcd(a,b,c) = 1$) are parametrized by two integers $m > n > 0$ of opposite parity with $\gcd(m,n) = 1$: taking $a = m^2 - n^2$, $b = 2mn$, $c = m^2 + n^2$ (or with $a, b$ swapped).

Every Pythagorean triple is a positive-integer multiple of a primitive one.

This is one of the oldest Diophantine problems, solved by Euclid or earlier, with connections to Gaussian integers (unique factorization in $\mathbb{Z}[i]$ gives the parametrization).

## Definition and Examples

<!-- section: pythagorean-def -->

:::definition[Pythagorean triple]{#pythagorean-triple}
Positive integers $a \le b < c$ with

$$a^2 + b^2 = c^2.$$
:::

Examples: 3,4,5 ; 5,12,13 ; 8,15,17 ; 7,24,25 ; 20,21,29 etc.

Multiples: 6,8,10 =2*(3,4,5).

:::intuition
Integer sided right triangles. The sides satisfy the Pythagorean theorem exactly.

The primitive ones are the "basic" shapes; others are scaled versions.
:::

:::example
Generate the triple $5, 12, 13$.
:::

:::solution
1. Step 1 (pick parameters). Choose $m = 3$, $n = 2$. Check the hypotheses: $m > n > 0$ $\checkmark$; opposite parity ($3$ odd, $2$ even) $\checkmark$; $\gcd(3,2) = 1$ $\checkmark$. So the output will be primitive.
2. Step 2 (apply the formulas). $a = m^2 - n^2 = 9 - 4 = 5$, $b = 2mn = 2\cdot 3\cdot 2 = 12$, $c = m^2 + n^2 = 9 + 4 = 13$.
3. Step 3 (sanity check). $a^2 + b^2 = 25 + 144 = 169 = 13^2 = c^2$. $\checkmark$ And $\gcd(5,12,13) = 1$, so it is primitive as expected. $\checkmark$
:::

## The Parametrization Theorem

<!-- section: pythagorean-parametrization -->

:::theorem[Parametrization of Pythagorean triples]{#pythagorean-parametrization}
Every primitive Pythagorean triple is of the form

$$(m^2 - n^2,\; 2mn,\; m^2 + n^2)$$

for integers $m > n > 0$ with $\gcd(m,n) = 1$ and $m, n$ of opposite parity (not both odd, not both even). Every triple is $k$ times a primitive one for some integer $k \ge 1$.
:::

:::proof
Elementary sketch. In a primitive triple exactly one leg is even; say $a$ is odd and $b$ is even (otherwise swap). Then
$$b^2 = c^2 - a^2 = (c - a)(c + a).$$
Since $a$ is odd and $c$ is odd, both $c - a$ and $c + a$ are even; write $c - a = 2u$, $c + a = 2v$. Then $b^2 = 4uv$, so $(b/2)^2 = uv$. One checks $\gcd(u,v) = 1$ (any common factor would divide $c$ and $a$, contradicting primitivity), and a product of coprime integers being a perfect square forces each factor to be a perfect square: $u = n^2$, $v = m^2$. Back-substituting $c = m^2 + n^2$, $a = m^2 - n^2$, $b = 2mn$ gives the parametrization.
:::

The same result drops out cleanly in the Gaussian integers $\mathbb{Z}[i]$: the equation factors as $(a + bi)(a - bi) = c^2$, and for a primitive triple the two factors are coprime, so unique factorization forces each to be a unit times a square, yielding the same $m, n$ (see the next section).

:::intuition
All primitive triples come from picking two "parameters" m>n with the conditions, and the formulas spit out the sides.

The even leg is always the 2mn one.
:::

:::example
Apply the parametrization with $m = 4$, $n = 1$.
:::

:::solution
1. Step 1 (check hypotheses). $m > n > 0$ $\checkmark$; $\gcd(4,1) = 1$ $\checkmark$; opposite parity ($4$ even, $1$ odd) $\checkmark$.
2. Step 2 (formulas). $a = m^2 - n^2 = 16 - 1 = 15$, $b = 2mn = 8$, $c = m^2 + n^2 = 16 + 1 = 17$.
3. Step 3 (sanity check). $8^2 + 15^2 = 64 + 225 = 289 = 17^2$. $\checkmark$ Since $\gcd(15,8,17) = 1$, the triple is primitive. $\checkmark$
:::

## Proof via Gaussian Integers (optional advanced)

<!-- section: pythagorean-gaussian -->

:::definition[Gaussian integers and their norm]{#gaussian-integers}
The ring of Gaussian integers is $\mathbb{Z}[i] = \{a + bi : a,b \in \mathbb{Z}\}$. It is a unique factorization domain (UFD), and its norm

$$N(a + bi) = a^2 + b^2$$

is multiplicative: $N(zw) = N(z)N(w)$.
:::

:::proof
If $a^2 + b^2 = c^2$ with $\gcd(a,b,c) = 1$ (so $a, b$ are not both odd), then $a + bi$ and $a - bi$ are coprime in $\mathbb{Z}[i]$: any common divisor would divide their sum $2a$ and difference $2bi$, and one checks this contradicts primitivity. Their product is $(a+bi)(a-bi) = a^2 + b^2 = c^2$.

In a UFD, when a product of two coprime elements is a perfect square, each factor is a unit times a square. The units of $\mathbb{Z}[i]$ are $\{1, -1, i, -i\}$, so $a + bi = u\,(m + ni)^2$ for some unit $u$; expanding $(m+ni)^2 = (m^2 - n^2) + 2mn\, i$ recovers the parametrization.
:::

:::intuition
The equation says the norm of a+bi is a square (c^2).

In a UFD with the right units, this forces a+bi itself to be (up unit) a square in the ring, which expands to the param.
:::

:::example
Recover $(3,4,5)$ from a Gaussian square.
:::

:::solution
1. Step 1 (norm is a square). $N(3 + 4i) = 3^2 + 4^2 = 25 = 5^2$, matching $c = 5$.
2. Step 2 (extract the square root in $\mathbb{Z}[i]$). Try $m = 2$, $n = 1$: $(2 + i)^2 = 4 + 4i + i^2 = 4 + 4i - 1 = 3 + 4i$. $\checkmark$
3. Step 3 (read off the parametrization). With $m = 2, n = 1$: $a = m^2 - n^2 = 3$, $b = 2mn = 4$, $c = m^2 + n^2 = 5$ — exactly the $(3,4,5)$ triple. $\checkmark$
:::

## Common Mistakes

- **Both m n odd gives non-primitive or not triple**: Both odd makes a,b,c all odd, but then a^2+b^2 ≡1+1=2 mod4, not a square (squares 0 or1 mod4).
- **Forgetting the k multiple for non-primitive**: Many triples are multiples.
- **a and b order**: The formula gives one even leg; swap if needed for a odd.
- **n=0 or m=n**: Gives degenerate  m,0,m not positive triple.

Pell's equation is the Diophantine equation $x^2 - d y^2 = 1$, where $d > 0$ is a square-free integer (if $d$ were a perfect square the left side would factor and the equation would have only trivial solutions).

It always has infinitely many integer solutions, generated from the fundamental solution (the smallest nontrivial $x_1, y_1 > 0$) via $(x_1 + y_1\sqrt{d})^k$ for $k = 1, 2, \dots$

The solutions come from the continued-fraction convergents to $\sqrt{d}$; the fundamental solution corresponds to the end of the period (or a multiple of it).

Pell's equation is the key to the negative Pell equation $x^2 - d y^2 = -1$ (which is solvable only for some $d$), to units in real quadratic fields, and to approximating $\sqrt{d}$ by rationals.

Named after John Pell, though studied by Fermat, Euler, etc.

## The Equation and Trivial Solutions

<!-- section: pell-def -->

:::definition[Pell's equation]{#pell-equation}
Pell's equation is

$$x^2 - d y^2 = 1$$

with $d > 0$ not a perfect square. The **trivial solutions** are $(x, y) = (\pm 1, 0)$, which work for every $d$.
:::

:::theorem[Infinitely many solutions]
Beyond the trivial ones there are always infinitely many **nontrivial** integer solutions.
:::

For $d = 2$: $3^2 - 2\cdot 2^2 = 9 - 8 = 1$, so the fundamental solution is $(3, 2)$.

For $d = 3$: $2^2 - 3\cdot 1^2 = 4 - 3 = 1$, so the fundamental solution is $(2, 1)$.

:::intuition
Think of it as a "best rational approximation" game: find integers $x, y$ so that $x/y$ is an astonishingly good approximation to $\sqrt{d}$ (error roughly $1/y^2$).

Algebraically the equation factors as $(x - y\sqrt{d})(x + y\sqrt{d}) = 1$, so a solution is exactly a "unit of norm $1$" in $\mathbb{Z}[\sqrt{d}]$ — a number you can multiply by another to get back to $1$.
:::

:::example
Find the fundamental solution of $x^2 - 7y^2 = 1$ by a short search.
:::

:::solution
Step 1 (search over $y$). For each $y = 1, 2, 3, \dots$ check whether $1 + 7y^2$ is a perfect square:

$y = 1$: $1 + 7 = 8$, not a square.
$y = 2$: $1 + 28 = 29$, not a square.
$y = 3$: $1 + 63 = 64 = 8^2$. $\checkmark$

Step 2 (read off the solution). $y = 3$ gives $x = 8$, so the fundamental solution is $(8, 3)$.

Step 3 (sanity check). $8^2 - 7\cdot 3^2 = 64 - 63 = 1$. $\checkmark$

The fundamental solution can be small (like $(8,3)$ here) or enormous: for $d = 61$ it is already $x = 1766319049$, $y = 226153980$, far beyond any hand search — which is exactly why the continued-fraction method of the next section is needed.
:::

## Solutions from Continued Fractions

<!-- section: pell-continued-fractions -->

The continued fraction expansion of $\sqrt{d}$ is eventually periodic, of the form $\sqrt{d} = [a_0; \overline{a_1, a_2, \dots, a_\ell}]$, where the bar marks the repeating block of length $\ell$ (the period).

Its convergents $p_k / q_k$ (the best rational approximations to $\sqrt{d}$) satisfy $|p_k^2 - d\, q_k^2|$ small — in fact bounded independently of $k$ — and the values $\pm 1$ occur precisely at the ends of periods.

:::theorem[Pell solutions at the end of a period]
The convergent $p_{\ell-1}/q_{\ell-1}$ (just before the period repeats) gives

$$p_{\ell-1}^2 - d\, q_{\ell-1}^2 = (-1)^{\ell}.$$

So:

- If the period $\ell$ is **even**, this convergent already solves the $+1$ Pell equation, and it is the fundamental solution.
- If the period $\ell$ is **odd**, this convergent solves the **negative** Pell equation $x^2 - dy^2 = -1$; squaring the corresponding unit (equivalently, going one more period to index $2\ell - 1$) then yields the fundamental solution of the $+1$ equation.
:::

The fundamental unit of $\mathbb{Z}[\sqrt{d}]$ is $p_{\ell-1} + q_{\ell-1}\sqrt{d}$.

:::intuition
$\sqrt{d}$ has a repeating "decimal" in its continued fraction. The best rational approximations (convergents) give the solutions to $x^2 - d y^2 = \pm 1$, appearing at the ends of the repeating block.

The smallest solution comes from the first repeat of the pattern.
:::

:::example
Solve Pell for $d = 2$ via the continued fraction of $\sqrt{2}$.
:::

:::solution
Step 1 (expand). $\sqrt{2} = 1.4142\ldots$, so $a_0 = 1$ and $\sqrt{2} - 1 = 0.4142\ldots$; its reciprocal is $2.4142\ldots$, giving $a_1 = 2$, and the pattern repeats. Thus $\sqrt{2} = [1; \overline{2}]$ with period $\ell = 1$ (odd).

Step 2 (convergents). The first convergents are:
$$\frac{p_0}{q_0} = \frac{1}{1}, \qquad \frac{p_1}{q_1} = 1 + \frac{1}{2} = \frac{3}{2}.$$

Step 3 (evaluate $p^2 - 2q^2$).
$p_0^2 - 2 q_0^2 = 1 - 2\cdot 1 = -1$ — this is the *negative* Pell solution (as expected since $\ell = 1$ is odd).
$p_1^2 - 2 q_1^2 = 9 - 2\cdot 4 = 9 - 8 = 1$ — the fundamental solution $(3, 2)$ of the $+1$ equation.

Step 4 (sanity check). $3^2 - 2\cdot 2^2 = 9 - 8 = 1$ $\checkmark$, matching the fundamental solution found earlier by direct search.
:::

## The Group of Solutions and Units

<!-- section: pell-units -->

:::theorem[Every solution is a power of the fundamental unit]
The solutions $(x_k, y_k)$ satisfy

$$x_k + y_k\sqrt{d} = (x_1 + y_1\sqrt{d})^k,$$

where $\varepsilon = x_1 + y_1\sqrt{d} > 1$ is the fundamental unit.
:::

:::theorem[Unit group of a real quadratic field]
The unit group of the ring of integers of the real quadratic field $\mathbb{Q}(\sqrt{d})$ is $\{\pm\varepsilon^k : k \in \mathbb{Z}\}$; Dirichlet's unit theorem gives rank $1$ here.
:::

Taking the norm $N(x + y\sqrt{d}) = x^2 - d y^2$, this describes all units of norm $+1$ (the Pell solutions) and, when the fundamental unit itself has norm $-1$, the norm $-1$ units (negative-Pell solutions) as well.

:::intuition
The solutions "multiply" using the ring multiplication: if two solutions, their "product" (x1 x2 + d y1 y2 , x1 y2 + y1 x2) is another solution.

Powers of the smallest nontrivial give all others.
:::

:::example
Generate the next Pell solution for $d = 2$ by powering the fundamental unit.
:::

:::solution
Step 1 (fundamental unit). From the previous sections, the fundamental solution of $x^2 - 2y^2 = 1$ is $(3, 2)$, so $\varepsilon = 3 + 2\sqrt{2}$.

Step 2 (square it). 
$$\varepsilon^2 = (3 + 2\sqrt{2})^2 = 9 + 2\cdot 3\cdot 2\sqrt{2} + (2\sqrt{2})^2 = 9 + 12\sqrt{2} + 8 = 17 + 12\sqrt{2}.$$
Reading off coordinates, the next solution is $(x_2, y_2) = (17, 12)$.

Step 3 (sanity check). $17^2 - 2\cdot 12^2 = 289 - 288 = 1$. $\checkmark$

Step 4 (equivalent recurrence). Multiplying $(x_{k+1} + y_{k+1}\sqrt 2) = (x_k + y_k\sqrt 2)(3 + 2\sqrt 2)$ gives $x_{k+1} = 3x_k + 4y_k$, $y_{k+1} = 2x_k + 3y_k$. From $(3,2)$: $x_2 = 3\cdot 3 + 4\cdot 2 = 17$, $y_2 = 2\cdot 3 + 3\cdot 2 = 12$ — same answer. $\checkmark$
:::

## Common Mistakes

- **All d have solutions to x^2 - d y^2 = -1**: No, only when the fundamental unit has norm -1 (period odd).
- **The fundamental solution is always small**: For some d like 61 it is huge (10 digits).
- **Pell equation always has only trivial**: No, infinitely many for every square-free d>0.
- **Confusing with x^2 + d y^2 =1**: That has only ±1,0 for d>0.
- **Solutions in rationals**: Trivial by clearing, the interest is integers.

The Hasse (or local-global) principle for quadratic forms says that a quadratic form over the rationals represents $0$ non-trivially if and only if it represents $0$ non-trivially over the reals $\mathbb{R}$ and over all $p$-adic fields $\mathbb{Q}_p$.

In other words, a homogeneous quadratic equation has a nontrivial rational solution if and only if it has a nontrivial real solution and nontrivial solutions in every $p$-adic completion.

For quadratic forms this holds (Hasse-Minkowski theorem), but for higher degree it fails (counterexamples by Selmer etc).

It is a fundamental principle in arithmetic geometry: local solubility everywhere implies global.

## The Local-Global Principle for Quadratics

<!-- section: hasse-local-global -->

:::theorem[Hasse-Minkowski, local-global principle]{#hasse-minkowski}
A homogeneous quadratic equation in several variables has a nontrivial rational solution if and only if it has one over $\mathbb{R}$ and over every $\mathbb{Q}_p$. Equivalently, the projective quadric has a rational point if and only if it has real and $p$-adic points for all $p$.
:::

The "only if" direction is easy: a rational solution *is* automatically a real and $p$-adic solution, since $\mathbb{Q}$ embeds into $\mathbb{R}$ and into each $\mathbb{Q}_p$.

The "if" is the deep Hasse-Minkowski theorem, proved using the theory of quadratic forms over local fields, Hilbert symbol, and class field or genus theory.

:::intuition
To decide if a quadratic thing has a rational solution, you can check "locally" in every completion (real numbers and p-adics, which are like numbers with p-adic "decimal" expansion).

For quadratics, if it works everywhere locally, it works globally over Q.
:::

:::example
Use a local obstruction to show $x^2 + y^2 = 3z^2$ has no nontrivial rational solution.
:::

:::solution
1. Step 1 (reduce to integers). A nontrivial rational solution can be scaled to a nontrivial *integer* solution $(x,y,z)$; divide out any common factor so that $\gcd(x,y,z) = 1$.
2. Step 2 (work modulo $3$). Squares are $\equiv 0$ or $1 \pmod 3$. Since $3z^2 \equiv 0 \pmod 3$, we need $x^2 + y^2 \equiv 0 \pmod 3$. The only way to write $0$ as a sum of two elements of $\{0,1\}$ mod $3$ is $0 + 0$, so $x \equiv y \equiv 0 \pmod 3$.
3. Step 3 (descend). Write $x = 3x'$, $y = 3y'$. Then $9x'^2 + 9y'^2 = 3z^2$, so $z^2 = 3(x'^2 + y'^2)$, forcing $3 \mid z^2$ and hence $3 \mid z$.
4. Step 4 (contradiction). Now $3$ divides $x, y, z$, contradicting $\gcd(x,y,z) = 1$. So no nontrivial solution exists. $\checkmark$
5. The same argument runs verbatim in $\mathbb{Q}_3$, so the form fails to be isotropic *locally at $3$* — this single failed local condition already rules out a rational solution, exactly as the Hasse principle predicts (local failure $\Rightarrow$ global failure).
6. For a *positive* illustration, $x^2 + y^2 = 2z^2$ **does** have local solutions everywhere, and correspondingly it has the rational (indeed integer) solution $(x,y,z) = (1,1,1)$: $1 + 1 = 2\cdot 1$. $\checkmark$
7. By contrast, the classic *higher-degree* counterexample $3x^3 + 4y^3 + 5z^3 = 0$ (Selmer) has solutions over $\mathbb{R}$ and every $\mathbb{Q}_p$ yet **no** nontrivial rational solution — the Hasse principle is a theorem for quadratics but fails for cubics.
:::

## Hilbert Symbol and Local Invariants

<!-- section: hasse-hilbert -->

:::definition[Hilbert symbol]{#hilbert-symbol}
The Hilbert symbol $(a,b)_p \in \{+1, -1\}$ records local solubility: $(a,b)_p = +1$ exactly when

$$z^2 = a x^2 + b y^2$$

has a nontrivial solution in $\mathbb{Q}_p$ (equivalently, when $a$ is a norm from the extension $\mathbb{Q}_p(\sqrt{b})$). Here $p$ ranges over all primes *and* the "infinite place" $p = \infty$ corresponding to $\mathbb{R}$.
:::

:::theorem[Product formula]
For fixed nonzero rationals $a, b$,

$$\prod_p (a,b)_p = +1$$

over all places (including $\infty$), and all but finitely many factors are $+1$.
:::

This reciprocity is what makes the local conditions consistent: you cannot have exactly one place where solubility fails, so the local data glues into global existence for quadratic forms.

:::intuition
The Hilbert symbol is a local "does this pair of numbers behave like a norm or square" yes/no at each p and real place.

The product of all these local yes/no is always +1; this is the only global obstruction for quadratic forms.
:::

:::example
Verify the product formula for $a = b = -1$.
:::

:::solution
We evaluate $(-1, -1)_p$ at every place, using the meaning "does $z^2 = -x^2 - y^2$ have a nontrivial solution in $\mathbb{Q}_p$?"

Step 1 (the real place $p = \infty$). Over $\mathbb{R}$, $z^2 = -x^2 - y^2$ forces $x = y = z = 0$ (a sum of squares is negative only when all are zero). No nontrivial real solution, so $(-1,-1)_\infty = -1$.

Step 2 (the prime $p = 2$). It is a standard computation that $z^2 = -x^2 - y^2$ has no nontrivial solution in $\mathbb{Q}_2$ either (equivalently $-1$ is not a sum of two squares that are $2$-adic units in the required way), so $(-1,-1)_2 = -1$.

Step 3 (odd primes $p$). For every odd prime $p$, the form $z^2 + x^2 + y^2$ is isotropic over $\mathbb{Q}_p$ (any nondegenerate ternary quadratic form over $\mathbb{Q}_p$ with $p$ odd represents $0$ nontrivially), so $(-1,-1)_p = +1$ for all odd $p$.

Step 4 (take the product). Only two factors are $-1$:
$$\prod_p (-1,-1)_p = (-1)_\infty \cdot (-1)_2 \cdot \prod_{p \text{ odd}} (+1) = (-1)(-1) = +1.$$
The product is $+1$, confirming the product formula. $\checkmark$ Notice the two "failures" (at $\infty$ and at $2$) are forced to come in a compatible pair — a single lone failure is impossible.
:::

## Failure for Higher Degree and Brauer-Manin

<!-- section: hasse-failure -->

For cubic and higher, the Hasse principle fails: there are varieties with points everywhere locally but no global point.

The Brauer-Manin obstruction (from the Brauer group of the variety) explains many (but not all) failures.

For quadratics the Brauer group is trivial in the relevant sense, so Hasse holds.

:::intuition
For more complicated equations, being solvable "in every p-adic world and the reals" is not enough; there can be a global "entanglement" obstruction.

For squares (quadratic), no such extra obstruction.
:::

:::example
Why the Selmer cubic $3X^3 + 4Y^3 + 5Z^3 = 0$ is a genuine Hasse failure.
:::

:::solution
1. Step 1 (real solubility). Over $\mathbb{R}$ the equation is easy: fix $Z = 1$, then $3X^3 + 4Y^3 = -5$ describes a smooth real curve, so infinitely many real points exist. Hence there is a nontrivial real solution.
2. Step 2 ($p$-adic solubility). For every prime $p$, Selmer showed the equation has a nontrivial solution in $\mathbb{Q}_p$ (checked via Hensel's lemma lifting a solution mod $p$, with the finitely many "bad" primes handled by hand). So it is soluble in $\mathbb{R}$ and in *every* $\mathbb{Q}_p$.
3. Step 3 (no rational solution). Despite being soluble everywhere locally, the equation has **no** nontrivial solution in $\mathbb{Q}$. The obstruction is not visible from any single completion; it lives in the Brauer–Manin pairing (equivalently, in the Tate–Shafarevich group of the associated elliptic curve).
4. Step 4 (contrast). For a *quadratic* form no such obstruction exists (its Brauer contribution is trivial), which is precisely why Hasse–Minkowski holds for quadratics but breaks for this cubic. $\checkmark$
:::

## Common Mistakes

- **Hasse holds for all varieties**: No, only for quadratics (and some other classes like Severi-Brauer).
- **Local always implies global for integers**: No, even for linear sometimes (but for linear it does by Hasse for degree 1).
- **p-adics are hard**: In practice for quadratic forms there are explicit criteria using Hilbert symbols that reduce to Legendre/Jacobi at the primes dividing the discriminant.
- **The real place is important**: Sometimes the only obstruction is the real place (signature of the form).

Thue's theorem (1909) says that if $f(x,y)$ is an irreducible binary form of degree $d \ge 3$ with integer coefficients, then the equation $f(x,y) = h$ has only finitely many integer solutions $(x,y)$ for any fixed nonzero $h$.

In particular, the Thue equation $f(x,y) = 1$ with $\deg f \ge 3$ irreducible has only finitely many solutions.

This is a far-reaching generalization of FLT for fixed exponent (the homogeneous form x^n + y^n - z^n but projective), and is proved using Diophantine approximation (how well algebraic numbers can be approximated by rationals, Thue's improvement on Liouville).

It is one of the first major results in the theory of Diophantine equations using approximation.

## Statement

<!-- section: thue-statement -->

:::theorem[Thue's theorem]{#thue-theorem}
Let $f(X,Y) \in \mathbb{Z}[X,Y]$ be a *binary form* (homogeneous polynomial) of degree $d \ge 3$ that is irreducible over $\mathbb{Q}$. Then for any fixed nonzero integer $h$, the equation

$$f(x,y) = h$$

has only finitely many solutions in integers $x, y$.
:::

The hypotheses all matter: degree $d \ge 3$ (degree $2$ can give infinitely many, as Pell shows), irreducibility (a reducible form can hide a Pell-type factor), and $h \ne 0$ (the equation $f(x,y) = 0$ asks for rational points on a curve, which is a different question).

:::intuition
A "curvy" homogeneous polynomial equation of degree 3 or higher (irreducible) can only equal a fixed h for finitely many integer points (x,y).

Unlike linear or quadratic (Pell infinite), higher degree "curves" have finite integer points for fixed height h.
:::

:::example
The Thue equation $x^3 - 2y^3 = 1$ has only finitely many integer solutions.
:::

:::solution
Step 1 (check the hypotheses). The form $f(x,y) = x^3 - 2y^3$ is homogeneous of degree $3 \ge 3$. It is irreducible over $\mathbb{Q}$ because $f(x,1) = x^3 - 2$ has no rational root ($\sqrt[3]{2}$ is irrational). And $h = 1 \ne 0$. So Thue's theorem applies and guarantees *finitely many* solutions.

Step 2 (find the solutions by a bounded search). Test small $y$:
$y = 0$: $x^3 = 1 \Rightarrow x = 1$, giving $(1, 0)$.
$y = -1$: $x^3 = 1 + 2(-1)^3 = 1 - 2 = -1 \Rightarrow x = -1$, giving $(-1, -1)$.
$y = 1$: $x^3 = 1 + 2 = 3$, not a cube.
$y = 2$: $x^3 = 1 + 16 = 17$, not a cube; $y = -2$: $x^3 = 1 - 16 = -15$, not a cube.

Step 3 (sanity check). $(1)^3 - 2(0)^3 = 1$ $\checkmark$ and $(-1)^3 - 2(-1)^3 = -1 + 2 = 1$ $\checkmark$.

Step 4 (conclusion). The only integer solutions are $(1,0)$ and $(-1,-1)$ — a finite set, as Thue guarantees. (Proving no *large* solutions exist is exactly the hard content of the theorem, addressed next.)
:::

## Proof Idea via Approximation

<!-- section: thue-approximation -->

:::theorem[Liouville's approximation theorem]
If $\alpha$ is a real algebraic number of degree $d$, there is a constant $c > 0$ with

$$\left|\alpha - \frac{p}{q}\right| > \frac{c}{q^d}$$

for all rationals $p/q$. (1844.)
:::

:::theorem[Thue's improvement]
The exponent $d$ can be lowered to roughly $\tfrac{d}{2} + 1 + \epsilon$, so algebraic numbers are *harder* to approximate than Liouville's weaker bound suggested. (1909.)
:::

Here is how that yields finiteness.

:::proof
Suppose $f(x,y) = h$ with $y \ne 0$. Factor the form over its roots: $f(X,Y) = a_d \prod_{i=1}^{d} (X - \alpha_i Y)$, where the $\alpha_i$ are the (distinct) roots of $f(T,1) = 0$, each algebraic of degree $d \ge 3$. Dividing $f(x,y) = h$ by $y^d$,
$$a_d \prod_{i=1}^{d}\left(\frac{x}{y} - \alpha_i\right) = \frac{h}{y^d}.$$

If $y$ is large, the right side is tiny, so at least one factor $\left|\dfrac{x}{y} - \alpha_i\right|$ must be tiny — meaning $x/y$ is an extremely good rational approximation to that root $\alpha_i$: the other factors stay bounded away from $0$, forcing
$$\left|\frac{x}{y} - \alpha_i\right| \approx \frac{C}{|y|^{d}}$$
for a constant $C$. But Thue's theorem forbids approximations that good (the exponent $d$ beats his improved bound $\tfrac{d}{2}+1+\epsilon < d$ for $d \ge 3$). This is a contradiction for all sufficiently large $|y|$, so only finitely many $(x,y)$ can occur.
:::

:::intuition
A rational x/y that makes f(x/y,1) very small (1/y^d) would be an extremely good approximation to the algebraic root α of f(T,1)=0.

Thue proved that algebraic numbers cannot be approximated that well by rationals (the exponent is too good), hence only small y possible.
:::

:::example
The exponent gap for $x^3 - 2y^3 = 1$.
:::

:::solution
1. Step 1 (identify the root). Here $\alpha = \sqrt[3]{2}$ is the real root of $f(T,1) = T^3 - 2 = 0$, algebraic of degree $d = 3$.
2. Step 2 (what a large solution would imply). If $(x,y)$ solved the equation with $|y|$ large, the identity above gives $\left|\dfrac{x}{y} - \sqrt[3]{2}\right| \approx \dfrac{C}{|y|^{3}}$ — an approximation of quality $1/|y|^3$.
3. Step 3 (compare with Thue's bound). Thue's improved exponent for $d = 3$ is about $\tfrac{d}{2} + 1 + \epsilon = 2.5 + \epsilon$, so he guarantees $\left|\dfrac{x}{y} - \sqrt[3]{2}\right| > \dfrac{c}{|y|^{2.5+\epsilon}}$.
4. Step 4 (contradiction). For large $|y|$ we would need $\dfrac{c}{|y|^{2.5+\epsilon}} < \dfrac{C}{|y|^{3}}$, i.e. $|y|^{3 - (2.5+\epsilon)} = |y|^{0.5 - \epsilon} < C/c$ — impossible once $|y|$ is large enough. Hence only finitely many solutions, consistent with the two we found: $(1,0)$ and $(-1,-1)$. $\checkmark$
5. (Even Liouville's weaker exponent $d = 3$ is not quite enough here — the size $1/|y|^3$ matches it exactly — which is precisely why Thue's *improvement* of the exponent is what does the work.)
:::

## Effective Versions and Baker's Method

<!-- section: thue-effective -->

Thue's proof is ineffective (does not give bound on the size of solutions).

Effective bounds came later with Baker's theory of linear forms in logarithms, which give explicit (huge) bounds on solutions to Thue equations.

Today Thue equations can be solved completely for reasonable coefficients using computational methods combining Baker, lattice reduction (LLL), and enumeration.

:::intuition
Thue proves "only finitely many solutions" but never tells you how large to search — like knowing a treasure chest holds finitely many coins without knowing the number.

Baker's linear-forms-in-logarithms give a concrete (if gigantic) ceiling like $\max(|x|,|y|) < 10^{10^{10}}$: still enormous, but finite, and clever reduction plus a computer then finds them all.
:::

:::example
Effective vs. ineffective, on $x^3 - 2y^3 = 1$.
:::

:::solution
1. Step 1 (what Thue alone gives). Thue's 1909 proof says: "there are finitely many solutions." It gives *no* number $B$ with $|x|, |y| \le B$, so in principle you could search forever without knowing you were done.
2. Step 2 (what Baker's method adds). Rewrite $x^3 - 2y^3 = 1$ as a statement about a unit in the cubic field $\mathbb{Q}(\sqrt[3]{2})$; a solution corresponds to a small value of a *linear form in logarithms* of the field's units. Baker's theorem gives an explicit lower bound for how small such a linear form can be, which converts into an explicit (astronomically large) upper bound like $\max(|x|,|y|) < 10^{10^{k}}$.
3. Step 3 (reduce and finish). That bound is far too big for brute force, but the LLL lattice-reduction algorithm shrinks it to a search of a few thousand candidates, which a computer checks in seconds — confirming the only solutions are $(1,0)$ and $(-1,-1)$.
4. Step 4 (takeaway). "Finite" (Thue) and "computable in practice" (Baker + LLL) are different guarantees; modern Thue solvers routinely close out such equations completely.
:::

## Connection to FLT and Other Equations

<!-- section: thue-flt-connection -->

FLT for fixed n is a special case of Thue (the form x^n + y^n , but it is reducible over Q(ζ), but one can reduce to irreducible factors or use in the cyclotomic).

Thue's work was motivated by trying to prove FLT.

More generally, superelliptic equations, generalized Fermat equations are attacked with similar approximation or modular methods.

:::intuition
Proving no solutions to x^n + y^n =1 for n>2 is a Thue-type statement (after homogenizing or projectivizing).

Thue gave the first general finiteness for such "higher degree" Diophantine.
:::

:::example
$x^3 + y^3 = 1$ as a Thue-type equation.
:::

:::solution
1. Step 1 (fit the shape). The form $f(x,y) = x^3 + y^3$ has degree $3$ and fixed value $h = 1 \ne 0$. (It factors as $(x+y)(x^2 - xy + y^2)$ over $\mathbb{Q}$, so it is *reducible*; Thue's finiteness still holds after handling the quadratic factor, which here contributes nothing infinite because $x^2 - xy + y^2 > 0$ is bounded once $x+y$ is bounded.)
2. Step 2 (find the integer solutions). Test small values: $(1, 0)$ gives $1 + 0 = 1$ $\checkmark$; $(0, 1)$ gives $0 + 1 = 1$ $\checkmark$. For $|x|, |y| \ge 2$ with both nonzero, $|x^3 + y^3|$ is either far from $1$ or the terms cancel to $0$ (when $y = -x$), never landing on $1$.
3. Step 3 (conclusion). The only integer solutions are $(1,0)$ and $(0,1)$ — a finite set. This is the exponent-$3$ shadow of Fermat's Last Theorem: writing $x^3 + y^3 = 1$ as $a^3 + b^3 = c^3$ with $c = 1$ shows there is no solution in *positive* integers, exactly FLT for $n = 3$. $\checkmark$
:::

## Common Mistakes

- **Thue gives effective bounds**: The original proof does not; effective versions require Baker theory.
- **Applies to all forms**: The form must be irreducible (or one reduces to the irreducible factors).
- **Degree 2**: For degree 2 it can have infinitely many (Pell-like).
- **h=0**: For h=0 it is about rational points on the curve, which may be infinite if genus 0 or 1 with rank.
- **Binary form only**: The theorem is for two variables; more variables need other tools (Schmidt subspace theorem etc).

Fermat's Last Theorem (FLT) states that there are no positive integers $a, b, c$ and integer $n > 2$ such that $a^n + b^n = c^n$.

Stated by Pierre de Fermat in 1637 in the margin of a book, with the claim "I have a truly marvelous proof which this margin is too narrow to contain."

It was proved by Andrew Wiles in 1994-95 (with a correction in 1995 with Taylor), using elliptic curves, modular forms, and the modularity theorem for semistable elliptic curves (the Taniyama-Shimura conjecture in the needed case).

The proof is one of the highest achievements of 20th century mathematics, connecting Diophantine equations to the Langlands program.

## Statement and Small Cases

<!-- section: flt-statement -->

:::theorem[Fermat's Last Theorem]{#flt}
For $n > 2$, the equation

$$a^n + b^n = c^n$$

has no solution in positive integers $a, b, c$.
:::

For $n = 1$ it is trivial (many solutions, e.g. $1 + 2 = 3$).

For $n = 2$ there are infinitely many solutions — the Pythagorean triples.

Fermat proved the case $n = 4$ using infinite descent (a solution would force a strictly smaller one, contradiction).

Euler proved $n = 3$ (his original argument had a gap, later filled).

Dirichlet and Legendre handled $n = 5$, Lamé and others further cases. It suffices to prove FLT for $n = 4$ and for every odd *prime* exponent $p$, since any $n > 2$ has such a factor. The general case (all primes at once) stayed open until Wiles.

:::intuition
You cannot have two perfect powers with exponent >2 that add to another perfect power with the same exponent.

For squares it works (Pythagoras), for cubes and higher, no.
:::

:::example
Spot-check $n = 3$ on small numbers (illustrating, not proving, FLT).
:::

:::solution
Step 1 (test sums of two cubes). Look for $a^3 + b^3$ equal to a cube $c^3$:
$1^3 + 2^3 = 1 + 8 = 9$, and $9$ lies between $2^3 = 8$ and $3^3 = 27$ — not a cube.
$2^3 + 3^3 = 8 + 27 = 35$, between $3^3 = 27$ and $4^3 = 64$ — not a cube.
$3^3 + 4^3 = 27 + 64 = 91$, between $4^3 = 64$ and $5^3 = 125$ — not a cube.
$3^3 + 5^3 = 27 + 125 = 152$, between $125$ and $6^3 = 216$ — not a cube.

Step 2 (a famous near-miss). $3^3 + 4^3 + 5^3 = 27 + 64 + 125 = 216 = 6^3$ — but this is a sum of *three* cubes, which is allowed; FLT only forbids a sum of *two*.

Step 3 (caution). No amount of checking proves FLT — there are infinitely many candidates. Euler's actual proof for $n = 3$ uses descent in the ring $\mathbb{Z}[\omega]$ with $\omega = e^{2\pi i/3}$. The point of this check is only to build the expectation that no small solutions exist. $\checkmark$
:::

## Fermat's Proof for n=4 by Descent

<!-- section: flt-n4-descent -->

:::proposition[Fermat's descent statement]
The equation

$$a^4 + b^4 = c^2$$

has no solution in positive integers.
:::

This is stronger than FLT for $n = 4$, and implies it: if $a^4 + b^4 = c^4$, then setting $C = c^2$ gives $a^4 + b^4 = C^2$, which is forbidden.

:::proof
The idea: $a^4 + b^4 = c^2$ means $(a^2)^2 + (b^2)^2 = c^2$, so $(a^2, b^2, c)$ is a Pythagorean triple whose two legs are themselves perfect squares. Feeding this into the Pythagorean parametrization forces the existence of a *strictly smaller* triple of the same special form — legs again perfect squares. Iterating produces an infinite strictly decreasing sequence of positive integers, which is impossible. Hence no solution exists.
:::

:::intuition
Assume a solution for exponent 4. Then it gives a Pythagorean triple where the legs are themselves squares. The param for that triple forces even smaller solution of the same form, and so on forever, impossible in positive integers.
:::

:::example
One descent step for $a^4 + b^4 = c^2$.
:::

:::solution
Assume a solution in positive integers with $\gcd(a,b) = 1$ and $c$ minimal; say $a$ odd, $b$ even.

Step 1 (first parametrization). $(a^2)^2 + (b^2)^2 = c^2$ is a primitive triple, so there exist coprime $m > n > 0$ of opposite parity with
$$a^2 = m^2 - n^2, \qquad b^2 = 2mn, \qquad c = m^2 + n^2.$$

Step 2 (second parametrization). From $a^2 + n^2 = m^2$ (another primitive triple, with $n$ even since $a$ is odd), there are coprime $r > s > 0$ with
$$a = r^2 - s^2, \qquad n = 2rs, \qquad m = r^2 + s^2.$$

Step 3 (a new square identity). Substitute into $b^2 = 2mn = 2(r^2 + s^2)(2rs) = 4rs(r^2 + s^2)$, so
$$\left(\frac{b}{2}\right)^2 = rs\,(r^2 + s^2).$$
The three factors $r$, $s$, $r^2 + s^2$ are pairwise coprime, and their product is a perfect square, so each is a perfect square: $r = x^2$, $s = y^2$, $r^2 + s^2 = z^2$.

Step 4 (the smaller solution). Then $x^4 + y^4 = r^2 + s^2 = z^2$ — a new solution of the *same* equation. And its "$c$" is $z$, with
$$z \le z^2 = r^2 + s^2 = m \le m^2 < m^2 + n^2 = c,$$
so $z < c$, contradicting the minimality of $c$.

Step 5 (conclusion). No minimal solution can exist, hence no solution at all. This is Fermat's infinite descent. $\checkmark$
:::

## The Modularity Approach for General n

<!-- section: flt-wiles-proof -->

Wiles' proof: assume a solution to a^p + b^p = c^p for odd prime p (the hard case; p=2 done).

:::definition[Frey curve]
To such a solution associate the elliptic curve

$$y^2 = x (x - a^p) (x + b^p),$$

the **Frey curve**.
:::

This curve is semistable, and if the solution exists it would be a counterexample to the modularity theorem (every elliptic curve over Q is modular, i.e. comes from a modular form).

:::theorem[Modularity for semistable elliptic curves]
Wiles (with Taylor) proved modularity for semistable elliptic curves over $\mathbb{Q}$; hence no such Frey curve exists, hence no solution.
:::

The proof involved deformation theory of Galois representations, Hecke rings, etc.

:::intuition
A hypothetical solution for large exponent would create a very special elliptic curve (Frey) that cannot exist because all elliptic curves are "modular" (have a corresponding modular form or Galois rep coming from automorphic), but this one wouldn't.

The contradiction proves no solution.
:::

:::example
Trace the logical chain of Wiles' proof.
:::

:::solution
1. Step 1 (assume a counterexample). Suppose $a^p + b^p = c^p$ has a solution in positive integers for some odd prime $p$, chosen coprime and with $b$ even.
2. Step 2 (build the Frey curve). Form the elliptic curve $E : y^2 = x(x - a^p)(x + b^p)$. Its discriminant is (up to a constant) $(abc)^{2p}$, a perfect $p$-th power in a very structured way — this makes $E$ *semistable* with unusually simple ramification.
3. Step 3 (what modularity would say). The modularity theorem (Wiles–Taylor, for semistable curves) says every such $E$ over $\mathbb{Q}$ arises from a modular form; its mod-$p$ Galois representation must match one coming from a modular form of a specific, small level.
4. Step 4 (Ribet's contradiction). Ribet's level-lowering theorem (the "epsilon conjecture") shows the Frey curve's Galois representation would have to come from a modular form of level $2$ — but there are **no** nonzero cusp forms of weight $2$ and level $2$. Contradiction.
5. Step 5 (conclusion). The assumed solution cannot exist, so $a^p + b^p = c^p$ has no positive-integer solution for any odd prime $p$; combined with Fermat's $n = 4$ case, FLT holds for all $n > 2$. $\checkmark$
6. There is no numerical instance to display precisely *because* the theorem says none exists — the "example" is the chain of implications that forces that conclusion.
:::

## Common Mistakes

- **FLT for n=2**: There are solutions, the Pythagorean triples.
- **Fermat had a simple proof**: Unlikely; the full proof is hundreds of pages of advanced machinery developed over centuries.
- **Checked for small a b c**: Yes, but the theorem is for all, and the proof is global.
- **Counterexamples in other rings**: In some number rings FLT fails, but over Z for n>2 no.
- **"Last" theorem**: It was the last of Fermat's claims to be proved; he proved or claimed several others.
