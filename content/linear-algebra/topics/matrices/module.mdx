# Matrices

A matrix is a rectangular array of numbers. This compact notation encodes systems of equations, linear transformations, data tables, and geometric operations. Everything you do in applied linear algebra involves matrices.

The operations — addition, multiplication, transposition, and inversion — are not arbitrary rules. Each arises from the task of representing and composing linear transformations. Once you understand the motivation, the rules become natural.

This chapter lays the algebraic groundwork for solving systems (Chapter 3), understanding vector spaces (Chapter 4), and computing eigenvalues (Chapter 5).

## Matrix notation and basic operations {#operations}

An $m \times n$ matrix has $m$ rows and $n$ columns, and the entry in row $i$, column $j$ is written $A_{ij}$. A matrix is square when $m = n$.

:::definition[Matrix addition and scalar multiplication]{#matrix-operations}
For matrices $A, B$ of the *same* dimensions and a scalar $c$, both operations act entry by entry:

$$(A+B)_{ij} = A_{ij}+B_{ij}, \qquad (cA)_{ij} = c\,A_{ij}.$$
:::

The equal-dimensions hypothesis is not a formality: you cannot add a $3\times 2$ to a $2\times 3$, because there is no entry to pair with.

:::definition[Transpose]{#transpose}
The transpose $A^T$ of an $m\times n$ matrix $A$ is the $n\times m$ matrix obtained by swapping rows and columns:

$$(A^T)_{ij} = A_{ji}.$$
:::

Key properties: $(AB)^T = B^TA^T$ (order reverses), $(A^T)^T = A$, $(A+B)^T = A^T+B^T$.

:::definition[Symmetric matrix]{#symmetric-matrix}
A square matrix is symmetric if $A = A^T$, that is $A_{ij} = A_{ji}$ for all $i, j$.
:::

Symmetric matrices appear ubiquitously in statistics (covariance matrices), physics (inertia tensors), and optimisation (Hessians). They are always square, and their eigenvalues are always real.

The trace of a square matrix is the sum of its diagonal entries: $\text{tr}(A) = \sum_{i=1}^n A_{ii}$. It equals the sum of the eigenvalues of $A$ and satisfies $\text{tr}(AB) = \text{tr}(BA)$ even when $AB \neq BA$.

:::intuition
A matrix is a spreadsheet of numbers. Adding two matrices is adding two spreadsheets cell by cell — they must have the same shape. Multiplying by a scalar scales every cell. Transposing rotates the spreadsheet so rows become columns.
:::

:::example[Addition and transpose]
$A = \begin{pmatrix}1&3\\2&0\end{pmatrix}$, $B = \begin{pmatrix}-1&4\\1&5\end{pmatrix}$.
:::

:::solution
1. $A+B = \begin{pmatrix}0&7\\3&5\end{pmatrix}$.
2. $2A = \begin{pmatrix}2&6\\4&0\end{pmatrix}$.
3. $A^T = \begin{pmatrix}1&2\\3&0\end{pmatrix}$. Note $A_{12}=3$ became $A^T_{21}=3$.
4. Is $A$ symmetric? $A_{12}=3 \neq 2=A_{21}$, so no.
5. Trace: $\text{tr}(A) = A_{11}+A_{22} = 1+0 = 1$. Sanity check the transpose-invariance $\text{tr}(A^T)=\text{tr}(A)$: transposing leaves the diagonal untouched, and indeed $\text{tr}(A^T) = 1+0 = 1$ ✓.
:::

## Matrix multiplication {#multiplication}

:::definition[Matrix product]{#matrix-product}
Let $A$ be $m\times n$ and $B$ be $n\times p$, so that the inner dimensions match. Their product $AB$ is the $m\times p$ matrix with entries

$$(AB)_{ij} = \sum_{k=1}^{n} A_{ik}\,B_{kj},$$

that is, row $i$ of $A$ dotted with column $j$ of $B$.
:::

Why this definition? It encodes composition of linear transformations. If $T_A: \mathbb{R}^n\to\mathbb{R}^m$ and $T_B: \mathbb{R}^p\to\mathbb{R}^n$, then the composed map $T_A \circ T_B$ is represented by $AB$. The rule $(AB)\mathbf{x} = A(B\mathbf{x})$ forces this definition.

Matrix multiplication is not commutative: $AB \neq BA$ in general, even when both products exist and have the same size. It is associative: $(AB)C = A(BC)$, and distributive: $A(B+C) = AB+AC$.

The identity matrix $I_n$ (ones on the diagonal, zeros elsewhere) satisfies $AI = IA = A$. It is the matrix analogue of the number $1$.

Powers such as $A^2 = AA$ or $A^n$ only make sense when $A$ is square: the product $AA$ requires the columns of $A$ to match its own rows. There is no $A^2$ for a non-square matrix.

:::proposition[Column picture of a matrix-vector product]{#column-picture}
If $\mathbf{a}_1, \ldots, \mathbf{a}_n$ are the columns of $A$ and $\mathbf{v} \in \mathbb{R}^n$, then

$$A\mathbf{v} = v_1\mathbf{a}_1 + v_2\mathbf{a}_2 + \cdots + v_n\mathbf{a}_n,$$

a linear combination of the columns of $A$ with coefficients taken from $\mathbf{v}$.
:::

This column view is the key to understanding column spaces and linear independence.

:::intuition
Matrix multiplication is like following two sets of instructions in sequence. $B$ maps inputs to an intermediate space; $A$ maps that to the final output. The product $AB$ gives you the combined effect. Because the order of instructions matters, $AB \neq BA$ in general.
:::

:::example[2×2 matrix multiplication]
$A = \begin{pmatrix}2&1\\3&4\end{pmatrix}$, $B = \begin{pmatrix}1&0\\-1&2\end{pmatrix}$.
:::

:::solution
1. $(AB)_{11}$: row $1$ of $A$ · col $1$ of $B$: $(2)(1)+(1)(-1) = 1$.
2. $(AB)_{12}$: row $1$ · col $2$: $(2)(0)+(1)(2) = 2$.
3. $(AB)_{21}$: row $2$ · col $1$: $(3)(1)+(4)(-1) = -1$.
4. $(AB)_{22}$: row $2$ · col $2$: $(3)(0)+(4)(2) = 8$.
5. $AB = \begin{pmatrix}1&2\\-1&8\end{pmatrix}$.
:::

:::example[Matrix powers and non-commutativity]
A power like $A^2$ just means $AA$ — the same rule, applied to the matrix and itself. Take the "shear" $A = \begin{pmatrix}1&1\\0&1\end{pmatrix}$.
:::

:::solution
1. $(A^2)_{11} = (1)(1)+(1)(0) = 1$; $(A^2)_{12} = (1)(1)+(1)(1) = 2$; $(A^2)_{21} = (0)(1)+(1)(0) = 0$; $(A^2)_{22} = (0)(1)+(1)(1) = 1$.
2. So $A^2 = \begin{pmatrix}1&2\\0&1\end{pmatrix}$. The pattern continues: $A^n = \begin{pmatrix}1&n\\0&1\end{pmatrix}$, each power shearing a little more.
3. Order matters — check it. With $B = \begin{pmatrix}0&1\\1&0\end{pmatrix}$: $AB = \begin{pmatrix}1&1\\1&0\end{pmatrix}$ but $BA = \begin{pmatrix}0&1\\1&1\end{pmatrix}$. Sanity check: $AB \neq BA$, confirming multiplication is not commutative.
:::

## Determinants {#determinants}

The determinant is a scalar assigned to every square matrix that captures whether it is invertible, how it scales area/volume, and whether it preserves orientation.

:::definition[Determinant of a 2×2 matrix]{#det-2x2}
$$\det\begin{pmatrix}a&b\\c&d\end{pmatrix} = ad - bc,$$

the main-diagonal product minus the anti-diagonal product.
:::

Geometric meaning: $|\det(A)|$ is the factor by which the transformation $A$ multiplies area ($n=2$) or volume ($n=3$). $\det(A)=2$ means areas are doubled; $\det(A)=0$ means the transformation collapses space to a lower dimension.

Sign of the determinant: $\det(A)>0$ means orientation is preserved (no reflection). $\det(A)<0$ means orientation is reversed.

:::theorem[Determinant criterion for invertibility]{#det-invertibility}
A square matrix $A$ is invertible if and only if $\det(A) \neq 0$.
:::

A singular matrix (det $=0$) squashes space and cannot be undone — its inverse does not exist.

Two more facts you will use often. The first is scaling: for an $n\times n$ matrix, $\det(cA) = c^n\det(A)$, because scaling by $c$ stretches all $n$ independent directions by $c$, so volume grows by $c^n$ — not $c$. The second is how to compute a determinant beyond the $2\times 2$ case.

:::recipe[Cofactor expansion]{#cofactor-expansion}
To evaluate $\det(A)$ for a $3\times 3$ or larger square matrix:

1. Pick any row $i$ (or any column) — preferably one with many zeros.
2. For each entry $A_{ij}$ in it, delete row $i$ and column $j$ and take the determinant of what remains; this is the minor $M_{ij}$.
3. Attach the sign $(-1)^{i+j}$ to get the cofactor, a checkerboard pattern starting with $+$ in the top-left.
4. Sum the products: $\det(A) = \sum_j A_{ij}(-1)^{i+j}M_{ij}$.
:::

:::intuition
The determinant measures how much a matrix stretches or squishes space. A value of $3$ means it triples all areas. A value of $-1$ means it reflects without changing size. A value of $0$ means it flattens everything — you lose a whole dimension and can never get it back.
:::

:::example[3×3 determinant by cofactor expansion]
Find $\det(A)$ for $A = \begin{pmatrix}2&1&0\\1&3&1\\0&1&2\end{pmatrix}$.
:::

:::solution
1. Expand along row $1$. The signs on that row are $+,\,-,\,+$.
2. First term: $+2\cdot\det\begin{pmatrix}3&1\\1&2\end{pmatrix} = 2(3\cdot 2 - 1\cdot 1) = 2(5) = 10$.
3. Second term: $-1\cdot\det\begin{pmatrix}1&1\\0&2\end{pmatrix} = -1(1\cdot 2 - 1\cdot 0) = -1(2) = -2$.
4. Third term: $+0\cdot(\cdots) = 0$ — the $0$ entry kills its cofactor, so we skip it. (Tip: always expand along the row or column with the most zeros.)
5. Sum: $\det(A) = 10 - 2 + 0 = 8$. Since $8 \neq 0$, $A$ is invertible.
:::

## Matrix inverse {#inverse}

:::definition[Inverse of a square matrix]{#inverse-definition}
The inverse of a square matrix $A$ is the square matrix $A^{-1}$ with

$$AA^{-1} = A^{-1}A = I.$$

By the determinant criterion it exists precisely when $\det(A) \neq 0$; a matrix without an inverse is called singular.
:::

:::proposition[Inverse of a 2×2 matrix]{#inverse-2x2}
If $A = \begin{pmatrix}a&b\\c&d\end{pmatrix}$ and $ad-bc \neq 0$, then

$$A^{-1} = \frac{1}{ad-bc}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}.$$
:::

In words: swap the main-diagonal entries, negate the off-diagonal entries, and divide by the determinant.

:::recipe[Inversion by Gauss-Jordan elimination]{#gauss-jordan-inverse}
For larger matrices, row-reduce the augmented matrix $[A\;|\;I]$. When the left block reaches $I$, the right block is $A^{-1}$.
:::

The inverse solves $A\mathbf{x}=\mathbf{b}$ immediately: $\mathbf{x} = A^{-1}\mathbf{b}$. However, computing $A^{-1}$ explicitly is costly. Gaussian elimination solves systems more efficiently without forming the inverse.

Key properties: $(AB)^{-1} = B^{-1}A^{-1}$ (order reverses), $(A^{-1})^{-1}=A$, $(A^T)^{-1}=(A^{-1})^T$, $\det(A^{-1})=1/\det(A)$.

Orthogonal matrices satisfy $Q^TQ=I$, so $Q^{-1}=Q^T$. For these matrices (rotations and reflections), the inverse is free — just transpose.

:::intuition
The inverse undoes what the matrix does. Rotate $30°$: the inverse rotates $-30°$. Double all lengths: the inverse halves them. A singular matrix flattens space — information is permanently lost and no inverse can recover it.
:::

:::example[Inverse of a 2×2 matrix with verification]
Find $A^{-1}$ for $A = \begin{pmatrix}3&1\\5&2\end{pmatrix}$.
:::

:::solution
1. $\det(A) = 6-5 = 1$. Inverse exists.
2. $A^{-1} = \frac{1}{1}\begin{pmatrix}2&-1\\-5&3\end{pmatrix}$.
3. Verify: $AA^{-1} = \begin{pmatrix}3&1\\5&2\end{pmatrix}\begin{pmatrix}2&-1\\-5&3\end{pmatrix} = \begin{pmatrix}6-5&-3+3\\10-10&-5+6\end{pmatrix} = \begin{pmatrix}1&0\\0&1\end{pmatrix}$ ✓.
:::

:::example[Inverse by Gauss-Jordan elimination]
Invert $A = \begin{pmatrix}1&2\\3&7\end{pmatrix}$ by row-reducing $[A\;|\;I]$ until the left block is $I$.
:::

:::solution
1. Start: $\left[\begin{array}{cc|cc}1&2&1&0\\3&7&0&1\end{array}\right]$.
2. Clear the entry below the first pivot: $R_2 \to R_2 - 3R_1$ gives $\left[\begin{array}{cc|cc}1&2&1&0\\0&1&-3&1\end{array}\right]$.
3. Clear the entry above the second pivot: $R_1 \to R_1 - 2R_2$ gives $\left[\begin{array}{cc|cc}1&0&7&-2\\0&1&-3&1\end{array}\right]$.
4. The left block is now $I$, so the right block is the inverse: $A^{-1} = \begin{pmatrix}7&-2\\-3&1\end{pmatrix}$.
5. Sanity check with the determinant formula: $\det(A) = 1\cdot 7 - 2\cdot 3 = 1$, and $\tfrac{1}{1}\begin{pmatrix}7&-2\\-3&1\end{pmatrix}$ matches ✓.
:::

## Special matrices {#properties}

Symmetric matrices: $A = A^T$. By the Spectral Theorem (Chapter 8), all eigenvalues are real and there exists an orthonormal eigenvector basis. These arise in covariance matrices, Hessians, and physics.

:::definition[Orthogonal matrix]{#orthogonal-matrix}
A square matrix $Q$ is orthogonal if

$$Q^TQ = I,$$

equivalently if its columns are orthonormal. Then $Q^{-1} = Q^T$.
:::

Orthogonal matrices have $\det(Q) = \pm 1$: they represent rotations ($\det=+1$) and reflections ($\det=-1$), and the inverse costs nothing but a transpose.

Diagonal matrices: nonzero entries only on the main diagonal. Trivial to invert ($D^{-1}_{ii}=1/D_{ii}$), multiply ($(D_1D_2)_{ii}=(D_1)_{ii}(D_2)_{ii}$), and exponentiate. Diagonalisation is the act of finding a basis in which a matrix looks diagonal.

Upper/lower triangular: all entries below/above the diagonal are zero.

:::proposition[Determinant of a triangular matrix]{#triangular-determinant}
If $A$ is square and triangular (upper or lower), then

$$\det(A) = A_{11}A_{22}\cdots A_{nn},$$

the product of its diagonal entries.
:::

Systems $L\mathbf{x}=\mathbf{b}$ (lower) are solved by forward substitution; $U\mathbf{x}=\mathbf{b}$ (upper) by back substitution. The LU decomposition writes any invertible matrix as $A=LU$.

Skew-symmetric (anti-symmetric) matrices: $A^T = -A$. Because $A_{ii} = -A_{ii}$ forces $A_{ii}=0$, every diagonal entry is zero. These encode rotations and cross products.

Idempotent matrices: $P^2=P$. Projection matrices are idempotent — projecting twice lands you where you already are, so it gives the same result. Because $\lambda^2 = \lambda$ for any eigenvalue, they have eigenvalues $0$ and $1$ only; hence $\det(P)$ is a product of $0$s and $1$s, and is $0$ unless $P=I$.

:::intuition
Symmetric matrices are perfectly balanced across their diagonal. Orthogonal matrices are rigid rotations — nothing stretches or shrinks. Diagonal matrices are the simplest: each axis is just scaled independently, with no mixing. These are the building blocks everything else reduces to.
:::

:::example[Recognizing and using special matrices]
Is $Q = \begin{pmatrix}0&-1\\1&0\end{pmatrix}$ orthogonal? Check $Q^TQ = I$. Here $Q^T = \begin{pmatrix}0&1\\-1&0\end{pmatrix}$.
:::

:::solution
1. $Q^TQ = \begin{pmatrix}0&1\\-1&0\end{pmatrix}\begin{pmatrix}0&-1\\1&0\end{pmatrix} = \begin{pmatrix}1&0\\0&1\end{pmatrix} = I$ ✓, so $Q$ is orthogonal and its inverse is free: $Q^{-1} = Q^T$.
2. Notice $Q^T = -Q$, so $Q$ is also skew-symmetric — its diagonal entries are indeed both $0$, as required.
3. Now use a diagonal matrix's shortcut. For $D = \begin{pmatrix}2&0\\0&3\end{pmatrix}$, powers act entry-wise on the diagonal: $D^3 = \begin{pmatrix}2^3&0\\0&3^3\end{pmatrix} = \begin{pmatrix}8&0\\0&27\end{pmatrix}$.
4. Sanity check the diagonal rule against the general one: $(D^3)_{22} = $ (product of diagonal $3$-powers) $= 3\cdot 3\cdot 3 = 27$ ✓.
:::

## Common Mistakes

- Assuming $AB = BA$. Matrix multiplication is almost never commutative. Even $2\times 2$ matrices fail this.
- Multiplying matrices with incompatible dimensions. An $m\times n$ matrix can only right-multiply an $n\times p$ matrix.
- Computing the inverse when $\det(A)=0$. Singular matrices have no inverse. The $2\times 2$ formula gives division by zero.
- Confusing the transpose with the inverse. $A^T \neq A^{-1}$ unless $A$ is orthogonal.
- Forgetting that $(AB)^{-1} = B^{-1}A^{-1}$ and $(AB)^T = B^TA^T$ — both reverse the order.
