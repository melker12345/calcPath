# Vector Spaces

Vector spaces are the abstract framework that unifies all of linear algebra. The same theory that applies to arrows in $\mathbb{R}^n$ applies equally to polynomials, matrices, functions, and signals. The key insight is that the 'size' of a space is fully captured by a single number: its dimension.

The four core concepts — span, linear independence, basis, dimension — provide the language for describing what a set of vectors can and cannot represent. The column space and null space give these abstract ideas concrete computational content.

Understanding vector spaces is the conceptual leap that separates people who use linear algebra from people who understand it. Every major theorem — eigenvalues, the SVD, least squares — is ultimately a statement about the structure of certain vector spaces.

## Subspaces {#subspaces}

:::definition[Subspace]{#subspace-definition}
A subspace of $\mathbb{R}^n$ is a subset $V$ satisfying three conditions:

1. $\mathbf{0} \in V$;
2. if $\mathbf{u},\mathbf{v}\in V$ then $\mathbf{u}+\mathbf{v}\in V$ (closed under addition);
3. if $\mathbf{v}\in V$ and $c\in\mathbb{R}$ then $c\mathbf{v}\in V$ (closed under scalar multiplication).
:::

:::proposition[One-step subspace test]{#subspace-test}
A nonempty subset $V \subseteq \mathbb{R}^n$ is a subspace if and only if every linear combination $c\mathbf{u}+d\mathbf{v}$ of vectors in $V$ stays in $V$.
:::

Examples of subspaces: $\{\mathbf{0}\}$, any line through the origin, any plane through the origin, $\mathbb{R}^n$ itself, the null space of any matrix $A$, and the column space of any matrix $A$.

Non-examples: a line not through the origin (fails condition 1), a circle (not closed under addition), $\{(x,y): x\geq 0\}$ (fails condition 3 — multiply any vector by $-1$ and you leave the set). The origin condition is always the fastest check.

The intersection $V\cap W$ of two subspaces is always a subspace. The union $V\cup W$ is usually not — to get a subspace from two subspaces, take their sum $V+W = \{\mathbf{v}+\mathbf{w}: \mathbf{v}\in V, \mathbf{w}\in W\}$.

:::intuition
A subspace is a flat surface (of any dimension) passing through the origin. You can add vectors and scale them all you like and you'll never leave the surface. A tilted plane not through the origin, or a curved surface, is not a subspace.
:::

:::example[Is $V=\{\langle x,y,z\rangle : x+y+z=0\}$ a subspace of $\mathbb{R}^3$?]
Check $\mathbf{0}\in V$: for $\langle 0,0,0\rangle$ we have $0+0+0=0$ ✓.
:::

:::solution
1. Check closure under addition: take $\mathbf{u}=\langle u_1,u_2,u_3\rangle$ and $\mathbf{v}=\langle v_1,v_2,v_3\rangle$ in $V$, so $u_1+u_2+u_3=0$ and $v_1+v_2+v_3=0$. Their sum satisfies $(u_1+v_1)+(u_2+v_2)+(u_3+v_3) = (u_1+u_2+u_3)+(v_1+v_2+v_3) = 0+0 = 0$, so $\mathbf{u}+\mathbf{v}\in V$ ✓.
2. Check closure under scaling: for $c\in\mathbb{R}$, $cu_1+cu_2+cu_3 = c(u_1+u_2+u_3) = c\cdot 0 = 0$, so $c\mathbf{u}\in V$ ✓.
3. All three conditions hold, so $V$ is a subspace. Sanity check: $V$ is a plane through the origin (a single homogeneous equation in $\mathbb{R}^3$), which is exactly the kind of flat-through-origin set the ELI5 describes.
4. Contrast: $W=\{\langle x,y,z\rangle : x+y+z=1\}$ is **not** a subspace — it fails step 1 since $0+0+0=0\neq 1$, so $\mathbf{0}\notin W$. That single failed check is enough to disqualify it.
:::

## Span {#span}

:::definition[Span]{#span-definition}
The span of $\{\mathbf{v}_1,\ldots,\mathbf{v}_k\}$ is the set of every possible linear combination of them:

$$\text{span}\{\mathbf{v}_1,\ldots,\mathbf{v}_k\} = \{c_1\mathbf{v}_1+\cdots+c_k\mathbf{v}_k : c_i\in\mathbb{R}\}.$$
:::

:::proposition[A span is a subspace]{#span-is-subspace}
For any vectors $\mathbf{v}_1,\ldots,\mathbf{v}_k \in \mathbb{R}^n$, their span is a subspace of $\mathbb{R}^n$.
:::

:::proof
The span contains $\mathbf{0}$: set all $c_i=0$. Adding two linear combinations of the $\mathbf{v}_i$ gives another linear combination of them, and scaling one by $c$ multiplies every coefficient by $c$, so the set is closed under addition and scaling. All three conditions of the definition hold.
:::

Geometrically in $\mathbb{R}^3$: one nonzero vector spans a line through the origin; two independent vectors span a plane; three independent vectors span all of $\mathbb{R}^3$.

:::recipe[Testing membership in a span]{#span-membership}
To check whether $\mathbf{b}\in\text{span}\{\mathbf{v}_1,\ldots,\mathbf{v}_k\}$, set up the augmented matrix $[\mathbf{v}_1\;\cdots\;\mathbf{v}_k\;|\;\mathbf{b}]$ and row-reduce. If the system is consistent, $\mathbf{b}$ is in the span, and the solution gives the coefficients.
:::

The column space $\text{Col}(A)$ is the span of the columns of $A$. The question 'is $\mathbf{b}\in\text{Col}(A)$?' is identical to 'is $A\mathbf{x}=\mathbf{b}$ consistent?'

:::intuition
The span of a set of vectors is everything you can reach by mixing them together. Vectors are like paint colors: red and blue span all mixtures of red and blue. Purple is in the span; orange is not (you'd need yellow). The span is your palette.
:::

:::example[Is a vector in the span?]
Is $\mathbf{b}=\langle 1,5,3\rangle$ in $\text{span}\{\mathbf{v}_1,\mathbf{v}_2\}$ with $\mathbf{v}_1=\langle 1,1,1\rangle$, $\mathbf{v}_2=\langle 0,2,1\rangle$?
:::

:::solution
1. Row-reduce $[\mathbf{v}_1\;\mathbf{v}_2\;|\;\mathbf{b}]$: $\left(\begin{array}{cc|c}1&0&1\\1&2&5\\1&1&3\end{array}\right)\to\left(\begin{array}{cc|c}1&0&1\\0&1&2\\0&0&0\end{array}\right)$.
2. Consistent. $c_1=1$, $c_2=2$: $\mathbf{b} = 1\cdot\mathbf{v}_1+2\cdot\mathbf{v}_2$.
3. Check: $\langle 1,1,1\rangle+2\langle 0,2,1\rangle = \langle 1,5,3\rangle$ ✓.
:::

## Linear independence {#independence}

:::definition[Linear independence]{#independence-definition}
Vectors $\{\mathbf{v}_1,\ldots,\mathbf{v}_k\}$ are linearly independent if

$$c_1\mathbf{v}_1+\cdots+c_k\mathbf{v}_k=\mathbf{0} \quad\Longrightarrow\quad c_1 = \cdots = c_k = 0.$$

If a non-trivial combination equals $\mathbf{0}$, the vectors are linearly dependent.
:::

Dependence means redundancy: at least one vector is expressible as a combination of the others and adds no new direction. Removing it does not shrink the span.

:::proposition[Pivot test for independence]{#independence-test}
Form $A=[\mathbf{v}_1\;\cdots\;\mathbf{v}_k]$ and row-reduce. The vectors are independent if and only if every column is a pivot column, if and only if $\text{Null}(A)=\{\mathbf{0}\}$.
:::

:::proposition[Too many vectors are dependent]{#too-many-vectors}
In $\mathbb{R}^n$, any set of more than $n$ vectors is linearly dependent.
:::

You cannot have more than $n$ independent directions in $n$-dimensional space.

Any set containing $\mathbf{0}$ is automatically dependent: $1\cdot\mathbf{0}=\mathbf{0}$ provides a non-trivial combination equalling zero.

:::intuition
Vectors are independent if none of them is 'redundant' — if knowing the others doesn't already tell you where this one points. If $\mathbf{v}_3 = 2\mathbf{v}_1 - \mathbf{v}_2$, then $\mathbf{v}_3$ adds no new information and the set is dependent.
:::

:::example[Dependence check in $\mathbb{R}^3$]
Are $\mathbf{v}_1=\langle 1,0,2\rangle$, $\mathbf{v}_2=\langle 0,1,3\rangle$, $\mathbf{v}_3=\langle 2,1,7\rangle$ independent?
:::

:::solution
1. Row-reduce: $\begin{pmatrix}1&0&2\\0&1&3\\2&1&7\end{pmatrix}\to\begin{pmatrix}1&0&2\\0&1&3\\0&0&0\end{pmatrix}$. Only 2 pivots — dependent.
2. From RREF: $\mathbf{v}_3=2\mathbf{v}_1+\mathbf{v}_2$. Check: $2\langle 1,0,2\rangle+\langle 0,1,3\rangle=\langle 2,1,7\rangle$ ✓.
:::

## Basis and dimension {#basis}

:::definition[Basis]{#basis-definition}
A basis for a subspace $V$ is a set of vectors that is both linearly independent and spans $V$.
:::

A basis is simultaneously a minimal spanning set (drop any vector and it no longer spans $V$) and a maximal independent set (add any other vector of $V$ and it becomes dependent) — it sits exactly at the boundary where "enough to reach everything" meets "no redundancy."

:::proposition[Unique representation in a basis]{#unique-coordinates}
If $\{\mathbf{b}_1,\ldots,\mathbf{b}_n\}$ is a basis for $V$, every vector of $V$ is a linear combination of the $\mathbf{b}_i$ in exactly one way.
:::

This uniqueness is what makes a basis a coordinate system: each vector has unique coordinates $(c_1,\ldots,c_n)$ relative to the chosen basis.

:::theorem[Dimension is well defined]{#dimension}
All bases for a subspace $V$ contain the same number of vectors. That number is the dimension $\dim(V)$.
:::

Dimension is therefore an intrinsic invariant of the space, not an artefact of the basis you happened to choose.

:::recipe[Bases for the column space and the null space]{#basis-recipe}
To find a basis for $\text{Col}(A)$: row-reduce $A$ and take the original columns (not the RREF columns) at pivot positions.

To find a basis for $\text{Null}(A)$: row-reduce, express the pivot variables in terms of the free variables, and write the general solution as a linear combination of vectors — those vectors are the basis.
:::

:::intuition
A basis is the minimum set of directions you need to describe every position in the space. In $\mathbb{R}^2$, any two non-parallel vectors form a basis: one is not enough (you're stuck on a line), three is too many (one is redundant). Dimension is just how many directions you need.
:::

:::example[Find a basis and the dimension of $V=\{\langle x,y,z\rangle : x+y+z=0\}$.]
Solve the constraint for one variable in terms of the others. Treat $y=s$ and $z=t$ as free; then $x = -s-t$.
:::

:::solution
1. Write the general vector using the free variables: $\langle x,y,z\rangle = \langle -s-t,\; s,\; t\rangle = s\langle -1,1,0\rangle + t\langle -1,0,1\rangle$.
2. Every vector in $V$ is a combination of $\mathbf{b}_1=\langle -1,1,0\rangle$ and $\mathbf{b}_2=\langle -1,0,1\rangle$, so these two span $V$.
3. They are independent: neither is a scalar multiple of the other (their $y$ and $z$ entries can't both be matched by one constant). A spanning set of two independent vectors is a basis.
4. Therefore $\dim(V)=2$. Sanity check: verify each basis vector satisfies the constraint — $-1+1+0=0$ ✓ and $-1+0+1=0$ ✓. This matches the intuition that one equation removes one degree of freedom from $\mathbb{R}^3$, leaving $3-1=2$.
:::

## Column space and null space {#linear-transformations}

:::definition[Column space and null space]{#col-null-definition}
For an $m\times n$ matrix $A$,

$$\text{Col}(A) = \{A\mathbf{x}: \mathbf{x}\in\mathbb{R}^n\}, \qquad \text{Null}(A) = \{\mathbf{x}\in\mathbb{R}^n: A\mathbf{x}=\mathbf{0}\}.$$

The column space is the span of the columns of $A$ — all possible outputs — and has dimension $\text{rank}(A)$. The null space is the set of inputs sent to zero; it is always a subspace of $\mathbb{R}^n$, and its dimension is the nullity.
:::

:::theorem[Rank-nullity theorem]{#rank-nullity}
For an $m\times n$ matrix $A$,

$$\text{rank}(A)+\text{nullity}(A)=n.$$
:::

:::proof
Row-reduce $A$. Every column either contributes a new independent direction — it holds a pivot, adding $1$ to the rank — or introduces a free variable, adding $1$ to the nullity. No column does both, and every column does one, so the two counts add to the total number $n$ of columns.
:::

The row space $\text{Row}(A)=\text{Col}(A^T)$ has dimension $\text{rank}(A)$ as well. Keep the ambient spaces straight for an $m\times n$ matrix $A$: $\text{Row}(A)$ and $\text{Null}(A)$ live in the input space $\mathbb{R}^n$, while $\text{Col}(A)$ and $\text{Null}(A^T)$ live in the output space $\mathbb{R}^m$.

:::theorem[Fundamental theorem of linear algebra]{#fundamental-theorem}
For an $m\times n$ matrix $A$, each pair of fundamental subspaces splits its ambient space into orthogonal complements:

$$\text{Row}(A)^\perp = \text{Null}(A) \text{ inside } \mathbb{R}^n, \qquad \text{Col}(A)^\perp = \text{Null}(A^T) \text{ inside } \mathbb{R}^m.$$
:::

"Orthogonal complements" means the two subspaces meet only at $\mathbf{0}$, every vector of one is perpendicular to every vector of the other, and their dimensions add up to the whole space.

:::intuition
The column space is everywhere the matrix can take you — all reachable destinations. The null space is everything the matrix erases — inputs it maps to zero. A large null space means the matrix loses a lot of information; a trivial null space means it is injective (one-to-one).
:::

:::example[Find bases for $\text{Col}(A)$ and $\text{Null}(A)$, and verify rank-nullity, for]
$$A=\begin{pmatrix}1&2&3\\0&1&1\\1&3&4\end{pmatrix}.$$
:::

:::solution
Row-reduce. Subtract row 1 from row 3: $\begin{pmatrix}1&2&3\\0&1&1\\0&1&1\end{pmatrix}$. Subtract row 2 from row 3: $\begin{pmatrix}1&2&3\\0&1&1\\0&0&0\end{pmatrix}$. Clear above the second pivot with row 1 $\to$ row 1 $-2\cdot$ row 2: RREF $=\begin{pmatrix}1&0&1\\0&1&1\\0&0&0\end{pmatrix}$.
Pivots are in columns 1 and 2, so $\text{rank}(A)=2$. Basis for $\text{Col}(A)$: take the **original** columns at those pivot positions, $\{\langle 1,0,1\rangle,\ \langle 2,1,3\rangle\}$ — not the RREF columns.
Basis for $\text{Null}(A)$: column 3 is free, so set $x_3=t$. The RREF rows give $x_1+x_3=0$ and $x_2+x_3=0$, i.e. $x_1=-t$, $x_2=-t$. The general solution is $t\langle -1,-1,1\rangle$, so $\{\langle -1,-1,1\rangle\}$ is a basis and $\text{nullity}(A)=1$.
Check rank-nullity: $\text{rank}+\text{nullity}=2+1=3=n$ ✓ (the matrix has $3$ columns).
Sanity check the null vector: $A\langle -1,-1,1\rangle$ has entries $1(-1)+2(-1)+3(1)=0$, $0(-1)+1(-1)+1(1)=0$, $1(-1)+3(-1)+4(1)=0$, so $A\langle -1,-1,1\rangle=\mathbf{0}$ ✓.
:::

## Common Mistakes

- Claiming any subset of $\mathbb{R}^n$ is a subspace without checking all three conditions. The easiest first check: does it contain $\mathbf{0}$?
- Confusing span with independence. A spanning set can be dependent (redundant); an independent set may not span. A basis must be both.
- Stating 'the dimension is $2$' because you found two independent vectors, without checking they actually span the space.
- Extracting the column space basis from the RREF matrix instead of the original matrix. Use pivot positions to identify which original columns to take.
- Forgetting the zero vector is always in the null space — $\text{Null}(A)$ is never empty.
