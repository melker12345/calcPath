# Eigenvalues and Eigenvectors

Eigenvalues and eigenvectors reveal the intrinsic skeleton of a linear transformation. Most vectors get both rotated and stretched when a matrix acts on them. But a few special vectors — the eigenvectors — only get stretched: their direction is preserved (or reversed), and the stretch factor is the eigenvalue.

Finding eigenvalues reduces to solving the characteristic equation $\det(A-\lambda I)=0$, a polynomial in $\lambda$. Each root is an eigenvalue; for each eigenvalue, the eigenvectors are the nonzero solutions to $(A-\lambda I)\mathbf{v}=\mathbf{0}$.

Diagonalization — writing $A=PDP^{-1}$ — is the payoff: once you have eigenvectors and eigenvalues, complex operations like $A^{100}$ become trivial. This chapter also covers the full theory of linear transformations, which underpins every subsequent result.

## Linear transformations and their matrices {#linear-transformations}

:::definition[Linear transformation]{#linear-map-definition}
A function $T:\mathbb{R}^n\to\mathbb{R}^m$ is linear if

$$T(\mathbf{u}+\mathbf{v})=T(\mathbf{u})+T(\mathbf{v}), \qquad T(c\mathbf{v})=cT(\mathbf{v})$$

for all vectors $\mathbf{u},\mathbf{v}$ and all scalars $c$.
:::

Together these imply $T(c\mathbf{u}+d\mathbf{v}) = cT(\mathbf{u})+dT(\mathbf{v})$ — linear maps preserve linear combinations.

:::theorem[Standard matrix of a linear map]{#standard-matrix}
Every linear transformation $T:\mathbb{R}^n\to\mathbb{R}^m$ has a unique representing matrix,

$$A = [\,T(\mathbf{e}_1)\;|\;T(\mathbf{e}_2)\;|\;\cdots\;|\;T(\mathbf{e}_n)\,],$$

whose columns are the images of the standard basis vectors.
:::

Once you know what $T$ does to the basis, you know everything.

Geometric examples: rotations, reflections, projections, shears, and scalings are all linear. Non-linear examples: translations, squaring a vector, adding a constant.

Composition of transformations corresponds to matrix multiplication: $(T_A\circ T_B)(\mathbf{x}) = A(B\mathbf{x}) = (AB)\mathbf{x}$. This is the geometric motivation for the matrix multiplication rule.

:::intuition
A linear transformation reshapes space without bending, tearing, or moving the origin. Lines stay lines. Parallel lines stay parallel. The whole space gets rotated, stretched, or squished in a uniform way. Every such rule is exactly captured by a matrix.
:::

:::example[Matrix of a 90° rotation]
Find the matrix for $90°$ counterclockwise rotation in $\mathbb{R}^2$.
:::

:::solution
1. $T(\mathbf{e}_1)=T(\langle 1,0\rangle) = \langle 0,1\rangle$ (the $x$-axis vector rotates to the $y$-axis).
2. $T(\mathbf{e}_2)=T(\langle 0,1\rangle) = \langle -1,0\rangle$.
3. Matrix: $R_{90} = \begin{pmatrix}0&-1\\1&0\end{pmatrix}$.
4. Apply to $\langle 3,2\rangle$: $\begin{pmatrix}0&-1\\1&0\end{pmatrix}\begin{pmatrix}3\\2\end{pmatrix} = \begin{pmatrix}-2\\3\end{pmatrix}$. Rotated $90°$ ✓.
:::

## Kernel and image {#kernel-image}

:::definition[Kernel and image]{#kernel-image}
For $T:\mathbb{R}^n\to\mathbb{R}^m$ with matrix $A$,

$$\ker(T) = \{\mathbf{x}: T(\mathbf{x})=\mathbf{0}\} = \text{Null}(A), \qquad \text{Im}(T) = \{T(\mathbf{x}): \mathbf{x}\in\mathbb{R}^n\} = \text{Col}(A).$$

The kernel is the set of inputs that $T$ collapses to zero; the image is the set of outputs it can produce.
:::

:::proposition[Injectivity and surjectivity]{#injective-surjective}
$T$ is injective (one-to-one) if and only if $\ker(T)=\{\mathbf{0}\}$, and surjective (onto) if and only if $\text{Im}(T)=\mathbb{R}^m$, equivalently $\text{rank}(A)=m$.
:::

An injective map sends only zero to zero, so different inputs always produce different outputs.

:::theorem[Rank-nullity theorem for transformations]{#rank-nullity}
For a linear map $T:\mathbb{R}^n\to\mathbb{R}^m$,

$$\dim(\ker(T))+\dim(\text{Im}(T))=n.$$
:::

The statement is independent of any choice of basis or matrix representation.

:::intuition
The kernel is the transformation's blind spot — inputs it can't distinguish from zero. The image is its range — all possible outputs. An injective map has a trivial kernel (no blind spots). A surjective map has an image that fills the entire output space.
:::

:::example[Kernel, image, and rank-nullity of a rank-1 map]
Let $T:\mathbb{R}^2\to\mathbb{R}^2$ have matrix $A=\begin{pmatrix}1&2\\2&4\end{pmatrix}$. Notice the second row is twice the first, so the rows are dependent — expect a nontrivial kernel.
:::

:::solution
1. Kernel: solve $A\mathbf{x}=\mathbf{0}$. Both rows give the same equation $x_1+2x_2=0$, i.e. $x_1=-2x_2$. With $x_2$ free, $\ker(T)=\text{span}\{\langle -2,1\rangle\}$, so $\dim(\ker(T))=1$.
2. Image: the columns are $\langle 1,2\rangle$ and $\langle 2,4\rangle=2\langle 1,2\rangle$, so they span a single line. $\text{Im}(T)=\text{span}\{\langle 1,2\rangle\}$, so $\dim(\text{Im}(T))=1$.
3. Check rank-nullity: $\dim(\ker(T))+\dim(\text{Im}(T))=1+1=2=n$ ✓.
4. Since $\ker(T)\neq\{\mathbf{0}\}$, $T$ is not injective; since $\text{Im}(T)\neq\mathbb{R}^2$, $T$ is not surjective. Verify the kernel vector collapses: $A\langle -2,1\rangle=\langle -2+2,\,-4+4\rangle=\langle 0,0\rangle$ ✓.
:::

## Eigenvalues and eigenvectors {#eigenvectors}

:::definition[Eigenvalue and eigenvector]{#eigenvector-definition}
Let $A$ be a square matrix. A *nonzero* vector $\mathbf{v}$ is an eigenvector of $A$ with eigenvalue $\lambda$ if

$$A\mathbf{v}=\lambda\mathbf{v}.$$
:::

The matrix merely scales $\mathbf{v}$ — it does not change its direction (or it reverses it when $\lambda<0$).

:::proposition[Characteristic equation]{#characteristic-equation}
A scalar $\lambda$ is an eigenvalue of the $n\times n$ matrix $A$ if and only if

$$\det(A-\lambda I)=0.$$
:::

:::proof
Rewrite $A\mathbf{v}=\lambda\mathbf{v}$ as $(A-\lambda I)\mathbf{v}=\mathbf{0}$. An eigenvector is by definition a *nonzero* solution of this homogeneous system, and such a solution exists exactly when $A-\lambda I$ is singular — that is, when $\det(A-\lambda I)=0$.
:::

The characteristic polynomial of an $n\times n$ matrix has degree $n$ and exactly $n$ roots in $\mathbb{C}$ (counting multiplicity). Real matrices may have complex eigenvalues in conjugate pairs.

:::definition[Eigenspace and multiplicities]{#eigenspace}
For each eigenvalue $\lambda_k$ of $A$, the eigenspace is

$$E_{\lambda_k}=\text{Null}(A-\lambda_k I),$$

whose nonzero vectors are exactly the eigenvectors for $\lambda_k$. Its dimension $\dim(E_{\lambda_k})$ is the geometric multiplicity of $\lambda_k$; the number of times $\lambda_k$ repeats as a root of the characteristic polynomial is its algebraic multiplicity.
:::

The eigenspace always has dimension at least $1$, since an eigenvalue by definition has at least one eigenvector, and always $1\le\text{geometric}\le\text{algebraic}$.

Trace and determinant shortcuts: $\sum_i \lambda_i = \text{tr}(A)$ and $\prod_i \lambda_i = \det(A)$, where the sum and product run over all $n$ eigenvalues counted with algebraic multiplicity. For a $2\times 2$ matrix, these two conditions fully determine the eigenvalues once you find the characteristic polynomial. One immediate consequence: $A$ is invertible iff $0$ is *not* an eigenvalue, since $\det(A)=0$ exactly when some $\lambda_i=0$.

Once you know that $\mathbf{v}$ is an eigenvector of $A$ with eigenvalue $\lambda$, the *same* $\mathbf{v}$ is an eigenvector of many related matrices, with a predictably transformed eigenvalue:

- $A^k\mathbf{v}=\lambda^k\mathbf{v}$ — powers scale the eigenvalue to the same power (apply $A$ repeatedly).
- $A^{-1}\mathbf{v}=\tfrac{1}{\lambda}\mathbf{v}$ when $A$ is invertible (so $\lambda\neq 0$) — invert the eigenvalue.
- $(cA)\mathbf{v}=c\lambda\mathbf{v}$ for any scalar $c$ — scaling the matrix scales the eigenvalue.
- $(A+cI)\mathbf{v}=(\lambda+c)\mathbf{v}$ — a shift $cI$ shifts every eigenvalue by $c$, keeping the eigenvectors.

Because eigenvectors are preserved by these operations, the eigenvalue rules follow by plugging into $A\mathbf{v}=\lambda\mathbf{v}$.

:::theorem[Cayley-Hamilton theorem]{#cayley-hamilton}
Every square matrix satisfies its own characteristic equation: if $p(\lambda)=\det(A-\lambda I)$, then

$$p(A)=0,$$

the zero matrix.
:::

:::intuition
Imagine pushing on a rubber sheet with a matrix. Most arrows move and spin. Eigenvectors are special arrows that only stretch or shrink — they never change direction. The eigenvalue is the stretch factor. If $\lambda=3$, the arrow triples in length. If $\lambda=-1$, it flips around.
:::

:::example[Eigenvalues and eigenvectors of a 2×2 matrix]
Find eigenvalues and eigenvectors of $A=\begin{pmatrix}3&1\\0&2\end{pmatrix}$.
:::

:::solution
1. Characteristic equation: $\det(A-\lambda I)=(3-\lambda)(2-\lambda)=0$. Eigenvalues: $\lambda_1=3$, $\lambda_2=2$.
2. For $\lambda_1=3$: $(A-3I)\mathbf{v}=\mathbf{0}\Rightarrow\begin{pmatrix}0&1\\0&-1\end{pmatrix}\mathbf{v}=\mathbf{0}$. Solution: $\mathbf{v}_1=\langle 1,0\rangle$.
3. For $\lambda_2=2$: $(A-2I)\mathbf{v}=\mathbf{0}\Rightarrow\begin{pmatrix}1&1\\0&0\end{pmatrix}\mathbf{v}=\mathbf{0}$. Solution: $\mathbf{v}_2=\langle 1,-1\rangle$.
4. Check: $\text{tr}(A)=5=3+2$ ✓. $\det(A)=6=3\times 2$ ✓.
:::

:::example[Eigenvalue rules and Cayley–Hamilton]
Take $A=\begin{pmatrix}3&1\\2&4\end{pmatrix}$. Its eigenvalues satisfy $\lambda^2-\text{tr}(A)\lambda+\det(A)=0$, i.e. $\lambda^2-7\lambda+10=0$, so $(\lambda-2)(\lambda-5)=0$ and $\lambda=2,5$.
:::

:::solution
1. Eigenvalues of $A^2$: square each, giving $4$ and $25$. Sanity check via trace: $\text{tr}(A^2)$ should equal $4+25=29$. Compute $A^2=\begin{pmatrix}11&7\\14&18\end{pmatrix}$, and $11+18=29$ ✓.
2. Eigenvalues of $A^{-1}$: invert each, giving $\tfrac12$ and $\tfrac15$. Their product $\tfrac{1}{10}=\det(A^{-1})=1/\det(A)=1/10$ ✓.
3. Eigenvalues of $A+3I$: shift each by $3$, giving $5$ and $8$.
4. Cayley–Hamilton says $A^2-7A+10I=0$. Verify the $(1,1)$ entry: $A^2_{11}-7A_{11}+10=11-21+10=0$ ✓, and indeed the whole matrix $\begin{pmatrix}11&7\\14&18\end{pmatrix}-\begin{pmatrix}21&7\\14&28\end{pmatrix}+\begin{pmatrix}10&0\\0&10\end{pmatrix}=\begin{pmatrix}0&0\\0&0\end{pmatrix}$ ✓.
:::

## Diagonalization {#diagonalization}

:::definition[Diagonalizable matrix]{#diagonalizable}
An $n\times n$ matrix $A$ is diagonalizable if

$$A=PDP^{-1},$$

where the columns of $P$ are $n$ linearly independent eigenvectors of $A$ and $D=\text{diag}(\lambda_1,\ldots,\lambda_n)$ holds the corresponding eigenvalues.
:::

:::theorem[Diagonalizability criterion]{#diagonalization-criterion}
An $n\times n$ matrix $A$ is diagonalizable if and only if it has $n$ linearly independent eigenvectors — equivalently, if and only if for *every* eigenvalue the geometric multiplicity equals the algebraic multiplicity.
:::

Having $n$ distinct eigenvalues is a sufficient (but not necessary) condition, because eigenvectors from distinct eigenvalues are automatically linearly independent. Repeated eigenvalues may or may not permit diagonalization: an eigenvalue with algebraic multiplicity $m$ contributes $m$ independent eigenvectors exactly when its geometric multiplicity equals $m$. When some eigenvalue has geometric $<$ algebraic multiplicity, the matrix is **defective** and cannot be diagonalized.

:::theorem[Real Spectral Theorem]{#spectral-theorem}
Every real symmetric matrix ($A=A^T$) is diagonalizable, with real eigenvalues and an orthonormal set of eigenvectors. Hence it admits the spectral decomposition

$$A=Q\Lambda Q^{T},$$

with $Q$ orthogonal ($Q^{-1}=Q^{T}$) and $\Lambda$ diagonal.
:::

:::proposition[Powers of a diagonalizable matrix]{#diagonal-powers}
If $A=PDP^{-1}$, then for every positive integer $k$,

$$A^k = PD^kP^{-1}, \qquad D^k=\text{diag}(\lambda_1^k,\ldots,\lambda_n^k).$$
:::

Since $D^k$ is trivial to write down, this turns computing $A^{100}$ into three matrix multiplications.

Geometric interpretation: $D=P^{-1}AP$ means that in the coordinate system of eigenvectors, the transformation $A$ acts as pure diagonal scaling. Diagonalisation finds the 'natural' coordinate system for $A$.

Non-diagonalisable matrices (defective matrices) require Jordan normal form — beyond this course but worth knowing exists.

:::intuition
Diagonalisation asks: is there a tilted coordinate system in which your transformation just stretches each axis independently? If you tilt your axes to align with the eigenvectors, the transformation becomes trivial. The tilt is $P$; the independent scalings are $D$.
:::

:::example[Diagonalize a matrix and use it to compute a power]
Diagonalize $A=\begin{pmatrix}3&1\\0&2\end{pmatrix}$, then compute $A^3$. From the earlier example, its eigenpairs are $\lambda_1=3$ with $\mathbf{v}_1=\langle 1,0\rangle$ and $\lambda_2=2$ with $\mathbf{v}_2=\langle 1,-1\rangle$.
:::

:::solution
1. The two eigenvectors are linearly independent (distinct eigenvalues), so $A$ is diagonalizable. Assemble $P=\begin{pmatrix}1&1\\0&-1\end{pmatrix}$ (eigenvectors as columns) and $D=\begin{pmatrix}3&0\\0&2\end{pmatrix}$ (eigenvalues in matching order).
2. Invert $P$: for a $2\times 2$ matrix $\det(P)=(1)(-1)-(1)(0)=-1$, so $P^{-1}=\frac{1}{-1}\begin{pmatrix}-1&-1\\0&1\end{pmatrix}=\begin{pmatrix}1&1\\0&-1\end{pmatrix}$. (Here $P^{-1}=P$, a coincidence of this matrix.)
3. Sanity check $A=PDP^{-1}$: $PD=\begin{pmatrix}3&2\\0&-2\end{pmatrix}$, then $PDP^{-1}=\begin{pmatrix}3&2\\0&-2\end{pmatrix}\begin{pmatrix}1&1\\0&-1\end{pmatrix}=\begin{pmatrix}3&1\\0&2\end{pmatrix}=A$ ✓.
4. Now the payoff: $A^3=PD^3P^{-1}$ with $D^3=\begin{pmatrix}27&0\\0&8\end{pmatrix}$. So $A^3=\begin{pmatrix}1&1\\0&-1\end{pmatrix}\begin{pmatrix}27&0\\0&8\end{pmatrix}\begin{pmatrix}1&1\\0&-1\end{pmatrix}=\begin{pmatrix}27&8\\0&-8\end{pmatrix}\begin{pmatrix}1&1\\0&-1\end{pmatrix}=\begin{pmatrix}27&19\\0&8\end{pmatrix}$.
5. Check against direct multiplication: $A^2=\begin{pmatrix}9&5\\0&4\end{pmatrix}$, and $A^3=A^2A=\begin{pmatrix}27&19\\0&8\end{pmatrix}$ ✓. The diagonal entries $27=3^3$ and $8=2^3$ are exactly $\lambda_i^3$, as expected.
:::

## Geometric transformations and their eigenvalues {#geometric}

:::proposition[Eigenvalues of a rotation]{#rotation-eigenvalues}
The counterclockwise rotation by $\theta$ has matrix

$$R_\theta=\begin{pmatrix}\cos\theta&-\sin\theta\\\sin\theta&\cos\theta\end{pmatrix}, \qquad \det(R_\theta)=1,$$

and eigenvalues $e^{\pm i\theta}$, which are non-real for $\theta\neq 0,\pi$.
:::

Area is preserved and orientation maintained, and for $\theta\neq 0,\pi$ there are no real eigenvectors — consistent with the fact that a rotation spins every direction.

Reflection across the $x$-axis: $\begin{pmatrix}1&0\\0&-1\end{pmatrix}$. Eigenvalues $\lambda_1=1$ (vectors on $x$-axis are fixed) and $\lambda_2=-1$ (vectors on $y$-axis are flipped). $\det=-1$: orientation reversed.

Projection onto a line: eigenvalues $1$ (vectors on the line are fixed by projection) and $0$ (vectors orthogonal to the line collapse to zero). Idempotent: $P^2=P$.

Shear $\begin{pmatrix}1&k\\0&1\end{pmatrix}$: repeated eigenvalue $\lambda=1$ with only one independent eigenvector. Not diagonalisable — it is a canonical example of a defective matrix.

:::intuition
Each transformation type has its own eigenvalue signature. Rotations have complex eigenvalues (no real fixed directions). Reflections have eigenvalues $\pm 1$ (one axis is fixed, the other flips). Projections have eigenvalues $0$ and $1$ (one subspace is kept, the complementary subspace is erased).
:::

:::example[Eigenvalues of a projection onto the $x$-axis]
Let $P=\begin{pmatrix}1&0\\0&0\end{pmatrix}$, the projection sending $\langle x,y\rangle\mapsto\langle x,0\rangle$.
:::

:::solution
1. Characteristic equation: $\det(P-\lambda I)=\det\begin{pmatrix}1-\lambda&0\\0&-\lambda\end{pmatrix}=(1-\lambda)(-\lambda)=0$, so $\lambda=1$ and $\lambda=0$.
2. For $\lambda=1$: $(P-I)\mathbf{v}=\begin{pmatrix}0&0\\0&-1\end{pmatrix}\mathbf{v}=\mathbf{0}$ forces $v_2=0$, so $\mathbf{v}=\langle 1,0\rangle$ — the $x$-axis is fixed, matching $P\langle 1,0\rangle=\langle 1,0\rangle$ ✓.
3. For $\lambda=0$: $(P-0I)\mathbf{v}=P\mathbf{v}=\mathbf{0}$ forces $v_1=0$, so $\mathbf{v}=\langle 0,1\rangle$ — the $y$-axis collapses, matching $P\langle 0,1\rangle=\langle 0,0\rangle$ ✓.
4. Idempotency check: $P^2=\begin{pmatrix}1&0\\0&0\end{pmatrix}\begin{pmatrix}1&0\\0&0\end{pmatrix}=\begin{pmatrix}1&0\\0&0\end{pmatrix}=P$, consistent with eigenvalues satisfying $\lambda^2=\lambda$ (only $0$ and $1$ do) ✓.
:::

## Common Mistakes

- Including the zero vector as an eigenvector. Eigenvectors must be nonzero by definition.
- Writing $\det(A-\lambda)=0$ instead of $\det(A-\lambda I)=0$. You cannot subtract a scalar from a matrix.
- Assuming every matrix is diagonalisable. A matrix with $n$ distinct eigenvalues is, but repeated eigenvalues can prevent it.
- Confusing eigenvalues (scalars $\lambda$) and eigenvectors (nonzero vectors $\mathbf{v}$). They are distinct objects that go together.
- Confusing geometric multiplicity ($\dim\text{Null}(A-\lambda I)$) with algebraic multiplicity (root multiplicity in the characteristic polynomial). Diagonalizability needs them equal for every eigenvalue; a shear like $\begin{pmatrix}1&1\\0&1\end{pmatrix}$ has algebraic multiplicity $2$ but geometric multiplicity $1$, so it is defective.
- Writing $A^{-1}$ has eigenvalue $-\lambda$; the correct rule is $1/\lambda$ (and it requires $\lambda\neq 0$, i.e. $A$ invertible).
- Forgetting to check the trace/determinant as a sanity check after computing eigenvalues.
