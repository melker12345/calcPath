# Linear Transformations

Linear transformations are the central objects of linear algebra. While vectors and matrices are the raw materials, it is the *functions* that map one vector space into another while preserving addition and scaling that give the subject its power and elegance.

Every linear transformation between finite-dimensional spaces can be represented by a matrix once bases are chosen. This representation lets us compute with abstract maps using the familiar tools of matrix algebra. The same map can look very different depending on the bases we pick.

The kernel and image of a transformation capture its most important structural information: what gets sent to zero, and what can be reached. The rank-nullity theorem relates these two subspaces in a fundamental way that appears throughout mathematics and data science.


## What is a linear transformation? {#definition}

A function $T: V \to W$ between vector spaces is a linear transformation if it preserves the two vector space operations: $T(\mathbf{u} + \mathbf{v}) = T(\mathbf{u}) + T(\mathbf{v})$ and $T(c\mathbf{v}) = c T(\mathbf{v})$ for all vectors and scalars.

These two properties together imply that linear transformations preserve all linear combinations: $T(c_1\mathbf{v}_1 + \cdots + c_k\mathbf{v}_k) = c_1 T(\mathbf{v}_1) + \cdots + c_k T(\mathbf{v}_k)$. This is the defining feature — linear maps send lines through the origin to lines through the origin (or to the zero vector).

The zero vector must always be sent to the zero vector: $T(\mathbf{0}) = \mathbf{0}$. Any map that fails this test cannot be linear.

Common examples: rotation, reflection, projection, differentiation (on polynomials), integration, and matrix multiplication $T(\mathbf{x}) = A\mathbf{x}$. Non-examples: translation, $T(x) = x^2$, or any map that moves the origin.

**ELI5**

- A linear transformation is like a perfectly fair machine: if you feed it a mixture of inputs, it gives you the same mixture of outputs. It never distorts the 'straight-line' relationships between vectors. Scaling an input by 3 always scales the output by 3, and adding two inputs always adds their outputs.

**Worked Example:**

**Checking linearity**

1. Is $T(x, y) = (x + y, x - y)$ a linear transformation from $\mathbb{R}^2$ to $\mathbb{R}^2$?
2. Check addition: $T((x_1,y_1) + (x_2,y_2)) = T(x_1+x_2, y_1+y_2) = (x_1+x_2+y_1+y_2, x_1+x_2 - (y_1+y_2))$.
3. And $T(x_1,y_1) + T(x_2,y_2) = (x_1+y_1, x_1-y_1) + (x_2+y_2, x_2-y_2) = (x_1+x_2+y_1+y_2, x_1+x_2-y_1-y_2)$. Same result, so addition is preserved.
4. Check scaling: $T(c(x,y)) = T(cx, cy) = (cx+cy, cx-cy) = c(x+y, x-y) = c\,T(x,y)$. Scaling is preserved too.
5. Both properties hold, so $T$ is linear. (Its matrix $\begin{pmatrix} 1 & 1 \\ 1 & -1 \end{pmatrix}$ has determinant $-2 < 0$, so geometrically $T$ is a reflection scaled by a factor of $\sqrt{2}$, not a pure rotation.)


## Kernel and image {#kernel-image}

The kernel (or null space) of $T: V \to W$ is $\ker(T) = \{\mathbf{v} \in V : T(\mathbf{v}) = \mathbf{0}\ \}$. It is always a subspace of $V$.

The image (or range) of $T$ is $\text{im}(T) = \{T(\mathbf{v}) : \mathbf{v} \in V\ \}$. It is always a subspace of $W$.

The rank-nullity theorem (also called the dimension theorem) states that for a linear map $T: V \to W$ between finite-dimensional spaces: $\dim(V) = \dim(\ker(T)) + \dim(\text{im}(T))$.

This is one of the most important results in linear algebra. It tells us that the 'loss of information' (dimension of the kernel) plus the 'new information produced' (dimension of the image) always equals the dimension of the domain.

$T$ is injective (one-to-one) if and only if $\ker(T) = \{\mathbf{0}\}$. $T$ is surjective (onto) if and only if $\text{im}(T) = W$.

**ELI5**

- Think of a linear transformation as a machine that processes vectors. The kernel is everything that gets completely destroyed (turned into nothing). The image is everything that can possibly come out the other end. The rank-nullity theorem says that what you put in equals what gets destroyed plus what comes out.

**Worked Example:**

**Kernel and image of a projection**

1. Let $T: \mathbb{R}^3 \to \mathbb{R}^3$ be the projection onto the $xy$-plane: $T(x,y,z) = (x,y,0)$.
2. Kernel: $T(x,y,z) = \mathbf{0}$ iff $x=0$, $y=0$, and $z$ anything. So $\ker(T) = $ the $z$-axis. Dimension 1.
3. Image: everything of the form $(x,y,0)$ — the entire $xy$-plane. Dimension 2.
4. Check: $3 = 1 + 2$. Rank-nullity holds.
5. $T$ is neither injective nor surjective, as expected.

**Worked Example:**

**Kernel dimension from a matrix via rank-nullity**

1. Let $T(\mathbf{x}) = A\mathbf{x}$ with $A = \begin{pmatrix} 1 & 2 \\ 2 & 4 \end{pmatrix}$, a map $\mathbb{R}^2 \to \mathbb{R}^2$. Find $\dim(\ker T)$.
2. Row reduce: $R_2 \to R_2 - 2R_1$ turns $A$ into $\begin{pmatrix} 1 & 2 \\ 0 & 0 \end{pmatrix}$. There is one pivot, so the rank (dimension of the image) is $1$.
3. Rank-nullity: $\dim(\ker T) = \dim(\text{domain}) - \text{rank} = 2 - 1 = 1$.
4. Sanity check: solve $A\mathbf{x} = \mathbf{0}$ directly. The single equation $x + 2y = 0$ gives $x = -2y$, so the kernel is $\{\,t(-2,1) : t \in \mathbb{R}\,\}$, a line — dimension $1$. ✓

**Worked Example:**

**Rank-nullity as a pure dimension count**

1. Suppose $T: \mathbb{R}^5 \to \mathbb{R}^3$ is linear with rank $2$ (its image is a $2$-dimensional subspace of $\mathbb{R}^3$). Find $\dim(\ker T)$. No formula for $T$ is needed — only the theorem.
2. The domain is $\mathbb{R}^5$, so $\dim(\text{domain}) = 5$. Rank-nullity gives $5 = \dim(\ker T) + 2$.
3. Therefore $\dim(\ker T) = 5 - 2 = 3$.
4. Consistency check: the rank can be at most $\min(5,3) = 3$, and here rank $2 \le 3$ and nullity $3 \le 5$, so the numbers are feasible. Note $T$ cannot be injective, since a nonzero kernel means distinct inputs can share an output.


## The matrix of a linear transformation {#matrix-representation}

Once we choose bases for the domain and codomain, every linear transformation $T: V \to W$ can be represented by a matrix. If $\mathcal{B} = \{\mathbf{b}_1, \dots, \mathbf{b}_n\}$ is a basis for $V$ and $\mathcal{C}$ is a basis for $W$, the matrix $A$ of $T$ with respect to these bases has columns that are the coordinate vectors of $T(\mathbf{b}_j)$ expressed in the $\mathcal{C}$ basis.

Applying the transformation then becomes matrix multiplication in coordinates: $[T(\mathbf{v})]_{\mathcal{C}} = A [\mathbf{v}]_{\mathcal{B}}$.

Different choices of bases produce different matrices for the same transformation. This is why 'the' matrix of a linear map is not unique until bases are specified.

The standard matrix (when using the standard bases) is the most common representation. For $T(\mathbf{x}) = A\mathbf{x}$, the matrix is simply $A$ itself.

The reason "images of basis vectors become columns" works is that any input decomposes as $\mathbf{v} = v_1\mathbf{b}_1 + \cdots + v_n\mathbf{b}_n$, and by linearity $T(\mathbf{v}) = v_1 T(\mathbf{b}_1) + \cdots + v_n T(\mathbf{b}_n)$. That right-hand side is exactly the matrix–vector product of the "columns are $T(\mathbf{b}_j)$" matrix with the coordinate vector. So knowing what $T$ does to a basis pins down what it does to everything.

**ELI5**

- To describe a machine completely, you only need to know what it does to each "pure ingredient" (each basis vector). Write those outputs side by side as columns and you have captured the whole machine in one matrix. Because the machine is fair (linear), any mixed input is just handled ingredient-by-ingredient.

**Worked Example:**

**Finding the matrix of a transformation**

1. Let $T: \mathbb{R}^2 \to \mathbb{R}^2$ be $T(x,y) = (x+y, x-y)$. Find the standard matrix of $T$.
2. Apply $T$ to the standard basis vectors: $T(1,0) = (1,1)$, $T(0,1) = (1,-1)$.
3. The matrix has these images as columns: $A = \begin{pmatrix} 1 & 1 \\ 1 & -1 \end{pmatrix}$.
4. Verify: $A \begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} 1 & 1 \\ 1 & -1 \end{pmatrix}\begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} x+y \\ x-y \end{pmatrix}$ — matches the definition of $T$.

**Worked Example:**

**A geometric map: reflection across the line $y = x$**

1. Reflecting across $y = x$ swaps the two coordinates. Track the standard basis: the reflection sends $(1,0) \mapsto (0,1)$ and $(0,1) \mapsto (1,0)$.
2. Put those images in as columns: $A = \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}$.
3. Sanity check on a point off the line: $A\begin{pmatrix} 3 \\ 5 \end{pmatrix} = \begin{pmatrix} 5 \\ 3 \end{pmatrix}$ — coordinates swapped, exactly what a reflection across $y=x$ should do.
4. Since reflecting twice returns the original point, we expect $A^2 = I$. Check: $\begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}\begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix} = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}$. ✓

**Worked Example:**

**Reading eigenvalue sums and products off the matrix**

1. Once $T$ is written as a matrix $A$, its eigenvalues are intrinsic to the map. Two shortcuts avoid solving the characteristic polynomial: the **sum** of the eigenvalues equals the **trace** (sum of diagonal entries), and the **product** equals the **determinant**.
2. Take $A = \begin{pmatrix} 4 & 1 \\ 0 & 3 \end{pmatrix}$. Trace $= 4 + 3 = 7$, so the eigenvalues sum to $7$.
3. Determinant $= (4)(3) - (1)(0) = 12$, so the eigenvalues multiply to $12$.
4. Cross-check directly: $A$ is upper-triangular, so its eigenvalues are the diagonal entries $4$ and $3$. Indeed $4 + 3 = 7$ ✓ and $4 \times 3 = 12$ ✓.


## Change of basis {#change-of-basis}

If we have two different bases for the same space, we need a way to convert coordinates from one basis to the other. The change-of-basis matrix $P$ from basis $\mathcal{B}$ to the standard basis has the vectors of $\mathcal{B}$ as its columns. Because $\mathcal{B}$ is a basis, its vectors are linearly independent, so $P$ is always invertible — which is what lets us write $P^{-1}$ below.

To get coordinates in the new basis: $[\mathbf{v}]_{\mathcal{B}} = P^{-1} \mathbf{v}$ (when $P$ changes from $\mathcal{B}$ to standard).

If a linear transformation has matrix $A$ in the standard basis, its matrix in a new basis $\mathcal{B}$ is given by the similarity transformation $P^{-1} A P$. Similar matrices represent the same linear transformation in different coordinate systems.

This is why eigenvalues are intrinsic to the transformation and do not depend on the basis — they are preserved under similarity.

**ELI5**

- Changing basis is like switching from Cartesian coordinates to a different coordinate grid. The same physical arrow has different numerical descriptions depending on which grid you use. The change-of-basis matrix is the translation table between the two descriptions.

**Worked Example:**

**Finding coordinates in a new basis**

1. Let $\mathcal{B} = \{(1,1), (1,-1)\}$ be a basis for $\mathbb{R}^2$. Find the $\mathcal{B}$-coordinates of $\mathbf{v} = (3,1)$ — the scalars $c_1, c_2$ with $c_1(1,1) + c_2(1,-1) = (3,1)$.
2. Writing the two components out gives the system $c_1 + c_2 = 3$ and $c_1 - c_2 = 1$.
3. Add the equations: $2c_1 = 4$, so $c_1 = 2$. Substitute back: $2 + c_2 = 3$, so $c_2 = 1$. Thus $[\mathbf{v}]_{\mathcal{B}} = (2, 1)$.
4. Same thing via the matrix formula: $P = \begin{pmatrix} 1 & 1 \\ 1 & -1 \end{pmatrix}$ (basis vectors as columns) changes $\mathcal{B}$-coordinates to standard, so $[\mathbf{v}]_{\mathcal{B}} = P^{-1}\mathbf{v}$. Here $P^{-1} = \frac{1}{-2}\begin{pmatrix} -1 & -1 \\ -1 & 1 \end{pmatrix} = \begin{pmatrix} 1/2 & 1/2 \\ 1/2 & -1/2 \end{pmatrix}$, and $P^{-1}\begin{pmatrix} 3 \\ 1 \end{pmatrix} = \begin{pmatrix} 2 \\ 1 \end{pmatrix}$. ✓
5. Sanity check: $2(1,1) + 1(1,-1) = (2+1, 2-1) = (3,1)$ — recovers $\mathbf{v}$. ✓


## Composition and invertibility {#composition}

The composition of two linear transformations is again linear. If $T: V \to W$ and $S: W \to U$, then the matrix of $S \circ T$ is the product of the individual matrices (in the appropriate order and bases).

A linear transformation $T: V \to V$ is invertible if and only if it is both injective and surjective (by the rank-nullity theorem, these are equivalent in finite dimensions). Equivalently, $\ker(T) = \{\mathbf{0}\}$ or $\text{im}(T) = V$.

The inverse of an invertible linear transformation is also linear. The matrix of the inverse is the matrix inverse of the matrix of the original map.

Invertible linear transformations are precisely the isomorphisms between vector spaces — they preserve all linear-algebraic structure.

One consequence worth internalizing: composition and inversion both **reverse order**. The matrix of $S \circ T$ is $M_S M_T$ (do $T$ first, so its matrix sits on the right, nearest the input vector). And undoing $S \circ T$ means undoing $S$ last-in-first-out: $(S \circ T)^{-1} = T^{-1} \circ S^{-1}$ — put your socks on then your shoes, take your shoes off then your socks.

**ELI5**

- Composing transformations is an assembly line: the vector passes through the first machine, then its output feeds the second. In matrix form you write the machines right-to-left in the order the vector meets them. Inverting the whole line means running it backwards, so you reverse the machines' order too.

**Worked Example:**

**Matrix of a composition: rotate, then scale**

1. Let $T$ be a $90°$ counterclockwise rotation and $S$ be scaling by $2$, both on $\mathbb{R}^2$. Find the matrix of $S \circ T$ (apply $T$ first, then $S$).
2. Rotation matrix: $T$ sends $(1,0) \mapsto (0,1)$ and $(0,1) \mapsto (-1,0)$, so $M_T = \begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix}$.
3. Scaling matrix: $S$ doubles both coordinates, so $M_S = 2I = \begin{pmatrix} 2 & 0 \\ 0 & 2 \end{pmatrix}$.
4. Since $T$ runs first, its matrix goes on the right: $M_{S \circ T} = M_S M_T = \begin{pmatrix} 2 & 0 \\ 0 & 2 \end{pmatrix}\begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix} = \begin{pmatrix} 0 & -2 \\ 2 & 0 \end{pmatrix}$.
5. Sanity check on $(1,0)$: rotating gives $(0,1)$, then scaling gives $(0,2)$. Directly, $\begin{pmatrix} 0 & -2 \\ 2 & 0 \end{pmatrix}\begin{pmatrix} 1 \\ 0 \end{pmatrix} = \begin{pmatrix} 0 \\ 2 \end{pmatrix}$ ✓. (Here $S$ is a scalar multiple of the identity, so $M_S M_T = M_T M_S$; in general the order matters.)

## Common Mistakes

- Claiming a map is linear just because it 'looks linear' — always verify the two defining properties.
- Forgetting that the kernel is always a subspace of the domain and the image is always a subspace of the codomain.
- Believing that rank-nullity only applies to square matrices — it applies to any linear map between finite-dimensional spaces.
- Treating the matrix representation as the transformation itself rather than a coordinate-dependent description.
- Forgetting that $T(\mathbf{0}) = \mathbf{0}$ must hold for any linear map.
- Confusing the kernel with the set of vectors that map to a particular nonzero vector.
- Assuming every linear transformation has an inverse (most do not).
- Mixing up the order when composing transformations with matrices.
- Thinking that the matrix of a transformation is unique without specifying bases.
