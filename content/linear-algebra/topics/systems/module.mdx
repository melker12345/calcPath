# Systems of Linear Equations

A system of linear equations is a set of constraints that must hold simultaneously. The question is always: do values of the unknowns exist that satisfy every equation at once, and if so, how many?

Gaussian elimination — systematically row-reducing the augmented matrix — gives a complete algorithmic answer to this question for any system, regardless of size. It is one of the most important algorithms in all of computational mathematics.

The theory connects directly to rank, the null space, and the fundamental theorem of linear maps. Every statement about when a system has zero, one, or infinitely many solutions follows from these ideas.

## Setting up augmented matrices {#gauss}

A linear system $a_{11}x_1 + \cdots + a_{1n}x_n = b_1, \ldots, a_{m1}x_1 + \cdots + a_{mn}x_n = b_m$ is written as the matrix equation $A\mathbf{x} = \mathbf{b}$, where $A$ is the $m\times n$ coefficient matrix, $\mathbf{x}$ is the unknown vector, and $\mathbf{b}$ is the right-hand side.

:::definition[Augmented matrix]{#augmented-matrix}
The augmented matrix of the system $A\mathbf{x} = \mathbf{b}$ is the array

$$[A\;|\;\mathbf{b}],$$

whose rows are the equations and whose vertical bar separates coefficients from constants.
:::

:::definition[Elementary row operations]{#row-operations}
Three operations may be applied to the rows of an augmented matrix:

1. (R1) swap two rows;
2. (R2) multiply a row by a nonzero scalar;
3. (R3) add a scalar multiple of one row to another.
:::

:::proposition[Row operations preserve the solution set]{#row-ops-preserve}
Elementary row operations turn a system into an equivalent one — a system with an identical solution set.
:::

Each operation corresponds exactly to a legal algebraic manipulation of the equations, which is why nothing is lost. You are not changing the solutions; you are changing the representation until the solution is obvious.

:::intuition
Each equation is a constraint on a map: 'I'm somewhere on this line' and 'I'm somewhere on that line.' The solution is where the lines cross.

Gaussian elimination redraws the map so the crossing point is obvious. Instead of two diagonal lines, you draw one horizontal and one vertical line. The answer is immediately readable.
:::

:::example[Writing a system as an augmented matrix and checking a row operation preserves solutions]
Take the system $x + 2y = 3,\; 2x + 5y = 8$. Line up the unknowns in the same order in every equation, then read off the coefficients.
:::

:::solution
1. Coefficient matrix $A=\begin{pmatrix}1&2\\2&5\end{pmatrix}$, right-hand side $\mathbf{b}=\begin{pmatrix}3\\8\end{pmatrix}$, so the augmented matrix is $\left(\begin{array}{cc|c}1&2&3\\2&5&8\end{array}\right)$.
2. Apply (R3), $R_2\leftarrow R_2-2R_1$: the new second row is $(2-2\cdot1,\;5-2\cdot2\;|\;8-2\cdot3)=(0,1\,|\,2)$, giving $\left(\begin{array}{cc|c}1&2&3\\0&1&2\end{array}\right)$.
3. The new second row says $y=2$; the first row then gives $x=3-2y=3-4=-1$.
4. Sanity check against the *original* equations: $x+2y=-1+4=3$ ✓ and $2x+5y=-2+10=8$ ✓. The row operation left the solution untouched — it only made it easier to read.
:::

## Gaussian elimination {#elimination}

:::definition[Row echelon form]{#row-echelon-form}
An augmented matrix is in row echelon form (REF) when it shows a staircase pattern: each row's leading nonzero entry (its pivot) lies to the right of the pivot in the row above, and every entry below a pivot is zero.
:::

:::recipe[Gaussian elimination]{#gaussian-elimination}
1. Work column by column from left to right.
2. Use row operations to create zeros below the current pivot.
3. Skip a column with no eligible pivot — that column becomes a free variable.
4. Once the matrix is in row echelon form, back-substitute: starting from the last nonzero row, solve for its pivot variable, then substitute upward through the other equations.
:::

:::definition[Reduced row echelon form]{#rref}
Reduced row echelon form (RREF) goes further than REF: each pivot is scaled to $1$, and zeros are created both above and below each pivot.
:::

From RREF the solution can be read directly, without back substitution.

A useful check: the number of pivots in RREF equals the rank of $A$. The number of non-pivot columns equals the number of free variables.

:::intuition
Gaussian elimination is like solving a crossword one row at a time. You use each equation to eliminate one unknown, until you have one equation with one unknown. Solve it, substitute back, solve the next, and so on.
:::

:::example[Solving a 3×3 system]
System: $x+y+z=6,\; 2x-y+z=3,\; x+2y-z=4$.
:::

:::solution
1. Augmented matrix: $\left(\begin{array}{ccc|c}1&1&1&6\\2&-1&1&3\\1&2&-1&4\end{array}\right)$.
2. Clear the first column below the pivot. $R_2\leftarrow R_2-2R_1$ gives $(0,-3,-1\,|\,-9)$; $R_3\leftarrow R_3-R_1$ gives $(0,1,-2\,|\,-2)$: $\left(\begin{array}{ccc|c}1&1&1&6\\0&-3&-1&-9\\0&1&-2&-2\end{array}\right)$.
3. Clear the second column below its pivot. $R_3\leftarrow R_3+\tfrac{1}{3}R_2$ turns the $1$ in position $(3,2)$ into $1+\tfrac{1}{3}(-3)=0$, and the rest into $\left(0,0,-2+\tfrac{1}{3}(-1)\,\middle|\,-2+\tfrac{1}{3}(-9)\right)=(0,0,-\tfrac{7}{3}\,|\,-5)$: $\left(\begin{array}{ccc|c}1&1&1&6\\0&-3&-1&-9\\0&0&-\tfrac{7}{3}&-5\end{array}\right)$. This is row echelon form — a clean staircase.
4. Back-substitute from the bottom. Row 3: $-\tfrac{7}{3}z=-5\Rightarrow z=\tfrac{15}{7}$. Row 2: $-3y-z=-9\Rightarrow y=\tfrac{9-z}{3}=\tfrac{9-15/7}{3}=\tfrac{16}{7}$. Row 1: $x=6-y-z=6-\tfrac{16}{7}-\tfrac{15}{7}=\tfrac{11}{7}$.
5. Sanity check in the original system: $x+y+z=\tfrac{11+16+15}{7}=\tfrac{42}{7}=6$ ✓, $2x-y+z=\tfrac{22-16+15}{7}=\tfrac{21}{7}=3$ ✓, $x+2y-z=\tfrac{11+32-15}{7}=\tfrac{28}{7}=4$ ✓.
:::

## Solution types {#consistency}

:::theorem[Trichotomy for linear systems]{#solution-trichotomy}
A system $A\mathbf{x} = \mathbf{b}$ over $\mathbb{R}$ has exactly one of three outcomes: no solution (the system is inconsistent), exactly one solution, or infinitely many solutions.
:::

There is no 'two solutions' in linear algebra.

Inconsistency is flagged by a row $[0\;0\;\cdots\;0\;|\;b]$ with $b\neq 0$ — the equation $0=b$ is impossible.

A unique solution exists when the system is consistent *and* every variable is a pivot variable — i.e. the coefficient matrix has full column rank ($\text{rank}(A)=n$). For a square consistent system this means RREF produces $[I\;|\;\mathbf{x}^*]$, reading off the answer directly. (Full column rank alone rules out extra solutions; consistency is what guarantees at least one exists.)

Infinitely many solutions arise when there are free variables — columns with no pivot. Each free variable can take any real value. You parameterise the solution set: express pivot variables in terms of free variables.

:::theorem[Structure of the general solution]{#general-solution}
If $A\mathbf{x}=\mathbf{b}$ is consistent, its complete solution set is

$$\mathbf{x} = \mathbf{x}_p + \mathbf{x}_h,$$

where $\mathbf{x}_p$ is any one particular solution and $\mathbf{x}_h$ ranges over the solutions of the homogeneous system $A\mathbf{x}=\mathbf{0}$.
:::

:::intuition
Two lines either cross at one point (unique solution), are parallel and never meet (no solution), or are the same line (infinitely many solutions). In higher dimensions, replace 'lines' with 'hyperplanes' — the three possibilities are the same.
:::

:::example[Parameterizing an infinite solution set as $\mathbf{x}_p + \mathbf{x}_h$]
System: $x+2y+z=4,\; 2x+5y+3z=9,\; x+3y+2z=5$. Augmented matrix $\left(\begin{array}{ccc|c}1&2&1&4\\2&5&3&9\\1&3&2&5\end{array}\right)$.
:::

:::solution
1. $R_2\leftarrow R_2-2R_1$ gives $(0,1,1\,|\,1)$; $R_3\leftarrow R_3-R_1$ gives $(0,1,1\,|\,1)$: $\left(\begin{array}{ccc|c}1&2&1&4\\0&1&1&1\\0&1&1&1\end{array}\right)$.
2. $R_3\leftarrow R_3-R_2$ gives $(0,0,0\,|\,0)$: $\left(\begin{array}{ccc|c}1&2&1&4\\0&1&1&1\\0&0&0&0\end{array}\right)$. The zero row is $0=0$, so the system is consistent; there are two pivots (columns $1,2$) and three variables, so $z$ is a free variable.
3. Let $z=t$ (any real number). Row 2: $y+z=1\Rightarrow y=1-t$. Row 1: $x=4-2y-z=4-2(1-t)-t=2+t$.
4. Split the general solution into a particular part plus a homogeneous part: $\begin{pmatrix}x\\y\\z\end{pmatrix}=\begin{pmatrix}2\\1\\0\end{pmatrix}+t\begin{pmatrix}1\\-1\\1\end{pmatrix}$. Setting $t=0$ gives the particular solution $\mathbf{x}_p=(2,1,0)$; the vector $(1,-1,1)$ spans the null space, so $\mathbf{x}_h=t(1,-1,1)$.
5. Sanity check with $t=1$, i.e. $(x,y,z)=(3,0,1)$: $x+2y+z=3+0+1=4$ ✓, $2x+5y+3z=6+0+3=9$ ✓, $x+3y+2z=3+0+2=5$ ✓.
:::

## Rank and the rank-nullity theorem {#rank}

:::definition[Rank and nullity]{#rank-definition}
The rank of a matrix $A$ is the number of pivot columns in its row echelon form — equivalently, the dimension of the column space $\text{Col}(A)$. Its nullity is the number of non-pivot (free) columns — equivalently, the dimension of the null space $\text{Null}(A)$, the solutions of $A\mathbf{x}=\mathbf{0}$ (defined in the next section).
:::

:::proposition[Consistency and uniqueness in terms of rank]{#rank-consistency}
The system $A\mathbf{x}=\mathbf{b}$ is consistent if and only if

$$\text{rank}([A\;|\;\mathbf{b}]) = \text{rank}(A),$$

and its solution is unique if and only if $\text{rank}(A)=n$.
:::

Adding $\mathbf{b}$ as a column must not create a new pivot — $\mathbf{b}$ must already lie in $\text{Col}(A)$. Full column rank, $\text{rank}(A)=n$, is the statement that there are no free variables.

:::theorem[Rank-nullity theorem]{#rank-nullity}
For any $m\times n$ matrix $A$,

$$\text{rank}(A) + \text{nullity}(A) = n,$$

where $n$ is the number of columns.
:::

:::proof
Row-reduce $A$. Pivot columns contribute to the rank; free columns contribute to the nullity. Every column is one or the other, so together they account for all $n$ columns.
:::

For an $m\times n$ matrix: $\text{rank}(A) \leq \min(m,n)$. Each pivot needs its own row and its own column, so the number of pivots cannot exceed either dimension — you cannot have more independent directions than the smaller dimension.

:::intuition
Rank counts how many truly independent equations you have. Ten equations might contain only $3$ independent constraints if the rest are just combinations of those $3$. Rank-nullity says: independent constraints plus free variables always adds up to the total number of unknowns.
:::

:::example[Reading off rank and nullity, then checking rank-nullity]
Let $A=\begin{pmatrix}1&2&1&1\\2&4&3&4\\1&2&2&3\end{pmatrix}$, a $3\times4$ matrix, so $n=4$ columns.
:::

:::solution
1. Row-reduce. $R_2\leftarrow R_2-2R_1$ gives $(0,0,1,2)$; $R_3\leftarrow R_3-R_1$ gives $(0,0,1,2)$: $\begin{pmatrix}1&2&1&1\\0&0&1&2\\0&0&1&2\end{pmatrix}$.
2. $R_3\leftarrow R_3-R_2$ gives $(0,0,0,0)$: $\begin{pmatrix}1&2&1&1\\0&0&1&2\\0&0&0&0\end{pmatrix}$. This is row echelon form.
3. Count pivots: there is a leading entry in column $1$ and in column $3$, so there are $2$ pivots. Hence $\text{rank}(A)=2$. Note column $2$ has no pivot even though the matrix has nonzero entries there — rank counts pivot *columns*, not nonzero entries.
4. Apply rank-nullity: $\text{nullity}(A)=n-\text{rank}(A)=4-2=2$. The two non-pivot columns ($2$ and $4$) correspond to the two free variables, confirming the count.
5. Sanity check the bound: $\text{rank}(A)=2\le\min(m,n)=\min(3,4)=3$ ✓.
:::

## Homogeneous systems {#homogeneous}

:::definition[Homogeneous system and null space]{#null-space}
A system is homogeneous when the right-hand side is all zeros:

$$A\mathbf{x}=\mathbf{0}.$$

Its solution set is the null space $\text{Null}(A)$, always a subspace of $\mathbb{R}^n$, whose dimension is the nullity of $A$.
:::

This is the "background" version of $A\mathbf{x}=\mathbf{b}$ with the constants stripped away — and it controls how many solutions the full system can have. A homogeneous system is always consistent, because the trivial solution $\mathbf{x}=\mathbf{0}$ always works: $A\mathbf{0}=\mathbf{0}$.

:::proposition[When nontrivial solutions exist]{#nontrivial-solutions}
The homogeneous system $A\mathbf{x}=\mathbf{0}$ with $n$ unknowns has a nontrivial solution if and only if $\text{rank}(A) < n$.
:::

There are then more unknowns than pivots, so at least one free variable exists, and the nullity equals the number of free variables.

:::theorem[Invertible Matrix Theorem]{#invertible-matrix-theorem}
For a square $n \times n$ matrix $A$, the following are equivalent:

1. $A$ is invertible;
2. $A\mathbf{x}=\mathbf{0}$ has only the trivial solution;
3. $\text{nullity}(A)=0$;
4. $\det(A)\neq 0$.
:::

:::intuition
A homogeneous system asks: what inputs does the matrix send to zero? Zero is always one answer. But if the matrix collapses space — if it's not full rank — then entire lines or planes of inputs get sent to zero. Those make up the null space.
:::

:::example[Finding a basis for the null space]
Solve $A\mathbf{x}=\mathbf{0}$ for $A=\begin{pmatrix}1&2&-1\\2&4&-2\end{pmatrix}$. Here $n=3$.
:::

:::solution
1. Row-reduce. $R_2\leftarrow R_2-2R_1$ gives $(0,0,0)$: $\begin{pmatrix}1&2&-1\\0&0&0\end{pmatrix}$. One pivot (column $1$), so $\text{rank}(A)=1$ and the two non-pivot columns $2,3$ give free variables $x_2,x_3$. By rank-nullity the nullity is $3-1=2$.
2. The surviving equation is $x_1+2x_2-x_3=0$, i.e. $x_1=-2x_2+x_3$.
3. Set the free variables independently. With $x_2=s,\;x_3=t$: $\mathbf{x}=\begin{pmatrix}-2s+t\\s\\t\end{pmatrix}=s\begin{pmatrix}-2\\1\\0\end{pmatrix}+t\begin{pmatrix}1\\0\\1\end{pmatrix}$.
4. A basis for $\text{Null}(A)$ is therefore $\left\{(-2,1,0),\,(1,0,1)\right\}$ — two vectors, matching the nullity of $2$. The null space is a plane through the origin in $\mathbb{R}^3$.
5. Sanity check each basis vector: $A(-2,1,0)^{\mathsf T}$ has first entry $1(-2)+2(1)-1(0)=0$ ✓; $A(1,0,1)^{\mathsf T}$ has first entry $1(1)+2(0)-1(1)=0$ ✓ (the second row is a multiple of the first, so it vanishes too).
:::

## Common Mistakes

- Multiplying a row by zero during elimination. This destroys information and is invalid.
- Seeing free variables and claiming 'no solution.' Free variables mean infinitely many solutions. Inconsistency requires a row $[0\;\cdots\;0\;|\;b]$ with $b\neq 0$.
- Confusing $\text{rank}(A)$ with $\text{rank}([A|\mathbf{b}])$. The system is consistent iff these are equal.
- Back-substituting in the wrong order. Always start from the bottom row and work upward.
- Forgetting to express the general solution as particular solution plus null-space solution.
