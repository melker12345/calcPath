# Systems of Linear Equations

A system of linear equations is a set of constraints that must hold simultaneously. The question is always: do values of the unknowns exist that satisfy every equation at once, and if so, how many?

Gaussian elimination — systematically row-reducing the augmented matrix — gives a complete algorithmic answer to this question for any system, regardless of size. It is one of the most important algorithms in all of computational mathematics.

The theory connects directly to rank, the null space, and the fundamental theorem of linear maps. Every statement about when a system has zero, one, or infinitely many solutions follows from these ideas.


## Setting up augmented matrices {#gauss}

A linear system $a_{11}x_1 + \cdots + a_{1n}x_n = b_1, \ldots, a_{m1}x_1 + \cdots + a_{mn}x_n = b_m$ is written as the matrix equation $A\mathbf{x} = \mathbf{b}$, where $A$ is the $m\times n$ coefficient matrix, $\mathbf{x}$ is the unknown vector, and $\mathbf{b}$ is the right-hand side.

The augmented matrix $[A\;|\;\mathbf{b}]$ packs all information into one array. Each row represents one equation. The vertical bar separates coefficients from constants.

Three elementary row operations preserve the solution set: (R1) swap two rows, (R2) multiply a row by a nonzero scalar, (R3) add a scalar multiple of one row to another. These correspond exactly to legal algebraic manipulations of equations.

Why row operations work: they produce equivalent systems — systems with identical solution sets. You are not changing the solutions; you are changing the representation until the solution is obvious.

**ELI5**

- Each equation is a constraint on a map: 'I'm somewhere on this line' and 'I'm somewhere on that line.' The solution is where the lines cross.
- Gaussian elimination redraws the map so the crossing point is obvious. Instead of two diagonal lines, you draw one horizontal and one vertical line. The answer is immediately readable.

**Worked Example:**

**Writing a system as an augmented matrix and checking a row operation preserves solutions**

1. Take the system $x + 2y = 3,\; 2x + 5y = 8$. Line up the unknowns in the same order in every equation, then read off the coefficients.
2. Coefficient matrix $A=\begin{pmatrix}1&2\\2&5\end{pmatrix}$, right-hand side $\mathbf{b}=\begin{pmatrix}3\\8\end{pmatrix}$, so the augmented matrix is $\left(\begin{array}{cc|c}1&2&3\\2&5&8\end{array}\right)$.
3. Apply (R3), $R_2\leftarrow R_2-2R_1$: the new second row is $(2-2\cdot1,\;5-2\cdot2\;|\;8-2\cdot3)=(0,1\,|\,2)$, giving $\left(\begin{array}{cc|c}1&2&3\\0&1&2\end{array}\right)$.
4. The new second row says $y=2$; the first row then gives $x=3-2y=3-4=-1$.
5. Sanity check against the *original* equations: $x+2y=-1+4=3$ ✓ and $2x+5y=-2+10=8$ ✓. The row operation left the solution untouched — it only made it easier to read.


## Gaussian elimination {#gauss}

Forward elimination reduces the augmented matrix to row echelon form (REF): a staircase pattern where each row's leading nonzero entry (pivot) is to the right of the pivot above, with zeros below each pivot.

The procedure: work column by column from left to right. Use row operations to create zeros below the current pivot. Skip a column with no eligible pivot — this creates a free variable.

Back substitution: starting from the last nonzero row, solve for the pivot variable, then substitute upward through the other equations.

Reduced row echelon form (RREF) goes further: each pivot is scaled to $1$, and zeros are created both above and below each pivot. The solution can be read directly without back substitution.

A useful check: the number of pivots in RREF equals the rank of $A$. The number of non-pivot columns equals the number of free variables.

**ELI5**

- Gaussian elimination is like solving a crossword one row at a time. You use each equation to eliminate one unknown, until you have one equation with one unknown. Solve it, substitute back, solve the next, and so on.

**Worked Example:**

**Solving a 3×3 system**

1. System: $x+y+z=6,\; 2x-y+z=3,\; x+2y-z=4$.
2. Augmented matrix: $\left(\begin{array}{ccc|c}1&1&1&6\\2&-1&1&3\\1&2&-1&4\end{array}\right)$.
3. Clear the first column below the pivot. $R_2\leftarrow R_2-2R_1$ gives $(0,-3,-1\,|\,-9)$; $R_3\leftarrow R_3-R_1$ gives $(0,1,-2\,|\,-2)$: $\left(\begin{array}{ccc|c}1&1&1&6\\0&-3&-1&-9\\0&1&-2&-2\end{array}\right)$.
4. Clear the second column below its pivot. $R_3\leftarrow R_3+\tfrac{1}{3}R_2$ turns the $1$ in position $(3,2)$ into $1+\tfrac{1}{3}(-3)=0$, and the rest into $\left(0,0,-2+\tfrac{1}{3}(-1)\,\middle|\,-2+\tfrac{1}{3}(-9)\right)=(0,0,-\tfrac{7}{3}\,|\,-5)$: $\left(\begin{array}{ccc|c}1&1&1&6\\0&-3&-1&-9\\0&0&-\tfrac{7}{3}&-5\end{array}\right)$. This is row echelon form — a clean staircase.
5. Back-substitute from the bottom. Row 3: $-\tfrac{7}{3}z=-5\Rightarrow z=\tfrac{15}{7}$. Row 2: $-3y-z=-9\Rightarrow y=\tfrac{9-z}{3}=\tfrac{9-15/7}{3}=\tfrac{16}{7}$. Row 1: $x=6-y-z=6-\tfrac{16}{7}-\tfrac{15}{7}=\tfrac{11}{7}$.
6. Sanity check in the original system: $x+y+z=\tfrac{11+16+15}{7}=\tfrac{42}{7}=6$ ✓, $2x-y+z=\tfrac{22-16+15}{7}=\tfrac{21}{7}=3$ ✓, $x+2y-z=\tfrac{11+32-15}{7}=\tfrac{28}{7}=4$ ✓.


## Solution types {#consistency}

A linear system has exactly one of three outcomes: no solution (inconsistent), exactly one solution, or infinitely many solutions. There is no 'two solutions' in linear algebra.

Inconsistency is flagged by a row $[0\;0\;\cdots\;0\;|\;b]$ with $b\neq 0$ — the equation $0=b$ is impossible.

A unique solution exists when the system is consistent *and* every variable is a pivot variable — i.e. the coefficient matrix has full column rank ($\text{rank}(A)=n$). For a square consistent system this means RREF produces $[I\;|\;\mathbf{x}^*]$, reading off the answer directly. (Full column rank alone rules out extra solutions; consistency is what guarantees at least one exists.)

Infinitely many solutions arise when there are free variables — columns with no pivot. Each free variable can take any real value. You parameterise the solution set: express pivot variables in terms of free variables.

The complete solution to $A\mathbf{x}=\mathbf{b}$ is $\mathbf{x} = \mathbf{x}_p + \mathbf{x}_h$, where $\mathbf{x}_p$ is any particular solution and $\mathbf{x}_h$ is any solution to the homogeneous system $A\mathbf{x}=\mathbf{0}$.

**ELI5**

- Two lines either cross at one point (unique solution), are parallel and never meet (no solution), or are the same line (infinitely many solutions). In higher dimensions, replace 'lines' with 'hyperplanes' — the three possibilities are the same.

**Worked Example:**

**Parameterizing an infinite solution set as $\mathbf{x}_p + \mathbf{x}_h$**

1. System: $x+2y+z=4,\; 2x+5y+3z=9,\; x+3y+2z=5$. Augmented matrix $\left(\begin{array}{ccc|c}1&2&1&4\\2&5&3&9\\1&3&2&5\end{array}\right)$.
2. $R_2\leftarrow R_2-2R_1$ gives $(0,1,1\,|\,1)$; $R_3\leftarrow R_3-R_1$ gives $(0,1,1\,|\,1)$: $\left(\begin{array}{ccc|c}1&2&1&4\\0&1&1&1\\0&1&1&1\end{array}\right)$.
3. $R_3\leftarrow R_3-R_2$ gives $(0,0,0\,|\,0)$: $\left(\begin{array}{ccc|c}1&2&1&4\\0&1&1&1\\0&0&0&0\end{array}\right)$. The zero row is $0=0$, so the system is consistent; there are two pivots (columns $1,2$) and three variables, so $z$ is a free variable.
4. Let $z=t$ (any real number). Row 2: $y+z=1\Rightarrow y=1-t$. Row 1: $x=4-2y-z=4-2(1-t)-t=2+t$.
5. Split the general solution into a particular part plus a homogeneous part: $\begin{pmatrix}x\\y\\z\end{pmatrix}=\begin{pmatrix}2\\1\\0\end{pmatrix}+t\begin{pmatrix}1\\-1\\1\end{pmatrix}$. Setting $t=0$ gives the particular solution $\mathbf{x}_p=(2,1,0)$; the vector $(1,-1,1)$ spans the null space, so $\mathbf{x}_h=t(1,-1,1)$.
6. Sanity check with $t=1$, i.e. $(x,y,z)=(3,0,1)$: $x+2y+z=3+0+1=4$ ✓, $2x+5y+3z=6+0+3=9$ ✓, $x+3y+2z=3+0+2=5$ ✓.


## Rank and the rank-nullity theorem {#rank}

The rank of a matrix $A$ is the number of pivot columns in its row echelon form — equivalently, the dimension of the column space $\text{Col}(A)$.

Consistency condition: $A\mathbf{x}=\mathbf{b}$ is consistent iff $\text{rank}([A\;|\;\mathbf{b}]) = \text{rank}(A)$. Adding $\mathbf{b}$ as a column must not create a new pivot — $\mathbf{b}$ must already lie in $\text{Col}(A)$.

Uniqueness condition: the solution is unique iff $\text{rank}(A)=n$ (no free variables).

The nullity of $A$ is the number of non-pivot (free) columns — equivalently, the dimension of the null space $\text{Null}(A)$ (the solutions of $A\mathbf{x}=\mathbf{0}$, defined in the next section). The rank-nullity theorem then says $\text{rank}(A) + \text{nullity}(A) = n$, where $n$ is the number of columns. Pivot columns contribute to rank; free columns contribute to nullity. Every column is one or the other, so together they account for all $n$ columns.

For an $m\times n$ matrix: $\text{rank}(A) \leq \min(m,n)$. Each pivot needs its own row and its own column, so the number of pivots cannot exceed either dimension — you cannot have more independent directions than the smaller dimension.

**ELI5**

- Rank counts how many truly independent equations you have. Ten equations might contain only $3$ independent constraints if the rest are just combinations of those $3$. Rank-nullity says: independent constraints plus free variables always adds up to the total number of unknowns.

**Worked Example:**

**Reading off rank and nullity, then checking rank-nullity**

1. Let $A=\begin{pmatrix}1&2&1&1\\2&4&3&4\\1&2&2&3\end{pmatrix}$, a $3\times4$ matrix, so $n=4$ columns.
2. Row-reduce. $R_2\leftarrow R_2-2R_1$ gives $(0,0,1,2)$; $R_3\leftarrow R_3-R_1$ gives $(0,0,1,2)$: $\begin{pmatrix}1&2&1&1\\0&0&1&2\\0&0&1&2\end{pmatrix}$.
3. $R_3\leftarrow R_3-R_2$ gives $(0,0,0,0)$: $\begin{pmatrix}1&2&1&1\\0&0&1&2\\0&0&0&0\end{pmatrix}$. This is row echelon form.
4. Count pivots: there is a leading entry in column $1$ and in column $3$, so there are $2$ pivots. Hence $\text{rank}(A)=2$. Note column $2$ has no pivot even though the matrix has nonzero entries there — rank counts pivot *columns*, not nonzero entries.
5. Apply rank-nullity: $\text{nullity}(A)=n-\text{rank}(A)=4-2=2$. The two non-pivot columns ($2$ and $4$) correspond to the two free variables, confirming the count.
6. Sanity check the bound: $\text{rank}(A)=2\le\min(m,n)=\min(3,4)=3$ ✓.


## Homogeneous systems {#homogeneous}

A system is *homogeneous* when the right-hand side is all zeros: $A\mathbf{x}=\mathbf{0}$. This is the "background" version of $A\mathbf{x}=\mathbf{b}$ with the constants stripped away — and it controls how many solutions the full system can have. A homogeneous system is always consistent — the trivial solution $\mathbf{x}=\mathbf{0}$ always works, since $A\mathbf{0}=\mathbf{0}$.

Nontrivial solutions exist iff $\text{rank}(A)<n$ — there are more unknowns than pivots, creating free variables.

The set of all solutions to $A\mathbf{x}=\mathbf{0}$ is the null space $\text{Null}(A)$, which is always a subspace of $\mathbb{R}^n$. Its dimension (the nullity) equals the number of free variables.

A square matrix $A$ is invertible iff $A\mathbf{x}=\mathbf{0}$ has only the trivial solution iff $\text{nullity}(A)=0$ iff $\det(A)\neq 0$. These conditions are all equivalent.

**ELI5**

- A homogeneous system asks: what inputs does the matrix send to zero? Zero is always one answer. But if the matrix collapses space — if it's not full rank — then entire lines or planes of inputs get sent to zero. Those make up the null space.

**Worked Example:**

**Finding a basis for the null space**

1. Solve $A\mathbf{x}=\mathbf{0}$ for $A=\begin{pmatrix}1&2&-1\\2&4&-2\end{pmatrix}$. Here $n=3$.
2. Row-reduce. $R_2\leftarrow R_2-2R_1$ gives $(0,0,0)$: $\begin{pmatrix}1&2&-1\\0&0&0\end{pmatrix}$. One pivot (column $1$), so $\text{rank}(A)=1$ and the two non-pivot columns $2,3$ give free variables $x_2,x_3$. By rank-nullity the nullity is $3-1=2$.
3. The surviving equation is $x_1+2x_2-x_3=0$, i.e. $x_1=-2x_2+x_3$.
4. Set the free variables independently. With $x_2=s,\;x_3=t$: $\mathbf{x}=\begin{pmatrix}-2s+t\\s\\t\end{pmatrix}=s\begin{pmatrix}-2\\1\\0\end{pmatrix}+t\begin{pmatrix}1\\0\\1\end{pmatrix}$.
5. A basis for $\text{Null}(A)$ is therefore $\left\{(-2,1,0),\,(1,0,1)\right\}$ — two vectors, matching the nullity of $2$. The null space is a plane through the origin in $\mathbb{R}^3$.
6. Sanity check each basis vector: $A(-2,1,0)^{\mathsf T}$ has first entry $1(-2)+2(1)-1(0)=0$ ✓; $A(1,0,1)^{\mathsf T}$ has first entry $1(1)+2(0)-1(1)=0$ ✓ (the second row is a multiple of the first, so it vanishes too).

## Common Mistakes

- Multiplying a row by zero during elimination. This destroys information and is invalid.
- Seeing free variables and claiming 'no solution.' Free variables mean infinitely many solutions. Inconsistency requires a row $[0\;\cdots\;0\;|\;b]$ with $b\neq 0$.
- Confusing $\text{rank}(A)$ with $\text{rank}([A|\mathbf{b}])$. The system is consistent iff these are equal.
- Back-substituting in the wrong order. Always start from the bottom row and work upward.
- Forgetting to express the general solution as particular solution plus null-space solution.
