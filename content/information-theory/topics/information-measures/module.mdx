# Information Measures

Entropy, joint and conditional entropy, mutual information, relative entropy, and entropy rate.

Information theory is the mathematical study of the quantification, storage, and communication of information. Founded by Claude Shannon in his landmark 1948 paper "A Mathematical Theory of Communication," it provides the theoretical limits for data compression, reliable transmission over noisy channels, and many modern technologies from the internet to machine learning.

It separates the engineering problem of communication from the semantics of the messages being sent.

## What is Information?

<!-- section: what-is-information -->

Information is fundamentally about reducing uncertainty. If an outcome is certain (probability 1), learning it tells you nothing new. The rarer or more surprising an event, the more information it carries when observed.

Formally, information theory models sources as random variables or stochastic processes and measures information via probabilities.

:::intuition
Imagine a weather forecast: "It will be sunny" on a desert planet carries almost zero information because it is expected. "It will snow" would be highly informative.

A fair coin flip resolves one bit of uncertainty; learning it happened "heads" cuts the possibilities exactly in half.
:::

:::example
A lottery has 1,000,000 equally likely tickets, so each specific ticket wins with probability $p = 1/1{,}000{,}000$. A message announcing that one specific ticket won carries self-information
:::

:::solution
$$I = -\log_2 \frac{1}{1{,}000{,}000} = \log_2 1{,}000{,}000 \approx 19.93 \text{ bits}.$$

Sanity check: $2^{20} = 1{,}048{,}576 \approx 1{,}000{,}000$, so the answer should sit just under 20 bits — and it does. Contrast this with the far more likely message "your ticket did not win" (probability $999{,}999/1{,}000{,}000$), whose self-information is $-\log_2(0.999999) \approx 0.0000014$ bits: hearing the expected outcome tells you almost nothing.
:::

## Quantifying Information

<!-- section: quantifying-information -->

:::definition[Self-information]{#self-information}
The self-information (or surprisal) of a specific outcome $x$ with probability $p(x)$ is

$$I(x) = -\log_2 p(x) \text{ bits}.$$
:::

Entropy is the average of this quantity over all outcomes: the entropy of a discrete random variable $X$ is the expected self-information,

$$H(X) = -\sum_x p(x) \log_2 p(x) = \mathbb{E}[-\log_2 p(X)].$$

Entropy is always non-negative, maximized for the uniform distribution over a given support, and is measured in bits when using log base 2 (or nats with natural log).

:::intuition
Entropy answers: on average, how many fair yes/no questions do you need to identify the value of X?

A perfectly fair coin has 1 bit of entropy. A coin that always lands heads has 0 bits of entropy—you already know the answer.
:::

:::example
Consider a random variable $X$ with four outcomes having probabilities $\tfrac12, \tfrac14, \tfrac18, \tfrac18$.
:::

:::solution
write each term $-p\log_2 p$. Since each probability is a power of $\tfrac12$, the surprisals are exact integers: $-\log_2\tfrac12 = 1$, $-\log_2\tfrac14 = 2$, $-\log_2\tfrac18 = 3$.

take the probability-weighted sum:

$$H(X) = \tfrac12(1) + \tfrac14(2) + \tfrac18(3) + \tfrac18(3) = 0.5 + 0.5 + 0.375 + 0.375 = 1.75 \text{ bits}.$$

Sanity check: the value lies between $0$ (a sure outcome) and $\log_2 4 = 2$ (four equally likely outcomes), as it must — and it is below $2$ because this distribution is more predictable than the uniform one.
:::

## Applications and Scope

<!-- section: applications-scope -->

Information theory gives fundamental limits, and two of them frame everything that follows.

:::theorem[Shannon's two coding theorems]{#shannon-limits}
The source coding theorem bounds lossless compression by $H(X)$; the noisy-channel coding theorem bounds the reliable transmission rate by the channel capacity $C$.
:::

These are not engineering suggestions but mathematical facts that no scheme can beat in the asymptotic regime.

Modern applications include zip files, error-correcting codes in hard drives and wireless, deep learning (cross-entropy loss), and cryptography.

:::intuition
Think of entropy as the "irreducible size" of a message on average. You can get close to it with good codes but never sustainably below it.

Channel capacity tells you the highest speed (in bits per transmission) at which you can talk over a noisy phone line with arbitrarily small error probability.
:::

:::example
A source produces independent symbols A ($p=0.5$), B ($p=0.25$), C ($p=0.25$).
:::

:::solution
1. per-symbol entropy: $H = -0.5\log_2 0.5 - 0.25\log_2 0.25 - 0.25\log_2 0.25 = 0.5(1) + 0.25(2) + 0.25(2) = 1.5$ bits per symbol.
2. because the symbols are independent, the entropy of a length-$1000$ block is exactly $1000 \times 1.5 = 1500$ bits.
3. the source coding theorem says no lossless scheme can average fewer than $1500$ bits for such blocks (asymptotically), and a good code (e.g. a Huffman code assigning A $\to$ 1 bit, B $\to$ 2 bits, C $\to$ 2 bits) meets this: expected length $= 0.5(1) + 0.25(2) + 0.25(2) = 1.5$ bits/symbol, matching $H$ exactly here because every probability is a power of $\tfrac12$.
:::

## Common Mistakes

- **Confusing information with meaning or importance**: A random string of digits can have high information content (entropy) yet be completely meaningless to a human.
- **Using the wrong logarithm base**: For bits always use log₂; using log₁₀ or ln changes the numerical value by a constant factor (log₂e ≈ 1.4427 for nats to bits).
- **Treating entropy as a property of a single string**: Entropy is defined for a distribution (ensemble); Kolmogorov complexity is the individual-string analogue.
- **Assuming maximum entropy is always uniform over the alphabet**: It is, but only when all symbols are possible; if the support size is smaller the max entropy is lower.
- **Mixing up H(X) and I(X;Y)**: Entropy H(X) is uncertainty in X alone; mutual information I(X;Y) is the reduction in that uncertainty when Y is observed.
- **Forgetting that real sources have memory**: The simple i.i.d. entropy formula is only the starting point; entropy rate accounts for dependence in sequences.

Entropy is the central quantity of information theory. It measures the average amount of information (or equivalently, uncertainty) produced by a stochastic source. Claude Shannon introduced it in 1948 as the unique (up to scaling) function satisfying a few intuitive axioms about how information should behave when sources are combined or observed.

Entropy sets the fundamental limits for both data compression and many other information-processing tasks.

## Definition of Entropy

<!-- section: definition -->

:::definition[Shannon entropy]{#entropy}
For a discrete random variable $X$ taking values in a finite alphabet with probability mass function $p(x)$, the Shannon entropy is

$$H(X) = - \sum_{x} p(x) \log_2 p(x).$$

When the sum is over an infinite support the series must converge.
:::

:::notation
By convention $0 \log 0 = 0$, the limiting value of $p \log p$ as $p \to 0$. Outcomes of probability zero therefore contribute nothing to the sum.
:::

Entropy can be interpreted as the average number of bits needed to describe the outcome of X using an optimal code.

:::intuition
Entropy is the "average surprise." Every time you see a realization of X you get on average H(X) bits of new information.

If you already know the distribution, entropy tells you how hard it is to guess the next draw on average.
:::

:::example
A biased coin with $P(\text{heads})=0.9$, $P(\text{tails})=0.1$ has entropy
:::

:::solution
1. $H = -0.9 \log_2(0.9) - 0.1 \log_2(0.1)$. Using $-\log_2(0.9)\approx 0.152$ and $-\log_2(0.1)\approx 3.322$, this is $0.9(0.152) + 0.1(3.322) \approx 0.137 + 0.332 = 0.469$ bits.
2. You can guess "heads" and be right $90\%$ of the time, so on average far less than 1 bit of uncertainty per flip.
3. Sanity check: $0 < 0.469 < 1$, i.e. between a sure coin and a fair coin — a biased-but-not-certain coin should land strictly inside that range.
:::

## Properties of Entropy

<!-- section: properties -->

:::proposition[Basic properties of entropy]{#entropy-properties}
Let $X$ take values in a finite alphabet $\mathcal{X}$. Then

$$0 \le H(X) \le \log_2 |\mathcal{X}|,$$

with equality on the left iff $X$ is deterministic and on the right for the uniform distribution. Moreover $H(f(X)) \le H(X)$ for any function $f$ (data processing), $H$ is concave in the distribution $p$, and for independent $X, Y$,

$$H(X,Y) = H(X) + H(Y).$$
:::

:::intuition
You cannot create uncertainty by relabeling or processing the outcomes deterministically; you can only lose information.

Independent coins add their entropies: two fair coins together have 2 bits.
:::

One special case of the entropy formula is used so often that it gets its own name and symbol.

:::definition[Binary entropy function]{#binary-entropy}
The binary entropy function is

$$h(p) = -p\log_2 p -(1-p)\log_2(1-p),$$

the entropy of a single bit that is $1$ with probability $p$. It appears everywhere in information theory.
:::

:::example
Consider two independent fair bits $X$ and $Y$. Then $H(X,Y) = H(X) + H(Y) = 2$ bits.
:::

:::solution
1. The joint distribution is uniform over 4 possibilities, confirming $\log_2(4) = 2$.
:::

## Calculating Entropy

<!-- section: calculating -->

To compute $H$ for a given pmf, simply plug into the formula. For small alphabets it is straightforward; for large ones one often uses the binary entropy or closed forms (e.g., geometric, Poisson in limit).

:::recipe[Computing an entropy from a pmf]
1. List the probabilities $p(x)$ of every outcome with positive probability.
2. Compute the surprisal $-\log_2 p(x)$ of each one.
3. Weight each surprisal by its probability and sum: $H(X) = \sum_x p(x)\bigl(-\log_2 p(x)\bigr)$.
4. Check the answer lies in $[0, \log_2|\mathcal{X}|]$.
:::

A useful table of small examples:

| Distribution          | Probabilities          | Entropy (bits) |
|-----------------------|------------------------|----------------|
| Deterministic         | (1)                    | 0              |
| Fair coin             | (0.5, 0.5)             | 1              |
| Biased coin (0.9)     | (0.9, 0.1)             | ≈0.469         |
| Fair 4-ary            | (0.25 each)            | 2              |
| Example in text       | (0.5,0.25,0.125,0.125) | 1.75           |

:::intuition
Make a table of probabilities, multiply each by -log2 of itself, and average (sum). That is the entropy.

When symbols are very unequal, entropy drops because you can predict the common ones easily.
:::

:::example
Symbols $A,B,C,D$ with $p = 0.4, 0.3, 0.2, 0.1$.
:::

:::solution
1. $H = -0.4 \log_2(0.4) -0.3 \log_2(0.3) -0.2 \log_2(0.2) -0.1 \log_2(0.1)$.
2. The surprisals are $-\log_2(0.4)\approx 1.322$, $-\log_2(0.3)\approx 1.737$, $-\log_2(0.2)\approx 2.322$, $-\log_2(0.1)\approx 3.322$.
3. $H \approx 0.4(1.322) + 0.3(1.737) + 0.2(2.322) + 0.1(3.322) \approx 0.529 + 0.521 + 0.464 + 0.332 = 1.846$ bits.
4. Sanity check: $0 < 1.846 < \log_2 4 = 2$, as required for a non-uniform distribution over four symbols.
:::

## Common Mistakes

- **Using log base e or 10 without converting**: The numerical value changes; remember the conversion factor log₂e ≈ 1.4427 when going from nats.
- **Forgetting the negative sign**: -sum p log p is positive; dropping the minus gives a negative nonsense value.
- **Treating 0 log 0 as undefined in code**: In math we define lim p→0 p log p = 0; always add a guard in implementations.
- **Confusing entropy of the distribution with entropy of a sample**: H is a property of p, not of any particular draw or finite sequence.
- **Assuming H(X|Y) = H(X) - something always**: Only the mutual information term subtracts; conditional entropy can be computed directly.
- **Ignoring that entropy rate ≠ single-symbol entropy for processes with memory**: Real text, images, etc. have dependence that must be modeled for accurate rate.

Joint entropy H(X,Y) extends the notion of entropy from a single random variable to a pair (or more generally a vector) of random variables. It quantifies the total uncertainty in the combined outcome of X and Y together.

It is the natural starting point for discussing how two variables interact information-theoretically.

## Joint Entropy Definition

<!-- section: definition-joint -->

:::definition[Joint entropy]{#joint-entropy}
Let $(X,Y)$ be a pair of discrete random variables with joint probability mass function $p(x,y)$. Their joint entropy is

$$H(X,Y) = -\sum_{x,y} p(x,y) \log_2 p(x,y).$$
:::

It is simply the ordinary entropy of the "big" random variable whose possible values are all pairs (x,y) that have positive probability.

:::intuition
Think of (X,Y) as one bigger roll of the dice. H(X,Y) tells the average surprise when you see both numbers at once.

If X is the first card and Y the second card drawn without replacement, H(X,Y) measures uncertainty about the ordered pair.
:::

:::example
Two independent fair bits $X, Y$.
:::

:::solution
1. list the joint pmf: the four pairs $(0,0), (0,1), (1,0), (1,1)$ are each equally likely with probability $\tfrac14$.
2. apply the definition: $H(X,Y) = -\sum_{x,y} p(x,y)\log_2 p(x,y) = -4\cdot\tfrac14\log_2\tfrac14 = -\log_2\tfrac14 = 2$ bits.
3. Sanity check: independence means $H(X,Y)$ should equal $H(X)+H(Y) = 1 + 1 = 2$ bits, and it does. Equivalently, four equally likely outcomes give $\log_2 4 = 2$ bits.
:::

## Relation to Individual Entropies

<!-- section: relation-to-marginals -->

:::proposition[Joint entropy dominates its marginals]{#joint-dominates-marginals}
For any pair of discrete random variables,

$$H(X) \le H(X,Y) \quad\text{and}\quad H(Y) \le H(X,Y).$$
:::

:::proof
The difference $H(X,Y) - H(X)$ equals the conditional entropy $H(Y|X)$, which is never negative; the same argument with the roles of $X$ and $Y$ exchanged gives the second inequality. Equality holds on the left when $Y$ is a deterministic function of $X$, since then $H(Y|X) = 0$.
:::

:::intuition
Knowing both variables together can never be less uncertain than knowing just one of them.

When the second variable is completely determined by the first, joint entropy collapses to the entropy of the first.
:::

:::example
Let $X$ be uniform on $\{0,1,2,3\}$ (so $H(X)=\log_2 4 = 2$ bits) and $Y = X \bmod 2$.
:::

:::solution
1. find the joint support. Since $Y$ is fixed once $X$ is known, only four pairs have positive probability: $(0,0),(1,1),(2,0),(3,1)$, each with probability $\tfrac14$.
2. compute the joint entropy: four equally likely pairs give $H(X,Y) = \log_2 4 = 2$ bits.
3. compare to the marginal: $H(X,Y) = 2 = H(X)$. The left inequality $H(X)\le H(X,Y)$ holds with equality, exactly as predicted, because $Y$ is a deterministic function of $X$ (so $H(Y|X)=0$). Adding a variable that carries no new information does not raise the joint entropy.
:::

## Chain Rule for Entropy

<!-- section: chain-rule -->

:::theorem[Chain rule for entropy]{#chain-rule}
For any pair of discrete random variables,

$$H(X,Y) = H(X) + H(Y|X) = H(Y) + H(X|Y).$$
:::

It is the information-theoretic analogue of the chain rule for probabilities $p(x,y)=p(x)p(y|x)$.

Read together with the fact that joint entropy dominates its marginals, it immediately implies that conditional entropy is non-negative: $H(Y|X) \ge 0$.

:::intuition
The total uncertainty about the pair = uncertainty about X plus whatever uncertainty remains about Y after you have seen X.

You can start with either variable; the math works symmetrically.
:::

:::example
A fair coin $X$ and an independent fair coin $Y$. Because they are independent, seeing $X$ tells you nothing about $Y$, so $H(Y|X)=H(Y)=1$. The chain rule then gives $H(X,Y) = H(X) + H(Y|X) = 1 + 1 = 2$ bits.
:::

:::solution
1. If instead $Y=X$ (you report the same single flip twice), knowing $X$ pins down $Y$ exactly, so $H(Y|X)=0$ and $H(X,Y) = H(X) + H(Y|X) = 1 + 0 = 1$ bit.
2. Sanity check: the two answers bracket the general truth $\max(H(X),H(Y)) \le H(X,Y) \le H(X)+H(Y)$, i.e. $1 \le H(X,Y) \le 2$. Independence hits the upper bound; perfect dependence hits the lower one.
:::

## Common Mistakes

- **Thinking H(X,Y) = H(X) + H(Y) always**: This holds only under independence; otherwise the joint is strictly smaller than the sum.
- **Confusing joint entropy with mutual information**: H(X,Y) is total uncertainty in the pair; I(X;Y) = H(X)+H(Y)-H(X,Y) is the shared part.
- **Forgetting that joint support may be smaller than product of marginal supports**: When variables are dependent many (x,y) pairs have probability zero, lowering the joint entropy.
- **Using marginal probabilities in the joint formula by mistake**: You must use the true joint p(x,y), not p(x)p(y).
- **Assuming H(X,Y) grows without bound as alphabet size grows**: It is bounded by log of the size of the joint support, which may be much smaller than |X|×|Y|.
- **Mixing up H(X,Y) and H(X|Y)**: The former is joint (total), the latter is conditional (residual after one is known).

Conditional entropy H(Y|X) measures how much uncertainty remains about Y once the value of X is known. It is the information-theoretic version of "residual variance" or "prediction error" when trying to guess Y from X.

It plays a starring role in the definitions of mutual information, channel capacity, and rate-distortion functions.

## Definition of Conditional Entropy

<!-- section: definition-conditional -->

:::definition[Conditional entropy]{#conditional-entropy}
The conditional entropy of $Y$ given $X$ is the expected entropy of the conditional distributions:

$$H(Y|X) = \sum_x p(x) H(Y|X=x) = -\sum_{x,y} p(x,y) \log_2 p(y|x).$$
:::

By the chain rule it can also be expressed as $H(Y|X) = H(X,Y) - H(X)$, and that identity is often the fastest route to a numerical value.

:::intuition
After you look at X, on average how many more bits do you still need to describe Y?

If X is the month and Y is the temperature in a city, H(Y|X) is the average remaining uncertainty about temperature once you know which month it is.
:::

:::example[(averaging over $x$):]
Let $X\in\{0,1\}$ with $P(X{=}0)=P(X{=}1)=\tfrac12$, and let the channel from $X$ to $Y$ be: if $X=0$ then $Y=0$ for sure; if $X=1$ then $Y$ is a fair coin ($Y=0$ or $1$ with probability $\tfrac12$ each).
:::

:::solution
1. conditional entropies for each value of $X$. Given $X=0$, $Y$ is deterministic, so $H(Y|X{=}0)=0$. Given $X=1$, $Y$ is a fair bit, so $H(Y|X{=}1)=1$.
2. take the $p(x)$-weighted average: $H(Y|X) = \tfrac12\,H(Y|X{=}0) + \tfrac12\,H(Y|X{=}1) = \tfrac12(0) + \tfrac12(1) = 0.5$ bits.
3. Sanity check via the joint. The joint pmf is $p(0,0)=\tfrac12$, $p(1,0)=\tfrac14$, $p(1,1)=\tfrac14$, giving $H(X,Y) = -\tfrac12\log_2\tfrac12 - \tfrac14\log_2\tfrac14 - \tfrac14\log_2\tfrac14 = 0.5 + 0.5 + 0.5 = 1.5$ bits. Since $H(X)=1$, the identity $H(Y|X)=H(X,Y)-H(X) = 1.5 - 1 = 0.5$ bits agrees.
:::

:::example[(deterministic case):]
$X$ a fair coin, $Y = X$ (an exact copy). Given $X$ you know $Y$ perfectly, so $H(Y|X{=}x)=0$ for both values of $x$, and hence $H(Y|X)=0$: once $X$ is revealed, no uncertainty about $Y$ remains.
:::

## Interpretation and Properties

<!-- section: interpretation-properties -->

:::proposition[Conditioning reduces entropy]{#conditioning-reduces-entropy}
Conditional entropy satisfies $H(Y|X) \ge 0$ always, and

$$H(Y|X) \le H(Y),$$

with strict inequality unless $I(X;Y)=0$; equivalently, $H(Y|X) = H(Y)$ exactly when $X$ and $Y$ are independent. Conditioning on more variables can only decrease (or keep) the conditional entropy:

$$H(Y|X,Z) \le H(Y|X).$$
:::

:::intuition
Learning X can never make you more uncertain about Y on average; it can only help or do nothing.

If X tells you nothing about Y they are independent and H(Y|X)=H(Y).
:::

:::example
$X$ uniform on $\{1,2,3,4\}$, $Y = X \bmod 2$ (so $Y=1$ for odd $X$, $Y=0$ for even $X$).
:::

:::solution
1. marginal of $Y$: two of the four values are odd and two are even, so $P(Y{=}0)=P(Y{=}1)=\tfrac12$ and $H(Y)=1$ bit.
2. condition on $X$: each value of $X$ determines $Y$ exactly, so $H(Y|X{=}x)=0$ for every $x$, giving $H(Y|X)=0$.
3. check the property: $H(Y|X) = 0 < 1 = H(Y)$, confirming that conditioning reduced entropy. The reduction $H(Y)-H(Y|X) = 1$ bit is exactly the mutual information $I(X;Y)$ — knowing $X$ resolves all of $Y$'s uncertainty here.
:::

## Chain Rule and Relations

<!-- section: chain-rule-relations -->

The chain rule $H(X,Y) = H(X) + H(Y|X)$ is the most useful identity in this chapter. It rearranges to

$$H(Y|X) = H(X,Y) - H(X), \qquad H(X|Y) = H(X,Y) - H(Y),$$

which is how conditional entropies are usually computed in practice: get the joint, get the marginal, subtract.

Everything conditions gracefully on a third variable as well.

:::proposition[Conditional chain rule]{#conditional-chain-rule}
For discrete random variables $X$, $Y$ and $Z$,

$$H(X,Y|Z) = H(X|Z) + H(Y|X,Z).$$
:::

:::intuition
Total joint uncertainty = uncertainty in X plus the extra uncertainty in Y once X is known.

You can "pay" the uncertainty of X first, then pay only the conditional part for Y.
:::

:::example
Suppose H(X)=2, H(Y)=3, H(X,Y)=4. Then H(Y|X) = 4-2 = 2 bits, and H(X|Y) = 4-3 = 1 bit. X is more informative about Y than vice versa.
:::

## Common Mistakes

- **Thinking H(Y|X) can be negative**: It cannot; conditional entropy is always ≥ 0.
- **Confusing H(Y|X) with I(X;Y)**: I(X;Y) = H(Y) - H(Y|X) is the reduction; H(Y|X) is what is left.
- **Writing H(Y|X) using only marginals p(y)**: You need the conditional p(y|x) or the joint.
- **Forgetting that H(Y|X) is an average**: For some particular x the conditional entropy H(Y|X=x) can be larger than H(Y), even though the average cannot.
- **Assuming H(Y|X)=0 implies X determines Y with probability 1 for every x**: It only requires that for almost every x (under p(x)) the conditional is deterministic.
- **Mixing conditional entropy with conditional probability**: They are related but one is a number (uncertainty), the other a function of the realized value.

Mutual information I(X;Y) is the most important derived quantity in information theory after entropy. It quantifies how much knowing one variable reduces uncertainty about the other — the strength of the statistical relationship in information units (bits).

It is symmetric, non-negative, and zero exactly when the variables are independent. It is the currency of communication: channel capacity is the maximum mutual information between input and output.

## Definition via Entropies

<!-- section: definition-mutual -->

:::definition[Mutual information]{#mutual-information}
The mutual information of $X$ and $Y$ can be given in several equivalent ways:

$$I(X;Y) = H(X) - H(X|Y) = H(Y) - H(Y|X) = H(X) + H(Y) - H(X,Y).$$
:::

The three forms agree because of the chain rule, and each is the convenient one in different circumstances. The last form shows it is the difference between the sum of marginal entropies and the joint entropy.

:::intuition
I(X;Y) is "how many bits of X's uncertainty are resolved by learning Y."

It is also "how much smaller the joint description is compared with describing X and Y separately."
:::

:::example
$X$ and $Y$ are identical fair bits ($Y=X$).
:::

:::solution
1. the marginals: each is a fair bit, so $H(X)=H(Y)=1$ bit.
2. the joint has only two equally likely pairs $(0,0)$ and $(1,1)$, so $H(X,Y)=1$ bit.
3. apply $I(X;Y) = H(X)+H(Y)-H(X,Y) = 1 + 1 - 1 = 1$ bit. Sanity check: $I(X;Y) = 1 = \min(H(X),H(Y))$, the maximum possible — they share all of their information, as expected for a perfect copy.
:::

## Interpretation as Information Transfer

<!-- section: interpretation -->

The two extremes of the quantity are worth reading off directly. Mutual information vanishes, $I(X;Y) = 0$, exactly when $X$ and $Y$ are independent. It reaches $I(X;Y) = H(X)$ when $Y$ determines $X$ perfectly, i.e. when $H(X|Y)=0$; between those two poles it interpolates smoothly.

In a communication setting, X is the message, Y the received signal; I(X;Y) is the average information successfully transferred.

:::intuition
Zero mutual information means "Y tells you nothing about X on average" — like two separate fair coins.

Maximum mutual information (equal to H(X)) means "Y tells you everything about X" — a perfect copy or noiseless observation.
:::

:::example
X uniform on 8 symbols (H(X)=3). After a noisy channel the receiver's uncertainty H(X|Y)=0.8 bits on average. Then I(X;Y)=3-0.8=2.2 bits were conveyed on average per transmission.
:::

## Properties and Special Cases

<!-- section: properties-special -->

:::proposition[Properties of mutual information]{#mutual-information-properties}
Mutual information is non-negative, $I(X;Y) \ge 0$, and symmetric, $I(X;Y)=I(Y;X)$. It satisfies $I(X;X) = H(X)$, the self-information of the variable. For independent $X, Y$ it is $0$; when $Y=f(X)$ bijectively it is $H(X)$.
:::

:::theorem[Data processing inequality]{#data-processing-inequality}
If $X - Y - Z$ form a Markov chain, then

$$I(X;Z) \le I(X;Y) \le \min\bigl(H(X),H(Y)\bigr).$$
:::

:::intuition
Processing a signal can only lose or preserve information about the original; it cannot create more.

Mutual information between a variable and itself is just its entropy.
:::

:::example[(data processing inequality):]
Let $X$ be a fair bit. Send it through a binary symmetric channel that flips the bit with probability $0.1$ to produce $Y$, then send $Y$ through a second, independent flip-with-probability-$0.1$ channel to produce $Z$. This is a Markov chain $X \to Y \to Z$.
:::

:::solution
1. $I(X;Y)$. For a fair input into a symmetric channel with crossover $p$, $I(X;Y) = 1 - h(p)$ where $h$ is the binary entropy. With $p=0.1$, $h(0.1)\approx 0.469$, so $I(X;Y) \approx 1 - 0.469 = 0.531$ bits.
2. $I(X;Z)$. Two independent flips compose into a single effective flip with probability $p' = 0.1(0.9) + 0.9(0.1) = 0.18$ (the bit is wrong iff exactly one of the two channels flips it). Then $I(X;Z) = 1 - h(0.18) \approx 1 - 0.680 = 0.320$ bits.
3. check the DPI: $I(X;Z) \approx 0.320 \le 0.531 \approx I(X;Y)$. Processing $Y$ into $Z$ could only lose information about $X$, never add it. Both values also respect the bound $I \le \min(H(X),H(Z)) = 1$ bit.
:::

## Common Mistakes

- **Thinking mutual information can be negative**: It cannot; I(X;Y) ≥ 0 always, with equality for independence.
- **Confusing I(X;Y) with H(X,Y) or conditional entropy**: I is the *shared* part; H joint is total, conditional is the leftover.
- **Assuming I(X;Y) = 0 implies no dependence of any kind**: It implies statistical independence; functional or higher-order dependence that averages to zero info is still possible in other senses but rare.
- **Forgetting symmetry**: Although defined asymmetrically via H(X)-H(X|Y), the value is always equal to H(Y)-H(Y|X).
- **Using I(X;Y) when the right quantity is I(X;Y|Z)**: Conditional mutual information is needed when there is a third variable (common cause, etc.).
- **Believing large I(X;Y) implies causation**: Mutual information is purely correlational/statistical; it says nothing about direction or mechanism.

Relative entropy, also known as Kullback-Leibler (KL) divergence, is a fundamental non-symmetric measure of how one probability distribution p differs from another reference distribution q. It is not a distance (it fails symmetry and the triangle inequality) but it is the right notion of "divergence" for many information-theoretic and statistical purposes.

It appears in the definition of mutual information, in large-deviations theory, in variational inference, and as the natural loss for comparing distributions.

## Definition of KL Divergence

<!-- section: definition-kl -->

:::definition[Relative entropy (KL divergence)]{#kl-divergence}
For discrete distributions $p$ and $q$ (with $p$ absolutely continuous with respect to $q$),

$$D_{KL}(p \| q) = \sum_x p(x) \log_2 \frac{p(x)}{q(x)} = \mathbb{E}_{x\sim p}\Bigl[\log_2 \frac{p(x)}{q(x)}\Bigr].$$

When the support of $p$ is not contained in that of $q$ the divergence is defined to be $+\infty$.
:::

:::intuition
Imagine you designed a compression code assuming the world follows q. If the world actually follows p, on average you waste D(p||q) extra bits per symbol.

It is the penalty you pay for using the wrong model.
:::

:::example
Let $p$ be Bernoulli$(0.9)$ (the true source) and $q$ be Bernoulli$(0.5)$ (the model you coded for).
:::

:::solution
apply the definition term by term:

$$D(p\|q) = 0.9\,\log_2\frac{0.9}{0.5} + 0.1\,\log_2\frac{0.1}{0.5} = 0.9\,\log_2(1.8) + 0.1\,\log_2(0.2).$$

evaluate the logs: $\log_2(1.8)\approx 0.848$ and $\log_2(0.2)\approx -2.322$.

combine: $D(p\|q) \approx 0.9(0.848) + 0.1(-2.322) = 0.763 - 0.232 = 0.531$ bits.

Interpretation: using fair-coin code lengths on biased-coin data wastes about half a bit per flip on average. Sanity check: $D \ge 0$ (it is), and since $p \ne q$ it is strictly positive, as Gibbs' inequality requires.
:::

## Interpretation as Surprise or Inefficiency

<!-- section: interpretation-kl -->

:::definition[Cross-entropy]{#cross-entropy}
The cross-entropy of $p$ relative to $q$ is

$$H(p,q) = -\sum_x p(x)\log_2 q(x),$$

the average code length when the code lengths are $-\log_2 q(x)$ but the data are drawn from $p$.
:::

:::proposition[KL divergence is excess code length]{#kl-excess-length}
$$D(p\|q) = H(p,q) - H(p).$$
:::

In words: divergence is cross-entropy minus entropy, the extra nats or bits you spend when coding with $q$ instead of the true $p$-optimal code. It is also the expected log-likelihood ratio under $p$.

:::intuition
Cross-entropy is the average number of bits you actually use when your code lengths are -log q. Subtract the true entropy and you get the waste.

In hypothesis testing it is the expected log odds in favor of the true hypothesis when data are from p.
:::

:::example
Suppose true p has entropy 0.469 bits (the biased coin). The cross-entropy when using q=0.5 is 1 bit (because -log2(0.5)=1 for every outcome). Waste = 1 - 0.469 = 0.531 bits, matching D(p||q).
:::

## Properties and Use in Information Theory

<!-- section: properties-uses -->

:::theorem[Gibbs' inequality]{#gibbs-inequality}
For any distributions $p$ and $q$ on the same alphabet,

$$D(p\|q) \ge 0,$$

with equality if and only if $p = q$ almost everywhere.
:::

:::proof
Write $-D(p\|q) = \mathbb{E}_{p}\bigl[\log_2 \tfrac{q(X)}{p(X)}\bigr]$. The logarithm is concave, so Jensen's inequality moves the expectation inside:

$$\mathbb{E}_{p}\Bigl[\log_2 \frac{q(X)}{p(X)}\Bigr] \le \log_2 \mathbb{E}_{p}\Bigl[\frac{q(X)}{p(X)}\Bigr] = \log_2 \sum_{x\,:\,p(x)>0} q(x) \le \log_2 1 = 0.$$

Hence $D(p\|q) \ge 0$. Because the logarithm is strictly concave, the first inequality is tight only when the ratio $q(x)/p(x)$ is constant, and the second only when $q$ puts no mass outside the support of $p$; together these force $p = q$.
:::

Divergence is emphatically not symmetric: $D(p\|q) \neq D(q\|p)$ in general, though it is jointly convex in the pair $(p,q)$. Its most important structural role is that it contains mutual information as a special case.

:::proposition[Mutual information as a divergence]{#mi-as-kl}
$$I(X;Y) = D\bigl(p(x,y) \,\big\|\, p(x)p(y)\bigr),$$

so mutual information is the KL divergence between the joint distribution and the product of the marginals.
:::

In rate-distortion and channel coding, many optimal quantities are characterized via KL minimizations or projections.

:::intuition
The "distance" from p to q is different from q to p because the expectation is taken under different measures.

Mutual information is exactly how far the joint is from independence (the product measure) in KL.
:::

:::example[(mutual information as a KL divergence):]
Take two correlated bits with joint pmf $p(0,0)=p(1,1)=0.4$ and $p(0,1)=p(1,0)=0.1$.
:::

:::solution
marginals: $P(X{=}0)=0.4+0.1=0.5$ and likewise $P(X{=}1)=0.5$; similarly for $Y$. So the product-of-marginals distribution assigns $0.25$ to each of the four cells.

compute $D(p_{X,Y}\,\|\,p_X p_Y) = \sum_{x,y} p(x,y)\log_2\frac{p(x,y)}{p_X(x)p_Y(y)}$:

$$= 2(0.4)\log_2\frac{0.4}{0.25} + 2(0.1)\log_2\frac{0.1}{0.25} = 0.8\log_2(1.6) + 0.2\log_2(0.4) \approx 0.8(0.678) + 0.2(-1.322) \approx 0.278 \text{ bits}.$$

cross-check via entropies. $H(X)=H(Y)=1$ bit, and $H(X,Y) = -2(0.4)\log_2 0.4 - 2(0.1)\log_2 0.1 \approx 1.722$ bits, so $I(X;Y) = H(X)+H(Y)-H(X,Y) \approx 2 - 1.722 = 0.278$ bits. The two routes agree, confirming $I(X;Y) = D(p_{X,Y}\,\|\,p_X p_Y)$: mutual information measures exactly how far the joint "sticks out" from independence. When $X,Y$ are independent the joint equals the product and this KL — hence $I$ — is $0$.
:::

## Common Mistakes

- **Treating KL as a symmetric distance**: D(p||q) is directed; the "cost" of approximating p by q is not the same as approximating q by p.
- **Ignoring infinite KL when supports mismatch**: If your model q assigns zero probability to something that can happen under p, D(p||q)=∞ and maximum-likelihood will be ill-behaved.
- **Using KL when total variation or other distances would be more natural**: KL is sensitive to tails and has information-theoretic meaning; sometimes Hellinger or TV distance is preferable for pure approximation.
- **Confusing D(p||q) with H(p) - H(q)**: The difference of entropies is unrelated in general; KL involves the cross term.
- **Forgetting that the expectation is under p**: The weights are p(x), not q(x); this is why it is not symmetric.
- **Applying the discrete formula directly to continuous densities without care**: For continuous variables the KL involves the densities and can be negative for differential entropy terms, but the divergence itself remains non-negative.

For a single random variable, entropy tells the uncertainty per draw. For a stochastic process that generates a sequence X₁, X₂, X₃, … the right quantity is the entropy *rate* — the average information per symbol in the long run.

This is the quantity that actually governs the compressibility of long files, the capacity of channels with memory, and the fundamental limits for sources with temporal structure (speech, video, text, DNA).

## Definition of Entropy Rate

<!-- section: definition-entropy-rate -->

:::definition[Entropy rate]{#entropy-rate}
The entropy rate of a discrete-time stochastic process is defined (when the limit exists) as

$$h = \lim_{n\to\infty} \frac{1}{n} H(X_1, X_2, \dots , X_n).$$
:::

The definition averages the whole block. For stationary processes there is an equivalent expression that looks only one symbol ahead:

$$h = \lim_{n\to\infty} H(X_n \mid X_1, \dots, X_{n-1}).$$

The two agree for stationary processes, and the second is usually the one you can actually compute, because it only needs the conditional law of the next symbol given the past.

:::intuition
Imagine writing a very long book. The total number of bits needed to describe the whole book divided by the number of letters (or words) approaches the entropy rate.

Early symbols may be surprising; after many symbols the next one becomes more predictable on average.
:::

:::example
An i.i.d. source with per-symbol entropy $H=2$ bits.
:::

:::solution
1. independence lets the joint entropy split additively: $H(X_1,\dots,X_n) = \sum_{i=1}^{n} H(X_i) = nH = 2n$ bits.
2. divide by $n$: $\tfrac1n H(X_1,\dots,X_n) = \tfrac{2n}{n} = 2$ exactly, for every $n$.
3. take the limit: the sequence is constant at $2$, so $h = 2$ bits per symbol. For i.i.d. sources the rate is reached at every block length, not merely in the limit — there is no benefit from block coding beyond single symbols.
:::

## Properties for Different Processes

<!-- section: properties-processes -->

:::proposition[Entropy rate of standard processes]{#entropy-rate-properties}
For an i.i.d. process the rate is the single-symbol entropy, $h = H(X)$. For a stationary Markov process of order $k$,

$$h = H(X_n \mid X_{n-k}, \dots, X_{n-1}),$$

the entropy of the next symbol given the last $k$ symbols. In all cases the rate is at most the marginal entropy, $h \le H(X_i)$.
:::

For ergodic stationary processes the limit exists and equals the almost-sure limit of $\tfrac1n \log \tfrac{1}{p(X_1 \dots X_n)}$ for typical sequences — the link to the asymptotic equipartition property taken up below.

:::intuition
Memoryless sources have rate equal to ordinary entropy.

Sources with strong memory (repetitive patterns, grammar) have much lower rate than their single-symbol entropy suggests.
:::

:::example
A binary Markov chain that stays in its current state with probability $0.9$ and flips with probability $0.1$ (symmetric in both states).
:::

:::solution
1. stationary distribution. By symmetry the chain spends equal time in each state, so the stationary marginal is $(\tfrac12,\tfrac12)$ and the single-symbol entropy is $H(X_i)=1$ bit.
2. conditional entropy of the next symbol given the current one. From either state, the next symbol is "stay" (prob $0.9$) or "flip" (prob $0.1$), so $H(X_{n+1}|X_n) = h(0.1) = -0.9\log_2 0.9 - 0.1\log_2 0.1 \approx 0.469$ bits.
3. for a stationary Markov chain the entropy rate equals this one-step conditional entropy: $h = H(X_{n+1}|X_n) \approx 0.469$ bits/symbol.
4. Sanity check: $h \approx 0.469 < 1 = H(X_i)$, confirming that memory (the tendency to repeat) makes the source more compressible than its marginal entropy alone would suggest.
:::

## Relation to Compression and AEP

<!-- section: asymptotic -->

:::theorem[Entropy rate is the compression limit]{#compression-limit}
The entropy rate is the fundamental limit for lossless compression of long sequences from the process: you can compress at rates arbitrarily close to $h$ bits per symbol but not below, asymptotically.
:::

The same number governs the shape of the sequence space itself.

:::theorem[Asymptotic equipartition property]{#aep}
Typical long sequences from the process have probability roughly

$$p(x_1, \dots, x_n) \approx 2^{-nh}.$$
:::

:::intuition
A good compressor for English text will achieve roughly the entropy rate (in bits per character) on long documents, not the naïve per-letter entropy.

The AEP says that almost all long realizations look "typical" and are describable with about n h bits.
:::

:::example
A file of $1{,}000{,}000$ symbols is drawn from a process with entropy rate $1.2$ bits/symbol.
:::

:::solution
1. total information: $H(\text{block}) \approx n h = 1{,}000{,}000 \times 1.2 = 1{,}200{,}000$ bits.
2. convert to bytes: $1{,}200{,}000 / 8 = 150{,}000$ bytes $= 150$ kB.
3. the source coding theorem says a good code can approach this $1.2$ Mbit target on typical files but cannot sustainably beat it. Using the naive per-symbol marginal entropy (which is $\ge h$ for a source with memory) would overestimate the needed size and miss achievable compression.
:::

## Common Mistakes

- **Using the single-symbol entropy for a source with memory**: This overestimates the true compressibility; the rate is the correct number.
- **Forgetting that the limit may not exist**: Some contrived non-stationary processes have no rate; stationarity + ergodicity guarantees existence.
- **Confusing entropy rate with the entropy of the stationary distribution**: The stationary dist gives marginal entropy; the rate accounts for the transition structure.
- **Thinking (1/n)H(X₁..Xn) is always decreasing**: It is non-increasing, but the conditional form H(X_n|past) may not be monotone.
- **Applying the i.i.d. formula when symbols are dependent**: Real sources almost always have dependence; you must model the conditional distributions.
- **Neglecting that rate is an asymptotic concept**: For short sequences the effective rate (1/n)H(block) can be noticeably higher than the limit.
