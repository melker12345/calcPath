# Statistical Inference: Estimation

Estimation is the process of using sample data to infer the value of an unknown population parameter. The two main tools are point estimates (a single best guess) and interval estimates (a range of plausible values).

The sampling distribution tells us how a statistic varies from sample to sample. Understanding it is the key to constructing valid confidence intervals.

Maximum Likelihood Estimation (MLE) provides a principled general-purpose method for finding the best-fitting parameter value given observed data.

## Sampling Distributions and Standard Error

<!-- section: sampling-distribution -->

A sampling distribution is the probability distribution of a statistic (such as $\bar{X}$) computed from all possible random samples of size $n$ from a population. It describes how the statistic varies from sample to sample.

The standard error of the mean is $SE_{\bar{X}} = \sigma/\sqrt{n}$, or estimated as $s/\sqrt{n}$ when $\sigma$ is unknown. It quantifies the precision of $\bar{X}$ as an estimator of $\mu$ — larger $n$ gives smaller $SE$ and therefore more precise estimates.

By the Central Limit Theorem, $\bar{X}$ is approximately $N(\mu, \sigma^2/n)$ for large $n$. This holds regardless of the shape of the population distribution, making normal-based inference broadly applicable.

A statistic is an unbiased estimator of a parameter $\theta$ if $E(\hat{\theta}) = \theta$. The sample mean $\bar{X}$ is unbiased for $\mu$. The sample variance $s^2$ (with $n-1$) is unbiased for $\sigma^2$.

The bias of an estimator is $\text{Bias}(\hat{\theta}) = E(\hat{\theta}) - \theta$; an unbiased estimator has zero bias. Mean Squared Error combines bias and variance into a single measure of accuracy: $\text{MSE}(\hat{\theta}) = \text{Var}(\hat{\theta}) + [\text{Bias}(\hat{\theta})]^2$. A good estimator minimises MSE — and because shrinking one term can grow the other, there is a bias-variance trade-off: a slightly biased estimator with much smaller variance can beat an unbiased one on MSE.

:::intuition
Imagine repeatedly drawing samples of size $n$ and computing the mean each time. You would get a slightly different mean every time, but they would cluster around the true $\mu$. The standard error measures how tightly they cluster. The bigger the sample, the tighter the cluster.
:::

:::example[standard error and the MSE trade-off]
A population has $\sigma = 30$. We take a sample of size $n = 36$.
:::

:::solution
1. Standard error of the mean: $SE_{\bar{X}} = \sigma/\sqrt{n} = 30/\sqrt{36} = 30/6 = 5$.
2. Now quadruple the sample to $n = 144$: $SE_{\bar{X}} = 30/\sqrt{144} = 30/12 = 2.5$. Sanity check: to halve the $SE$ we needed $4\times$ the data, matching the $\sqrt{n}$ law.
3. MSE comparison. Estimator A is unbiased with $\text{Var} = 5$, so $\text{MSE}_A = 5 + 0^2 = 5$. Estimator B has $\text{Bias} = 1$ but $\text{Var} = 2$, so $\text{MSE}_B = 2 + 1^2 = 3$.
4. Since $3 < 5$, the biased estimator B is actually more accurate on average — a concrete instance of the bias-variance trade-off.
:::

## Point Estimation and MLE

A point estimate is a single numerical value used as a best guess for a population parameter. Common examples: $\bar{x}$ estimates $\mu$; $s^2$ estimates $\sigma^2$; $\hat{p} = x/n$ estimates $p$.

Maximum Likelihood Estimation (MLE) finds the parameter value $\hat{\theta}$ that maximises the likelihood function $L(\theta) = \prod_{i=1}^n f(x_i;\theta)$ — the probability of observing the actual data, viewed as a function of $\theta$.

In practice, we maximise $\ell(\theta) = \ln L(\theta)$ (log-likelihood) instead of $L$. Because $\ln$ is strictly increasing, it has its maximum at the same $\theta$, but it turns the product into a sum that is far easier to differentiate. Set $d\ell/d\theta = 0$ and solve (checking the second derivative is negative to confirm a maximum). For a normal population, MLE gives $\hat{\mu}=\bar{x}$ and $\hat{\sigma}^2 = \frac{1}{n}\sum(x_i-\bar{x})^2$ (note: MLE uses $n$, not $n-1$, so it is slightly biased downward for $\sigma^2$).

An alternative recipe is the **method of moments**: set the population moments equal to the sample moments and solve. For example, matching $E(X)=\mu$ to $\bar{x}$ gives an estimate for $\mu$; the two methods often agree but need not.

Two properties describe how good an estimator gets as data accumulates. An estimator is **consistent** if it converges (in probability) to the true value as $n\to\infty$ — collect enough data and you home in on the truth. Among *unbiased* estimators, the one with the smallest possible variance (achieving the Cramér-Rao lower bound $\text{Var}(\hat{\theta})\geq 1/I(\theta)$, where $I(\theta)$ is the Fisher information) is the most **efficient**. MLE has excellent asymptotic behaviour on both counts: under mild regularity conditions it is consistent, asymptotically efficient, and asymptotically normal ($\sqrt{n}(\hat{\theta}_{MLE}-\theta)\to N(0,1/I(\theta))$). For large samples it is the go-to estimation method.

:::intuition
MLE asks: given the data I observed, which parameter value would have made this data most likely? It's like tuning a radio — you turn the dial until the signal is clearest. The dial setting that gives the clearest signal is your maximum likelihood estimate.
:::

:::example[deriving the MLE for a Bernoulli proportion]
Observe $n$ independent coin flips with $k$ heads (each flip is Bernoulli$(p)$). We want $\hat{p}$.
:::

:::solution
1. Likelihood: each head contributes $p$, each tail contributes $1-p$, so $L(p) = p^{k}(1-p)^{n-k}$.
2. Log-likelihood: $\ell(p) = k\ln p + (n-k)\ln(1-p)$.
3. Differentiate and set to zero: $\dfrac{d\ell}{dp} = \dfrac{k}{p} - \dfrac{n-k}{1-p} = 0$.
4. Solve: $k(1-p) = (n-k)p \Rightarrow k - kp = np - kp \Rightarrow k = np \Rightarrow \hat{p} = k/n$.
5. Sanity check: with $k=3$ heads in $n=5$ flips, $\hat{p} = 3/5 = 0.6$ — exactly the observed frequency, which is the intuitive "best guess" for a coin's bias.
:::

:::example[MLE for a Poisson rate]
Data $\{2,3,1,4,2\}$ are counts modelled as Poisson$(\lambda)$, with pmf $f(x;\lambda)=e^{-\lambda}\lambda^{x}/x!$.
:::

:::solution
1. Log-likelihood: $\ell(\lambda) = \sum_i\big(-\lambda + x_i\ln\lambda - \ln x_i!\big) = -n\lambda + \big(\textstyle\sum_i x_i\big)\ln\lambda - \sum_i\ln x_i!$.
2. Set $\dfrac{d\ell}{d\lambda} = -n + \dfrac{\sum_i x_i}{\lambda} = 0 \Rightarrow \hat{\lambda} = \dfrac{\sum_i x_i}{n} = \bar{x}$.
3. Compute: $\sum_i x_i = 2+3+1+4+2 = 12$, $n=5$, so $\hat{\lambda} = 12/5 = 2.4$.
4. Sanity check: the Poisson mean *is* $\lambda$, so estimating it by the sample mean is exactly what we would hope.
:::

## Confidence Intervals

<!-- section: confidence-intervals -->

A $100(1-\alpha)\%$ confidence interval provides a range of plausible values for an unknown parameter: $\bar{x} \pm z_{\alpha/2}\cdot SE$ for a known $\sigma$, or $\bar{x} \pm t_{\alpha/2,n-1}\cdot(s/\sqrt{n})$ when $\sigma$ is estimated.

Correct interpretation: if we were to repeat the sampling procedure many times, approximately $100(1-\alpha)\%$ of the resulting intervals would contain the true parameter. The interval either contains $\mu$ or it does not — after construction, there is no probability to speak of.

The margin of error $E = z^*\cdot SE$ determines the half-width of the interval. To achieve a desired margin of error $E$, use $n = (z^*\sigma/E)^2$.

The $t$-distribution has heavier tails than the normal and is appropriate when $\sigma$ is estimated from data. As degrees of freedom $df = n-1$ increases, the $t$-distribution converges to the standard normal. For $n \geq 30$ the difference is minimal in practice.

For a proportion $p$: $\hat{p} \pm z^*\sqrt{\hat{p}(1-\hat{p})/n}$. Valid when $n\hat{p}\geq 10$ and $n(1-\hat{p})\geq 10$.

:::intuition
A $95\%$ confidence interval is like saying: 'I used a method that catches the true value $95\%$ of the time.' It's like fishing with a net that lands fish $95\%$ of the time. This particular net either caught the fish or didn't — the $95\%$ refers to the reliability of the net, not this specific cast.
:::

:::example[95% t-interval for a mean]
$\bar{x}=52$, $s=8$, $n=16$. Construct a $95\%$ CI.
:::

:::solution
1. Check conditions: $\sigma$ is unknown (we only have $s$) and $n$ is small, so we use the $t$-distribution with $df=n-1=15$.
2. $SE = s/\sqrt{n} = 8/\sqrt{16} = 8/4 = 2$.
3. $t^*_{0.025,15} = 2.131$ (from $t$-table with $df=15$).
4. CI: $52 \pm 2.131(2) = 52 \pm 4.262 = (47.74,\; 56.26)$.
5. Interpretation: we are $95\%$ confident the true population mean falls between $47.74$ and $56.26$.
:::

:::example[95% CI for a proportion]
A poll finds $\hat{p}=0.6$ in a sample of $n=100$. Construct a $95\%$ CI for $p$.
:::

:::solution
1. Check conditions: $n\hat{p} = 100(0.6) = 60 \geq 10$ and $n(1-\hat{p}) = 100(0.4) = 40 \geq 10$, so the normal approximation is valid.
2. $SE = \sqrt{\hat{p}(1-\hat{p})/n} = \sqrt{0.6(0.4)/100} = \sqrt{0.0024} \approx 0.049$.
3. Margin of error: $E = z^*\cdot SE = 1.96(0.049) \approx 0.096$.
4. CI: $0.6 \pm 0.096 = (0.504,\; 0.696)$.
5. Sanity check: the whole interval lies above $0.5$, so we can be $95\%$ confident of a genuine majority.
:::

:::example[sample size for a target margin of error]
We want a $95\%$ CI for a mean with margin of error $E \leq 3$, and we believe $\sigma = 15$.
:::

:::solution
1. Rearrange $E = z^*\sigma/\sqrt{n}$ to solve for $n$: $n = (z^*\sigma/E)^2$.
2. Substitute: $n = (1.96\times 15/3)^2 = (9.8)^2 = 96.04$.
3. Always round *up* (rounding down would exceed the target margin): $n = 97$.
4. Sanity check: with $n=97$, $SE = 15/\sqrt{97}\approx 1.523$ and $E = 1.96(1.523)\approx 2.99 \leq 3$. ✓
:::

## Type I and Type II Errors

<!-- section: errors -->

A Type I error (false positive, size $\alpha$) occurs when $H_0$ is true but we reject it. We control this by choosing $\alpha$ before testing.

A Type II error (false negative, probability $\beta$) occurs when $H_0$ is false but we fail to reject it. Power $= 1-\beta$ is the probability of correctly detecting a real effect.

Factors that increase power: larger sample size $n$ (reduces $SE$, making it easier to detect real differences); larger true effect size (bigger signal); larger $\alpha$ (less strict rejection criterion); smaller $\sigma$ (less variability).

Sample size planning: choose $n$ to achieve a desired power (typically $80\%$ or $90\%$) at a specified effect size and significance level $\alpha$.

:::intuition
Type I error: you shout 'fire!' when there is no fire (false alarm). Type II error: there is a fire but you say nothing (miss). To reduce false alarms, raise the bar for shouting fire ($\alpha$ gets smaller) — but then you will miss more real fires. Only collecting more information (larger $n$) reduces both simultaneously.
:::

:::example[reading the two error rates from a decision table]
Suppose a test is run at $\alpha = 0.05$ and, for a specific alternative, has power $= 0.80$.
:::

:::solution
1. $\alpha = 0.05$ is the Type I error rate: if $H_0$ is in fact true, there is a $5\%$ chance we wrongly reject it.
2. $\beta = 1 - \text{power} = 1 - 0.80 = 0.20$ is the Type II error rate: if $H_0$ is in fact false (at that effect size), there is a $20\%$ chance we fail to detect it.
3. Now suppose we tighten to $\alpha = 0.01$ to cut false positives. With everything else fixed the rejection region shrinks, so real effects are harder to detect: $\beta$ rises and power falls below $0.80$.
4. Sanity check: $\alpha$ and $\beta$ move in opposite directions when only the threshold changes; the one lever that lowers *both* is increasing $n$.
:::

## Practical vs. Statistical Significance

<!-- section: p-value -->

Statistical significance ($p \leq \alpha$) means the data is unlikely under $H_0$. Practical significance means the effect is large enough to matter in the real world. These are independent: large samples make tiny effects statistically significant; small samples may miss large effects.

Effect size measures the magnitude of an effect independently of sample size. Cohen's $d = (\bar{x}-\mu_0)/s$ for means; $r$ or $r^2$ for correlations; odds ratio for proportions. Always report effect size alongside $p$-values.

Confidence intervals are more informative than $p$-values alone: they show both the direction, magnitude, and uncertainty of an estimate — not merely a binary decision.

:::intuition
With a huge sample, even a change of $0.001$ degrees in temperature becomes 'statistically significant' — but nobody cares about $0.001$ degrees. Statistical significance just means 'the data is very unlikely under $H_0$.' Practical significance asks the more important question: 'Does this actually matter?'
:::

:::example[significant but trivial (Cohen's $d$)]
A study of $n = 40{,}000$ finds $\bar{x} = 100.2$ against $H_0: \mu_0 = 100$, with $s = 15$.
:::

:::solution
1. Test statistic: $SE = s/\sqrt{n} = 15/\sqrt{40000} = 15/200 = 0.075$, so $z = (\bar{x}-\mu_0)/SE = 0.2/0.075 \approx 2.67$, giving $p \approx 0.008 < 0.05$ — statistically significant.
2. Effect size: $d = (\bar{x}-\mu_0)/s = 0.2/15 \approx 0.013$. This is a *tiny* effect (Cohen's benchmarks: $0.2$ small, $0.5$ medium, $0.8$ large).
3. Sanity check: unlike the $z$-statistic, $d$ has no $\sqrt{n}$ in it, so it does not grow with sample size. The effect is negligible whatever $n$ is, even though the large sample pushed $p$ below $0.05$. Report both: "significant, but the effect is negligible."
:::

## Common Mistakes

- Interpreting a $95\%$ CI as '$95\%$ probability the parameter is inside.' The parameter is fixed. The randomness is in the interval.
- Confusing 'fail to reject $H_0$' with 'accept $H_0$.' Failing to reject only means evidence is insufficient — it is not proof of $H_0$.
- Using a $z$-interval when $\sigma$ is unknown and $n$ is small. Use the $t$-interval with $n-1$ degrees of freedom.
- Ignoring effect size and reporting only the $p$-value. A small $p$-value with a trivially small effect size is not a scientifically important finding.
- Claiming $p = 0.049$ is strong evidence and $p = 0.051$ is no evidence at all. The $p$-value is a continuous measure of evidence, not a binary threshold.
