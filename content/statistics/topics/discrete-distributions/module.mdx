# Discrete Probability Distributions

A discrete probability distribution assigns probabilities to a countable set of outcomes. The binomial and Poisson distributions model the most common real-world counting processes.

The foundation is the random variable: a function that assigns a number to each outcome. Expected value and variance summarize its center and spread.

Mastering discrete distributions is the first step toward understanding statistical inference — all confidence intervals and hypothesis tests are built on distributional assumptions.

## Random Variables and Expected Value

<!-- section: expected-value -->

A random variable $X$ is a function from the sample space to the real numbers. Discrete random variables take a countable set of values (integers, fractions). Continuous random variables take any value in an interval.

The probability mass function (PMF) of a discrete $X$ gives $P(X=x_i)$ for each possible value. The PMF must satisfy $P(X=x_i)\geq 0$ and $\sum_i P(X=x_i) = 1$.

The expected value (population mean) is $\mu = E(X) = \sum_i x_i P(X=x_i)$. It is the long-run average over infinitely many independent repetitions. It does not need to be a possible value of $X$ — a fair die has $E(X)=3.5$.

The variance of $X$ is $\sigma^2 = \text{Var}(X) = E[(X-\mu)^2] = E(X^2)-[E(X)]^2$. The standard deviation $\sigma = \sqrt{\text{Var}(X)}$ is in the same units as $X$.

Key properties: $E(aX+b)=aE(X)+b$, $\text{Var}(aX+b) = a^2\text{Var}(X)$. For independent variables: $E(X+Y)=E(X)+E(Y)$ always, and $\text{Var}(X+Y)=\text{Var}(X)+\text{Var}(Y)$ only when $X$ and $Y$ are independent.

:::intuition
The expected value is what you would get on average if you played the game an enormous number of times. Roll a fair die a million times and the average will be very close to $3.5$, even though $3.5$ is never an actual outcome. It's the 'gravity center' of the distribution.

Variance measures how unpredictable the outcomes are. Low variance means the outcomes cluster tightly around the mean. High variance means you get wildly different outcomes each time.
:::

:::example[Expected value and variance of a PMF]
A game pays \$10 with probability $0.1$, \$5 with probability $0.3$, and -\$2 with probability $0.6$.
:::

:::solution
1. First check the PMF is valid: the probabilities are all $\geq 0$ and $0.1+0.3+0.6 = 1$ ✓.
2. $E(X) = 10(0.1)+5(0.3)+(-2)(0.6) = 1+1.5-1.2 = 1.3$.
3. For the variance, use $\text{Var}(X)=E(X^2)-[E(X)]^2$, which is usually less error-prone than the definition $E[(X-\mu)^2]$.
4. $E(X^2) = 100(0.1)+25(0.3)+4(0.6) = 10+7.5+2.4 = 19.9$.
5. $\text{Var}(X) = 19.9 - 1.3^2 = 19.9-1.69 = 18.21$. $\sigma = \sqrt{18.21}\approx 4.27$.
6. Sanity check: the spread of payouts runs from $-2$ to $10$, so a standard deviation of about $4.3$ is a believable "typical distance from $1.3$".
:::

:::example[Transforming a random variable]
Let $X$ be the roll of a fair die, so $E(X)=3.5$ and (computing $E(X^2)=\tfrac{1}{6}(1+4+9+16+25+36)=\tfrac{91}{6}$) $\text{Var}(X)=\tfrac{91}{6}-3.5^2 = 15.1\overline{6}-12.25 \approx 2.917$.
:::

:::solution
1. A game pays $Y = 2X + 1$ dollars. Find $E(Y)$ and $\text{Var}(Y)$.
2. Using $E(aX+b)=aE(X)+b$: $E(Y)=2(3.5)+1 = 8$.
3. Using $\text{Var}(aX+b)=a^2\text{Var}(X)$ (the $+b$ shift does not change spread): $\text{Var}(Y)=2^2(2.917) \approx 11.67$.
4. Sanity check: doubling the payout doubles the mean-plus-constant and multiplies the variance by $2^2=4$, not by $2$ — spread scales with the *square* of the multiplier.
:::

## The Binomial Distribution

<!-- section: binomial -->

The binomial distribution models the number of successes $X$ in exactly $n$ independent trials, each with the same success probability $p$. It arises in coin flips, quality control, clinical trials, and polling.

Requirements (BINS): Binary outcomes only, Independent trials, Number of trials $n$ is fixed in advance, Same probability $p$ for each trial.

PMF: $P(X=k) = \binom{n}{k}p^k(1-p)^{n-k}$, for $k=0,1,\ldots,n$. The $\binom{n}{k}$ term counts the number of ways to arrange exactly $k$ successes among $n$ trials.

Mean: $\mu = np$. Standard deviation: $\sigma = \sqrt{np(1-p)}$. When $p=0.5$ the distribution is symmetric; when $p\neq 0.5$ it is skewed toward $0$ (if $p<0.5$) or toward $n$ (if $p>0.5$).

Cumulative probabilities $P(X\leq k)$ are computed by summing the PMF or using tables/software. For $P(X\geq k)$, use the complement: $1-P(X\leq k-1)$.

:::intuition
The binomial distribution counts 'how many times did I succeed out of $n$ tries?' Each try is a coin flip — it either works or it doesn't, with the same probability each time. The binomial formula accounts for all the different orders in which those successes could have occurred.
:::

:::example[Binomial probability — exactly $k$ successes]
A fair coin is flipped $5$ times. Find $P(X=3)$.
:::

:::solution
1. Check BINS: two outcomes (H/T), independent flips, $n=5$ fixed, $p=0.5$ constant ✓ — the binomial applies.
2. $\binom{5}{3} = 10$, $p = 0.5$, $1-p=0.5$.
3. $P(X=3) = 10\cdot(0.5)^3\cdot(0.5)^2 = 10\cdot 0.125\cdot 0.25 = 0.3125$.
4. Also: $\mu=5(0.5)=2.5$, $\sigma=\sqrt{5(0.5)(0.5)}=\sqrt{1.25}\approx 1.12$.
:::

:::example[A cumulative probability with the complement]
For $X\sim B(6,0.3)$, find $P(X\geq 2)$ — the chance of at least two successes.
:::

:::solution
1. Summing $P(X=2)+P(X=3)+\cdots+P(X=6)$ is five terms; the complement $P(X\geq 2)=1-P(X=0)-P(X=1)$ is only two, so use that.
2. $P(X=0)=\binom{6}{0}(0.3)^0(0.7)^6 = (0.7)^6 \approx 0.1176$.
3. $P(X=1)=\binom{6}{1}(0.3)^1(0.7)^5 = 6(0.3)(0.16807) \approx 0.3025$.
4. $P(X\geq 2) = 1 - 0.1176 - 0.3025 = 0.5799$.
5. Sanity check: the mean is $\mu=np=1.8$, so "at least $2$" straddles the mean and a probability near $0.58$ is reasonable.
:::

## The Poisson Distribution

<!-- section: poisson -->

The Poisson distribution models the count of independent events in a fixed interval of time, area, or volume, when events occur at a constant average rate $\lambda > 0$.

PMF: $P(X=k) = e^{-\lambda}\lambda^k/k!$, for $k=0,1,2,\ldots$. The Poisson distribution has no upper bound — in principle any count is possible.

Both the mean and variance equal $\lambda$: $E(X)=\text{Var}(X)=\lambda$. A Poisson random variable is characterised entirely by $\lambda$.

Typical applications: calls arriving at a call centre per hour, photons hitting a detector per second, mutations in a DNA sequence per million base pairs, accidents at an intersection per month.

Poisson as a limit of the binomial: when $n$ is large, $p$ is small, and $np=\lambda$ is moderate, the binomial $B(n,p)$ is well-approximated by Poisson($\lambda$). This is the rare-event approximation.

:::intuition
The Poisson distribution answers: 'how many times will a rare event happen in a fixed window?' If buses arrive randomly at a rate of $3$ per hour, the Poisson($3$) distribution gives you the probability of seeing $0, 1, 2, 3, \ldots$ buses in the next hour.
:::

:::example[Poisson probability]
Emails arrive at rate $\lambda=4$ per hour. Find $P(X=2)$ — exactly $2$ emails in one hour.
:::

:::solution
1. $P(X=2) = e^{-4}\cdot 4^2/2! = e^{-4}\cdot 16/2 = 8e^{-4} \approx 8(0.01832) \approx 0.147$.
2. Also: $P(X=0) = e^{-4}\approx 0.018$. There is only a $1.8\%$ chance of zero emails.
:::

:::example["At least one" via the complement]
Accidents occur at $\lambda=2$ per week. Find $P(X\geq 1)$ in a given week.
:::

:::solution
1. "At least one" spans infinitely many counts ($1,2,3,\ldots$), but its complement is the single term $P(X=0)$, so compute $P(X\geq 1)=1-P(X=0)$.
2. $P(X=0)=e^{-2}\cdot 2^0/0! = e^{-2} \approx 0.1353$.
3. $P(X\geq 1) = 1 - 0.1353 = 0.8647$.
4. Sanity check: with an average of $2$ events per week, a week with zero events should be uncommon, so a large value like $0.86$ is expected.
:::

:::example[Poisson approximation to the binomial]
A part is defective with probability $p=0.03$; a lot has $n=100$ parts. Approximate $P(X=0)$ (no defectives).
:::

:::solution
1. Here $n$ is large and $p$ is small, so set $\lambda = np = 100(0.03) = 3$ and treat $X$ as approximately Poisson($3$).
2. $P(X=0) \approx e^{-3} \approx 0.0498$.
3. Sanity check against the exact binomial: $P(X=0)=(1-0.03)^{100}=(0.97)^{100} \approx 0.0476$. The Poisson value $0.0498$ is within about $0.002$ — a good approximation, and far quicker than the exact power.
:::

## The Geometric and Negative Binomial Distributions

<!-- section: geometric -->

The geometric distribution models the number of independent trials until (and including) the first success, where each trial succeeds with the same probability $p$, $0 < p \le 1$. Its PMF is $P(X=k) = (1-p)^{k-1}p$ for $k = 1, 2, 3, \ldots$ — the formula reads as "$k-1$ failures, then a success". The mean is $1/p$ and the variance is $(1-p)/p^2$. The geometric distribution is memoryless: $P(X>m+n \mid X>m) = P(X>n)$, meaning past failures give no information about how many more trials you will need.

The negative binomial distribution generalises the geometric: it counts the number of trials needed to achieve exactly $r$ successes (the geometric is the $r=1$ case). Its mean is $r/p$ and its variance is $r(1-p)/p^2$. Its PMF is $P(X=k) = \binom{k-1}{r-1}(1-p)^{k-r}p^{r}$ for $k = r, r+1, \ldots$: the last trial must be a success, and the remaining $r-1$ successes fall anywhere among the first $k-1$ trials.

The hypergeometric distribution models sampling without replacement from a finite population of size $N$ containing $K$ "successes". Drawing $n$ items, $P(X=k) = \binom{K}{k}\binom{N-K}{n-k}\big/\binom{N}{n}$. Use it when the population is small enough that each draw changes the remaining probabilities — for example, selecting $5$ cards from a deck without replacing them. (When $N$ is large relative to $n$, the draws are nearly independent and the binomial is a good approximation.)

:::intuition
The geometric distribution answers: 'how many times do I have to try until I succeed?' If each attempt has a $20\%$ success rate, the geometric distribution tells you the probabilities of succeeding on the first try, second try, third try, and so on. Memorylessness is like a fair slot machine: it does not "owe" you a win no matter how long you have been losing — the odds reset with every pull.
:::

:::example[Geometric probability, mean, and variance]
A basketball player sinks each free throw independently with probability $p=0.25$. Let $X$ be the shot number of her first make. Find $P(X=3)$, the mean, and the variance.
:::

:::solution
1. $P(X=3) = (1-p)^{3-1}p = (0.75)^2(0.25) = 0.5625 \times 0.25 = 0.140625$ — two misses, then a make.
2. Mean: $E(X) = 1/p = 1/0.25 = 4$. On average it takes $4$ shots to get the first make.
3. Variance: $\text{Var}(X) = (1-p)/p^2 = 0.75/0.0625 = 12$.
4. Sanity check: $P(X>3) = (1-p)^3 = 0.75^3 \approx 0.422$, so there is still a $42\%$ chance the first make has not happened by the third shot — consistent with a mean of $4$.
:::

:::example[Negative binomial]
Using the same shooter ($p=0.5$ now, for a cleaner number), let $X$ be the shot on which she records her $r=3$rd make. Find $P(X=5)$.
:::

:::solution
1. The 5th shot must be the 3rd make, and exactly $2$ of the first $4$ shots are makes: $P(X=5) = \binom{4}{2}(0.5)^{2}(0.5)^{3} = 6(0.25)(0.125) = 0.1875$.
2. Check the mean: $E(X) = r/p = 3/0.5 = 6$, so needing exactly $5$ trials (just under the mean) being fairly likely is reasonable.
:::

## Choosing the Right Distribution

<!-- section: choosing -->

Binomial: fixed $n$ trials, each independent with probability $p$, counting the number of successes.

Poisson: counting rare, independent events in a fixed window; no upper bound on the count; mean and variance are equal.

Geometric: counting the number of trials until the first success; memoryless.

Hypergeometric: like the binomial but sampling without replacement from a finite population; used when the population is small relative to the sample.

Decision guide: if $n$ is large, $p$ is small, and $np$ is moderate, the Poisson approximation to the binomial is accurate and simpler to compute.

:::intuition
Binomial = 'I flip this coin exactly $n$ times, how many heads?' Poisson = 'Calls arrive randomly, how many in the next hour?' Geometric = 'I keep flipping until I get a head, how many flips?' Each distribution is the right tool for a specific type of counting question.
:::

:::example[Picking the distribution from the wording]
Scenario A: "A quiz has $10$ true/false questions; a student guesses each. How many does she get right?" There is a fixed number of trials ($n=10$), each independent, each with constant $p=0.5$, and you count successes → **binomial**, $B(10,0.5)$.
:::

:::solution
1. Scenario B: "A page averages $0.5$ typos. What is the chance a page has no typos?" You are counting rare events in a fixed window (one page) at a constant rate → **Poisson**, $\lambda=0.5$, giving $P(X=0)=e^{-0.5}\approx 0.607$.
2. Scenario C: "How many pages must an editor read before finding the first typo?" You are counting trials until the first success → **geometric**.
3. Scenario D: "A box holds $20$ fuses, $4$ of them defective; you grab $3$ without replacing. How many are defective?" Sampling without replacement from a small population → **hypergeometric**, not binomial, because $p$ changes after each draw.
4. The tells: *fixed count of trials* → binomial; *rate over an interval* → Poisson; *wait until first success* → geometric; *drawing from a small finite pool without replacement* → hypergeometric.
:::

## Common Mistakes

- Applying the binomial formula when trials are not independent or the sample is drawn without replacement from a small population (use hypergeometric instead).
- Forgetting that Poisson requires events to be independent and the rate to be constant — a traffic jam violates both.
- Confusing $\lambda$ (Poisson rate) with $p$ (binomial success probability). They measure different things even though both parameterise how often something happens.
- Computing $P(X \geq k)$ directly when it is easier to use $1-P(X \leq k-1)$.
- Using the binomial formula for continuous data. The binomial is for counts; for continuous data use normal or other continuous distributions.
