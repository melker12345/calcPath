# Relations and Equivalence

While sets collect objects, relations describe how objects stand to one another. The most important relations are those that behave like "equality" (equivalence relations) and those that behave like "less than or equal" (partial and total orders). These concepts underlie modular arithmetic, database normalization, sorting, topological sorting in compilers, and the ordering of tasks in project management.

A relation is simply a set of ordered pairs, yet the properties we impose on it — reflexivity, symmetry, transitivity, antisymmetry — turn it into a powerful organizational tool.

## Binary Relations

<!-- section: relations -->

A **binary relation** $R$ on a set $A$ is defined as a subset of the Cartesian product $A \times A$ (the set of all ordered pairs $(a,b)$ with $a,b \in A$). We write $a\,R\,b$ (or $(a,b) \in R$) to mean that $a$ is related to $b$. "Binary" means it relates two things at a time; because both components come from the same set $A$, we can draw the whole relation on a single picture of $A$.

- The **domain** of $R$ is the set of all first components that actually appear in some pair of $R$.
- The **range** of $R$ is the set of all second components that appear.

Relations can be represented as:
- Lists of pairs
- Directed graphs (nodes = elements of $A$, an arrow $a \to b$ exactly when $a\,R\,b$)
- $0$-$1$ matrices (rows and columns indexed by $A$, with a $1$ at position $(i,j)$ iff $i\,R\,j$)

Because a relation is *any* subset of $A \times A$, and $|A \times A| = |A|^2$, a set with $n$ elements has $2^{(n^2)}$ possible relations on it — for example, $n = 3$ gives $2^9 = 512$.

Examples: "is parent of", "is greater than", "divides", "is congruent modulo $m$".

**ELI5**

- A relation is a directed "friendship" or "arrow" between members of the same club. Some people point to themselves (loops), some point one way, some both ways.
- Not every pair needs an arrow; the relation picks which connections exist.

### Worked Examples

**Worked Example:** Matrix representation of a relation.

Let $A = \{1,2,3\}$ and $R = \{(1,1),(1,2),(2,1),(3,3)\}$. We build the $3 \times 3$ matrix $M$ where the entry in row $i$, column $j$ is $1$ when $(i,j) \in R$ and $0$ otherwise.

- Row 1: $(1,1)\in R$ and $(1,2)\in R$, but $(1,3)\notin R$ → $1\ 1\ 0$.
- Row 2: $(2,1)\in R$, but $(2,2)\notin R$ and $(2,3)\notin R$ → $1\ 0\ 0$.
- Row 3: $(3,1),(3,2)\notin R$, but $(3,3)\in R$ → $0\ 0\ 1$.

$$M = \begin{pmatrix} 1 & 1 & 0 \\ 1 & 0 & 0 \\ 0 & 0 & 1 \end{pmatrix}$$

**Sanity check:** count the $1$s: there are $4$ of them ($M_{11}, M_{12}, M_{21}, M_{33}$), which matches $|R| = 4$. The diagonal is $1,0,1$, so this relation has self-loops on $1$ and $3$ but not on $2$ — it is not reflexive on all of $A$.

## Properties of Relations

<!-- section: properties -->

Important properties (for a relation R on A):

- **Reflexive**: for every a in A we have (a,a) in R. (Everyone relates to self; diagonal of matrix is all 1s.)
- **Irreflexive**: ∀a, (a,a) ∉ R. (No self-loops.)
- **Symmetric**: aRb ⇒ bRa. (Arrows come in both directions or none.)
- **Antisymmetric**: aRb and bRa ⇒ a = b. (The only two-way arrows are self-loops.)
- **Transitive**: aRb and bRc ⇒ aRc. (Arrows compose: if path of length 2 then direct arrow.)
- **Total (connected)**: for all a ≠ b, either aRb or bRa (or both).

These are independent in general; combinations produce the named classes of relations we care about.

**ELI5**

- Reflexive: "I am the same age as myself" — always true for equality-like things.
- Symmetric: "is a sibling of" — if Alice is sibling of Bob, Bob is sibling of Alice.
- Transitive: "is an ancestor of" — if A ancestor of B and B of C, then A of C.
- Antisymmetric: "is less than or equal" — if a ≤ b and b ≤ a then a must equal b.

### Worked Examples

**Worked Example:** Checking all four properties on a small relation.

Let $A = \{a,b,c\}$ and $R = \{(a,a),(b,b),(c,c),(a,b),(b,a),(a,c)\}$. To test each property we scan every relevant pair; a property holds only if *no* pair violates it.

- **Reflexive?** We need $(a,a),(b,b),(c,c)$ all present. All three are in $R$, so **yes**.
- **Symmetric?** For each $(x,y)\in R$ with $x\neq y$ we need $(y,x)\in R$ too. We have $(a,b)$ and its mirror $(b,a)$ ✓, but $(a,c)\in R$ while $(c,a)\notin R$ ✗. So **no**.
- **Antisymmetric?** A violation is a pair $x\neq y$ with both $(x,y)$ and $(y,x)$ in $R$. Here $(a,b)$ and $(b,a)$ are both present with $a\neq b$, so **no**.
- **Transitive?** We need: whenever $(x,y)\in R$ and $(y,z)\in R$, then $(x,z)\in R$. Check every length-2 chain among the non-loop pairs: $(a,b)$ then $(b,a)$ requires $(a,a)$ ✓; $(b,a)$ then $(a,b)$ requires $(b,b)$ ✓; $(b,a)$ then $(a,c)$ requires $(b,c)$ — but $(b,c)\notin R$ ✗. So **no**.

**Sanity check:** notice symmetric and antisymmetric both failed here — a relation can lack both at once (they are not opposites). And the single missing pair $(b,c)$ is what breaks transitivity, showing how one absent arrow can spoil a property.

## Equivalence Relations

<!-- section: equivalence -->

An **equivalence relation** is one that satisfies reflexivity, symmetry, and transitivity all at once.

It captures the idea of "being the same in some respect" or "indistinguishable for our purposes".

Famous examples:
- Equality itself.
- Congruence modulo m: a ≡ b (mod m) iff m divides (a-b).
- "Has the same birthday" on people (assuming no leap issues).
- "Is the same connected component" in a graph.

**ELI5**

- Equivalence is "sameness" that is consistent: if I'm the same type as you, you're the same as me (sym), I'm same as myself (refl), and if you're same as her then I am too (trans).
- It lets us treat whole groups as single "super elements".

### Worked Examples

**Worked Example:** Verifying congruence mod 3 is an equivalence relation.

On the integers $\mathbb{Z}$, define $a \sim b$ iff $3 \mid (a-b)$ (read "$3$ divides $a-b$", i.e. $a-b = 3k$ for some integer $k$). We check all three defining properties.

- **Reflexive:** for any $a$, $a - a = 0 = 3\cdot 0$, so $3 \mid (a-a)$. Thus $a \sim a$ ✓.
- **Symmetric:** if $a \sim b$ then $a - b = 3k$ for some integer $k$. Then $b - a = -(a-b) = 3(-k)$, and $-k$ is an integer, so $3 \mid (b-a)$, giving $b \sim a$ ✓.
- **Transitive:** if $a \sim b$ and $b \sim c$ then $a - b = 3k$ and $b - c = 3m$ for integers $k,m$. Adding, $a - c = (a-b)+(b-c) = 3k + 3m = 3(k+m)$, and $k+m$ is an integer, so $3 \mid (a-c)$, giving $a \sim c$ ✓.

All three hold, so $\sim$ is an equivalence relation.

**Sanity check with numbers:** $7 \sim 1$ because $7 - 1 = 6 = 3 \cdot 2$; and $1 \sim 4$ because $1 - 4 = -3 = 3\cdot(-1)$; transitivity then predicts $7 \sim 4$, and indeed $7 - 4 = 3 = 3\cdot 1$ ✓. The distinct classes are $[0], [1], [2]$, where $[k] = \{\, n \in \mathbb{Z} \mid n \equiv k \pmod 3 \,\}$ — every integer lands in exactly one of these three.

## Equivalence Classes and Partitions

<!-- section: partitions -->

Given equivalence relation ~ on A, the **equivalence class** of a is [a] = {b ∈ A | b ~ a}.

Key facts:
- Every element belongs to exactly one class (its own).
- Classes are either equal or disjoint.
- The set of all distinct equivalence classes forms a **partition** of A: the blocks are nonempty, pairwise disjoint, and cover A.

Conversely, every partition of A defines an equivalence relation: a ~ b iff a and b are in the same block of the partition.

The set of equivalence classes is called the **quotient set** A / ~ .

**ELI5**

- Each equivalence class is a "bucket" or "team". Everyone in a bucket is equivalent; different buckets are distinct.
- The buckets cover the whole group and don't overlap — a clean division of the club into teams.

### Worked Examples

**Worked Example:** Building the partition from an equivalence relation on a finite set.

Take $A = \{0,1,2,3,4,5\}$ with $a \sim b$ iff $a \equiv b \pmod 3$. To find the classes, compute each element's remainder mod $3$ and group equal remainders:

- Remainder $0$: $0$ and $3$ → $[0] = \{0,3\}$.
- Remainder $1$: $1$ and $4$ → $[1] = \{1,4\}$.
- Remainder $2$: $2$ and $5$ → $[2] = \{2,5\}$.

So there are $3$ distinct classes: $\{0,3\},\ \{1,4\},\ \{2,5\}$.

**Sanity check that this is a partition:** each block is nonempty ✓; the blocks are pairwise disjoint (no element appears twice) ✓; their union is $\{0,1,2,3,4,5\} = A$ ✓. The sizes add up: $2+2+2 = 6 = |A|$. Going the other direction, if you were *handed* the partition $\{\{0,3\},\{1,4\},\{2,5\}\}$, defining "$a \sim b$ iff $a,b$ lie in the same block" recovers exactly this relation — this is the two-way correspondence between partitions and equivalence relations.

## Partial Orders and Posets

<!-- section: partial-orders -->

A **partial order** (or poset) is a relation satisfying reflexivity, antisymmetry, and transitivity.

We often write ≤ or | (divides) or ⊆ .

Not every pair of elements needs to be comparable. When a and b have neither a ≤ b nor b ≤ a they are **incomparable**.

Examples:
- Subset inclusion on the power set of any set.
- Divisibility on positive integers (1 divides everything; primes are minimal above 1).
- "Is a prerequisite for" on university courses (some courses have no prereq relation either way).
- Task dependency graphs in project management (DAGs induce posets).

A **poset** is a set equipped with a partial order.

**ELI5**

- Partial order is "can be lined up some but not all ways". Some people are taller than others, but two people of same height are equal; two unrelated people may not have height order in our data.
- "Divides" : 2 divides 8, 4 divides 8, but 3 and 4 are incomparable under divides.

### Worked Examples

**Worked Example:** Verifying a poset and reading its Hasse diagram.

Order the power set of $\{1,2\}$ — that is, $\{\emptyset, \{1\}, \{2\}, \{1,2\}\}$ — by subset inclusion $\subseteq$. First confirm $\subseteq$ is a partial order:

- **Reflexive:** every set satisfies $S \subseteq S$ ✓.
- **Antisymmetric:** if $S \subseteq T$ and $T \subseteq S$, then $S$ and $T$ have exactly the same elements, so $S = T$ ✓.
- **Transitive:** if $S \subseteq T$ and $T \subseteq U$, then every element of $S$ is in $T$, hence in $U$, so $S \subseteq U$ ✓.

All three hold, so $(\,\mathcal{P}(\{1,2\}), \subseteq\,)$ is a poset. Now list the comparabilities. $\emptyset$ is a subset of all four sets; $\{1,2\}$ is a superset of all four; $\{1\} \subseteq \{1,2\}$ and $\{2\} \subseteq \{1,2\}$. The only pair with **neither** containment is $\{1\}$ and $\{2\}$: neither is a subset of the other, so they are **incomparable**.

The Hasse diagram (which draws only *covering* relations, omitting loops and edges forced by transitivity) has three levels:

- Bottom: $\emptyset$.
- Middle: $\{1\}$ and $\{2\}$, side by side with no line between them (incomparable).
- Top: $\{1,2\}$, sitting above both.

**Sanity check:** among the $\binom{4}{2} = 6$ unordered pairs of distinct sets, exactly $5$ are comparable and $1$ (namely $\{1\}$ vs $\{2\}$) is incomparable. This is the Boolean lattice of rank $2$ — a square standing on one corner.

## Total Orders

<!-- section: total-orders -->

A **total order** (linear order, chain) is a partial order where every pair of elements is comparable (for any a, b either aRb or bRa).

Examples: the usual ordering of numbers, alphabetical order on strings, chronological order on dates.

In a total order there are no "branches": every element sits in one definite position, so the whole set can be laid out as a single line with no side-by-side incomparable pairs.

A **well-order** is a total order in which *every* nonempty subset has a least element. The natural numbers under $\le$ are well-ordered (any nonempty set of naturals has a smallest member). The integers and the reals under $\le$ are **not**: $\mathbb{Z}$ itself has no least element (you can always go more negative), and the open interval $(0,1)$ has no least element (whatever candidate you pick, half of it is smaller). Every well-order is a total order, but not conversely.

**ELI5**

- Total order is a complete ranking: first place, second, third... with no two people left "side by side with no ranking between them".
- Partial allows side-by-side incomparable items; total forces a decision on every pair.

### Worked Examples

**Worked Example:** Extending a partial order to a total order (linear extension).

Start with the poset on $\{a,b,c\}$ where $a \le b$ and $a \le c$, but $b$ and $c$ are incomparable. A **linear extension** is a total order that keeps every relation already present and adds enough new ones to make *every* pair comparable. The only undecided pair is $b$ versus $c$, so we choose an order for it:

1. Put $b$ before $c$: this gives $a \le b \le c$.
2. Put $c$ before $b$: this gives $a \le c \le b$.

Both keep $a$ below $b$ and $a$ below $c$, so both respect the original poset. (These are exactly the *topological sorts* of the Hasse diagram — the orderings a compiler or task scheduler would produce.)

**Sanity check:** why exactly two? A total order on a 3-element set is just a ranking of the three items, and there are $3! = 6$ rankings in total. The constraint "$a$ must come first" fixes the top slot, leaving $2! = 2$ ways to arrange $b$ and $c$ — matching the two extensions found above. Without any constraints, all $6$ orderings would be valid total orders.

## Common Mistakes

- Confusing symmetric with antisymmetric. "Is sibling of" is symmetric; "≤" is antisymmetric. They are almost opposites.
- Forgetting reflexivity when checking equivalence or partial orders (many students remember sym+trans but drop refl).
- Thinking every equivalence relation is equality — no, it can collapse many elements into one class (modular arithmetic).
- Believing that in a poset every pair must be comparable — that would make it total. Partial allows incomparables.
- Mixing up "partition" (the blocks) with the equivalence relation itself.
- Forgetting that antisymmetry only kicks in when both directions hold: it forces a=b, but allows one-way relations freely.
- Assuming the inverse of a relation automatically inherits the same properties (symmetry yes, transitivity no in general).
