# Sets and Functions

Sets are the most fundamental objects in mathematics. Almost everything — numbers, functions, graphs, spaces — can be defined in terms of sets. Functions describe how elements of one set are mapped to elements of another; they are the primary tool for relating different collections of objects.

In computer science, sets model collections without duplicates (e.g., hash sets), while functions model mappings, transformations, and algorithms. Understanding when a function is invertible (bijective) is crucial for encryption, data compression, and database keys.

This chapter covers the language of sets, the algebra of set operations, the precise definition of functions, and the important special classes: injections, surjections, and bijections. We finish with power sets, which are central to counting and computability.

## Sets: Definitions and Notation

<!-- section: basic-sets -->

A **set** is an unordered collection of distinct objects (elements). We write $a \in S$ to mean "a is an element of S" and $a \notin S$ otherwise. Sets are usually denoted by capital letters and listed inside curly braces: $S = \{1, 3, 5\}$.

Order does not matter and duplicates are ignored: $\{1,2,2\} = \{2,1\}$.

The **empty set** $\emptyset = \{\}$ contains no elements. It is a subset of every set.

A set $A$ is a **subset** of $B$, written $A \subseteq B$, if every element of $A$ is also in $B$. We write $A \subset B$ for proper (strict) subset when $A \neq B$. The **universal set** $U$ is the set of all objects under consideration in a given context.

Two sets are **equal** if they contain exactly the same elements: $A = B \iff A \subseteq B$ and $B \subseteq A$.

:::intuition
A set is a club with no duplicate members and no ordering of members. "Alice and Bob are in the club" is the same as "Bob and Alice are in the club".

The empty set is the club with zero members. It is still a perfectly valid club, and it is a "sub-club" of every other club.
:::

### Worked Examples

:::example[Subset checks]
Is $\{1,3\} \subseteq \{1,2,3,4\}$? Yes, both elements appear.
:::

:::solution
1. Is $\{1,5\} \subseteq \{1,2,3,4\}$? No, 5 is missing.
2. $\emptyset \subseteq \{1,2\}$? Yes, vacuously — there are no elements in the empty set that fail to be in the bigger set.
3. $\{1,2\} \subseteq \{1,2\}$? Yes (every set is a subset of itself).
:::

## Set Operations

<!-- section: operations -->

The basic operations on sets are:

- **Union**: $A \cup B = \{x \mid x \in A \text{ or } x \in B \text{ (or both)}\}$
- **Intersection**: $A \cap B = \{x \mid x \in A \text{ and } x \in B\}$
- **Set difference**: $A \setminus B = \{x \mid x \in A \text{ and } x \notin B\}$
- **Complement** (relative to universal set $U$): $A^c = U \setminus A = \{x \in U \mid x \notin A\}$

**Venn diagrams** are visual representations using overlapping circles. They make the distributive laws and De Morgan's laws for sets intuitive:

- De Morgan: $(A \cup B)^c = A^c \cap B^c$ and $(A \cap B)^c = A^c \cup B^c$

Key identities (all provable from definitions):

- $A \cup A = A$, $A \cap A = A$ (idempotent)
- $A \cup \emptyset = A$, $A \cap U = A$
- $A \cup B = B \cup A$ (commutative), likewise for $\cap$
- Distributivity: $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$
- $|A \cup B| = |A| + |B| - |A \cap B|$ (inclusion-exclusion for two sets)

:::intuition
Union is "everyone from either club" (merge the membership lists, remove duplicates).

Intersection is "people who belong to both clubs".

Difference is "members of A who are not in B".

Complement is "everyone in the universe who is not in A".
:::

### Worked Examples

:::example[Computing with small sets]
Let $A = \{1,2,3,4\}$, $B = \{3,4,5,6\}$, $U = \{1,2,3,4,5,6,7\}$.
:::

:::solution
$A \cup B = \{1,2,3,4,5,6\}$ — everything in either set, listed once.
$A \cap B = \{3,4\}$ — the elements common to both.
$A \setminus B = \{1,2\}$ — in $A$, removing anything that is also in $B$.
$B \setminus A = \{5,6\}$ — note this differs from $A \setminus B$; set difference is not symmetric.
$A^c = U \setminus A = \{5,6,7\}$ — everything in the universe $U$ outside $A$.
$|A \cup B| = |A| + |B| - |A \cap B| = 4 + 4 - 2 = 6$. We subtract $|A\cap B|$ because the shared elements $3,4$ were counted once in $|A|$ and again in $|B|$; without the correction we would double-count them.

**Sanity check.** The direct listing $A \cup B = \{1,2,3,4,5,6\}$ has $6$ elements, matching the inclusion–exclusion count of $6$. ✓
:::

:::example[Proving a set identity]
We prove distributivity of union over intersection:
$$(A \cup B) \cap (A \cup C) = A \cup (B \cap C).$$
The standard way to prove two sets are equal is to show each is a subset of the other (the definition of equality above). Here we show both inclusions at once by proving that an arbitrary $x$ is in the left side **if and only if** it is in the right side.
:::

:::solution
Take any $x$. By the definitions of $\cup$ and $\cap$:
$$x \in (A \cup B) \cap (A \cup C) \iff (x \in A \text{ or } x \in B) \text{ and } (x \in A \text{ or } x \in C).$$

Now split into two cases on whether $x \in A$:

**Case $x \in A$.** Then both "or" clauses on the left are satisfied, so $x$ is in the left side. On the right, $x \in A$ makes $x \in A \cup (B \cap C)$. Both sides hold.
**Case $x \notin A$.** Then the first clause forces $x \in B$ and the second forces $x \in C$, so $x \in B \cap C$, which puts $x \in A \cup (B \cap C)$. Conversely, if $x \notin A$ but $x \in A \cup (B \cap C)$, then $x \in B \cap C$, so $x \in B$ and $x \in C$, giving $(x \in A \text{ or } x \in B)$ and $(x \in A \text{ or } x \in C)$, i.e. $x$ is in the left side.

In every case $x$ is in the left side exactly when it is in the right side, so the two sets are equal. $\blacksquare$

**Sanity check.** Try $A=\{1\}$, $B=\{2\}$, $C=\{3\}$. Left: $(A\cup B)\cap(A\cup C) = \{1,2\}\cap\{1,3\} = \{1\}$. Right: $A\cup(B\cap C) = \{1\}\cup\emptyset = \{1\}$. They match.
:::

## Functions: Definition and Properties

<!-- section: functions -->

A **function** $f: A \to B$ (from domain A to codomain B) is a rule that assigns to every element $x \in A$ exactly one element $f(x) \in B$.

- The **image** (range) of f is $\{f(x) \mid x \in A\} \subseteq B$.
- The **preimage** of a set $C \subseteq B$ is $f^{-1}(C) = \{x \in A \mid f(x) \in C\}$.

Functions must be **total** (defined for every element of the domain) and **single-valued**.

In set theory a function is formally a set of ordered pairs $(x,y)$ with no two pairs sharing the same first component but different seconds.

:::intuition
A function is a perfect "machine" or "vending rule": drop in any input from the domain and it always spits out exactly one output in the codomain. No input left out, no input giving two different answers.

Think of $f(x) = x^2$ from reals to reals: every real goes in, a nonnegative real comes out.
:::

### Worked Examples

:::example[Checking whether a relation is a function]
Relation on $\{1,2,3\}$: pairs $(1,4), (2,4), (3,5)$. This **is** a function from $\{1,2,3\}$ to $\{4,5\}$ — each input appears as the first component of exactly one pair, so each input has exactly one output. (Two inputs sharing an output, here $1$ and $2$ both giving $4$, is allowed; that only costs injectivity, not being a function.)
:::

:::solution
1. Pairs $(1,4), (1,5), (2,3)$: **not** a function — input $1$ maps to two values, violating single-valuedness.
2. Pairs $(1,4), (2,5)$: **not** a function from $\{1,2,3\}$ because $3$ has no output, violating totality.
:::

:::example[Image and preimage]
Let $f: \{1,2,3,4\} \to \{a,b,c\}$ be given by $f(1)=a,\ f(2)=b,\ f(3)=a,\ f(4)=b$.
:::

:::solution
**Image (range).** Collect every output: $f$ produces $a$ (from $1,3$) and $b$ (from $2,4$), but never $c$. So the image is $\{a,b\}$, a *proper* subset of the codomain $\{a,b,c\}$ — the codomain is what we declared, the image is what actually gets hit.
**Preimage of a subset.** $f^{-1}(\{a\})$ is every input that lands on $a$: that is $\{1,3\}$. Note $f^{-1}$ here acts on *sets* and returns a set — it does not require $f$ to be invertible.
$f^{-1}(\{c\}) = \emptyset$, since nothing maps to $c$. A preimage can be empty.
$f^{-1}(\{a,b\}) = \{1,2,3,4\}$, the whole domain, because every input lands in $\{a,b\}$.

**Sanity check.** The preimages of the individual outputs, $\{1,3\}$ and $\{2,4\}$, are disjoint and together cover the whole domain — as they must, since every input has exactly one output.
:::

## Injective and Surjective Functions

<!-- section: injective-surjective -->

- **Injective** (one-to-one): $f(x_1) = f(x_2)$ implies $x_1 = x_2$. Different inputs give different outputs. No two arrows point to the same target.
- **Surjective** (onto): Every element of the codomain is the image of at least one element in the domain. The function "covers" the entire codomain.
- For finite sets, an injection from A to B implies $|A| \leq |B|$; a surjection implies $|A| \geq |B|$.

To test injectivity: assume $f(x_1)=f(x_2)$ and prove $x_1=x_2$ (often by algebra or contradiction).

To test surjectivity: for arbitrary $y \in B$, solve $f(x)=y$ and show a solution $x$ exists in A.

:::intuition
Injective: like a unique ID — no two people share the same fingerprint produced by the function.

Surjective: like every seat in the theater is occupied by at least one audience member mapped by "who sits where".
:::

### Worked Examples

:::example[Linear function example]
Consider $f: \mathbb{R} \to \mathbb{R}$, $f(x) = 3x + 1$. (Injectivity and surjectivity always depend on the declared domain and codomain — here both are all of $\mathbb{R}$.)
:::

:::solution
**Injective.** Suppose $f(x_1) = f(x_2)$, i.e. $3x_1 + 1 = 3x_2 + 1$. Subtract $1$: $3x_1 = 3x_2$. Divide by $3$: $x_1 = x_2$. So equal outputs force equal inputs — injective.
**Surjective.** Take an arbitrary target $y \in \mathbb{R}$ and solve $3x + 1 = y$: this gives $x = \tfrac{y-1}{3}$, which is a real number for every real $y$, and it lies in the domain $\mathbb{R}$. Check: $f\!\left(\tfrac{y-1}{3}\right) = 3\cdot\tfrac{y-1}{3} + 1 = (y-1)+1 = y$. So every $y$ is hit — surjective.
Being both, $f$ is bijective, with inverse $f^{-1}(y) = \tfrac{y-1}{3}$.
:::

:::example[Non-injective, non-surjective example]
$f: \mathbb{Z} \to \mathbb{Z}$, $f(n) = n^2$. (The domain is the integers, including negatives — this is what breaks injectivity.)
:::

:::solution
**Injective?** No. A single counterexample suffices: $f(2) = 4 = f(-2)$, yet $2 \neq -2$. Distinct inputs share an output.
**Surjective?** No. The output $y = 2$ has no integer $n$ with $n^2 = 2$ (indeed $n^2$ is never negative and never a non-square), so $2$ is in the codomain but never hit.

Note how the domain matters: restrict to $f: \mathbb{N} \to \mathbb{N}$ with $f(n)=n^2$ and it *becomes* injective (no two distinct naturals have the same square), though it is still not surjective (e.g. $2$ is still missed).
:::

## Bijective Functions and Inverses

<!-- section: bijections -->

A function is **bijective** if it is both injective and surjective. Equivalently, it has a two-sided inverse function $f^{-1}: B \to A$ such that $f(f^{-1}(y)) = y$ for all y and $f^{-1}(f(x)) = x$ for all x.

For finite sets of the same size, any injection is automatically a surjection (and vice versa) — the pigeonhole principle forces it.

Bijections establish that two sets have exactly the same "size" (cardinality), even if infinite.

:::intuition
Bijective is a perfect matching: every input has a unique output and every output is used exactly once. Like a perfect pairing of dance partners with no one left out and no one dancing with two people.

The inverse simply swaps the direction of every arrow.
:::

### Worked Examples

:::example[Showing a function is bijective]
Let $f: \mathbb{R}^+ \to \mathbb{R}^+$, $f(x) = 1/x$, on the positive reals. (We exclude $0$ deliberately: $1/x$ is undefined at $0$, so the domain must avoid it — a place where stating the domain matters.)
:::

:::solution
**Injective.** Suppose $f(x_1) = f(x_2)$, i.e. $\tfrac{1}{x_1} = \tfrac{1}{x_2}$. Cross-multiplying (valid since $x_1, x_2 > 0$ are nonzero) gives $x_2 = x_1$. Injective.
**Surjective.** Take any $y > 0$ and set $x = \tfrac{1}{y}$, which is positive, so it lies in the domain. Then $f(x) = \tfrac{1}{1/y} = y$. Every target is hit — surjective.
Being both, $f$ is bijective. Its inverse is itself: $f(f(x)) = \tfrac{1}{1/x} = x$, so $f^{-1} = f$.
:::

:::example[Finite set counting]
Any two finite sets of the same size can be put in bijection. Concretely, count the bijections from $\{1,2,3\}$ to $\{a,b,c\}$.
:::

:::solution
Building a bijection means deciding where each input goes, with **no output reused** (injectivity) so that all three outputs get used (surjectivity, forced here since the sets are the same size):

$1$ can map to any of the $3$ outputs.
$2$ must avoid whatever $1$ took, leaving $2$ choices.
$3$ must take the last remaining output, $1$ choice.

So there are $3 \times 2 \times 1 = 3! = 6$ bijections. In general there are $n!$ bijections between two $n$-element sets — exactly the number of permutations of $n$ objects. For $n=5$ this is $5! = 120$.

**Sanity check.** Listing the images of $(1,2,3)$: $(a,b,c),(a,c,b),(b,a,c),(b,c,a),(c,a,b),(c,b,a)$ — six of them, no repeats and no reused letters within a row.
:::

## Power Sets and Cardinality

<!-- section: power-sets -->

The **power set** of S, written $\mathcal{P}(S)$ or 2^S, is the set of all subsets of S.

- If S is finite with n elements, $|\mathcal{P}(S)| = 2^n$.
- This includes $\emptyset$ and S itself.
- Power sets grow extremely fast: a 10-element set has 1024 subsets; 20 elements → over a million.

For infinite sets, Cantor's theorem says $|\mathcal{P}(S)| > |S|$ always (no set is in bijection with its power set). This is the basis of the idea that there are "different sizes" of infinity.

:::intuition
The power set is "the club of all possible sub-clubs you can form from the original club members", including the empty club and the full club.

Each element can be "in or out" of a subset independently — hence 2 choices per element, 2^n total subsets.
:::

### Worked Examples

:::example[List the power set]
Let $S = \{a,b\}$. To list every subset, decide for each element whether it is "in" or "out":
:::

:::solution
out, out $\to \emptyset$
in, out $\to \{a\}$
out, in $\to \{b\}$
in, in $\to \{a,b\}$

So $\mathcal{P}(S) = \{ \emptyset, \{a\}, \{b\}, \{a,b\} \}$, exactly $4 = 2^2$ elements — one per row of the in/out table.
:::

:::example[Why the count is $2^n$, and applying it]
The listing above is the whole idea in miniature: a subset is chosen by making one independent yes/no ("in or out") decision per element. With $n$ elements that is $n$ independent binary choices, and by the multiplication principle the number of subsets is
$$\underbrace{2 \times 2 \times \cdots \times 2}_{n \text{ factors}} = 2^n.$$
:::

:::solution
Apply it directly:

$n=0$ (the empty set $S = \emptyset$): $2^0 = 1$ subset — just $\emptyset$ itself. So $\mathcal{P}(\emptyset) = \{\emptyset\}$, a set with **one** element. (This is exactly why $\emptyset \neq \{\emptyset\}$.)
$n=1$: $2^1 = 2$ subsets.
$n=2$: $2^2 = 4$, matching the list above.
$n=3$: $2^3 = 8$. Grouped by size: $1$ empty set, $3$ singletons, $3$ two-element subsets, $1$ full set, and $1+3+3+1 = 8$. ✓

**Sanity check.** The size-by-size counts $1,3,3,1$ are the row of Pascal's triangle for $n=3$ (the binomial coefficients $\binom{3}{k}$), and they sum to $2^3 = 8$ — a good consistency check whenever you enumerate a power set by hand.
:::

## Common Mistakes

- Confusing $\subseteq$ (subset, allows equal) with $\subset$ (sometimes used for proper).
- Thinking $\emptyset$ is the same as $\{\emptyset\}$ — the latter has one element.
- Forgetting that union and intersection are commutative but difference is not: $A \setminus B \neq B \setminus A$ in general.
- Believing every function has an inverse — only bijections do.
- Confusing codomain with range (image). The codomain is declared; the image may be smaller.
- Assuming a function from a larger finite set to a smaller one can be injective (pigeonhole forbids it).
- Writing $f(x) \in A \to B$ instead of $f: A \to B$.
- Forgetting the empty set when counting subsets.
