# Combinatorial Optimization

Matroids, matchings, network flows, and linear programming for discrete optimization problems.

A matroid is a combinatorial structure that abstracts the notion of linear independence. Matroids appear in linear algebra, graph theory, combinatorial optimization, and many other areas. Their theory provides a unified min-max and algorithmic framework for a wide range of "independence" problems.

## Definition via Independent Sets (and Other Axioms)

<!-- section: definition-axioms -->

A matroid M = (E, I) consists of a finite ground set E and a family I of subsets of E (the independent sets) satisfying:

1. ∅ ∈ I.
2. If A ∈ I and B ⊂ A then B ∈ I (hereditary / downward closed).
3. (Augmentation) If A, B ∈ I and |A| < |B|, then there exists e ∈ B \ A such that A ∪ {e} ∈ I.

Equivalent axiomatizations exist using bases, circuits (minimal dependent sets), the rank function (submodular, monotone), and the closure operator.

**ELI5**

- Think of "independent" as "no redundancy." A team where everyone brings a *different* skill is independent; the moment someone duplicates a skill already on the team, they are redundant (dependent).
- The augmentation axiom is the magic: if your team is smaller than a rival team, you can always poach *someone* from the rival who adds a genuinely new skill to yours. That "you can always grow toward the bigger set" property is what makes greedy hiring work.
- The axioms are deliberately chosen so that every nice theorem about bases and rank from linear algebra keeps holding in this abstract world.

**Worked Example:**

Let us verify that the uniform matroid $U_{2,3}$ really is a matroid. Take ground set $E = \{1,2,3\}$ and declare $I$ to be *all* subsets of size at most $2$:
$$I = \{\emptyset,\ \{1\},\{2\},\{3\},\ \{1,2\},\{1,3\},\{2,3\}\}.$$

Check each axiom:

- **(1) $\emptyset \in I$.** Yes, $\emptyset$ has size $0 \le 2$. ✓
- **(2) Hereditary.** Any subset of a set of size $\le 2$ also has size $\le 2$, so it is in $I$. ✓
- **(3) Augmentation.** Suppose $A, B \in I$ with $|A| < |B|$. Then $|A| \le 1$ and $|B| \le 2$. Since $|B| > |A|$, the set $B$ contains an element $e \notin A$; adding it gives $|A \cup \{e\}| = |A| + 1 \le 2$, so $A \cup \{e\} \in I$. ✓

All three hold, so $U_{2,3}$ is a matroid.

Now contrast this with a *non-example* to see why augmentation is the load-bearing axiom. Keep $E = \{1,2,3\}$ but take the hereditary family
$$I'' = \{\emptyset,\ \{1\},\{2\},\{3\},\ \{1,2\}\}.$$
Axioms (1) and (2) still hold (every subset of $\{1,2\}$ is listed). But augmentation fails: take $A = \{3\}$ and $B = \{1,2\}$, both in $I''$ with $|A| = 1 < 2 = |B|$. The elements of $B \setminus A$ are $1$ and $2$, giving candidates $\{3,1\}$ and $\{3,2\}$ — *neither* is in $I''$. So no element of $B$ can extend $A$, and axiom (3) is violated. Thus $I''$ is hereditary but **not** a matroid, and (as the Common Mistakes section notes) greedy can fail on such a family — which is exactly what axiom (3) rules out.

## Important Examples

<!-- section: examples -->

- **Vector matroid / linear matroid**: columns of a matrix; independent = linearly independent columns.
- **Graphic matroid**: edges of a graph; independent = acyclic sets of edges (forests). Rank of a set of edges = v − c in the subgraph.
- **Partition matroid / transversal**: given a partition of E into blocks with capacities, independent sets take at most the capacity from each block.
- **Uniform matroid U_{k,n}**: all subsets of size ≤ k are independent.
- **Fano matroid**, projective geometries, etc.

Many theorems true for vector spaces or for graphs have matroid generalizations.

**ELI5**

- In a graph, a forest is "independent" because it has no cycles (the circuit axiom: a cycle is a minimal dependent set).
- In a vector space the circuits are the minimal linearly dependent sets (relations).

**Worked Example:**

Consider the cycle graph $C_4$ on vertices $\{1,2,3,4\}$ with edges $e_1=12$, $e_2=23$, $e_3=34$, $e_4=41$. Its graphic matroid has ground set $E = \{e_1,e_2,e_3,e_4\}$, and a set of edges is independent iff it is acyclic (a forest).

- **Rank of the whole set.** The graph is connected with $v = 4$ vertices and $c = 1$ component, so the rank formula gives $r(E) = v - c = 4 - 1 = 3$. A maximal forest (basis) therefore has $3$ edges.
- **Which 3-edge sets are bases?** Any $3$ of the $4$ edges omit exactly one edge and form a path on all $4$ vertices — a tree, hence acyclic and independent. All $\binom{4}{3} = 4$ triples are bases.
- **The unique circuit.** Taking all $4$ edges closes the cycle $1\text{-}2\text{-}3\text{-}4\text{-}1$. This is a minimal dependent set (removing any one edge makes it independent again), so $\{e_1,e_2,e_3,e_4\}$ is the single circuit of this matroid.

**Sanity check:** rank $3$, bases of size $3$, and adding the $4$th edge to any basis creates the circuit — consistent with "a basis is a maximal independent set." ✓

## Optimization and Min-Max Theorems

<!-- section: optimization -->

The greedy algorithm (sort elements by weight descending, then scan through them adding each one iff the current set stays independent) finds a maximum-weight basis exactly when the set system is a matroid. In fact this is a *characterization*: a hereditary set system is a matroid if and only if greedy returns a maximum-weight basis for **every** weight function.

The matroid intersection theorem gives a min-max formula for the largest set independent in *two* different matroids on the same ground set; it is solved in polynomial time.

These results generalize Kruskal's MST algorithm, bipartite matching, and many other classical optimization results.

**ELI5**

- Greedy works perfectly for matroids: always pick the next best item that doesn't create a "circuit".
- For two matroids (e.g. one graphic, one partition) the common independent sets (e.g. matchings that are also forests) have a clean min-max size.

**Worked Example:**

Kruskal's algorithm for the maximum-weight spanning tree *is* the matroid greedy algorithm on the graphic matroid. Let us run it explicitly. Take the triangle $K_3$ on vertices $\{a,b,c\}$ with edge weights
$$w(ab) = 3,\quad w(bc) = 2,\quad w(ca) = 1.$$
We want a **maximum**-weight basis (spanning tree), so we sort descending and add each edge iff it keeps the set acyclic:

1. **$ab$ (weight $3$).** Current set $\emptyset$; adding $ab$ stays a forest. Take it → $\{ab\}$.
2. **$bc$ (weight $2$).** $\{ab, bc\}$ is a path $a\text{-}b\text{-}c$, still acyclic. Take it → $\{ab, bc\}$.
3. **$ca$ (weight $1$).** Adding $ca$ would close the triangle $a\text{-}b\text{-}c\text{-}a$, a cycle — dependent. Skip it.

Result: the tree $\{ab, bc\}$ with total weight $3 + 2 = 5$.

**Sanity check:** $K_3$ has $v=3$ vertices, so every spanning tree has $v-1 = 2$ edges; there are $3$ spanning trees with weights $3{+}2{=}5$, $3{+}1{=}4$, $2{+}1{=}3$, and greedy correctly picked the heaviest, $5$. ✓ (For a *minimum* spanning tree, sort ascending instead — the same argument shows greedy is optimal because forests form a matroid.)

## Common Mistakes

- **Thinking every hereditary family is a matroid**: The augmentation axiom is crucial; without it greedy can fail.
- **Confusing circuits with bases**: Circuits are the minimal *dependent* sets; bases are the maximal *independent* sets.
- **Assuming all matroids are representable over a field**: Many are not (e.g. the non-Pappus matroid); the abstract theory is richer.
- **Forgetting that graphic matroids are a proper subclass**: Not every matroid comes from a graph.
- **Overlooking the algorithmic power**: Matroid algorithms (greedy, intersection, union, etc.) give polynomial-time solutions for many problems that look hard when stated in the original language.

A matching is a set of edges that share no vertices. Matchings are among the most fundamental objects in graph theory and combinatorial optimization; they model pairings, assignments, and resource allocation.

The theory is especially rich in bipartite graphs, where min-max theorems and efficient algorithms abound.

## Definitions and Basic Facts

<!-- section: definition-matching -->

A matching M is a subset of edges with no two sharing a vertex.

A vertex is matched (covered) if incident to an edge in M; otherwise free (exposed).

A maximum matching has the largest possible number of edges.

An augmenting path with respect to M is an alternating path (edges alternately in and out of M) that begins and ends at free vertices.

By Berge's lemma, a matching is maximum if and only if it admits no augmenting path.

**ELI5**

- A matching is a collection of "paired" edges that don't fight over people (vertices).
- An augmenting path is an alternating chain that lets you flip and get one more pair.

**Worked Example:**

Take the path $P_5$ on vertices $a\text{-}b\text{-}c\text{-}d\text{-}e$ (four edges: $ab$, $bc$, $cd$, $de$). Start from the small matching $M = \{bc\}$, of size $1$. Vertices $b,c$ are matched; $a,d,e$ are free.

Look for an augmenting path — an alternating path (out-of-$M$, in-$M$, out-of-$M$, …) whose two endpoints are both free. Start at the free vertex $a$:
$$a \xrightarrow{ab \notin M} b \xrightarrow{bc \in M} c \xrightarrow{cd \notin M} d.$$
The endpoints $a$ and $d$ are both free, and the edges alternate out/in/out, so $a\text{-}b\text{-}c\text{-}d$ is augmenting. **Flip** membership along it: remove $bc$, add $ab$ and $cd$. The new matching is
$$M' = \{ab,\ cd\},\qquad |M'| = 2,$$
one larger than before, as promised. Now $a,b,c,d$ are matched and only $e$ is free. Any alternating path from $e$ is $e\text{-}d\text{-}c\text{-}b\text{-}a$, but $a$ is matched, so it does **not** end at a free vertex — no augmenting path exists.

**Sanity check:** by Berge's lemma, no augmenting path means $M'$ is maximum. Indeed $P_5$ has $5$ vertices, so a matching has at most $\lfloor 5/2\rfloor = 2$ edges, and $|M'| = 2$ attains it. ✓

## Hall's Theorem in Bipartite Graphs

<!-- section: halls-theorem -->

Hall's marriage theorem: Let G be bipartite with parts L and R. There is a matching that saturates (covers) every vertex of L if and only if for every S ⊆ L we have |N(S)| ≥ |S|, where N(S) is the set of neighbors of S in R.

This is a necessary and sufficient condition and a prototype min-max theorem.

**ELI5**

- To marry off every boy (L) to a girl (R) such that each girl gets at most one, you need that any group of k boys collectively knows at least k girls.
- If some group of boys knows fewer girls than boys, obviously impossible.

**Worked Example:**

Let $L = \{A,B,C\}$ and $R = \{1,2,3\}$ with neighborhoods
$$N(A) = \{1,2\},\quad N(B) = \{1\},\quad N(C) = \{1,2,3\}.$$
To apply Hall we must check $|N(S)| \ge |S|$ for **every** $S \subseteq L$. The dangerous cases are the small, "cramped" ones — a set is only in danger if its members share few neighbors:

- Singletons: $|N(A)|=2\ge1$, $|N(B)|=1\ge1$, $|N(C)|=3\ge1$. ✓
- Pairs: $N(\{A,B\})=\{1,2\}$ ($2\ge2$); $N(\{A,C\})=\{1,2,3\}$ ($3\ge2$); $N(\{B,C\})=\{1,2,3\}$ ($3\ge2$). ✓
- All three: $N(\{A,B,C\}) = \{1,2,3\}$ ($3 \ge 3$). ✓

Every subset satisfies Hall's condition, so a matching saturating $L$ exists. To construct one, match the most constrained vertex first: $B$ can only take $1$, so set $B\text{-}1$; then $A$ takes $2$; then $C$ takes the remaining $3$. This gives the perfect matching
$$M = \{B\text{-}1,\ A\text{-}2,\ C\text{-}3\}.$$

**Sanity check:** the three chosen right-vertices $1,2,3$ are distinct, and each edge respects the neighborhoods ($1\in N(B)$, $2\in N(A)$, $3\in N(C)$). ✓ Notice the failure mode Hall guards against: if instead $N(A)=N(C)=\{1\}$ too, then $S=\{A,B,C\}$ would have $|N(S)|=1<3$ and no such matching could exist.

## Algorithms and Min-Max

<!-- section: algorithms -->

In bipartite graphs: reduce to max flow (unit capacities from source to L, edges L-R capacity 1, R to sink). Ford-Fulkerson or Dinic gives max matching. Hopcroft-Karp is faster O(E√V).

In general graphs: Edmonds' blossom algorithm contracts odd alternating cycles ("blossoms") and recurses; polynomial time.

König's theorem (bipartite): size of max matching = size of min vertex cover.

**ELI5**

- Flow models "sending one unit of assignment along an edge without exceeding capacities."
- Blossoms are the odd-cycle obstacles that require special shrinking in the non-bipartite case.

**Worked Example:**

Let us find a maximum matching in the bipartite graph $L=\{A,B,C\}$, $R=\{1,2,3\}$ with edges
$$A\text{-}1,\ A\text{-}2,\ B\text{-}1,\ C\text{-}2,\ C\text{-}3,$$
using the augmenting-path method (the combinatorial heart of the flow reduction).

1. **Start empty.** $M = \emptyset$.
2. **Grow from $A$:** edge $A\text{-}1$ reaches free $1$. Add it → $M=\{A\text{-}1\}$.
3. **Grow from $B$:** edge $B\text{-}1$, but $1$ is taken. Try the alternating path $B \to 1 \to A \to 2$ (out $B1$, in $A1$, out $A2$), ending at free $2$. Augment: drop $A\text{-}1$, add $B\text{-}1$ and $A\text{-}2$ → $M=\{B\text{-}1,\ A\text{-}2\}$, size $2$.
4. **Grow from $C$:** edge $C\text{-}3$ reaches free $3$. Add it → $M=\{B\text{-}1,\ A\text{-}2,\ C\text{-}3\}$, size $3$.

No free left vertex remains, so no augmenting path exists and $M$ is maximum with $|M| = 3$.

**Sanity check via König.** The vertex set $\{1,2,3\}$ (all of $R$) is a vertex cover of size $3$ — every edge has a right endpoint. Since max matching $\le$ min vertex cover always, and here matching $=3=$ this cover, both are optimal: max matching $=$ min vertex cover $=3$, as König's theorem guarantees for bipartite graphs. ✓

## Common Mistakes

- **Allowing shared vertices in a 'matching'**: By definition no two edges in a matching share a vertex.
- **Confusing matching with edge cover or vertex cover**: A vertex cover touches *all* edges; a matching is a *packing* of edges.
- **Thinking Hall's condition is only sufficient**: It is necessary and sufficient.
- **Forgetting that in non-bipartite graphs min vertex cover can be strictly larger than max matching** (e.g., a triangle: matching 1, vertex cover 2).
- **Assuming perfect matchings always exist when |L|=|R|**: Hall's (or Tutte's) condition may fail.

Network flows model the movement of a commodity through a network with capacities on the arcs. The maximum flow problem and its min-cut dual are among the most important and versatile tools in combinatorial optimization.

## Flow Networks and Feasible Flows

<!-- section: flow-networks -->

A flow network G = (V,E) has distinguished source s and sink t, and a capacity function c : E → ℝ≥0.

A flow f : E → ℝ satisfies:

- Capacity: 0 ≤ f(e) ≤ c(e) for every edge.
- Conservation: for every v ≠ s,t, sum_{edges into v} f = sum_{edges out of v} f.

The value |f| of the flow is the net flow out of s.

**ELI5**

- Think of pipes with limited throughput (capacity) carrying water from s to t.
- At every junction (non s/t) the amount flowing in must equal the amount flowing out.

**Worked Example:**

Consider a network with vertices $s, a, b, t$ and directed capacities
$$s\to a:\ 3,\quad s\to b:\ 2,\quad a\to t:\ 2,\quad b\to t:\ 3,\quad a\to b:\ 2.$$
Let us build **one feasible flow** and verify it obeys both rules. Try
$$f(s\to a)=3,\ f(a\to t)=2,\ f(a\to b)=1,\ f(s\to b)=2,\ f(b\to t)=3.$$

- **Capacity** ($0 \le f(e) \le c(e)$): $3\le3$, $2\le2$, $1\le2$, $2\le2$, $3\le3$ — all hold. ✓
- **Conservation** at internal vertices:
  - At $a$: in $= f(s\to a) = 3$; out $= f(a\to t) + f(a\to b) = 2 + 1 = 3$. Balanced. ✓
  - At $b$: in $= f(s\to b) + f(a\to b) = 2 + 1 = 3$; out $= f(b\to t) = 3$. Balanced. ✓

The value is the net flow out of $s$: $|f| = f(s\to a) + f(s\to b) = 3 + 2 = 5$. (It matches the inflow to $t$: $f(a\to t)+f(b\to t) = 2+3 = 5$, as conservation forces.) We show in the next section that this flow is in fact *maximum*.

## The Max-Flow Min-Cut Theorem

<!-- section: maxflow-mincut -->

The max-flow min-cut theorem asserts that the maximum possible flow value equals the minimum capacity of an s-t cut.

An s-t cut is a partition of V into S ∋ s and T = V\S ∋ t; its capacity is the sum of c(e) over edges e from S to T.

**ELI5**

- You cannot push more flow across the network than the total "pipe capacity" crossing any cut that separates s from t.
- The theorem says there is always a bottleneck cut whose capacity exactly matches the max flow you can achieve.

**Worked Example:**

Take the same network as in the previous section:
$$s\to a:\ 3,\quad s\to b:\ 2,\quad a\to t:\ 2,\quad b\to t:\ 3,\quad a\to b:\ 2.$$
An $s$-$t$ cut $(S, T)$ has $s \in S$, $t \in T$, and capacity $=$ sum of capacities of edges that go **from $S$ to $T$** (backward edges $T\to S$ do *not* count). Enumerate all four cuts:

| $S$ | edges from $S$ to $T$ | capacity |
|---|---|---|
| $\{s\}$ | $s\to a,\ s\to b$ | $3+2 = 5$ |
| $\{s,a\}$ | $a\to t,\ a\to b,\ s\to b$ | $2+2+2 = 6$ |
| $\{s,b\}$ | $s\to a,\ b\to t$ | $3+3 = 6$ |
| $\{s,a,b\}$ | $a\to t,\ b\to t$ | $2+3 = 5$ |

The **minimum** cut capacity is $5$, attained by both $S=\{s\}$ and $S=\{s,a,b\}$.

**Sanity check (max-flow $=$ min-cut).** The flow of value $5$ we built in the previous section meets this bottleneck exactly: $5 = 5$. By the max-flow min-cut theorem this equality certifies that our flow is maximum *and* that these cuts are minimum — no separate optimality proof is needed. Note also that the cut $\{s,a\}$ has capacity $6 > 5$: not every cut is tight, only the minimum one, which is why you must minimize over cuts rather than picking any convenient one.

## Algorithms and Applications

<!-- section: applications -->

Ford-Fulkerson / Edmonds-Karp: repeatedly augment along a path in the residual graph (forward residual capacity or backward flow) until no s-t path in residual.

With integer capacities the max flow is integer and the method terminates.

Applications: bipartite matching, assignment problem, transportation, circulation with demands, image segmentation (min-cut), project selection, etc.

**ELI5**

- Residual graph lets you "undo" previous flow decisions to reroute.
- Many real-world "shipping with capacities" or "matching with constraints" reduce to a max-flow computation.

**Worked Example:**

Let us turn a bipartite matching problem into a flow computation. Take $L=\{A,B\}$, $R=\{1,2\}$ with edges $A\text{-}1$, $A\text{-}2$, $B\text{-}1$. Build the flow network:

- add a source $s$ with $s\to A$ and $s\to B$, each capacity $1$;
- direct each original edge left-to-right with capacity $1$: $A\to1$, $A\to2$, $B\to1$;
- add a sink $t$ with $1\to t$ and $2\to t$, each capacity $1$.

**Why unit capacities model matching:** the cap-$1$ edge $s\to A$ forces at most one unit through $A$, so $A$ is matched to at most one right vertex; the cap-$1$ edge $1\to t$ forces $1$ to receive at most one unit, so it is matched at most once. An integral flow is therefore exactly a matching.

Run augmenting paths: push $1$ unit along $s\to A\to 1\to t$ (flow $1$). Now try $s\to B\to 1\to t$, but $1\to t$ is saturated; instead augment along $s\to B\to 1$, then *backward* along the used $A\to1$ (cancelling it via the residual edge), then $A\to 2\to t$: the path $s\to B\to 1 \dashrightarrow A\to 2\to t$ adds a second unit. Max flow $=2$.

**Sanity check:** the integral flow of value $2$ saturates both $s\to A$ and $s\to B$, corresponding to the matching $\{B\text{-}1,\ A\text{-}2\}$ of size $2$. Since $|L|=2$ this saturates $L$ and is clearly maximum. ✓ The backward (residual) step is precisely the augmenting-path re-routing from the Definitions section, now seen through the flow lens.

## Common Mistakes

- **Allowing negative flows or violating conservation**: Feasibility requires both.
- **Confusing the residual graph with the original**: Backward edges have capacity equal to current flow (can cancel).
- **Thinking max flow is always the sum of capacities out of s**: That is only an upper bound; other cuts may be tighter.
- **Forgetting that the min cut found from residual reachability is a proof of optimality**: After running any max-flow alg, the reachable set from s in residual gives a cut of capacity equal to the flow value.
- **Assuming all flows are integral**: With fractional capacities you may need fractional flows; the integral flow theorem holds when all capacities are integers.

Linear programming (LP) is the problem of optimizing a linear objective over a polyhedron defined by linear inequalities. It is both a fundamental algorithmic tool and the source of powerful min-max theorems and duality in combinatorics.

Many combinatorial optimization problems admit natural LP formulations that are integral, so that LP solvers (or combinatorial algorithms derived from them) solve the discrete problem exactly.

## The Linear Programming Problem

<!-- section: lp-problem -->

In inequality form: maximize c^T x subject to A x ≤ b, x ≥ 0.

(Equality form obtained by adding slack variables.)

The feasible region is a convex polyhedron. **Fundamental theorem of LP:** if the feasible region is nonempty and the objective is bounded above on it, then the optimum is attained, and — provided the polyhedron has at least one vertex (which holds here because $x\ge0$ prevents lines) — it is attained at a vertex (a *basic feasible solution*, where enough constraints are tight to pin down the point uniquely). This is why algorithms need only search the finitely many vertices, not the whole region.

**ELI5**

- You have a linear "profit" function c·x and a bunch of linear resource limits A x ≤ b.
- The best point is always at a "corner" of the feasible region.

**Worked Example:**

Solve $\max\ 3x + 4y$ subject to $x + y \le 5$, $x \ge 0$, $y \ge 0$.

The feasible region is the triangle bounded by the three lines $x+y=5$, $x=0$, $y=0$. Its vertices are the pairwise intersections of those boundary lines:

- $x=0,\ y=0 \Rightarrow (0,0)$, objective $3(0)+4(0) = 0$.
- $y=0,\ x+y=5 \Rightarrow (5,0)$, objective $3(5)+4(0) = 15$.
- $x=0,\ x+y=5 \Rightarrow (0,5)$, objective $3(0)+4(5) = 20$.

By the fundamental theorem the optimum sits at a vertex, so we just compare the three values: the maximum is $\boxed{20}$ at $(0,5)$.

**Sanity check:** the objective gradient is $(3,4)$, which points "up and to the left"; since $y$ has the larger coefficient we expect to prefer $y$ over $x$, and indeed the all-$y$ corner $(0,5)$ wins. ✓

## Duality

<!-- section: duality -->

Every primal LP has a dual LP. For the standard max c x s.t. A x ≤ b, x≥0 the dual is min b y s.t. A^T y ≥ c, y ≥0.

Weak duality: **any** primal-feasible $x$ and dual-feasible $y$ satisfy $c^T x \le b^T y$. (Quick proof: $c^T x \le (A^Ty)^T x = y^T(Ax) \le y^T b$, using $A^Ty\ge c$ with $x\ge0$ for the first inequality and $Ax\le b$ with $y\ge0$ for the second.) So every dual-feasible point hands you an upper bound on the primal, and vice versa.

Strong duality: if **both** problems are feasible and bounded, then their optimal values are equal and optimal solutions exist for both. The hypothesis matters: if one side is infeasible the other may be unbounded (then no finite common value exists), so "both feasible and bounded" is the condition that closes the gap.

**ELI5**

- The dual provides a "pricing" or "certificate" problem whose value upper-bounds the primal.
- At optimality the best primal profit exactly equals the best dual "cost".

**Worked Example:**

**Primal:** $\max\ x_1 + x_2$ subject to $x_1 + 2x_2 \le 4$, $x_1, x_2 \ge 0$.

There is one constraint ($m=1$), so the dual has one variable $y \ge 0$. Reading off $b = 4$ and the columns of $A = (1\ \ 2)$ against $c = (1, 1)$:

**Dual:** $\min\ 4y$ subject to $y \ge 1$ (from the $x_1$ column), $2y \ge 1$ (from the $x_2$ column), $y \ge 0$.

Solve each side:

- *Primal.* Vertices of the feasible region are $(0,0)$ [value $0$], $(4,0)$ [value $4$], $(0,2)$ [value $2$]. Maximum $= 4$ at $(4,0)$.
- *Dual.* The binding constraint is $y \ge 1$ (it implies $2y \ge 2 \ge 1$), so the smallest feasible $y$ is $y = 1$, giving objective $4(1) = 4$.

Both optima equal $4$, exactly as strong duality predicts.

**Sanity check (complementary slackness).** At the primal optimum $(4,0)$: the constraint $x_1 + 2x_2 = 4 \le 4$ is *tight*, which is consistent with the dual variable $y = 1 > 0$. And $x_1 = 4 > 0$ pairs with the dual constraint $y \ge 1$ being *tight* ($y = 1$); $x_2 = 0$ is allowed to leave its dual constraint $2y \ge 1$ slack ($2 > 1$). All slackness conditions hold, certifying both solutions optimal. ✓

## Combinatorial Applications

<!-- section: combinatorial-apps -->

- Bipartite matching / assignment as LP with totally unimodular (TU) constraint matrix → integral optima.
- Network flows and min-cost flows.
- Shortest paths, min spanning trees (via LP or duals).
- Many packing and covering problems admit LP relaxations whose integrality gap is 1 or can be rounded.

A matrix is **totally unimodular (TU)** if every square submatrix has determinant $0$, $+1$, or $-1$. When the constraint matrix is TU and the right-hand side $b$ is integral (network matrices, interval matrices, bipartite incidence matrices, etc.), every vertex of the polyhedron has integer coordinates — so the LP optimum is automatically an integer solution and LP solves the integer program exactly, with no rounding.

**ELI5**

- You write the combinatorial problem as "maximize profit subject to linear packing constraints"; if the matrix is nice the best fractional solution is already integral.
- Duality often recovers the classical min-max theorems (König, max-flow min-cut, etc.).

**Worked Example:**

Consider the $2\times2$ **assignment problem**: assign workers $\{1,2\}$ to jobs $\{1,2\}$ to maximize total value, with values
$$w_{11}=5,\ w_{12}=3,\ w_{21}=2,\ w_{22}=4.$$
Introduce $x_{ij}\in[0,1]$ (allowed to be fractional in the LP relaxation) and write
$$\max\ 5x_{11}+3x_{12}+2x_{21}+4x_{22}$$
subject to each worker used once ($x_{11}+x_{12}=1$, $x_{21}+x_{22}=1$), each job filled once ($x_{11}+x_{21}=1$, $x_{12}+x_{22}=1$), and $x_{ij}\ge0$.

The constraint matrix is the bipartite incidence matrix, which is TU, so — even though we *permitted* fractional $x$ — every vertex of this polytope is a $0/1$ permutation matrix. There are only two:

- $x_{11}=x_{22}=1$ (worker $1\to$job $1$, worker $2\to$job $2$): value $5+4 = 9$.
- $x_{12}=x_{21}=1$ (worker $1\to$job $2$, worker $2\to$job $1$): value $3+2 = 5$.

The LP optimum is $\max(9,5) = 9$, attained at the integral point $x_{11}=x_{22}=1$.

**Sanity check:** the relaxation never beat the best integer assignment — TU guarantees the fractional optimum coincides with the combinatorial one, so there was no "integrality gap" to round away. ✓

## Common Mistakes

- **Thinking every LP has an integral optimum**: Only when the polyhedron has integer vertices (TU or other conditions).
- **Forgetting strong duality requires feasibility of both sides**: If one is infeasible the other may be unbounded.
- **Confusing simplex (vertex walking) with interior-point methods**: Both solve LP; simplex has combinatorial flavor.
- **Assuming all combinatorial problems have small integrality gap**: Some have large gaps; approximation algorithms study the gap.
- **Neglecting degeneracy and multiple optima**: A vertex may have several bases; complementary slackness helps certify optimality.
