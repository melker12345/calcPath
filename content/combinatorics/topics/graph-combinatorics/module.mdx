# Graph Combinatorics

Graph coloring, Ramsey theory, extremal graph theory, Turán's theorem, and Szemerédi's theorem.

Graph coloring is the assignment of labels ("colors") to vertices or edges so that certain adjacency or incidence constraints are satisfied. The chromatic number χ(G) — the smallest number of colors needed for a proper vertex coloring — is a fundamental graph invariant with deep connections to topology, scheduling, and complexity.

## Vertex Coloring Basics

<!-- section: vertex-coloring -->

:::definition[Proper coloring]{#proper-coloring}
A proper k-coloring of the vertices is a function c : V → {1,2,...,k} such that if uv is an edge then c(u) ≠ c(v).
:::

:::definition[Chromatic number]{#chromatic-number}
The chromatic number χ(G) is the smallest k for which a proper k-coloring exists.
:::

:::intuition
Color the countries on a map so that countries sharing a border get different colors. The "graph" has a vertex per country and edges for shared borders.

The minimal number of colors needed is the chromatic number.
:::

:::example
Compute $\chi(C_4)$, the 4-cycle $1\text{–}2\text{–}3\text{–}4\text{–}1$.
:::

:::solution
Step 1 (lower bound). $C_4$ has an edge, so $\chi \ge 2$: adjacent vertices need different colors.
Step 2 (construction). Color the two "even" vertices $2,4$ with color A and the two "odd" vertices $1,3$ with color B. Check each edge: $1\text{–}2$ is B–A ✓, $2\text{–}3$ is A–B ✓, $3\text{–}4$ is B–A ✓, $4\text{–}1$ is A–B ✓. No edge is monochromatic, so 2 colors suffice.
Step 3. Combining, $\chi(C_4)=2$.
Sanity check: $C_4$ is an even cycle, hence bipartite (no odd cycle), and every bipartite graph with at least one edge has $\chi=2$ ✓.

Two contrasting extremes: for the triangle $K_3$ every pair of vertices is adjacent, so no color can be reused and $\chi(K_3)=3$; a single edge $K_2$ needs $\chi=2$.
:::

## Chromatic Number and Bounds

<!-- section: chromatic-number -->

Here $\Delta(G)$ denotes the maximum degree — the largest number of edges meeting any single vertex.

:::theorem[Greedy bound]{#greedy-bound}
For every graph $G$,

$$\chi(G) \le \Delta(G) + 1.$$
:::

:::proof
Process the vertices in any order and give each the smallest color not already used by its already-colored neighbors; a vertex has at most $\Delta$ neighbors, so at most $\Delta$ colors are blocked and one of the first $\Delta+1$ colors is always free.
:::

:::theorem[Brooks' theorem]{#brooks}
For a connected graph $G$ that is neither a complete graph nor an odd cycle,

$$\chi(G) \le \Delta(G).$$
:::

The two excluded families are exactly the graphs where the $\Delta+1$ bound is forced.

:::theorem[Four Color Theorem]{#four-color}
For planar graphs, $\chi(G) \le 4$.
:::

(This hypothesis matters: it holds only for graphs drawable in the plane without crossing edges — see Common Mistakes.)

:::intuition
Greedy: when you color a vertex, at worst all its neighbors have used different colors, so you may need one new color beyond the degree.

Odd cycles and cliques force χ = Δ+1 in the exceptional cases.
:::

:::example
A 5-cycle $C_5$ has $\Delta=2$ (every vertex has exactly two neighbors). Try to 2-color it by alternating around the cycle: $1\to$A, $2\to$B, $3\to$A, $4\to$B, $5\to$A. But vertex 5 and vertex 1 are adjacent and both got A — the alternation fails to close because the cycle has odd length. So $\chi(C_5) \ge 3$; three colors clearly suffice (e.g. A,B,A,B,C), giving $\chi(C_5)=3$. Since $3 = \Delta+1$ and $C_5$ is an odd cycle, this is exactly one of the two Brooks exceptions — the bound $\chi \le \Delta$ genuinely fails here.
:::

:::example[(greedy):]
Run greedy on the "paw" graph: a triangle on $\{a,b,c\}$ plus a pendant vertex $d$ joined only to $c$. Here $\Delta=3$ (vertex $c$).
:::

:::solution
Order $a,b,c,d$. $a\to 1$; $b\to 2$ (neighbor $a$ blocks 1); $c\to 3$ (neighbors $a,b$ block 1,2); $d\to 1$ (neighbor $c$ blocks 3, so 1 is free). Uses 3 colors.
The triangle already forces $\chi\ge 3$, so $\chi=3$ here, matching the greedy result.
Note $3 = \chi < \Delta+1 = 4$: the greedy bound is not tight, and indeed Brooks applies ($G$ is connected, not complete, not an odd cycle) giving $\chi\le\Delta=3$ ✓.
:::

## Applications and Algorithms

<!-- section: applications -->

Coloring models exam scheduling (vertices = exams, edge = student taking both, colors = time slots), register allocation in compilers, map coloring, frequency assignment, and Sudoku (as graph coloring on a special graph).

Computing χ(G) is NP-hard, but for special classes (bipartite, chordal, perfect) it is polynomial.

:::intuition
Final exams: if two exams share a student they can't be at the same time slot (color).

The minimal number of slots needed to avoid conflicts is the chromatic number of the conflict graph.
:::

:::example
Schedule 4 exams $A,B,C,D$ into as few time slots as possible. Two exams conflict (need different slots) when a student takes both. Conflicts: $A\text{–}B$, $A\text{–}C$, $B\text{–}C$, $B\text{–}D$.
:::

:::solution
Step 1 (lower bound). $A,B,C$ are mutually conflicting — a triangle $K_3$ in the conflict graph — so they need 3 distinct slots. Hence $\chi \ge 3$.
Step 2 (construction). Slot 1: $\{A\}$. Slot 2: $\{B\}$. Slot 3: $\{C\}$. Now place $D$: its only conflict is $B$ (slot 2), so $D$ may share slot 1 or slot 3. Put $D$ in slot 1 with $A$ (they have no student in common).
Step 3. Assignment $A,D\to$ slot 1, $B\to$ slot 2, $C\to$ slot 3 uses 3 slots and has no conflict in any slot.
Sanity check: 3 slots meet the lower bound from Step 1, so this is optimal: $\chi=3$.
:::

## Common Mistakes

- **Confusing vertex coloring with edge coloring**: Edge chromatic number (Vizing) is Δ or Δ+1; different theory.
- **Assuming χ(G) = clique number ω(G)**: Always χ ≥ ω, but can be strictly larger (odd cycles, Mycielski constructions).
- **Thinking every graph is 2-colorable**: Only the bipartite ones; odd cycles are the obstruction.
- **Forgetting that the four color theorem is for planar graphs only**: Non-planar graphs can require arbitrarily many colors (K_n).
- **Greedy depends on ordering**: Different vertex orders can use different numbers of colors even though the bound Δ+1 always holds.

Ramsey theory is the study of conditions under which order must appear. Its central message is that "complete disorder is impossible": in any sufficiently large structure, no matter how the edges are colored or the elements partitioned, a large ordered monochromatic or homogeneous substructure is forced to exist.

## Ramsey Numbers

<!-- section: ramsey-numbers -->

:::definition[Ramsey number]{#ramsey-number}
The Ramsey number R(s,t) is the smallest integer n such that every red/blue coloring of the edges of the complete graph K_n contains either a red clique of size s or a blue clique of size t.
:::

:::proposition[The smallest non-trivial Ramsey number]
R(3,3) = 6: any 6 people contain 3 mutual friends or 3 mutual strangers.
:::

:::intuition
With 5 people it is possible to arrange friendships so there is no trio of all friends and no trio of all strangers (the 5-cycle coloring).

At 6 the mathematics forces one or the other.
:::

:::example
Prove $R(3,3)=6$. This needs two parts: an upper bound (6 always works) and a lower bound (5 does not).
:::

:::solution
Upper bound, $R(3,3) \le 6$. Take any red/blue coloring of the edges of $K_6$. Fix a vertex $v$; it has 5 edges. By pigeonhole, since $5 = 2\cdot 2 + 1$, at least $\lceil 5/2\rceil = 3$ of them share a color, say red — call three such neighbors $x,y,z$. Now look at the three edges $xy,yz,xz$. If any one of them is red, say $xy$, then $v,x,y$ are pairwise red: a red triangle. If none of them is red, then $xy,yz,xz$ are all blue: $x,y,z$ form a blue triangle. Either way a monochromatic triangle exists.
Lower bound, $R(3,3) > 5$. Color $K_5$ by making the edges of a 5-cycle $1\text{–}2\text{–}3\text{–}4\text{–}5\text{–}1$ red and the remaining edges (the "pentagram" $1\text{–}3\text{–}5\text{–}2\text{–}4\text{–}1$) blue. Each color class is itself a 5-cycle, which is triangle-free, so there is no monochromatic triangle. Thus 5 vertices are not enough.
Sanity check: the two parts pin the smallest forcing $n$ to exactly 6, so $R(3,3)=6$ ✓.
:::

## Infinite Ramsey Theory

<!-- section: infinite-ramsey -->

:::theorem[Ramsey's theorem, infinite form]{#infinite-ramsey}
In any finite coloring of the k-subsets of an infinite set there exists an infinite homogeneous subset.
:::

:::corollary[Infinite monochromatic clique]
For graphs (k=2, 2 colors) this says any 2-coloring of the edges of K_ℕ contains an infinite monochromatic clique.
:::

:::intuition
No matter how you color the infinite complete graph with two colors, you can always find an infinite set where all edges inside are the same color.

The proof uses repeated infinite pigeonhole: build the set one vertex at a time, always keeping an infinite reservoir of the same color.
:::

:::example
Build an infinite monochromatic clique in a 2-coloring of $K_{\mathbb N}$.
:::

:::solution
Set $S_0 = \mathbb N$ and pick any $v_1 \in S_0$. The edges from $v_1$ to $S_0\setminus\{v_1\}$ are colored red or blue; that infinite set splits into its red-neighbors and blue-neighbors of $v_1$. A set partitioned into two pieces cannot have both finite, so at least one piece is infinite (infinite pigeonhole). Pick an infinite one and call it $S_1$; record its color as $c_1$. Every edge from $v_1$ into $S_1$ has color $c_1$.
Step 2. Pick $v_2 \in S_1$. Repeat the argument inside $S_1$: an infinite subset $S_2 \subseteq S_1\setminus\{v_2\}$ where all edges from $v_2$ have a single color $c_2$.
Step 3. Iterating gives $v_1,v_2,v_3,\dots$ and colors $c_1,c_2,\dots$, where every edge $v_iv_j$ with $i<j$ has color $c_i$ (because $v_j\in S_i$). Since there are only 2 colors, infinitely many of the $c_i$ agree — say they equal red at indices $i_1<i_2<\cdots$. Then $\{v_{i_1},v_{i_2},\dots\}$ is an infinite set all of whose internal edges are red.
Sanity check: at each step we only ever shrink to a still-infinite set, so the construction never stalls, and the final subsequence is genuinely infinite ✓.
:::

## Broader Applications and Philosophy

<!-- section: ramsey-applications -->

Ramsey theory extends to arithmetic progressions (van der Waerden, Szemerédi), geometric configurations (Happy Ending problem), and higher uniformity.

It is existential and non-constructive in flavor; the numbers are often huge and the proofs give little information about where the structures are located.

:::intuition
In any large enough set of numbers you are guaranteed long arithmetic progressions (Szemerédi), even if the set looks "random".

The theory guarantees structure but rarely helps you find it efficiently.
:::

:::example
The van der Waerden number $W(3,2)=9$: any 2-coloring of $\{1,\dots,9\}$ contains a monochromatic 3-term arithmetic progression, and 9 is the smallest such length.
:::

:::solution
Why $8$ is not enough: color $\{1,\dots,8\}$ by red $=\{1,2,5,6\}$, blue $=\{3,4,7,8\}$. Neither class contains a 3-AP — e.g. the red pairs have differences $1,4,5,\dots$ but no red $a,a+d,a+2d$ all occur, and likewise for blue. So $W(3,2) > 8$.
Why $9$ forces one: with 9 numbers and only 2 colors, the extra room removes every escape; the theorem guarantees a monochromatic progression $a, a+d, a+2d$.
Illustration inside a forced coloring: if $\{2,5,8\}$ all end up red, that is a red 3-AP with $a=2,d=3$: indeed $2, 2+3, 2+6 = 2,5,8$ ✓.
Takeaway: even $W(3,2)$ is only $9$, but the numbers grow explosively — e.g. $W(3,3)=27$ and larger parameters become astronomically large.
:::

## Common Mistakes

- **Thinking small Ramsey numbers are all known**: Only a handful of exact R(s,t) are known; most have only huge bounds.
- **Confusing Ramsey with Turán or extremal graph theory**: Turán maximizes edges without a clique; Ramsey forces the clique in colorings regardless of density.
- **Expecting constructive proofs or small witnesses**: Most proofs are by induction or compactness and give no explicit construction.
- **Forgetting the infinite case is easier in statement**: The infinite Ramsey theorem is in some senses simpler than the finite quantitative versions.
- **Believing R(3,3) >6 because of some party example**: If your party of 6 has no mono triangle, you have a counterexample to the theorem — but none exists.

Extremal graph theory asks: what is the maximum number of edges (or other structures) a graph on n vertices can have while avoiding a certain forbidden subgraph H?

The answers often take the form of a specific "extremal graph" that is just on the threshold of containing H.

## The Extremal Function

<!-- section: extremal-function -->

:::definition[Extremal function]{#extremal-function}
ex(n, H) = max { e(G) | G has n vertices, H is not a subgraph of G }.
:::

Turán's theorem solves the case H = K_{r+1} exactly. Erdős–Stone gives the asymptotic density for any H with chromatic number >2.

:::intuition
How many edges can you draw on n points without creating a triangle? The answer is the complete bipartite graph with parts as equal as possible.

Adding one more edge forces a K_3.
:::

:::example
By Mantel's theorem (the $r=2$ case of Turán), $\mathrm{ex}(n, K_3) = \lfloor n^2/4\rfloor$, achieved by the balanced complete bipartite graph $K_{\lfloor n/2\rfloor,\lceil n/2\rceil}$.
:::

:::solution
Check it for $n=5$:

Step 1 (candidate). Split 5 vertices into parts of sizes 2 and 3, joined completely: $K_{2,3}$. Edge count $= 2\cdot 3 = 6$. It is triangle-free because any triangle would need two vertices in the same part, but parts have no internal edges.
Step 2 (formula). $\lfloor 5^2/4\rfloor = \lfloor 25/4\rfloor = \lfloor 6.25\rfloor = 6$ ✓, matching the construction.
Step 3 (tightness). Any triangle-free graph on 5 vertices has at most 6 edges; adding a 7th edge to $K_{2,3}$ must go inside a part, and it immediately closes a triangle with any vertex of the other part.
Why the balanced split wins: an $a$-vs-$(n-a)$ split has $a(n-a)$ edges, and $a(n-a)$ is maximized when $a$ is as close to $n/2$ as possible (by AM–GM the product of two numbers with fixed sum is largest when they are equal), giving $\lfloor n^2/4\rfloor$.
:::

## Turán's Theorem in Detail

<!-- section: turan-special -->

:::definition[Turán graph]{#turan-graph}
The Turán graph $T(n,r)$ is the complete $r$-partite graph on $n$ vertices with part sizes as equal as possible (differ by at most 1).
:::

:::proposition[The Turán graph is extremal]
$T(n,r)$ is $K_{r+1}$-free and has the maximum possible edges among all $K_{r+1}$-free graphs.
:::

:::proof
A clique can use at most one vertex per part, so the largest clique in $T(n,r)$ has $r$ vertices and no $K_{r+1}$ fits. That the edge count is maximal is Turán's theorem, stated in full below.
:::

:::proposition[Edge count of the Turán graph]
The number of edges of $T(n,r)$ is

$$\left(1 - \tfrac{1}{r}\right)\tfrac{n^2}{2} + o(n^2),$$

where the $o(n^2)$ term absorbs the small correction from parts not dividing $n$ evenly; the exact count is $\binom{n}{2}-\sum_i\binom{s_i}{2}$ over the part sizes $s_i$.
:::

:::intuition
To avoid a clique of size r+1 you can safely put all edges between r groups, but none inside groups.

Balancing the groups maximizes the cross edges.
:::

:::example
Compute $T(5,2)$. With $r=2$ and $n=5$, the part sizes as-equal-as-possible are $2$ and $3$, so $T(5,2)=K_{2,3}$.
:::

:::solution
Edge count directly: $2\cdot 3 = 6$.
Edge count via the formula: $\binom{5}{2} - \binom{2}{2} - \binom{3}{2} = 10 - 1 - 3 = 6$ ✓.
Via the asymptotic formula: $\left(1-\tfrac12\right)\tfrac{5^2}{2} = \tfrac{25}{4} = 6.25$; the exact value $6$ differs by only the $o(n^2)$ correction ✓.
It is triangle-free (bipartite), and any 7th edge must be added inside one of the two parts, immediately forming a triangle with any vertex of the other part.

For $n=6$: parts $3,3$ give $T(6,2)=K_{3,3}$ with $3\cdot 3 = 9$ edges, and $\binom{6}{2}-2\binom{3}{2}=15-6=9$ ✓.
:::

## Other Classical Results and Tools

<!-- section: other-theorems -->

- Kővári–Sós–Turán theorem for bipartite forbidden subgraphs (Zarankiewicz problem).
- Erdős–Stone–Simonovits theorem: the asymptotic extremal density depends only on the chromatic number of H.
- The regularity lemma of Szemerédi provides a powerful analytic tool for proving approximate extremal results and embedding theorems.

:::intuition
Forbidding $K_{s,t}$ is like a seating rule: no two guests are allowed to share two common friends. To pack in the most friendships under that rule, you cannot build the neat balanced-groups graph from Turán; the best layouts look almost random or come from geometry (points-and-lines "incidence" pictures) where no little rectangle of connections ever closes up.

The regularity lemma is a "blur your eyes" tool: zoom out on any huge graph and it breaks into a few clusters, and between most clusters the edges look like uniform random noise. Counting little shapes in that blurry random picture is easy, and the answer transfers back to the real graph.
:::

:::example
Bound the maximum number of edges in a graph on $n$ vertices with no $K_{2,2}$ (equivalently no $C_4$, a 4-cycle).
:::

:::solution
Step 1 (count "cherries"). A cherry is a path of length 2, i.e. a pair of edges sharing a middle vertex. A vertex of degree $d_v$ is the center of $\binom{d_v}{2}$ cherries, so the total is $\sum_v \binom{d_v}{2}$.
Step 2 (the $C_4$-free constraint). Each unordered pair of endpoints $\{x,y\}$ can be the ends of at most one cherry — a second such cherry would give two common neighbors of $x,y$, i.e. a $K_{2,2}$. So $\sum_v \binom{d_v}{2} \le \binom{n}{2}$.
Step 3 (convexity). By Jensen/convexity, $\sum_v\binom{d_v}{2} \ge n\binom{\bar d}{2}$ where $\bar d = 2e/n$ is the average degree. Combining with Step 2 and solving gives $e \le \tfrac12\left(1+\sqrt{4n-3}\right)\tfrac{n}{2} = O(n^{3/2})$.
Sanity check / tightness: this $O(n^{3/2})$ is the right order — incidence graphs of finite projective planes are $C_4$-free with about $\tfrac12 n^{3/2}$ edges, so the exponent $3/2$ cannot be improved.

This is the simplest case of the Kővári–Sós–Turán theorem, which more generally gives $\mathrm{ex}(n, K_{s,t}) = O\!\left(n^{2 - 1/s}\right)$ for $2\le s\le t$.
:::

## Common Mistakes

- **Confusing ex(n,H) with Ramsey numbers**: Extremal maximizes edges before H appears; Ramsey forces monochromatic H in *any* coloring once n is large, independent of total edges.
- **Assuming the extremal graph is always the Turán graph**: Only when H is a clique. For bipartite H the extremal graphs have very different structure (often no dense bipartite subgraphs).
- **Forgetting the o(n^2) in Erdős–Stone**: The theorem gives the leading density term; the error and stability require more work.
- **Getting ex(n, tree) wrong**: For a tree $T$ on $k$ vertices the extremal number is *linear* in $n$, not quadratic. The Erdős–Sós conjecture (proved for large $n$) predicts $\mathrm{ex}(n,T) = \tfrac{k-2}{2}\,n$; the key point is that forbidding a sparse (bipartite) graph gives a far smaller threshold than forbidding a clique.
- **Overlooking stability versions**: Not only the max number but that graphs achieving near the max must be close in edit distance to the extremal example (Erdős–Simonovits stability).

Turán's theorem is the cornerstone of extremal graph theory. It gives the exact maximum number of edges in an n-vertex graph that does not contain a clique K_{r+1} as a subgraph, and identifies the unique extremal graph achieving the bound.

## Statement and Proof Ideas

<!-- section: statement-proof-idea -->

:::theorem[Turán's theorem]{#turan-theorem}
(1941) The maximum number of edges in a K_{r+1}-free graph on n vertices is the number of edges in the Turán graph T(n,r), the complete r-partite graph on n vertices with part sizes as equal as possible. Moreover, T(n,r) is the unique such graph.
:::

Common proofs: Zykov's symmetrization (iteratively make non-adjacent vertices "twins"), averaging or Cauchy-Schwarz on degrees, or double counting.

:::intuition
To pack as many handshakes as possible among n people without creating a clique of r+1 mutual friends, divide into r groups and let everyone in different groups shake hands.

Balancing the groups maximizes the handshakes.
:::

:::example
Apply the theorem for $r=2$ (forbidding $K_3$) on $n=6$ vertices.
:::

:::solution
Turán says the maximum is attained by $T(6,2)$, the balanced complete bipartite graph $K_{3,3}$.
Step 2. Edge count: $3\cdot 3 = 9$, i.e. $\mathrm{ex}(6,K_3)=9 = \lfloor 6^2/4\rfloor$.
Step 3 (uniqueness in action). Any triangle-free graph on 6 vertices with 9 edges must be $K_{3,3}$; a 10th edge would force a triangle (Mantel's theorem).
Sanity check of symmetrization intuition: start from any triangle-free 6-vertex graph and repeatedly "clone" the higher-degree endpoint of a non-edge onto the lower-degree one. Cloning never creates a triangle (clones are non-adjacent) and never decreases edges, and the process terminates at a complete multipartite graph — here it collapses to $K_{3,3}$, confirming it is extremal ✓.
:::

## The Turán Graph T(n,r)

<!-- section: the-graph -->

:::definition[The Turán graph in detail]{#turan-graph-detail}
T(n,r) has r parts whose sizes differ by at most one. There is an edge between every pair of vertices in different parts, and none inside parts.
:::

It is r-colorable (color by part) and therefore K_{r+1}-free.

:::proposition[Edge count by subtraction]
The edge count can be computed as

$$\binom{n}{2} - \sum_i \binom{s_i}{2},$$

that is, all possible pairs minus the pairs inside each part (the missing edges), summed over the part sizes $s_i$.
:::

:::intuition
The graph is the complete r-partite "blow-up" of an r-clique, with parts equalized.

It is the "most edges you can add while keeping the graph r-partite."
:::

:::example
$T(6,3)$: split 6 vertices into parts of sizes $2,2,2$.
:::

:::solution
Count by pairs of parts: there are $\binom{3}{2}=3$ pairs of parts, each contributing $2\times 2 = 4$ cross edges, so $3\cdot 4 = 12$ edges.
Cross-check with the subtraction formula: $\binom{6}{2} - 3\binom{2}{2} = 15 - 3\cdot 1 = 12$ ✓.

$T(7,3)$: sizes $3,2,2$ (as equal as possible: one part gets the extra vertex).

Count by pairs of parts: $(3\cdot 2) + (3\cdot 2) + (2\cdot 2) = 6+6+4 = 16$ edges.
Cross-check: $\binom{7}{2} - \left(\binom{3}{2} + \binom{2}{2} + \binom{2}{2}\right) = 21 - (3+1+1) = 21 - 5 = 16$ ✓.
Rigor note: the "differ by at most 1" rule matters — an unbalanced $4,2,1$ split would give $\binom{7}{2}-(\binom{4}{2}+\binom{2}{2}+\binom{1}{2}) = 21-(6+1+0)=14 < 16$ edges, confirming the balanced split is better.
:::

## Corollaries and Significance

<!-- section: corollaries -->

:::corollary[Mantel's theorem]{#mantel}
For $r = 2$,

$$\mathrm{ex}(n, K_3) = \lfloor n^2/4 \rfloor.$$
:::

- Any graph with more edges than T(n,r) contains not only a K_{r+1} but many copies (supersaturation).
- The theorem is the starting point for the Erdős–Stone theorem that asymptotically solves the problem for all non-bipartite forbidden graphs.

:::intuition
Once you exceed the Turán number you are forced to have the forbidden clique.

The construction is "stable": graphs with almost as many edges are close to some T(n,r).
:::

:::example
Show that every graph on 5 vertices with 7 edges contains a triangle.
:::

:::solution
By Mantel/Turán, $\mathrm{ex}(5,K_3) = \lfloor 5^2/4\rfloor = 6$: no triangle-free 5-vertex graph has more than 6 edges.
Step 2. Our graph has $7 > 6$ edges, exceeding the extremal threshold, so it cannot be triangle-free — it must contain a $K_3$.
Sanity check: the densest triangle-free graphs on 5 vertices are $K_{2,3}$ (6 edges) and $C_5$ (5 edges); both sit at or below 6, so 7 edges genuinely has no triangle-free realization ✓.
:::

## Common Mistakes

- **Forgetting the uniqueness**: T(n,r) is the unique maximizer; many students think "any complete r-partite" works, but unbalanced ones have fewer edges.
- **Confusing with Ramsey**: Turán controls the total number of edges before a clique appears in the *uncolored* graph; Ramsey forces monochromatic cliques in colored graphs.
- **Wrong part sizes**: The sizes must be as equal as possible; differing by 2 or more can be improved by moving a vertex.
- **Thinking the theorem gives the number of K_{r+1} copies**: It gives only the threshold for at least one; supersaturation and removal lemmas give quantitative versions.
- **Applying directly to non-clique H**: For general H one needs Erdős–Stone or other tools; the exact ex(n,H) is known only in special cases.

Szemerédi's theorem (1975) is one of the great triumphs of combinatorics: any subset of the integers that occupies a positive proportion (in the sense of upper density) must contain arithmetic progressions of every finite length.

It vastly generalizes van der Waerden's theorem from colorings to dense sets and has transformed additive combinatorics and ergodic theory.

## The Statement

<!-- section: statement -->

:::theorem[Szemerédi's theorem]{#szemeredi}
Let A ⊂ ℕ have positive upper density:

$$\overline{d}(A) = \limsup_{N\to\infty} \frac{|A \cap \{1,\dots,N\}|}{N} > 0.$$

Then for every $k \ge 3$, $A$ contains infinitely many arithmetic progressions of length $k$:

$$a,\; a+d,\; a+2d,\; \dots,\; a+(k-1)d \qquad \text{with } d \ge 1.$$
:::

The hypothesis is essential: positive upper density is *sufficient* but not *necessary*, and there exist infinite sets of density zero that contain no 3-term AP at all (Behrend / Salem–Spencer constructions).

:::intuition
If you have a "thick" enough set of numbers (more than a vanishing fraction in big intervals), then you are guaranteed to find 3-term, 4-term, any-length APs inside it.

The primes are too thin (density zero) for the theorem to apply directly, yet they still contain APs (Green-Tao).
:::

:::example
Check the hypothesis on two concrete sets.
:::

:::solution
Positive density (theorem applies). The even numbers $A = 2\mathbb N = \{2,4,6,\dots\}$ have $|A \cap \{1,\dots,N\}| \approx N/2$, so $\overline d(A) = \tfrac12 > 0$. Szemerédi guarantees APs of every length, which we can see directly: doubling any AP $a,a+d,\dots$ gives an AP $2a, 2a+2d,\dots$ living entirely inside the evens. For length 4: $2,4,6,8$ is a 4-AP with $d=2$ ✓.
Density zero (theorem gives no conclusion). The squares $\{1,4,9,16,25,\dots\}$ satisfy $|A\cap\{1,\dots,N\}| \approx \sqrt N$, so $\overline d(A) = \lim \sqrt N / N = 0$. Since the density hypothesis fails, Szemerédi's theorem simply says nothing here. (In fact a classical theorem of Fermat/Euler says four distinct squares can never form an AP, so the squares contain no 4-term AP — illustrating that a density-zero set may lack long progressions.)
Takeaway: the theorem is a one-way implication — positive density $\Rightarrow$ all AP lengths — and its power is precisely that it needs only density, not any structural assumption.
:::

## Proof Ideas

<!-- section: proof-ideas -->

Szemerédi's original proof is combinatorial and uses the regularity lemma to reduce the problem to finding APs in a dense "regular" approximation of the set.

Furstenberg's proof (1977) translates the problem via the correspondence principle into a multiple recurrence statement in ergodic theory: for any measure-preserving transformation T and set of positive measure, the set of x such that x, Tx, T^2 x, … , T^{k-1}x all lie in the set has positive measure.

Later analytic proofs by Gowers, Green-Tao-Ziegler etc. use uniformity norms and inverse theorems.

:::intuition
Regularity lemma says "any large graph looks like a random blow-up of a small graph on clusters"; the AP search reduces to the small model.

Ergodic proof: think of shifting the integers; positive density means positive measure; recurrence means you return to the set simultaneously for several shifts.
:::

:::example
The density-increment skeleton of Roth's proof for $k=3$ (why a positive-density set must have a 3-AP):
:::

:::solution
Step 1 (dichotomy). Take $A\subseteq\{1,\dots,N\}$ of density $\delta = |A|/N$. Either $A$ behaves "randomly" (its Fourier coefficients are all small), or it does not.
Step 2 (random case). If $A$ is Fourier-uniform, a direct count shows it has roughly $\delta^3 N^2$ three-term APs — the same as a random set of that density — which is positive, so a 3-AP exists.
Step 3 (structured case). If instead some Fourier coefficient is large, then $A$ correlates with an arithmetic progression: on some sub-progression $P$ of length $\to\infty$, $A$ has density at least $\delta + c\,\delta^2$, a genuine increment.
Step 4 (iterate). Rescale $P$ to look like $\{1,\dots,N'\}$ and repeat. Density can only rise, but it is bounded by 1, so the increment step can happen only finitely often — forcing us eventually into the random case of Step 2, which produces the 3-AP.
Sanity check: the argument breaks only if the starting density was already $o(1)$, exactly matching Roth's conclusion that a 3-AP-free set of $\{1,\dots,N\}$ has size $o(N)$ ✓.
:::

## Impact and Generalizations

<!-- section: impact -->

:::theorem[Green–Tao theorem]{#green-tao}
(2004) The primes contain arbitrarily long arithmetic progressions (relative Szemerédi in a pseudorandom majorant).
:::

- Multidimensional, polynomial, and density versions in other groups.
- Connections to property testing, removal lemmas, graph limits, and higher-order Fourier analysis.
- Quantitative bounds are still very poor (tower-type or worse for large k).

:::intuition
The primes are "random enough" that the same combinatorial arguments that work for dense sets can be transferred to them.

The theorem is the prototype for "structure from density" results across mathematics.
:::

:::example
The Green–Tao theorem guarantees arbitrarily long arithmetic progressions consisting entirely of primes. Verify one concrete instance of length 5:
:::

:::solution
Candidate: $5, 11, 17, 23, 29$ with first term $a=5$ and common difference $d=6$.
Check it is an AP: $11-5 = 6$, $17-11 = 6$, $23-17 = 6$, $29-23 = 6$ — constant gap ✓.
Check all terms are prime: $5$ ✓, $11$ ✓, $17$ ✓, $23$ ✓, $29$ ✓.
So this is a 5-term AP of primes. Green–Tao says such progressions exist for every length $k$ (though the known ones grow enormous), even though the primes have density zero — a striking case where the conclusion of a Szemerédi-type theorem survives despite the density hypothesis failing.
:::

## Common Mistakes

- **Claiming the theorem applies to any infinite set**: No — only those with positive upper density. There are infinite sets with no 3-AP (Behrend, Salem-Spencer, etc.).
- **Confusing upper density with natural density**: The lim sup >0 is enough; the actual limit need not exist.
- **Thinking quantitative versions are practical**: The bounds from all known proofs are astronomically large; for concrete computation one uses much weaker van der Waerden numbers.
- **Forgetting that Szemerédi is for the integers/Z, while finite versions are for [N] with N large depending on density and k**.
- **Attributing the ergodic proof to Szemerédi**: Furstenberg gave the ergodic proof; Szemerédi the combinatorial one.
