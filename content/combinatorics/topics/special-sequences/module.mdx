# Special Sequences & Numbers

Catalan, Stirling, and Bell numbers — classical combinatorial sequences with deep structural meaning.

The Catalan numbers form one of the most famous sequences in combinatorics: 1, 1, 2, 5, 14, 42, 132, …

They count an astonishing variety of objects that at first glance seem unrelated, all unified by the same recursive structure or the reflection principle.

## The Formula and Generating Function

<!-- section: definition-formula -->

The $n$th Catalan number (defined for integers $n \ge 0$) is

$$C_n = \frac{1}{n+1}\binom{2n}{n} = \binom{2n}{n} - \binom{2n}{n-1}.$$

The two forms are equal because $\binom{2n}{n-1} = \frac{n}{n+1}\binom{2n}{n}$, so $\binom{2n}{n} - \binom{2n}{n-1} = \left(1 - \frac{n}{n+1}\right)\binom{2n}{n} = \frac{1}{n+1}\binom{2n}{n}$.

The ordinary generating function $C(x) = \sum_{n \ge 0} C_n x^n$ satisfies the quadratic equation $C = 1 + x\,C^2$ (this equation encodes the recurrence $C_n = \sum_{i} C_i C_{n-1-i}$ derived later). Solving the quadratic for $C$ and taking the branch that is finite at $x = 0$ gives

$$C(x) = \frac{1 - \sqrt{1 - 4x}}{2x}, \qquad |x| < \tfrac14 .$$

:::intuition
Think of $\binom{2n}{n}$ as counting *every* way to walk a grid with $n$ ups and $n$ downs, good or bad. Some walks cheat by dipping below the floor. The $\frac{1}{n+1}$ factor is exactly the "toll" that throws out the cheaters: it converts the count of *all* walks into the count of only the *legal* (Dyck) ones. The subtraction form $\binom{2n}{n} - \binom{2n}{n-1}$ says the same thing more bluntly — "all paths minus the bad paths."
:::

:::example
Compute $C_4$ two ways and check they agree.
:::

:::solution
product form. $\binom{8}{4} = \frac{8!}{4!\,4!} = \frac{40320}{24 \cdot 24} = 70$, so
$$C_4 = \frac{1}{4+1}\binom{8}{4} = \frac{70}{5} = 14.$$

subtraction form. $\binom{8}{3} = \frac{8!}{3!\,5!} = \frac{40320}{6 \cdot 120} = 56$, so
$$C_4 = \binom{8}{4} - \binom{8}{3} = 70 - 56 = 14.$$

Sanity check: both routes give $14$, which matches the known sequence $1, 1, 2, 5, 14, \dots$ at index $4$. ✓
:::

## Combinatorial Interpretations

<!-- section: combinatorial-interpretations -->

Catalan numbers count:

- Balanced parentheses strings with n pairs (Dyck words)
- Binary trees with n+1 leaves (or n internal nodes, plane binary trees)
- Monotonic lattice paths from (0,0) to (n,n) never rising above the diagonal
- Triangulations of a convex (n+2)-gon
- Non-crossing partitions of n points on a circle
- Stack-sortable permutations of [n]

:::intuition
Parentheses: every prefix has at least as many opens as closes, and total equal.

Trees: every left/right subtree split obeys the same rule recursively.

Paths: never have more up steps than down steps in any prefix (like balanced parentheses).
:::

:::example
Number of ways to correctly match $3$ pairs of parentheses: $C_3 = 5$.
:::

:::solution
First confirm the count from the formula: $C_3 = \frac{1}{4}\binom{6}{3} = \frac{20}{4} = 5$.

Now list all five strings and verify each is *balanced* (reading left to right, the running count of "opens minus closes" never goes negative and ends at $0$):

$((()))$ — running counts $1,2,3,2,1,0$ ✓
$(()())$ — running counts $1,2,1,2,1,0$ ✓
$(())()$ — running counts $1,2,1,0,1,0$ ✓
$()(())$ — running counts $1,0,1,2,1,0$ ✓
$()()()$ — running counts $1,0,1,0,1,0$ ✓

All five stay non-negative and land on $0$, and there is no sixth balanced string, so the count is $5$ as promised. The string $())((\,)$, for instance, is excluded because its running count hits $-1$.
:::

## Applications and Proof Techniques

<!-- section: applications -->

The reflection principle (or the cycle lemma) proves the formula by counting *all* lattice paths and subtracting the bad ones that step above the diagonal. The recursive definition

$$C_0 = 1, \qquad C_n = \sum_{i=0}^{n-1} C_i\, C_{n-1-i} \quad (n \ge 1)$$

directly encodes the first-return decomposition of a Dyck path (or, equivalently, the root-plus-subtrees split of a binary tree).

:::intuition
Reflection is a "trick mirror" for counting the cheaters. Every legal path from $(0,0)$ to $(n,n)$ stays weakly below the diagonal. A *bad* path is one that pokes above it — meaning it touches the forbidden line $y = x + 1$. Take the first moment it touches that line and flip the whole path before that moment across the mirror $y = x + 1$. This reflection is a perfect one-to-one pairing between bad paths and *all* paths to the reflected endpoint $(n-1, n+1)$, of which there are $\binom{2n}{n-1}$. So good $=$ all $-$ bad $= \binom{2n}{n} - \binom{2n}{n-1}$. The recurrence, meanwhile, comes from asking "when does the path *first* return to the diagonal?" — that first return splits the path into an inner good path and a leftover good path.
:::

:::example
Number of triangulations of a convex hexagon (a $6$-gon, i.e. the $(n+2)$-gon case with $n = 4$): $C_4 = 14$.
:::

:::solution
set up the recurrence. Fix one edge of the polygon as the *base*. In any triangulation, exactly one triangle uses that base; call its apex vertex $v$. Vertex $v$ splits the remaining polygon into a smaller polygon on the left of the triangle and one on the right.

count the pieces. If the base is treated as the "$(n+2)$-gon edge," the left piece is an $(i+2)$-gon and the right piece is a $(j+2)$-gon with $i + j = n - 1$. The left piece can be triangulated in $C_i$ ways and the right in $C_j$ ways, independently.

sum over the apex. Summing over all choices of $v$ (equivalently over $i = 0, \dots, n-1$) gives $C_n = \sum_{i=0}^{n-1} C_i C_{n-1-i}$ — exactly the Catalan recurrence.

evaluate for $n = 4$:
$$C_4 = C_0C_3 + C_1C_2 + C_2C_1 + C_3C_0 = 1\cdot 5 + 1\cdot 2 + 2\cdot 1 + 5\cdot 1 = 5 + 2 + 2 + 5 = 14.$$

Sanity check: this matches the formula result $C_4 = 14$ computed earlier. ✓
:::

## Common Mistakes

- **Forgetting the $1/(n+1)$ or using plain binomial**: $\binom{2n}{n}$ counts *all* paths or all sequences; Catalan counts only the balanced/good ones.
- **Off-by-one in indexing**: $C_n$ for $n$ pairs, $n$ internal nodes, an $(n+2)$-gon, semilength $n$.
- **Thinking all trees are Catalan**: Only *plane binary* or *rooted plane* trees with the ordering; unlabeled unordered trees have different counts (Otter etc.).
- **Missing the base case $C_0 = 1$**: The empty object is counted; without it the recurrence fails for $n=1$.
- **Confusing with other famous sequences**: Motzkin, Schröder, Fine numbers are close cousins but count slightly different objects (colored steps, etc.).

Stirling numbers come in two flavors and are the "change of basis" coefficients between the monomial basis and the falling/rising factorial bases. Combinatorially they count set partitions (second kind) and permutations by number of cycles (first kind).

They are fundamental in enumerative combinatorics and appear in many explicit formulas.

## Stirling Numbers of the Second Kind

<!-- section: stirling-second -->

$S(n,k)$ is the number of ways to partition an $n$-element set into exactly $k$ non-empty *unlabeled* subsets (called *blocks*), defined for integers $0 \le k \le n$. The boundary values are $S(0,0) = 1$, $S(n,0) = 0$ for $n > 0$, and $S(n,n) = 1$.

The total Bell number $B_n = \sum_{k=0}^{n} S(n,k)$ counts all partitions with any number of blocks.

:::intuition
Imagine handing out $n$ distinct people into rooms, where the rooms have no names — you only care *who is with whom*, not which room they land in. $S(n,k)$ counts the ways to fill exactly $k$ rooms with nobody left out and no room empty. Because the rooms are anonymous, $\{\{1,2,3\},\{4\}\}$ is a single arrangement. If you then *painted labels* on the rooms ("Room A", "Room B", …), each partition would sprout $k!$ labeled versions — that is why $k!\,S(n,k)$ counts surjections onto a labeled $k$-set.
:::

:::example
Compute $S(4,2)$ by cases, then cross-check with the closed formula.
:::

:::solution
1. split by block-size shape. A partition of $\{1,2,3,4\}$ into $2$ blocks has either sizes $3+1$ or sizes $2+2$.
2. size $3 + 1$. Choosing the singleton determines the partition, so there are $\binom{4}{1} = 4$ of these.
3. size $2 + 2$. Choose the block containing element $1$ (pick its one partner from the other $3$): $\binom{3}{1} = 3$ ways, and the remaining two form the other block. Since the two size-$2$ blocks are unlabeled, this already counts each partition once, giving $3$.
4. total. $S(4,2) = 4 + 3 = 7$.
5. Cross-check with the surjection formula (see the Bell-relation section): $S(4,2) = \frac{1}{2!}\big(2^4 - 2\cdot 1^4\big) = \frac{16 - 2}{2} = 7$. ✓
:::

## Stirling Numbers of the First Kind

<!-- section: stirling-first -->

The unsigned Stirling numbers of the first kind $c(n,k)$ (also written $|s(n,k)|$ or $\left[{n \atop k}\right]$) count the number of permutations of $n$ elements with exactly $k$ cycles in their disjoint-cycle decomposition, where fixed points count as $1$-cycles. They are defined for $0 \le k \le n$.

The signed versions $s(n,k) = (-1)^{n-k}\,c(n,k)$ appear in the change of basis from powers to the falling factorial:

$$(x)_n = x(x-1)\cdots(x-n+1) = \sum_{k=0}^{n} s(n,k)\, x^k .$$

:::intuition
Every permutation is really a set of loops: follow $1 \to \sigma(1) \to \sigma(\sigma(1)) \to \cdots$ until you come back, and you have traced one cycle. $c(n,k)$ asks: "of all $n!$ permutations, how many break into exactly $k$ loops?" For $n = 3$: the identity is three $1$-loops (so $3$ cycles), each of the $3$ transpositions is a $2$-loop plus a fixed point ($2$ cycles), and each of the $2$ three-cycles is a single $3$-loop ($1$ cycle). That accounts for all $1 + 3 + 2 = 6 = 3!$ permutations.
:::

:::example
Show that $c(4,2) = 11$: count the permutations of $\{1,2,3,4\}$ whose cycle decomposition has exactly $2$ cycles.
:::

:::solution
1. split by cycle-length shape. Two cycles covering $4$ elements have lengths either $3 + 1$ or $2 + 2$.
2. shape $3 + 1$ (one $3$-cycle and one fixed point). Choose the fixed point: $\binom{4}{1} = 4$ ways. The other $3$ elements form a $3$-cycle, and a set of $3$ elements can be arranged into $(3-1)! = 2$ distinct cycles. That gives $4 \cdot 2 = 8$ permutations.
3. shape $2 + 2$ (two $2$-cycles). Pair up $4$ elements into two unordered pairs: $\frac{1}{2}\binom{4}{2} = \frac{6}{2} = 3$ ways. Each $2$-cycle is uniquely determined by its pair, so that is $3$ permutations.
4. total. $c(4,2) = 8 + 3 = 11$.
5. Sanity check: summing the whole row, $c(4,1) + c(4,2) + c(4,3) + c(4,4) = 6 + 11 + 6 + 1 = 24 = 4!$, as it must, since every permutation has *some* number of cycles. ✓
:::

## Relation to Bell Numbers and Other Objects

<!-- section: bell-relation -->

The $n$th Bell number is the row sum $B_n = \sum_{k=0}^{n} S(n,k)$.

There is also an explicit formula for a single Stirling number:

$$S(n,k) = \frac{1}{k!}\sum_{j=0}^{k} (-1)^{k-j}\binom{k}{j} j^n ,$$

which is inclusion–exclusion counting surjections from $[n]$ onto a labeled $k$-set, divided by $k!$ to make the blocks unlabeled. The exponential generating function of the column with $k$ fixed is $\frac{(e^x - 1)^k}{k!}$.

:::intuition
Picture the Stirling triangle: row $n$ lists $S(n,0), S(n,1), \dots, S(n,n)$ — the ways to make a partition with $0, 1, 2, \dots$ blocks. Add up the whole row and you have counted *every* partition regardless of block count — that total is the Bell number. The explicit formula for $S(n,k)$ works like counting the ways to seat $n$ guests at $k$ *labeled* tables with no table empty (inclusion–exclusion strips out the arrangements that leave a table bare), and then dividing by $k!$ because the tables were never really labeled.
:::

:::example
Compute $B_4$ from the Stirling row, then confirm each entry.
:::

:::solution
1. write the row. $S(4,0) = 0$, $S(4,1) = 1$, $S(4,2) = 7$, $S(4,3) = 6$, $S(4,4) = 1$.
2. check the middle entry with the explicit formula: $S(4,3) = \frac{1}{3!}\sum_{j=0}^{3}(-1)^{3-j}\binom{3}{j}j^4 = \frac{1}{6}\big(-0 + 3\cdot 1 - 3\cdot 16 + 1\cdot 81\big) = \frac{3 - 48 + 81}{6} = \frac{36}{6} = 6$. ✓
3. sum the row: $B_4 = 0 + 1 + 7 + 6 + 1 = 15$.
4. Sanity check: $B_4 = 15$ agrees with the standard Bell sequence $1, 1, 2, 5, 15, 52, \dots$ ✓
:::

## Common Mistakes

- **Confusing first and second kind**: Second kind = set partitions (blocks), first kind = cycle counts in permutations.
- **Forgetting that blocks/subsets are unlabeled**: $S(n,k)$ already treats the $k$ subsets as indistinguishable; $k!\,S(n,k)$ is the number of surjections.
- **Sign errors with signed Stirling first**: The signed ones alternate so that the polynomial identity holds with falling factorials.
- **Using $S(n,k)$ when $k > n$ or $k=0$ (except $n=0$)**: $S(n,0)=0$ for $n>0$, but $S(0,0)=1$.
- **Mixing Bell with Stirling**: Bell is the sum; individual $S(n,k)$ are the "exactly $k$ blocks" numbers.

The Bell numbers $B_n$ count the partitions of an $n$-element set — every possible way to group $n$ distinct objects into non-empty unlabeled groups, with no restriction on the number of groups.

They are the row sums of the Stirling numbers of the second kind and have a rich exponential generating function $\exp(e^x - 1)$.

## Definition and Basic Values

<!-- section: definition-bell -->

The Bell sequence begins $B_0 = 1,\ B_1 = 1,\ B_2 = 2,\ B_3 = 5,\ B_4 = 15,\ B_5 = 52,\ B_6 = 203,\ \dots$

$B_n$ is the number of equivalence relations on an $n$-set, equivalently the number of ways to partition $[n] = \{1, 2, \dots, n\}$ into non-empty blocks.

:::intuition
For $3$ people $A, B, C$ the groupings are: all together ($1$ way); one pair plus a loner ($3$ ways — $AB|C$, $AC|B$, $BC|A$); and all separate ($1$ way). Total $5 = B_3$. Each partition is a way to sort the people into *indistinguishable* rooms with no room left empty — nobody cares which room, only who shares one.
:::

:::example
Compute $B_4 = 15$ for $\{1,2,3,4\}$ by grouping partitions according to their *block-size shape* (a partition of the number $4$).
:::

:::solution
Shape $4$ (one block of all four): $1$ partition.
Shape $3 + 1$ (a triple and a singleton): choose the singleton, $\binom{4}{1} = 4$ partitions.
Shape $2 + 2$ (two pairs): $\frac{1}{2}\binom{4}{2} = \frac{6}{2} = 3$ partitions (divide by $2$ because the two pairs are interchangeable).
Shape $2 + 1 + 1$ (one pair, two singletons): choose the pair, $\binom{4}{2} = 6$ partitions.
Shape $1 + 1 + 1 + 1$ (all singletons): $1$ partition.

Step — add them up: $1 + 4 + 3 + 6 + 1 = 15$.

Sanity check: this matches $B_4 = 15$ from the sequence and from the Stirling row sum $1 + 7 + 6 + 1$ computed in the Bell-relation section. ✓
:::

## Set Partitions and the Recurrence

<!-- section: set-partitions -->

The fundamental recurrence (valid for $n \ge 1$, with base case $B_0 = 1$) is

$$B_n = \sum_{k=0}^{n-1} \binom{n-1}{k} B_k .$$

Interpretation: look at the block containing element $n$. Suppose it contains exactly $k$ *other* elements; choose those $k$ companions from the remaining $n-1$ elements in $\binom{n-1}{k}$ ways, then partition the $n-1-k$ elements outside that block arbitrarily in $B_{n-1-k}$ ways. As $k$ ranges over $0, \dots, n-1$ the index $n-1-k$ ranges over $n-1, \dots, 0$, so the sum is equivalently written with $B_k$.

:::intuition
The newcomer (person $n$) always ends up in *some* group. Let them decide who else joins their group — any subset of the people already present. Whoever is *not* invited then partitions themselves however they like. Because we singled out "person $n$'s group" — a block that is unambiguous, since $n$ can only be in one block — this never double-counts a partition. Summing over the size of the newcomer's chosen crew gives the recurrence.
:::

:::example
Compute $B_3$ from the recurrence using $B_0 = 1$, $B_1 = 1$, $B_2 = 2$.
:::

:::solution
write the sum for $n = 3$ (so $n - 1 = 2$):
$$B_3 = \binom{2}{0}B_0 + \binom{2}{1}B_1 + \binom{2}{2}B_2 .$$

evaluate the binomials and Bell values: $\binom{2}{0} = 1$, $\binom{2}{1} = 2$, $\binom{2}{2} = 1$, giving $B_3 = 1\cdot 1 + 2\cdot 1 + 1\cdot 2 = 1 + 2 + 2 = 5$.

Sanity check: $B_3 = 5$ matches the direct count of the five partitions of a $3$-set. ✓
:::

## Applications and Growth

<!-- section: applications-growth -->

Bell numbers appear in set theory (equivalence relations), database theory (grouping records), probability (Poisson–Dirichlet process limits), and the enumeration of relational structures.

The exponential generating function is

$$\sum_{n \ge 0} \frac{B_n}{n!}\, x^n = \exp(e^x - 1).$$

Asymptotically, $B_n$ grows super-exponentially but strictly slower than $n!$. A convenient rough form is $B_n \approx \left(\frac{n}{e \ln n}\right)^{n}$; more precisely $B_n \sim n^{-1/2}\,\lambda(n)^{\,n+1/2}\,e^{\lambda(n) - n - 1}$ where $\lambda(n)$ solves $\lambda \ln \lambda = n$ (so $\lambda(n) \approx \ln n - \ln\ln n$).

:::intuition
Every way to cluster $n$ data points into unnamed groups is one Bell number's worth of possibilities. The EGF $\exp(e^x - 1)$ is the "set of sets" recipe: $e^x - 1$ is the EGF for a *single* non-empty block, and wrapping it in $\exp(\cdot)$ says "take an unordered collection of such blocks" — which is exactly what a set partition is.
:::

:::example
Count the equivalence relations on a $5$-element set, and confirm it equals $B_5 = 52$.
:::

:::solution
reframe. Every equivalence relation on a set corresponds bijectively to exactly one partition of that set into equivalence classes, so the count is the Bell number $B_5$.

compute $B_5$ from the recurrence with $n = 5$ (so $n-1 = 4$), using $B_0=1, B_1=1, B_2=2, B_3=5, B_4=15$:
$$B_5 = \binom{4}{0}B_0 + \binom{4}{1}B_1 + \binom{4}{2}B_2 + \binom{4}{3}B_3 + \binom{4}{4}B_4 .$$

evaluate: $\binom{4}{0}=1, \binom{4}{1}=4, \binom{4}{2}=6, \binom{4}{3}=4, \binom{4}{4}=1$, so
$$B_5 = 1\cdot 1 + 4\cdot 1 + 6\cdot 2 + 4\cdot 5 + 1\cdot 15 = 1 + 4 + 12 + 20 + 15 = 52.$$

Sanity check: $52$ matches the tabulated value $B_5 = 52$. ✓
:::

## Common Mistakes

- **Thinking partitions are ordered or labeled**: The blocks are unordered; if you label the blocks you count $k!\,S(n,k)$ instead.
- **Confusing with Stirling second kind**: $B_n$ is the *total* over all $k$; $S(n,k)$ is "exactly $k$ blocks".
- **Forgetting $B_0=1$**: The empty partition exists and is needed for recurrences.
- **Using $2^n$**: That counts *labeled* or *ordered* something (subsets, or functions to $\{0,1\}$), not partitions.
- **Assuming all partitions have the same block size**: Most have mixed sizes; the count sums over all type partitions.
